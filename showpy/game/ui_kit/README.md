# UI Kit 플러그인 (렌파이 UI 묶음 + 편집기)

예전에 따로 있던 플러그인 네 개를 폴더 하나로 합치고, 이미지·영상 배치 기능을 더한 렌파이 플러그인입니다.

| 기능 | 하는 일 | 예전 폴더 |
|---|---|---|
| 타이틀 메뉴 | 타이틀 메뉴 항목을 자유 배치(위치·회전·기울기·글꼴·색·외곽선), 선택을 옮기면 다른 항목이 밀려나는 연출, hover 영상, 게임 메뉴 목록 | `title_menu` |
| 선택지 | 스크립트의 `menu`에서 선택지마다 위치·글꼴·색·자간·줄 간격·회전 등을 지정, 등장 연출, hover 영상 | `choice_menu` |
| 커스텀 UI | 커서 애니메이션, 클릭 대기 표시(ctc) 애니메이션, 대사 출력 소리, 텍스트 속도 기본값, 퀵메뉴 처음 표시 여부 | `custom_ui` |
| 대사 스타일 | 대사 한 줄마다 위치·글꼴·크기·색, 이름 위치·모양, 나오는 속도·등장 효과 바꾸기 | `say_style` |
| 이미지·영상 배치 | `movies/` 폴더 영상 자동 등록(`mask_`로 시작하면 투명 영상), `bg` 태그는 항상 맨 뒤, show·hide·scene 줄의 위치·전환 효과를 편집기에서 골라 원고에 저장 | (2.6에서 새로 생김) |

그리고 이 기능들을 **게임을 실행한 채로 마우스로 고치는 편집기**가 들어 있습니다. (개발 모드에서 Shift+M)
대사, 선택지, show·hide·scene 줄은 편집기에서 고친 값이 **원고(.rpy)의 그 줄에 바로 저장**됩니다.

버전 3.22 · 렌파이 8.5.3 기준으로 만들었습니다.

### 3.21에서 바뀐 점

- 대사 탭: 글자 등장 효과, 줄마다 화면 효과·덮개(VHS)·덮개 휘어짐·커서 줄을 뺌. "대사 효과는 PyKaki에서" 안내. 원고에 이미 적힌 괄호(`fx=`, `fx_overlay=`, `fx_warp=`, `fx_cursor=`, 등장 효과)는 그대로 동작.
- 커서/대사 소리 탭: 그림 폴더 안내(커서 `game/gui/cursor/`, 클릭 대기 표시 `game/gui/ctc/`), Screen FX 4.5가 있으면 "커서와 셰이더 (여기에서부터)".
- 원고 쓰기 도구(`script_edit`): 줄 넣기의 `replace`가 사이 빈 줄을 넘어 예전 줄을 찾음. PyKaki 원고에서 `$ screen_fx.` 줄을 넣고 바꾸고 지움(받는 기록 `insert`, `replace`, `remove`).
- 실시간 연결: `custom_ui.cursor_lines`, 명령 `custom_ui.cursor`. warp 뒤 셰이더, 커서 상태 맞추기.
- pygaki 묶음 새 프로젝트에 커서·CTC 샘플 그림(64x64, 6장씩).

### 3.20에서 바뀐 점

- 원고의 줄로 게임 옮기기 `ui_editor.goto_line(파일, 줄)`: 이번에 지나온 줄이면 되감기(그때 변수와 화면 그대로), 아니면 렌파이 warp(게임을 다시 시작해서 그 줄까지 scene/show만 따라 하고 들어감, 그 사이 변수는 빠질 수 있음, 개발 모드에서만). 지금 보이는 대사 안의 줄이면 그대로. 빈 줄, 주석 줄은 그 뒤 첫 문장으로. warp 뒤 편집기는 같은 탭으로 다시 열림.
- 실시간 연결 명령 `goto`에 `where: "line"`(`file`, `line`). PyKaki 앱 [showpy] 화면의 원고 칸에서 줄을 누르면 씀.

### 3.19에서 바뀐 점

- 타이틀 배경: 기본은 검은 화면(`tmenu.background = None`). 그림이나 webm 영상 경로를 적거나 편집기 "배경" 버튼으로 고릅니다. ESC 메뉴는 기본이 투명(`tmenu.pause_dim = None`), `tmenu.pause_background`로 그림이나 영상. 렌파이 기본 GUI의 반투명 판(`tmenu.main_menu_frame`)도 기본은 끔.
- 제목, 부제(`tmenu.labels`, `tmenu.pause_labels`): 메뉴 항목처럼 위치, 회전, 크기, 글꼴, 색, 효과. 저장하면 `title_menu_layout.rpy`의 `tmenu.label_layout`, `pause_label_layout`, 배경은 `tmenu.screen_layout`.
- 글자 효과 `"effect"`: 메뉴 항목, 제목, 부제에 대사 등장 효과(텍스트 셰이더). 나오는 속도는 `tmenu.effect_cps`(기본 30).
- 편집기 타이틀 메뉴 탭: 분홍 네모(회전 손잡이)를 끌면 돌아감(Shift: 15도씩), "글자 효과:" 줄, "배경:" 버튼(고르기 창 `background`). Tab으로 제목, 부제도 고름.
- 실시간 연결: `state.title.items`에 제목, 부제(`kind: "label"`), `background`, `effects`. 명령 `title.background`. 파일 목록에 `movies`. 저장 수(`editor.pending`)에 원고 줄 변경도 셈.

### 3.13에서 바뀐 점

- **게임 메뉴 화면을 ESC 메뉴 옆으로**: 대사록, 저장, 불러오기, 환경설정, 버전정보, 조작방법 화면에서 왼쪽에 ESC 메뉴가 같은 자리, 같은 모양으로 남고, 제목과 내용은 그 오른편에 나옵니다. 지금 열린 화면의 항목은 선택된 모양으로 보입니다. 타이틀에서 연 화면은 타이틀 메뉴 항목이 왼쪽에 나옵니다.
  - 내용이 시작하는 자리는 메뉴의 오른쪽 끝을 재서 알아서 정합니다. 직접 정하려면 `define tmenu.game_menu_content_x = 400`.

  - 렌파이 기본 `screens.rpy`의 `game_menu` 스크린을 대신 정의합니다. `screens.rpy`에서 `game_menu`를 고쳐 쓰던 프로젝트는 `game_menu_side = False`여도 이 파일의 것이 쓰이니, 고친 내용이 있으면 `title_menu.rpy`에 옮기세요.

### 3.12에서 바뀐 점

- **등장 효과 셰이더를 한 파일로** (`engine/text_effects.glsl`): 등장 효과 20개의 셰이더 코드를 셰이더만 담은 파일로 옮겼습니다. `engine/text_effects.rpy`는 게임을 켤 때 이 파일을 읽어 등록만 합니다. 효과의 모양과 값은 3.11과 똑같습니다.
  - PyKaki가 같은 파일(사본)로 미리보기를 WebGL로 그려서, PyKaki 미리보기와 렌파이 효과가 같은 코드에서 나옵니다.
  - 새 효과는 `text_effects.glsl`에 한 번만 쓰면 됩니다. 편집기 대사 탭의 효과 버튼도 이 파일에서 이름을 가져옵니다. 적는 법은 파일 맨 위에 있습니다.
    ```
    @effect pop 튀어나오기
    @cps
    @slow u__duration
    @set u__duration 8.0
    @variables
        uniform float u__duration;
        uniform float u_text_slow_duration;
        uniform float u_text_slow_time;
        attribute float a_text_min_time;
        attribute vec2 a_text_center;
        varying float v_tfx_pop;
    @vertex_30
    @use T
        gl_Position.xy = a_text_center + (gl_Position.xy - a_text_center) * mix(1.6, 1.0, l__t);
        v_tfx_pop = l__t;
    @fragment_350
        gl_FragColor = gl_FragColor * clamp(v_tfx_pop * 3.0, 0.0, 1.0);
    ```
    대사에서는 `e "펑!" (effect="pop")`처럼 씁니다. (`@use T`는 파일 위쪽의 공통 조각으로, 이 글자가 나오기 시작한 뒤 얼마나 지났는지를 `l__t`(0에서 1)에 넣습니다.)
- 고침: 게임을 켤 때 `pykaki_preview.json`이 없으면 PyKaki가 처음 쓴 미리보기를 띄우지 않던 것.
- 옮기기: `ui_kit` 폴더를 통째로 바꿔 넣고(`text_effects.glsl`이 같이 있어야 함) `.rpyc`를 지웁니다. PyKaki도 같이 새로 고침합니다.

  | `wipe` | 위에서 그려지기: 글자가 위에서부터 드러남 |

  ```renpy
  e "따라온다." (cps=30, effect="echo")
  e "빛난다." (effect="glow:u__color=#9fd8ff")
  e "큰 글자도 끝까지." (size=80, cps=20, effect="wipe:u__span=80")
  ```
  `echo`의 복사본은 글자 외곽선 겹으로 그립니다. 대사에 `outlines`를 따로 적지 않으면 파랑, 노랑 두 겹을 넣습니다.

### 3.5에서 바뀐 점

- **등장 효과 7개 추가** (`engine/text_effects.rpy`): 글자마다 움직이는 효과를 렌파이 텍스트 셰이더로 등록했습니다. 대사 괄호의 `effect`에 이름을 적고, 대사 탭의 효과 버튼에도 있습니다.

  | 이름 | 모습 |
  |---|---|
  | `scatter` | 흩어졌다 모이기: 여기저기 돌아간 채 흩어져 있다가 제자리로 |
  | `drop` | 떨어지기: 위에서 떨어져 살짝 튕김 |

  - **패널 위에서 마우스 휠**을 굴리면 스크롤, 오른쪽의 분홍 **스크롤바**를 끌어도 됩니다. (끄는 동안은 막대만 움직이고, 손을 떼면 내용이 따라옵니다)
  - **패널 밖에서 휠**은 전처럼 회전, 글자 크기입니다.
  - 내용이 짧으면 스크롤바는 숨고 패널도 전과 똑같이 보입니다. 탭을 바꾸면 맨 위로 돌아갑니다.
- 고친 파일은 `editor/editor.rpy` 하나입니다. 설정 파일(`*_config.rpy`)과 편집기 저장 파일(`*_layout.rpy`), 세이브는 2.6 것을 그대로 쓸 수 있습니다. 옮길 때는 `editor/` 폴더와 `engine/ui_kit.rpy`를 새것으로 바꾸고 `.rpyc`도 같이 지우세요.

### 2.6에서 바뀐 점

- **이미지·영상 배치 (`stage`) 추가.** 13장.
  - `game/movies/`에 넣은 `.webm`은 파일 이름으로 바로 씁니다. `movies/rain.webm` → `show rain`. 이름이 **`mask_`로 시작하면 투명 영상**(side_mask)으로 읽고 이름에서는 뺍니다. `movies/mask_ghost.webm` → `show ghost`.
  - 그림은 렌파이가 원래 `game/images/`를 자동 등록하므로(안쪽 폴더 포함) 그대로 씁니다.
  - **`bg` 태그는 항상 맨 뒤**에 그립니다. `zorder`를 적어도 맨 뒤.
  - 원고에 쓰는 도우미: `at stage.pos(x, y)`, `with stage.move("inleft", 0.8)` / `stage.ease(…)` / `stage.zoom("in", 0.8)`.
- **편집기 "이미지/영상" 탭.** (4-6)
  - 화면의 그림·영상을 누르면 그것을 띄운 줄이 골라지고, 끌면 위치가 바뀝니다. 위치 버튼(왼쪽·가운데·오른쪽 …), 전환 효과(서서히·검게 페이드·이동·부드럽게 이동·닦아내기 …)와 방향·시간. **show와 hide 둘 다.**
  - **줄 번호 기준**: 같은 원고 파일의 show·hide·scene 줄을 줄 번호와 함께 목록으로 보여주고, `[` `]`로 앞뒤 줄, 줄 번호 입력, "그 줄로 가기"(렌파이의 줄 이동). 지금 장면에서 실행된 줄은 R로 전환까지 다시 봅니다.
  - Ctrl+S → 원고의 그 줄에서 **at 절과 with 절만** 바꿉니다. (`show eileen happy at stage.pos(420, 720) with Dissolve(1.0)`)
- **패널이 화면을 가리지 않게.** (4-7)
  - 패널 제목(= UI 편집기)을 **끌어서 아무 데나** 옮기기, **X**로 한 줄로 접기, **Space를 누르고 있는 동안** 패널 숨기기.
  - 고른 것(그림, 대사, 선택지, 타이틀 메뉴 항목)이 패널 아래에 있으면 **패널이 다른 구석으로 비킵니다.** (B로 끄고 켜기)
  - 화면에서 누르기 어려운 그림은 패널 목록(줄 번호)이나 Tab으로 고릅니다.
  - 모든 탭의 패널 위에 **"지금 줄: script.rpy 42번째 줄"**을 보여줍니다.
- 2.6에서 더한 부분은 렌파이 8.5.3의 소스에 맞춰 만들고 원고 고치기·전환 식 읽기/쓰기는 따로 시험했지만, 렌파이를 실제로 실행한 시험은 하지 못했습니다. 넣은 뒤 런처에서 **Lint**와 실행을 한 번 확인해 주세요.

### 2.5에서 바뀐 점

- `screen_fx` 3.2와 같이 쓰면 대사 탭의 "대상" 줄이 **"글자 빼기"** 줄로 바뀝니다. [대사와 이름] [선택지] [메뉴와 화면]을 켜고 끄면(켜진 것 = 효과에서 뺌) 원고의 그 줄에 `(fx_exclude=("say",))`처럼 저장됩니다. [효과 설정대로]는 괄호에서 지우기. (4-3)
- 예전에 저장한 `fx_target="screen"`/`"scene"`도 그대로 읽고 동작합니다.
- `screen_fx` 3.2는 대사창을 `sfx_say`, 선택지를 `sfx_choice` 층에 띄웁니다. 편집기의 대사·선택지 탭은 그대로 동작합니다.
- 그 밖의 설정 이름과 동작은 2.4와 같습니다.

### 2.4에서 바뀐 점

- `screen_fx` 3.1과 같이 쓰면 대사 탭의 화면 효과 아래에 **"덮개"·"대상"** 줄이 생깁니다. 고른 효과 위에 VHS를 덮거나(`fx_overlay="vhs_crt"`), 이번만 화면 전체·장면만(`fx_target="screen"` / `"scene"`)으로 바꿔 원고에 저장합니다. (4-3)
- 타이틀 화면의 **배경 그림(배경 영상 포함)에 "장면만" 화면 효과**가 씌워집니다. (`screen_fx`의 기본 효과를 `"scene"` 대상으로 두면 메뉴 글자는 선명하고 배경에만 효과)
- 그 밖의 설정 이름과 동작은 2.3과 같습니다. 설정 파일은 그대로 쓰면 됩니다.

### 2.3에서 바뀐 점

- `screen_fx` 3.0과 같이 쓰면 **대사 탭에 "화면 효과" 줄**이 생깁니다. 이 대사부터 켤 화면 효과(VHS, 흑백 …), 선택취소, 전환(TV 껐다 켜기·서서히·바로)을 고르면 원고의 그 대사 줄에 `(fx="mono")`처럼 저장됩니다. (4-3)
- 편집기의 "VHS 효과" 탭은 `screen_fx`의 **"화면 효과" 탭**으로 바뀌었습니다.
- 다른 플러그인의 탭이 Ctrl+S 한 번에 파일 여러 개를 저장할 수 있게 했습니다.
- 그 밖의 설정 이름과 동작은 2.2와 같습니다. 설정 파일은 그대로 쓰면 됩니다.

### 2.2에서 바뀐 점

- **대사·선택지는 "그 줄만" 고칩니다.** Ctrl+S를 누르면 원고의 그 줄 괄호에 바로 적히고, 게임을 다시 불러와 같은 장면으로 돌아옵니다. (예전처럼 Ctrl+C로 복사해 붙여넣을 필요 없음)
- 대사·선택지 탭의 "캐릭터 기본값", "모든 선택지 기본값"(3번 키)은 없앴습니다. 모두에 적용할 값은 설정 파일(`say_style_config.rpy`, `choice_menu_config.rpy`)에서 고칩니다. 예전에 저장한 `say_style_layout.rpy`, `choice_menu_layout.rpy`는 그대로 적용됩니다.
- 대사 탭에서 **이름 위치**(이름 상자째)와 이름 글자 크기·글꼴·색을 고칠 수 있습니다. (Tab으로 대사/이름 바꾸기)
- 대사 탭에서 **나오는 속도(배율)와 등장 효과**(서서히, 타자기, 물결, 떨림 등)를 고르고, R로 그 줄을 다시 볼 수 있습니다.
- 원고를 고치기 전에 원본을 프로젝트 폴더의 `ui_kit_backup/`에 남깁니다.

## 2. 설치

`ui_kit` 폴더를 프로젝트의 `game` 폴더 안에 넣으면 끝입니다. **`screens.rpy`는 고치지 않아도 됩니다.**

렌파이 기본 `screens.rpy`의 스크린 세 개를 대신 정의합니다. 원본 파일보다 늦게 실행되도록(`init offset = 1`) 되어 있어서 항상 이 플러그인 쪽이 적용됩니다.

| 스크린 | 하는 일 |
|---|---|
| `main_menu` | 타이틀 화면 |
| `navigation` | 게임 메뉴(대사록·저장·불러오기·환경설정 화면) 왼쪽의 버튼 목록 |
| `choice` | 선택지 |

### 기능 켜고 끄기

네 기능은 각자 설정 파일 맨 위의 스위치로 끌 수 있습니다. 끄면 **렌파이 기본과 똑같이** 보입니다. (렌파이로 갓 만든 프로젝트와 화면을 비교해 확인했습니다)

| 설정 파일 | 스위치 | 끄면 |
|---|---|---|
| `title_menu_config.rpy` | `define tmenu.enabled = False` | 렌파이 기본 타이틀 화면·게임 메뉴 목록 |
| `choice_menu_config.rpy` | `define cmenu.enabled = False` | 렌파이 기본 선택지. 스크립트의 선택지 괄호 값은 무시 |
| `custom_ui_config.rpy` | `define custom_ui.enabled = False` | 커서·ctc·대사 소리·텍스트 속도·퀵메뉴 모두 렌파이 기본 |
| `say_style_config.rpy` | `define say_style.enabled = False` | 대사 괄호의 짧은 이름(`x`, `size` …)은 무시하고 캐릭터 기본값으로 |
| `stage_config.rpy` | `define stage.enabled = False` | 영상 자동 등록, `bg` 맨 뒤, 편집기의 이미지/영상 탭이 꺼짐. 원고에 적은 `stage.pos(…)` 등은 그대로 동작 |

설정 파일에 직접 적은 `style` 문(예: `style navigation_button_text:`)은 스위치와 상관없이 적용됩니다. 완전히 기본으로 돌리려면 그 줄도 주석 처리하세요.

### 다른 플러그인과 같이 쓰기

- `hotkeys`, `screen_fx`와 같이 쓸 수 있습니다.
- `screen_fx`가 있으면 편집기에 "타이틀 일렁임", "화면 효과" 탭이 더해지고, 대사 탭에 "화면 효과" 줄이 생깁니다. (사용법은 `screen_fx/README.md`)
- 편집기는 화면 효과가 닿지 않는 맨 위 층(`ui_editor`)에 그려집니다. 편집하는 동안에도 `screen_fx` 효과가 켜진 채로 보이고(`screen_fx` 3.4 이상), V로 끄고 켭니다. 화면을 휘는 효과는 가장자리에서 보이는 자리와 눌리는 자리가 조금 어긋나니, 정확히 끌어 놓을 때는 V로 잠깐 끄세요.

## 3. 예전 플러그인 네 개에서 옮기기

1. `game/title_menu`, `game/choice_menu`, `game/custom_ui`, `game/say_style` 폴더를 **`.rpyc` 파일까지** 통째로 지웁니다. (`.rpyc`가 남으면 지운 코드가 계속 실행되어 스크린이 두 번 정의됩니다)
2. `ui_kit` 폴더를 `game/`에 넣습니다.
3. 예전 폴더에 있던 설정 파일 네 개(`*_config.rpy`)를 `ui_kit/`에 **덮어씁니다.** 설정 이름과 문법은 그대로라서 고칠 것이 없습니다. (스위치 줄이 없으면 켜진 것으로 봅니다)
4. 예전 타이틀 편집 모드로 저장한 `title_menu/title_menu_layout.rpy`가 있었다면 `ui_kit/`로 옮깁니다. 형식이 같아서 그대로 쓰입니다.
5. 런처에서 Lint를 실행합니다.

옮기면서 달라진 점:

- **텍스트 속도**: 예전에는 게임을 켤 때마다 `custom_ui.text_cps` 값으로 되돌아가서, 플레이어가 환경설정에서 바꾼 속도가 유지되지 않았습니다. 지금은 처음 실행할 때와 이 값을 바꿨을 때만 적용하고, 그 뒤로는 플레이어가 고른 값을 그대로 둡니다. 환경설정의 "초기화"를 누르면 이 값으로 돌아갑니다.
- **편집기**: Shift+M이 타이틀 화면뿐 아니라 게임 중에도 열립니다. 예전 타이틀 편집 모드의 기능은 "타이틀 메뉴" 탭에 그대로 있습니다.
- **대사 스타일 설정의 기본 글꼴**: 배포용 `say_style_config.rpy`의 `t` 캐릭터 글꼴이 `gui.text_font`로 바뀌었습니다. (예전 파일을 덮어쓰면 예전 값 그대로)
- **캐릭터 이름 겹침**: `say_style_config.rpy`는 `t`, `n1`~`n3` 캐릭터를 정의합니다. 스크립트에서 같은 이름을 이미 정의했다면 둘 중 한 곳에서 지우세요.

## 4. 편집기

개발 모드(런처에서 실행)일 때 **Shift+M**으로 열고 닫습니다. 배포판(개발 모드 꺼짐)에서는 열리지 않고, 화면에도 아무것도 추가되지 않습니다.

편집기가 열려 있는 동안에는 클릭·키보드가 게임으로 가지 않습니다. (대사가 넘어가거나 선택지가 골라지지 않음) Shift+R(다시 불러오기), Shift+O(콘솔), Shift+D(개발자 메뉴), F(전체 화면)는 그대로 쓸 수 있습니다.

### 4-1. 탭

| 탭 | 쓸 수 있을 때 | 고칠 수 있는 것 | 저장하면 |
|---|---|---|---|
| 타이틀 메뉴 | 타이틀 화면, 게임 중 ESC 메뉴(3.1) | 항목 위치·회전·기울기·확대·글자 크기·글꼴·색, 선택됐을 때 값. ESC 메뉴를 연 채로 열면 ESC 메뉴의 항목을 고침 | `title_menu_layout.rpy` (ESC 메뉴는 `tmenu.pause_layout`) |
| 선택지 | 선택지가 떠 있을 때 | 선택지 하나의 위치(세로 목록 → 자유 배치 포함)·회전·기울기·확대·글자 크기·글꼴·색, 마우스 올렸을 때 값 | **원고의 그 선택지 줄** |
| 대사 | 대사가 떠 있을 때 | 대사 한 줄의 위치·글자 크기·글꼴·색, 이름 위치·크기·글꼴·색, 나오는 속도·등장 효과, 이 대사부터 켤 화면 효과와 커서 자리(`screen_fx`가 있을 때) | **원고의 그 대사 줄** |
| 이미지/영상 | 게임을 진행하는 중 | show·hide·scene 줄 하나의 위치(끌기, 위치 버튼)와 전환 효과·방향·시간, 줄 번호로 고르기 | **원고의 그 줄** (at 절, with 절) |
| 커서/대사 소리 | 어디서나 | 텍스트 속도, 대사 소리 파일·음량, 클릭 대기 표시·커서 켜기/프레임 폴더/속도, 퀵메뉴 | `custom_ui_layout.rpy` |
| 타이틀 일렁임 | 타이틀 화면 (`screen_fx`가 있을 때) | 일렁임 세기·물결 크기·속도·반사광 등 | `screen_fx/watermorph_layout.rpy` |
| 화면 효과 | 어디서나 (`screen_fx`가 있을 때) | VHS 덮개, ASCII, 레트로 터미널, 게임보이 등 효과마다 값, 켜기, 덮개 켬/끔, 글자 빼기, 프리셋, "이 대사부터 이 효과", 기본 효과와 전환(기본 효과, 덮개 켬/끔, TV 전환 시간, 섬광, 소리 음량)과 미리 보기 | `screen_fx/<효과 이름>_layout.rpy`, `screen_fx/screen_fx_layout.rpy` |

편집기를 열면 지금 화면에 맞는 탭이 먼저 열립니다. T로 다른 탭으로 바꿉니다.

### 4-2. 대사·선택지는 원고에 바로 저장

대사·선택지 탭은 **지금 화면에 있는 그 줄**만 고칩니다. Ctrl+S를 누르면

1. 원고(.rpy)의 그 줄 괄호를 고치고 (원래 괄호에 있던 다른 값과 줄 뒤의 `with dissolve` 등은 그대로 둠)
2. 고치기 전 원본을 프로젝트 폴더의 `ui_kit_backup/`에 남기고 (원고 파일 하나당 최근 30개)
3. 게임을 다시 불러와 같은 장면으로 돌아옵니다. 편집기도 같은 탭으로 다시 열립니다.

```
## 저장 전
    e "어디 갔었어?"
        "꺼져!":
## 저장 후
    e "어디 갔었어?" (x=520, y=60, name_x=820, name_y=-60, speed=0.5, effect="jitter")
        "꺼져!" (x=300, y=350, rotate=-4):
```

다음 경우에는 원고를 고치지 않고 이유를 알려줍니다. 그 값은 남아 있으니 **Ctrl+C로 복사해서 그 줄 괄호에 붙여넣으세요.**

- 대사가 여러 줄에 걸쳐 있거나, 괄호·줄이 다음 줄로 이어질 때
- 원고의 그 줄이 게임이 읽은 내용과 다를 때 (편집 중에 VS Code 등에서 원고를 고쳐 줄 번호가 밀린 경우)
- 편집을 시작한 뒤 다른 프로그램에서 그 줄을 고쳤을 때

> VS Code 등에 원고를 열어 둔 채 저장하지 않은 변경이 있으면, 그쪽에서 저장할 때 편집기가 쓴 내용이 덮어써질 수 있습니다. 편집기로 저장하기 전에 다른 편집기의 변경을 먼저 저장하세요.

모두에 적용할 기본값은 설정 파일에서 고칩니다: 대사는 캐릭터 정의(`say_style_config.rpy` 등), 선택지는 `choice_menu_config.rpy`의 `cmenu.default`. 타이틀 메뉴 탭은 원고에 줄이 없으니 예전처럼 3번 키로 "이 항목만 / 모든 항목 공통 값"을 바꾸고 `title_menu_layout.rpy`에 저장합니다.

### 4-3. 대사 탭

| 고칠 것 | 방법 | 원고에 적히는 이름 |
|---|---|---|
| 대사 위치·크기 | 끌기, 방향키, S/W, 휠 | `x`, `y`, `size` |
| 대사 글꼴·색 | 패널의 글꼴·색 버튼 | `font`, `color` |
| 이름 위치 | **Tab**(또는 "이름" 버튼)으로 이름을 고른 뒤 끌기 | `name_x`, `name_y` |
| 이름 크기·글꼴·색 | 이름을 고른 뒤 S/W, 글꼴·색 버튼 | `name_size`, `name_font`, `name_color` |
| 나오는 속도 | 속도 버튼 (×0.25 ~ ×4) | `speed` |
| 등장 효과 | 효과 버튼 (없음, 서서히, 타자기, 흐리게 대기, 뒤집히며, 커지며, 떨림, 물결) | `effect` |
| 화면 효과 (`screen_fx`가 있을 때) | "화면 효과" 줄: 그대로 / 선택취소 / ASCII / 레트로 터미널 / 게임보이 / 효과 없음 … | `fx` |
| 화면 효과 전환 | "전환" 줄: TV 껐다 켜기 / 서서히 / 바로 (기본 전환과 다를 때만 적힘) | `fx_transition` |
| 덮개 (`screen_fx` 4.0) | "덮개(VHS)" 줄: 그대로 / 켬 / 끔 ("그대로"면 적히지 않음) | `fx_overlay` |
| 덮개 휘어짐 (`screen_fx` 4.0) | "덮개 휘어짐" 줄: 그대로 / 설정값 / 0 ~ 5 ("그대로"면 적히지 않음) | `fx_warp` |
| 글자 빼기 (`screen_fx` 3.2) | "글자 빼기" 줄: 효과 설정대로 / 대사와 이름 / 선택지 / 메뉴와 화면 (켜진 것 = 뺌. "효과 설정대로"면 적히지 않음) | `fx_exclude` |

- 위치는 **대사 창 왼쪽 위 기준**입니다. 보통 캐릭터는 대사 창이 화면 아래에 있어서, 이름을 창 위로 올리면 `name_y`가 음수가 됩니다. 패널에는 화면 기준 위치도 같이 나옵니다.
- 이름은 **이름 상자째** 움직입니다. 이름 뒤 배경 그림(`gui/namebox.png`)도 같이 따라갑니다. 이름이 없는 캐릭터(`t` 등)에서는 "이름" 버튼이 눌리지 않습니다.
- 속도는 **배율**입니다. 플레이어가 환경설정에서 고른 텍스트 속도에 곱해져서, 플레이어 설정이 그대로 살아 있습니다. ×1을 고르면 원고에서 `speed`를 지웁니다.
- 속도와 효과를 바꾸면 그 줄을 처음부터 다시 보여줍니다. R(또는 "R 다시 보기")로 언제든 다시 볼 수 있습니다.
- **화면 효과**는 그 대사가 나오기 전에 바뀌고, 다음에 바꿀 때까지 이어집니다. "선택취소"는 기본 효과(배포 설정은 효과 없음 + VHS 덮개)로 돌아가기, "그대로"는 이 줄에서 바꾸지 않기(괄호의 `fx`를 지움)입니다.
  ```renpy
  e "어? 화면이…" (fx="ascii")                           # 이 대사부터 ASCII
  e "돌아왔다." (fx="default")                           # 선택취소
  e "서서히." (fx="gameboy", fx_transition="fade")       # 전환을 따로
  e "덮개 없이." (fx="ascii", fx_overlay=False)          # ASCII만 (VHS 덮개 끔)
  e "덮개만 켬." (fx_overlay=True)                       # 효과는 그대로, 덮개만
  e "화면이 휜다." (fx_warp=3.0)                          # 덮개 휘어짐 3 ("default"면 설정값)
  e "전부 글자로." (fx="ascii", fx_exclude=())            # 이번만 대사창까지 전부 (아무것도 안 뺌)
  e "대사만 또렷." (fx="retro_term", fx_exclude=("say",))  # 레트로 터미널에서 대사·이름만 빼기
  ```
- "덮개(VHS)", "덮개 휘어짐" 줄은 효과를 바꾸지 않는 대사에서도 고를 수 있습니다. "전환", "글자 빼기" 줄은 이 줄에서 효과를 바꿀 때만 보입니다. 자세한 것은 `screen_fx/README.md`의 5장, 3-8.
- 대사 탭도 화면 효과를 켠 채 보여줍니다. 글자를 정확히 끌어 놓을 때 방해되면 V(또는 "화면 효과 보기(V)")로 끕니다. 이 줄의 전환을 다시 보려면 "전환 미리 보기". 패널 안내 줄에 "이 줄부터 ASCII + 덮개 VHS (휘어짐 1)" / "효과 없음 + 덮개 VHS (앞에서 이어짐)"처럼 지금 효과가 나옵니다.
- Ctrl+S로 원고에 저장하면 원고를 다시 불러옵니다. 고친 줄은 그 앞 대사(저장 지점)부터 다시 나오니, 한 번 넘기면 보입니다.
- 텍스트 속도가 "즉시"(렌파이 새 프로젝트의 기본값)면 글자가 한 번에 나와서 속도와 서서히·타자기 같은 효과가 보이지 않습니다. 물결·떨림은 보입니다. 게임의 환경설정에서 텍스트 속도를 낮추거나 `custom_ui.text_cps`를 정하세요.

### 4-5. 저장

- 대사·선택지는 원고의 그 줄을 고칩니다. (4-2)
- 그 밖의 탭은 바뀐 탭의 파일만 씁니다. 파일은 설정 파일과 같은 폴더(`ui_kit/`)에 생깁니다.
- `*_layout.rpy`의 값은 설정 파일의 같은 값보다 **우선**합니다. 직접 고쳐도 되지만, 편집기에서 다시 저장하면 덮어써집니다.
- 설정 파일로 옮기고 싶으면 Ctrl+C로 복사해 설정 파일에 붙여넣고 `*_layout.rpy`를 지우세요.
- 원고를 고쳤을 때와 커서 설정·클릭 대기 표시 켜기·끄기를 저장했을 때는 자동으로 다시 불러온 뒤 편집기를 같은 탭으로 다시 엽니다. (원고에 바로 쓰지 못한 줄이 남아 있으면 다시 불러오지 않고 알려줍니다)
- Shift+R로 다시 불러와도 편집기는 같은 탭으로 다시 열립니다. 대사·선택지의 저장 안 한 값은 남고, 그 밖의 탭의 저장 안 한 값은 사라집니다.
- 다른 플러그인의 탭(예: `screen_fx`)은 저장 파일을 그 플러그인 폴더에 만듭니다.
- 프로젝트가 Dropbox 안에 있으면 파일을 쓰는 순간 잠겨 있을 수 있어서, 몇 번 다시 시도합니다. 그래도 안 되면 "저장 실패"가 나오니 동기화를 잠시 멈추고 다시 저장하세요.

### 4-6. 이미지/영상 탭

게임을 진행하는 중에 Shift+M → T로 "이미지/영상" 탭. 원고의 **show / hide / scene 줄 하나**를 골라 고칩니다.

| 고칠 것 | 방법 | 원고에 적히는 것 |
|---|---|---|
| 고를 줄 | 화면의 그림·영상 누르기 / Tab(화면의 그림 차례로) / `[` `]` / 목록 / 줄 번호 입력 | |
| 위치 (show·scene) | 그림 끌기, 방향키. **배경(bg)은 옮기지 않음** | `at stage.pos(420, 720)` |
| 위치 버튼 | 기본 / 왼쪽 / 가운데 / 오른쪽 / 정중앙 / 화면 밖 왼쪽·오른쪽 | `at left` 등. "기본"은 at 절의 위치를 지움 |
| 전환 효과 | 없음 / 서서히 / 검게 페이드 / 픽셀 / 이동 / 부드럽게 이동 / 닦아내기 / 미끄러지기 / 밀어내기 / 확대·축소 / 흔들기 | `with dissolve`, `with moveinleft` … "없음"은 with 절을 지움 |
| 방향 | 이동·부드럽게 이동: 제자리 / ← → ↑ ↓ (show는 그쪽에서 들어옴, hide는 그쪽으로 나감) | `with easeinleft`, `with moveoutright` … |
| 시간 | 0.3 ~ 3초 버튼 | 기본 시간이면 `with dissolve`, 다르면 `with Dissolve(1.0)`, `with stage.ease("inleft", 0.8)` |

```renpy
## 저장 전
    scene bg room
    show eileen happy
    hide eileen
## 저장 후
    scene bg room with fade
    show eileen happy at stage.pos(420, 720) with stage.ease("inleft", 0.8)
    hide eileen with moveoutright
```

- **at 절과 with 절만** 바꿉니다. 이미지 이름, `onlayer`, `as`, `zorder`, `behind`, 줄 끝의 `:`(ATL 블록), 주석은 그대로입니다. at 절에 위치가 아닌 것(`at left, shake`의 `shake`)도 그대로 두고 위치만 바꿉니다.
- 위치 `stage.pos(x, y)`는 그림의 **아래 가운데**(렌파이 기본 위치와 같은 기준)가 화면의 (x, y)에 오게 합니다. 기준은 `stage.anchor`로 바꿉니다.
- **줄 번호**: 패널 위에 "script.rpy 42번째 줄"과 같은 파일의 show·hide·scene 줄 목록(앞뒤 7줄)이 나옵니다. 분홍 번호 = 지금 장면에서 실행된 줄, `*` = 저장 안 한 변경이 있는 줄. 줄 번호 칸을 눌러 숫자를 넣고 엔터를 치면 그 줄(아니면 가장 가까운 뒤 줄)을 고릅니다.
- **미리 보기**: 지난 대사(또는 선택지·pause) 뒤에 실행된 줄은 "지금 장면"입니다. 위치는 끄는 대로 바로 보이고, 전환을 바꾸면 그 장면을 다시 실행해 전환까지 보여줍니다(R로 언제든 다시). 그 밖의 줄은 값만 고치고, **"그 줄로 가기"**로 렌파이의 줄 이동(`warp`)을 써서 그 줄부터 볼 수 있습니다. 줄 이동은 그 앞의 변수 값이 비어 있을 수 있습니다.
- **그림/영상 고르기**(3.0): 줄을 고른 뒤 "그림/영상 고르기" → `game/images`, `game/movies`의 파일 목록에서 고르고
  - [이 줄의 그림 바꾸기]: 그 줄의 이미지 이름만 바꿈 (`show eileen happy` → `show ghost`)
  - [아래에 show 넣기] / [아래에 scene 넣기]: 그 줄 바로 아래에 `show ghost` / `scene ghost` 줄을 넣음
  - 저장 전에도 화면에 잠깐 보여 주고, Ctrl+S로 원고에 들어갑니다. 넣은 줄의 위치와 전환은 저장 뒤 그 줄을 골라서 고치세요.

  ```renpy
  ## 저장 전                         ## [room] → 이 줄의 그림 바꾸기, [hand] → 아래에 show 넣기 → Ctrl+S
      scene fx_bg                         scene room
                                          show hand
  ```

- 화면의 그림에는 그것을 띄운 줄 번호가 테두리와 함께 표시됩니다. 원고의 show·scene 줄로 띄운 그림만 고를 수 있습니다. (세이브를 불러온 직후처럼 줄을 모르는 그림은 목록으로 고르세요)
- `show expression …`, `show screen …`, `show layer …`, 그림 없는 `scene`, 여러 줄에 걸친 줄은 고칠 수 없습니다. 이유가 패널에 나오고, Ctrl+C로 새 줄을 복사할 수 있습니다.
- **배경(bg)은 위치를 고정합니다**(2.8). `stage.bg_tag` 목록의 태그(기본 `bg`) 그림은 눌러서 줄을 고를 수는 있지만, 끌기, 방향키, 위치 버튼으로 옮기지 않습니다. 전환 효과는 고칠 수 있습니다. 원고에 이미 위치가 적혀 있으면 "기본 위치로 되돌리기"로 위치만 지웁니다. 배경 앞에 다른 그림이 겹쳐 있으면 앞의 그림이 먼저 골라집니다.
- 편집기를 닫으면 장면을 원래 모습(원고대로)으로 다시 보여줍니다. 저장하지 않은 값은 편집기가 열려 있을 때만 보입니다.
- `show a` 다음 줄에 따로 `with dissolve`처럼 적은 전환은 그 `with` 줄의 것이라 이 탭에서 고치지 않습니다. show 줄 끝에 붙은 `with`만 고칩니다.

### 4-7. 패널이 가릴 때

패널이 커서 고칠 글자나 그림을 가리면:

- **패널 제목(= UI 편집기)을 끌어서** 아무 데나 옮깁니다. 그 자리에 고정되고, P를 누르면 다시 구석으로 돌아갑니다.
- **X**로 패널을 한 줄(탭 이름, 지금 줄, 저장 버튼)로 접습니다. 다시 X로 펼칩니다.
- **Space를 누르고 있는 동안** 패널이 사라집니다. 화면을 확인할 때 씁니다. (그동안에도 끌기·방향키는 동작)
- **자동 비키기**(기본 켬): 고른 것(이미지/영상 탭의 그림, 대사 탭의 대사·이름, 선택지, 타이틀 메뉴 항목)이 패널 아래에 있으면 패널이 가리지 않는 구석으로 잠깐 비킵니다. B로 끄고 켭니다. 패널을 끌어서 옮긴 동안에는 비키지 않습니다.
- F1로 단축키 안내를 접으면 패널이 더 작아집니다. 이미지/영상 탭은 L로 줄 목록을 접습니다.
- 패널이 화면보다 길면(대사 탭에서 화면 효과, 덮개, 글자 빼기 줄까지 펼쳤을 때 등) 아래쪽이 **스크롤**됩니다. (2.7)
  - 패널 위에서 **마우스 휠**, 또는 오른쪽 분홍 **스크롤바**를 끌기. 스크롤바는 끄는 동안 막대만 움직이고, 손을 떼면 내용이 따라옵니다.
  - 탭 버튼과 저장/복사/닫기/접기 줄은 늘 위에 보입니다.
  - 휠 한 칸에 움직이는 양은 40픽셀입니다. 탭을 바꾸면 맨 위로 돌아갑니다.

## 5. 타이틀 메뉴 (`title_menu_config.rpy`)

규칙은 두 가지입니다.

1. 항목에 적지 않은 값은 `tmenu.default`의 값을 따릅니다.
2. 이름 앞에 `hover_`를 붙이면 **선택됐을 때의 값**입니다. (`color` = 평소 색, `hover_color` = 선택됐을 때 색)

```renpy
define tmenu.default = {
    "font": "NeoDGMpro.ttf",
    "size": 35,
    "color": "#fff6f6",
    "hover_color": "#ffffff",
}

define tmenu.items = [
    {
        "id": "start",
        "text": _("시작한다"),
        "action": Start(),
        "x": 640, "y": 375,
        "rotate": -5,
        "hover_text": "START",
        "hover_movie": "movies/menu_start.webm",
    },
    ## ...
]
```

### 5-1. 항목에 쓰는 값

| 이름 | 뜻 | 예 |
|---|---|---|
| `id` | 항목 이름. 편집기 저장에 쓰이니 꼭 붙이세요 | `"start"` |
| `text` | 표시할 글자 (필수) | `_("시작한다")` |
| `action` | 눌렀을 때 동작 (필수). `None`이면 누를 수 없는 항목 | `Start()`, `ShowMenu("load")`, `Quit(confirm=False)` |
| `x`, `y` | 위치. 정수는 픽셀, 소수는 화면 비율 | `640`, `0.5` |
| `xalign`, `yalign` | 렌파이 align과 같은 방식의 위치 (x, y가 있으면 무시) | `0.5` |
| `anchor` | 위치의 기준점. 기본은 글자 한가운데 | `(0.5, 0.5)` |
| `rotate` | 회전 (도, 시계 방향) | `-5` |
| `skew` | 기울기 (도). 양수면 윗부분이 오른쪽으로 | `10` |
| `zoom` | 확대 | `1.2` |
| `alpha` | 투명도 | `0.8` |
| `hover_rotate`, `hover_skew`, `hover_zoom`, `hover_alpha` | 선택됐을 때 값 | `"hover_zoom": 1.3` |
| `hover_offset` | 선택됐을 때 이동 (픽셀) | `(30, 0)` |
| `hover_text` | 선택됐을 때 바뀌는 글자 | `"START"` |
| `hover_movie` | 선택됐을 때 **모든 글자 뒤에** 깔리는 영상 | `"movies/start_bg.webm"` |
| `hover_movie_pos` | 그 영상의 위치 (항목 위치 기준 이동, 픽셀) | `(0, 10)` |
| `hover_movie_anchor` | 그 영상의 기준점 | `(0.5, 0.5)` |
| `hover_movie_rotate`, `hover_movie_zoom` | 그 영상의 회전·확대 | `-8`, `1.5` |
| `hover_movie_size` | 영상 크기를 미리 알려줌 (첫 프레임 전 위치 흔들림 방지) | `(400, 200)` |
| `hover_movie_side_mask` | 투명 영상 방식 사용 여부 (기본 `True`) | `False` |
| `hover_movie_loop` | 반복 재생 (기본 `True`) | `False` |
| `hover_label_movie` | 선택됐을 때 **글자 대신** 나오는 영상 | `"movies/start_label.webm"` |
| `hover_label_movie_offset`, `_size`, `_side_mask`, `_loop` | 위와 같은 뜻 | |
| `push` | 다른 항목이 선택됐을 때 밀려날지 (기본 `True`) | `False` |
| `push_scale` | 이 항목만 더 많이·적게 밀리게 | `2.0` |
| `shift` | 이 항목이 선택되면 **메뉴 전체**가 이동할 양 | `(-20, 0)` |
| `show_if` | 조건이 참일 때만 보임 (문자열 또는 함수) | `"persistent.cleared"` |
| `keyboard` | 키보드 이동에 포함할지 (기본 `True`) | `False` |
| `hit_padding` | 클릭 영역을 글자보다 넓히는 정도 (픽셀) | `12` |
| `hover_sound`, `activate_sound` | 이 항목만의 효과음 | `"audio/select.ogg"` |

위 표에 없는 이름은 모두 **렌파이 텍스트 스타일 속성**으로 그대로 전달됩니다. `font`, `size`, `color`, `outlines`, `kerning`, `bold`, `italic`, `underline`, `strikethrough`, `line_spacing` 등을 쓸 수 있고, 앞에 `hover_`를 붙이면 선택됐을 때 값입니다. 오타가 있으면 타이틀 화면이 나올 때 어느 항목의 어떤 이름이 틀렸는지 오류 화면으로 알려줍니다.

```renpy
## 외곽선 2겹 (검은 테두리 + 오른쪽 아래 빨간 그림자)
"outlines": [ (4, "#000000", 0, 0), (2, "#e0245e", 6, 6) ],
"hover_outlines": [ (6, "#000000", 0, 0) ],
```

### 5-2. 전체 설정

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `tmenu.enabled` | `True` | 이 기능을 쓸지 |
| `tmenu.start_index` | `0` | 처음에 선택돼 있을 항목 번호. `None`이면 처음엔 아무것도 선택 안 됨 |
| `tmenu.push_before` | `(0, -10)` | 선택 항목보다 목록 **앞쪽** 항목이 밀리는 방향·거리 |
| `tmenu.push_after` | `(0, 10)` | 선택 항목보다 목록 **뒤쪽** 항목이 밀리는 방향·거리 |
| `tmenu.push_falloff` | `0.6` | 한 칸 멀어질 때마다 밀리는 정도에 곱하는 값 |
| `tmenu.move_time` | `0.25` | 움직이는 시간(초) |
| `tmenu.move_warper` | `"easeout"` | 속도 곡선. `"ease"`, `"linear"`, `"easeout_back"`(살짝 튕김) 등 렌파이 ATL warper 이름 |
| `tmenu.fade_time` | `0.12` | 평소 글자 ↔ 선택 글자 페이드 시간 |
| `tmenu.intro` | `True` | 처음 나타날 때 하나씩 미끄러져 들어오는 연출 |
| `tmenu.intro_delay`, `intro_time`, `intro_offset` | `0.06`, `0.35`, `(-30, 0)` | 등장 간격, 시간, 출발 위치 |
| `tmenu.background_movie` | `None` | 타이틀 배경 영상 경로 |
| `tmenu.background_side_mask` | `False` | 배경 영상이 투명 영상 방식이면 `True` |
| `tmenu.hover_sound`, `tmenu.activate_sound` | `None` | 선택 이동·결정 효과음 |
| `tmenu.keyboard_order` | `True` | 방향키를 목록 순서대로 이동하게 함 |
| `tmenu.hit_padding` | `8` | 클릭 영역 여백 |
| `tmenu.insensitive_alpha` | `0.4` | 누를 수 없는 항목의 투명도 |
| `tmenu.movie_group` | `None` | 문자열을 넣으면 영상 전환 때 빈 프레임 깜빡임을 줄임 |
| `tmenu.show_version` | `True` | 타이틀의 게임 제목 아래 버전 번호 표시 |
| `tmenu.main_menu_frame` | `True` | 렌파이 기본 GUI의 메뉴 뒤 반투명 판(`gui/overlay/main_menu.png`) 표시 |
| `tmenu.title_game_menu_navigation` | `True` | 타이틀에서 연 환경설정·불러오기 화면에 왼쪽 목록 표시. `False`면 "돌아가기"만 |
| `tmenu.game_menu_side` | `True` | 대사록·저장·불러오기·환경설정 화면 왼쪽에 ESC 메뉴(타이틀에서 열면 타이틀 메뉴)를 그대로 두고, 제목과 내용은 그 오른편에. `False`면 렌파이 기본 모양 (4.14) |

### 5-3. 게임 제목과 게임 메뉴

타이틀의 게임 제목 위치·색, 게임 메뉴 버튼 글자는 렌파이 스타일 문법으로 설정 파일에 적습니다. 적은 속성만 바뀌고 나머지는 렌파이 기본값을 따릅니다.

```renpy
style main_menu_vbox:          ## 게임 제목·버전 묶음의 위치
    xalign 0.45
    yalign 0.42

style main_menu_title:         ## 게임 제목 글자
    color "#ffffff"

style navigation_button_text:  ## 게임 메뉴 왼쪽 버튼 글자 ("돌아가기"에도 적용)
    size 35
    hover_strikethrough True
```

`tmenu.game_menu_side = True`(기본)이면 게임 메뉴 왼쪽에는 ESC 메뉴 항목(`tmenu.pause_items`)이, 타이틀에서 연 화면에는 타이틀 메뉴 항목(`tmenu.items`)이 같은 자리에 나옵니다. 항목을 바꾸려면 그 목록을 고치세요. 제목 글자는 `style game_menu_label_text:`로 바꿉니다.

`tmenu.game_menu_side = False`일 때 게임 메뉴 왼쪽 목록을 바꾸려면 `tmenu.game_menu`에 (글자, 동작) 또는 (글자, 동작, "보일 조건")을 순서대로 적습니다.

```renpy
define tmenu.game_menu = [
    (_("대사록"), ShowMenu("history"), "not main_menu"),
    (_("저장하기"), ShowMenu("save"), "not main_menu"),
    (_("불러오기"), ShowMenu("load")),
    (_("환경설정"), ShowMenu("preferences")),
    (_("메인 메뉴"), MainMenu(), "not main_menu"),
    (_("종료하기"), Quit(), "renpy.variant('pc')"),
]
```

### 5-4. 클릭 영역에 대해

글자가 밀려나거나 커져도 **클릭 영역은 평소 위치에 고정**되어 있습니다. 움직이는 글자를 따라 판정이 바뀌면 마우스를 가만히 둬도 선택이 깜빡이며 왔다 갔다 하는 현상이 생기기 때문입니다. 회전·기울기가 있는 항목은 클릭 영역도 같이 회전·기울어져 있어서 정확하게 판정됩니다. 편집기를 열면 클릭 영역이 반투명 상자로 보입니다.

### 5-5. 게임 중 ESC 메뉴 (3.1)

게임 중에 **ESC**나 **오른쪽 클릭**을 누르면 나오는 메뉴입니다. 게임 화면이 어둡게 깔리고, 그 위에 타이틀 메뉴와 같은 모양의 메뉴가 뜹니다.

| 하고 싶은 것 | 값 (`title_menu_config.rpy`) |
|---|---|
| 켜기 / 끄기 (끄면 렌파이 기본: ESC → 저장 화면) | `define tmenu.pause = True` / `False` |
| 뒤 화면 어둡게 하는 정도 | `define tmenu.pause_dim = "#000000b3"` (마지막 두 자리 = 진하기, `None` = 안 어둡게) |
| 어둡게 하는 대신 그림 깔기 | `define tmenu.pause_background = "gui/game_menu.png"` |
| 항목 바꾸기 | `define tmenu.pause_items = [ … ]` (쓰는 법은 `tmenu.items`와 같음) |
| 글꼴, 크기, 색, 선택됐을 때 모양 | 타이틀 메뉴와 같이: `tmenu.default` (또는 편집기에서 "모든 항목 공통") |
| 항목 자리 | ESC 메뉴를 연 채로 Shift+M → "타이틀 메뉴" 탭 → 끌어서 옮기고 Ctrl+S |

```renpy
## 항목을 다섯 개로 줄이고, 붉은빛으로 어둡게
define tmenu.pause_dim = "#20000099"
define tmenu.pause_items = [
    { "id": "return", "text": _("계속하기"), "action": Return(),
      "xalign": 0.08, "yalign": 0.35, "rotate": -3, "hover_zoom": 1.15 },
    { "id": "save",   "text": _("저장하기"), "action": ShowMenu("save"),
      "xalign": 0.09, "yalign": 0.45, "rotate": -1, "hover_zoom": 1.15 },
    { "id": "load",   "text": _("불러오기"), "action": ShowMenu("load"),
      "xalign": 0.10, "yalign": 0.55, "rotate": 1, "hover_zoom": 1.15 },
    { "id": "prefs",  "text": _("환경설정"), "action": ShowMenu("preferences"),
      "xalign": 0.11, "yalign": 0.65, "rotate": 3, "hover_zoom": 1.15 },
    { "id": "main",   "text": _("타이틀로"), "action": MainMenu(),
      "xalign": 0.12, "yalign": 0.75, "rotate": 5, "hover_zoom": 1.15, "size": 26 },
]
```

- ESC를 한 번 더 누르면 게임으로 돌아갑니다.
- 저장, 불러오기 화면 안의 "돌아가기"는 렌파이 기본처럼 **게임으로** 돌아갑니다(ESC 메뉴로 가지 않음).
- 편집기 "타이틀 메뉴" 탭은 지금 떠 있는 메뉴를 고칩니다. 패널에 "ESC 메뉴 항목 1/7"처럼 나옵니다. 저장하면 `title_menu_layout.rpy`에 타이틀 것은 `tmenu.layout`, ESC 메뉴 것은 `tmenu.pause_layout`으로 따로 적힙니다. "모든 항목 공통"(3번)으로 고친 값은 둘이 같이 씁니다.
- 스크린 이름은 `tmenu_pause`입니다. 다른 스크린에서 열려면 `ShowMenu("tmenu_pause")`.

## 6. 선택지 (`choice_menu_config.rpy` + 스크립트)

### 6-1. 스크립트에서 쓰기

선택지 글자 뒤 괄호 안에 값을 적습니다. 적지 않은 값은 설정 파일의 기본값을 따릅니다.

```renpy
menu:
    "꺼져, 듣고 싶지 않으니까!" (x=300, y=350, font="fonts/ChosunGu.ttf", size=25, color="#aa0000", hover_color="#ff4444", line_spacing=-10):
        jump angry

    "(계속해보라는 듯이 끄덕인다)" (x=900, y=350, font="fonts/KBLJump_c.ttf", size=30, rotate=-4, kerning=2):
        jump listen

    "그냥 세로 목록에 나오는 선택지":
        jump normal
```

`menu` 뒤 괄호에 적은 값은 그 메뉴의 모든 선택지에 적용되고, 선택지에 따로 적은 값이 우선합니다.

```renpy
menu (font="fonts/KBLJump_c.ttf", size=28, appear="fade"):
    "첫 번째":
        pass
    "두 번째" (color="#ff4444"):
        pass
```

| 이름 | 뜻 | 예 |
|---|---|---|
| `x`, `y` | 위치. 정수는 픽셀, 소수는 화면 비율. **하나라도 적으면 자유 배치** | `x=300, y=350` |
| `xalign`, `yalign` | 렌파이 align 방식의 위치 | `xalign=0.8` |
| `anchor` | 위치 기준점 (기본: 글자 한가운데) | `anchor=(0.0, 0.5)` |
| `rotate`, `skew`, `zoom`, `alpha` | 회전(도), 기울기(도), 확대, 투명도 | `rotate=-5` |
| `hover_rotate`, `hover_skew`, `hover_zoom`, `hover_alpha` | 마우스를 올렸을 때 값 | `hover_zoom=1.2` |
| `hover_offset` | 마우스를 올렸을 때 이동(픽셀). 크게 주면 버튼이 마우스에서 벗어나 깜빡일 수 있어요 | `hover_offset=(8, 0)` |
| `width` | 이 폭(픽셀)을 넘으면 줄바꿈. `None`이면 줄바꿈 안 함 | `width=400` |
| `text_xalign` | 버튼이 글자보다 넓을 때(`button_xsize`) 버튼 안에서 글자의 가로 위치 | `text_xalign=0.0` |
| `appear` | 등장 연출: `"pop"`, `"fade"`, `"slide"`, `None` | `appear="slide"` |
| `delay` | 나타나기까지 기다릴 시간(초) | `delay=0.5` |
| `hover_movie` | 마우스를 올렸을 때 뒤에 나오는 영상. `None`이면 끔 | `hover_movie="movies/red.webm"` |
| `hover_movie_zoom`, `hover_movie_offset`, `hover_movie_size` | 그 영상의 확대·위치·크기 | `hover_movie_zoom=2.0` |
| `hover_movie_side_mask`, `hover_movie_loop` | 투명 영상 방식(기본 `True`), 반복 재생(기본 `True`) | |
| `hover_sound`, `activate_sound` | 이 선택지만의 효과음 | |
| 렌파이 텍스트 스타일 속성 | `font`, `size`, `color`, `kerning`(자간), `line_spacing`(줄 간격), `outlines`, `bold`, `italic`, `underline`, `strikethrough`, `textalign` … | `kerning=3` |
| `hover_` + 스타일 속성 | 마우스를 올렸을 때 글자 스타일 | `hover_color="#ff4444"` |
| `insensitive_` + 스타일 속성 | 고를 수 없는 선택지의 글자 스타일 | `insensitive_color="#555"` |
| `button_` + 스타일 속성 | 선택지 버튼의 배경·여백·크기 | `button_padding=(30, 8)` |

이름에 오타가 있으면 그 선택지가 나올 때 어느 선택지의 어떤 이름이 틀렸는지 오류 화면으로 알려줍니다.

### 6-2. 모든 선택지의 기본값

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `cmenu.enabled` | `True` | 이 기능을 쓸지 |
| `cmenu.default` | 렌파이 기본 선택지 모양 | 모든 선택지의 기본값. 쓰는 이름은 6-1 표와 같음 |

style choice_vbox:

## 7. 커스텀 UI (`custom_ui_config.rpy`)

처음에는 기능이 모두 꺼져 있어서 렌파이 기본과 같습니다. 쓰려는 기능만 켜고 경로를 적으세요.

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `custom_ui.enabled` | `True` | 이 기능 전체를 쓸지 |
| `custom_ui.cursor` | `False` | 커서 애니메이션 켜기 |
| `custom_ui.cursor_frames` | `gui/cursor/cursor1~6.png` | 프레임 이미지 목록 (순서대로 재생). 편집기 칸은 12개 |
| `custom_ui.cursor_hold` | `2` | 24fps에서 그림 한 장을 보여줄 프레임 수. `1` 초당 24장, `2` 초당 12장 (3.0) |
| `custom_ui.cursor_mode` | `"software"` | `"software"` 렌파이가 그림 (24fps 정확, 그림 크기 제한 없음) / `"hardware"` 운영체제 커서 (반응이 가장 빠르지만 최대 20fps) (3.0) |
| `custom_ui.cursor_hotspot` | `(0, 0)` | 클릭 기준점 (이미지 왼쪽 위에서 x, y 픽셀) |
| `custom_ui.ctc` | `False` | 클릭 대기 표시 애니메이션 켜기 |
| `custom_ui.ctc_name` | `"ctc_anim"` | 만들어지는 이미지 이름. `Character(ctc="ctc_anim")`처럼 써도 됨 |
| `custom_ui.ctc_frames` | `gui/ctc/ctc1~6.png` | 프레임 이미지 목록. 편집기 칸은 12개 |
| `custom_ui.ctc_hold` | `2` | 24fps에서 그림 한 장을 보여줄 프레임 수. `1` 초당 24장, `2` 초당 12장 (3.0) |
| `custom_ui.ctc_all_characters` | `True` | ctc를 따로 지정하지 않은 모든 캐릭터(내레이션 포함)에 붙임 |
| `custom_ui.ctc_position` | `"nestled"` | `"nestled"`(글자 바로 뒤), `"nestled-close"`, `"fixed"`(say 스크린에서 정한 자리) |
| `custom_ui.typing_sound` | `None` | 대사 글자가 나오는 동안 재생할 소리. `None`이면 끔 |
| `custom_ui.typing_volume` | `1.0` | 음량 (0.0~1.0). 환경설정의 "효과음 음량"에도 같이 따름 |
| `custom_ui.typing_loop` | `True` | 글자가 다 나올 때까지 반복 재생 |
| `custom_ui.text_cps` | `None` | 텍스트 속도 기본값 (1초에 나오는 글자 수, 0이면 한 번에). `None`이면 `options.rpy` 값 |
| `custom_ui.quick_menu` | `True` | 새 게임을 시작할 때 퀵메뉴를 보일지 |

- 커서와 클릭 대기 표시는 **초당 24프레임 고정**입니다(3.0). 예를 들어 6장을 2프레임마다 넣으면 0.5초, 12장을 2프레임마다 넣으면 1초에 한 바퀴 돕니다.

  ```renpy
  define custom_ui.cursor = True
  define custom_ui.cursor_frames = [
      "gui/cursor/cursor1.png",
      "gui/cursor/cursor2.png",
      "gui/cursor/cursor3.png",     # … 최대 12장 권장
  ]
  define custom_ui.cursor_hold = 2              # 2프레임마다 (초당 12장)
  define custom_ui.cursor_mode = "software"     # 24fps가 정확한 소프트웨어 커서
  define custom_ui.ctc = True
  define custom_ui.ctc_hold = 1                 # 클릭 대기 표시는 1프레임마다 (초당 24장)
  ```

- 편집기 "커서/대사 소리" 탭에서 칸 12개를 눌러 그림을 고르고, [1프레임마다] / [2프레임마다], 커서 방식을 고릅니다. 커서 켜기/끄기, 방식, 커서 그림, 클릭 대기 표시 켜기/끄기는 저장하면 다시 불러온 뒤 적용됩니다.
- **Screen FX(4.2 이상)가 같이 있으면** 소프트웨어 커서도 화면 효과를 받습니다(3.1). 기본은 효과와 VHS 덮개를 다 받아서, ASCII 장면에서는 커서도 글자로, 게임보이 장면에서는 4색 점으로 보입니다. 구간마다 바꾸는 법:

  ```renpy
  ## screen_fx_config.rpy: 평소 값
  define screen_fx.cursor = "effect"       # "effect" 효과까지 / "overlay" 덮개(VHS)만 / "top" 효과 안 받음

  ## 스크립트: 다시 바꿀 때까지 유지 (세이브에 저장)
  $ screen_fx.set_cursor("top")
  e "커서만 덮개 밑으로." (fx_cursor="overlay")
  ```

  자세한 것은 `screen_fx/README.md` 5-3.
- 대사 소리는 모든 캐릭터에 자동으로 붙습니다. 캐릭터마다 바꾸거나 끄려면 `Character("이름", cb_typing_sound="audio/other.ogg")`, `Character("이름", cb_typing_sound=None)`.
- 대사 소리는 전용 채널(`typing`)로 재생되어 다른 효과음을 끊지 않습니다. 텍스트 속도가 최대이거나 넘기는 중일 때는 나지 않습니다.
- 텍스트 속도는 처음 실행할 때와 이 값을 바꿨을 때만 적용됩니다. 플레이어가 환경설정에서 바꾸면 그 값이 유지됩니다.
- 퀵메뉴는 게임 중에 `$ quick_menu = True`로 켤 수도 있고, 세이브를 불러오면 저장할 때의 상태가 유지됩니다.

## 8. 대사 스타일 (`say_style_config.rpy` + 스크립트)

대사 뒤 괄호에 짧은 이름으로 값을 적으면 **그 한 줄에만** 적용됩니다. 다음 대사는 원래 설정으로 돌아갑니다.

```renpy
t "글쎄, 난 봤다니까요." (x=520, y=300, size=30, color="#aa0000")
n2 "……그런 게 없다고?" (color="#aa0000")
e "어디 갔었어?" (name_x=820, name_y=-60, speed=0.5, effect="jitter")
```

| 짧은 이름 | 뜻 | 예 |
|---|---|---|
| `x`, `y` | 위치 (대사 창 왼쪽 위 기준 픽셀. `t`는 대사 창이 화면 전체라서 화면 기준) | `x=520, y=300` |
| `pos` | 위치를 한 번에 | `pos=(520, 300)` |
| `font` | 글꼴 | `font="fonts/ChosunGu.TTF"` |
| `size` | 글자 크기 | `size=30` |
| `color` | 글자 색 | `color="#aa0000"` |
| `outline` | 외곽선 (두께, 색, x, y) | `outline=[(2, "#000000", 0, 0)]` |
| `spacing` | 줄 간격 | `spacing=-10` |
| `bold`, `italic` | 굵게, 기울임 | `bold=True` |
| `kerning` | 자간 | `kerning=2` |
| `width` | 한 줄 최대 너비 (넘으면 줄바꿈) | `width=500` |
| `align` | 줄 정렬 (0.0 왼쪽 ~ 1.0 오른쪽) | `align=0.5` |
| `speed` | 나오는 속도 배율 (플레이어 텍스트 속도에 곱함. 0.5 = 절반 속도). 텍스트 속도가 "즉시"면 효과가 없음 | `speed=0.5` |
| `cps` | 나오는 속도, 1초에 나오는 글자 수. 플레이어 텍스트 속도와 상관없이 이 값 | `cps=20` |
| `effect` | 등장 효과: `"dissolve"` 서서히, `"typewriter"` 타자기, `"slowalpha"` 흐리게 대기, `"flip"` 뒤집히며, `"zoom"` 커지며, `"jitter"` 떨림, `"wave"` 물결. showpy 효과(3.5~3.6): `"scatter"` 흩어졌다 모이기, `"drop"` 떨어지기, `"spin"` 회전하며, `"shuffle"` 무작위 순서, `"flash"` 색 번쩍, `"slam"` 크게 찍히기, `"typecursor"` 커서 타자기, `"echo"` 색 잔상, `"glitch"` 글리치, `"glow"` 빛 번짐, `"blurin"` 흐렸다 또렷해지기, `"wipe"` 위에서 그려지기, `"blockglitch"` 블록 글리치, `"melt"` 녹아내림, `"mosh"` 데이터모싱 흉내, `"liquid"` 일렁임, `"vhs"` VHS 지직거림, `"rise"` 떠오르기, `"lean"` 기울며 들어오기, `"stretch"` 늘어나며 들어오기 | `effect="wave"` |
| `name_x`, `name_y` | 이름 상자 위치 (대사 창 왼쪽 위 기준. 이름 배경 그림째 움직임) | `name_x=820, name_y=-60` |
| `name_font`, `name_size`, `name_color` | 이름 글꼴, 크기, 색 | `name_size=34` |
| `fx` | (`screen_fx`가 있을 때) 이 대사부터 켤 화면 효과. `"default"` = 선택취소. 다음에 바꿀 때까지 이어짐 | `fx="ascii"` |
| `fx_transition` | (`screen_fx`가 있을 때) 이 줄의 효과 전환: `"tv"`, `"fade"`, `None`(바로) | `fx_transition="fade"` |
| `fx_overlay` | (`screen_fx` 4.0) VHS 덮개 `True` 켬 / `False` 끔. `fx` 없이 쓰면 덮개만 바꿈 | `fx_overlay=False` |
| `fx_warp` | (`screen_fx` 4.0) 덮개 가장자리 휘어짐 (0 평평 ~ 5 크게). `"default"` = 설정값으로. 다음에 바꿀 때까지 이어짐 | `fx_warp=3.0` |
| `fx_exclude` | (`screen_fx` 3.2) 이번 효과에서 뺄 글자: `"say"` 대사·이름, `"choice"` 선택지, `"screens"` 메뉴·화면. `()` 아무것도 안 뺌 | `fx_exclude=("say",)` |
| `fx_target` | (`screen_fx` 3.1, 예전 이름) `"scene"` 글자 전부 빼기, `"screen"` 안 빼기 | `fx_target="screen"` |

- `what_alpha` 같은 렌파이 원래 이름도 그대로 적을 수 있습니다. 자주 쓰는 이름은 설정 파일의 `say_style.alias`에 `"짧은이름": "렌파이 속성"`으로 추가하세요.
- 적지 않은 값은 그 캐릭터의 기본값을 따릅니다. `x`만 적으면 높이는 그대로입니다.
- 한 줄 안의 **일부 글자만** 바꿀 때는 텍스트 태그를 씁니다: `"그건 {color=#a00}{size=30}거짓말{/size}{/color}이야"`
- 설정 파일에는 화면 어디에나 대사를 놓을 수 있는 내레이션용 캐릭터 `t`와 위치 프리셋 `n1`~`n3`가 정의되어 있습니다. 이름을 바꾸거나 같은 방식으로 더 만들어도 됩니다.
- `effect`에는 렌파이 텍스트 셰이더 문법을 그대로 쓸 수 있습니다. 예: `effect="wave:u__amplitude=10"`(물결 높이 10), `effect="dissolve|wave"`(서서히 나타나며 물결)
- `name_x`, `name_y`는 렌파이 새 프로젝트의 `screens.rpy`에 들어 있는 `config.character_id_prefixes.append('namebox')` 줄이 있어야 동작합니다. 없으면 무엇을 넣어야 하는지 오류로 알려줍니다.
- 예전 편집기가 저장한 캐릭터 기본값(`say_style_layout.rpy`)이 있으면 계속 적용됩니다. 2.2부터는 캐릭터 정의에서 직접 고칩니다.

## 9. 영상 준비

- 형식은 **WebM (VP9)** 을 권장합니다.
- 동시에 재생되는 영상(배경 + hover 영상)은 **프레임레이트를 똑같이** 맞추세요. 다르면 프레임이 끊길 수 있습니다.
- hover 영상은 화면 전체 크기가 아니라 **필요한 부분만** 잘라서 만들면 가볍습니다.

### 투명 영상 (side_mask 방식)

렌파이는 webm의 투명 채널을 직접 읽지 못해서, 영상을 좌우로 나눠 **왼쪽은 색, 오른쪽은 흑백 투명도**로 만든 파일을 씁니다. 그래서 파일 가로 크기는 실제 표시 크기의 두 배가 됩니다.

애프터 이펙트 등에서 투명 배경 영상(ProRes 4444 `.mov` 등)으로 뽑은 뒤 ffmpeg로 변환합니다.

```bash
## .mov(ProRes 4444) 등 투명 영상 → side_mask 영상
ffmpeg -i input.mov -filter_complex "[0:v]format=rgba,split[c][a];[a]alphaextract,format=yuv420p[m];[c]format=yuv420p[cc];[cc][m]hstack" -c:v libvpx-vp9 -pix_fmt yuv420p -b:v 0 -crf 30 -an output.webm

## 투명 webm이 원본이면 -i 앞에 디코더를 지정해야 투명도가 읽힙니다
ffmpeg -c:v libvpx-vp9 -i input.webm -filter_complex "(위와 같음)" ... output.webm
```

투명하지 않은 영상(화면 전체 배경 등)은 그대로 쓰고, 설정에서 `side_mask`를 `False`로 두면 됩니다.

## 13. 이미지·영상 배치 (`stage_config.rpy` + 스크립트)

### 13-1. 영상 자동 등록

`game/movies/` 폴더(안쪽 폴더 포함)의 `.webm`은 게임을 켤 때 파일 이름으로 등록됩니다. 렌파이가 `images/`의 그림을 등록하는 방법과 같습니다(소문자로, 공백은 이미지 이름의 낱말 구분).

| 파일 | 스크립트에서 | 읽는 방법 |
|---|---|---|
| `movies/rain.webm` | `show rain`, `scene rain` | 보통 영상 |
| `movies/mask_ghost.webm` | `show ghost` | **투명 영상**(side_mask: 왼쪽 절반 색, 오른쪽 절반 투명도) |
| `movies/fx/mask_fire big.webm` | `show fire big` | 투명 영상. 태그는 `fire`, 속성은 `big` |
| `movies/bg rain.webm` | `scene bg rain` | 보통 영상. `bg` 태그라 항상 맨 뒤 |

- 투명 영상 만드는 법은 9장. 렌파이는 webm의 투명 채널을 직접 읽지 못해서 side_mask 형식으로 만들고, 파일 이름 앞에 `mask_`를 붙입니다.
- 같은 이름의 그림이 `images/`에 있거나 `image` 문으로 정의돼 있으면 영상은 등록하지 않습니다. (그림이 우선) 이미지/영상 탭 안내 줄에 "등록 못 한 영상"으로 나옵니다.
- 기본은 반복 재생입니다. 한 번만 재생할 영상은 `define stage.movie_once = [ "door_open" ]`.
- 여러 영상을 동시에 띄워도 됩니다. 렌파이가 영상마다 채널을 따로 잡습니다. 소리가 들어 있으면 같이 재생됩니다.

| 설정 | 기본값 | 뜻 |
|---|---|---|
| `stage.movies_dir` | `"movies"` | 영상 폴더 (game 기준) |
| `stage.movie_extensions` | `(".webm",)` | 등록할 확장자 |
| `stage.mask_prefix` | `"mask_"` | 투명 영상 표시 |
| `stage.movie_loop` | `True` | 반복 재생 |
| `stage.movie_once` | `[ ]` | 한 번만 재생할 영상 이름 |

### 13-2. bg는 항상 맨 뒤

`bg` 태그의 그림·영상(`scene bg room`, `show bg street`)은 다른 그림보다 항상 뒤에 그립니다. `show bg room zorder 5`처럼 적어도 맨 뒤이고, 다른 그림에 `bg`보다 낮은 `zorder`를 적어도 `bg` 바로 앞으로 올라옵니다. 순서 값은 `stage.bg_zorder`(기본 -1000). 편집기에서는 배경의 위치를 옮기지 않습니다(4-6).

태그는 그림 이름의 첫 단어입니다(`as`를 적었으면 `as` 뒤의 이름). 배경으로 볼 태그는 `stage_config.rpy`의 `stage.bg_tag`에 목록으로 적습니다.

```renpy
define stage.bg_tag = [ "bg" ]                  # 기본: scene bg room, show bg street …
define stage.bg_tag = [ "bg", "fx_bg" ]         # scene fx_bg 도 배경으로
define stage.bg_tag = [ "bg", "room", "sky" ]   # scene room night, show sky dawn 도 배경으로
define stage.bg_tag = "bg"                      # 2.7까지처럼 하나만 적어도 됨
define stage.bg_tag = [ ]                       # 배경 처리 끔 (맨 뒤, 위치 고정 둘 다)
```

### 13-3. 스크립트에서 쓰는 도우미

편집기가 원고에 적는 것과 같고, 직접 써도 됩니다.

```renpy
show eileen happy at stage.pos(420, 720)          # 그림의 아래 가운데를 (420, 720)에
show eileen happy at stage.pos(0.3, 1.0)          # 소수 = 화면 비율
show ghost at stage.pos(640, 360, anchor=(0.5, 0.5))   # 기준점을 한가운데로

show eileen with stage.move("inleft", 0.8)        # moveinleft를 0.8초로
hide eileen with stage.ease("outright", 1.2)      # easeoutright를 1.2초로
show eileen at right with stage.move("", 0.4)     # 제자리에서 옮기는 move를 0.4초로
show ghost with stage.zoom("in", 0.8)             # zoomin을 0.8초로 ("out" = zoomout)
```

나머지 전환은 렌파이 기본 이름과 클래스를 그대로 적습니다: `dissolve` / `Dissolve(1.0)`, `fade` / `Fade(0.5, 0.0, 0.5)`, `pixellate` / `Pixellate(2.0, 5)`, `wipeleft` / `CropMove(0.5, "wipeleft")`, `slideleft`·`slideawayleft`, `pushleft` / `PushMove(0.5, "pushleft")`, `vpunch`, `hpunch`.

편집기가 읽지 못하는 전환(직접 만든 전환 등)은 "직접 쓴 전환"으로 보여주고, 버튼을 누르기 전까지 그대로 둡니다.

### 13-4. 위치 버튼 바꾸기

```renpy
define stage.positions = [
    ("left", "왼쪽"),
    ("center", "가운데"),
    ("right", "오른쪽"),
    ("my_left2", "왼쪽 2"),        # transform my_left2: … 로 직접 만든 위치도 됨
]
```

직접 만든 위치 이름은 편집기가 "위치"로 알아보지 못해서, 그 버튼을 다시 누르면 at 절에 위치가 두 개 생길 수 있습니다. 렌파이 기본 이름(`left`, `right`, `center`, `truecenter`, `top`, `topleft`, `topright`, `offscreenleft`, `offscreenright`)과 `stage.pos(…)`, `Position(…)`만 위치로 알아봅니다.
