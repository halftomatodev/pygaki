# 효과 폴더

이 폴더에 `.glsl` 파일을 넣으면 그 안의 효과가 게임과 pygaki 앱에 저절로 생깁니다. 파일을 빼면 없어집니다.
효과 하나에 파일 하나로 두면 넣고 빼기 쉽습니다.

- **글자 등장 효과** (`@effect`): 대사 괄호에 `effect="이름"`. PyKaki [대본 편집]의 등장 효과 목록에 나옵니다.
- **그림 등장 효과** (`@transition`): `scene`, `show` 뒤에 `with img_fx.use("이름")`. PyKaki 배경/보이기 줄의 "나타나는 방식" 목록에 나옵니다.

파일을 넣거나 뺀 뒤에는 게임을 껐다 켭니다. 앱은 창으로 돌아오거나 내보낼 때 폴더를 다시 읽습니다.

pygaki 앱의 **[효과]** 화면에서도 같은 일을 할 수 있습니다: 효과를 샘플로 돌려 보기, 켜고 끄기, [파일 넣기]로 효과 파일 넣기(형식을 먼저 검사함), [빼기](지운 파일은 프로젝트 폴더의 `ui_kit_backup/effects/`에 남고, 대본에서 쓰던 줄은 다른 효과로 바꿔 줌). 이 폴더에서 뺀 샘플은 앱의 "효과 모음"에 남아 있어 [넣기]로 다시 넣을 수 있습니다.

## 들어 있는 샘플

| 파일 | 종류 | 이름 | 모양 |
|---|---|---|---|
| `maskup.glsl` | 글자 | `maskup` 아래에서 올라오기 | 보이지 않는 선 아래에 숨어 있다가 위로 올라옴 |
| `tracking.glsl` | 글자 | `tracking` 자간이 좁아지며 | 줄 전체가 넓게 벌어진 채 나타나 제 간격으로 모임 |
| `sweep.glsl` | 글자 | `sweep` 빛 지나가기 | 어둡게 나온 글자 위로 빛 띠가 지나가며 제 밝기가 됨 |
| `irisin.glsl` | 그림 | `irisin` 원으로 열리기 | 한 점에서 커지는 원 안으로 새 그림이 나타남 |
| `bands.glsl` | 그림 | `bands` 띠로 덮였다 열리기 | 색 띠가 차례로 화면을 덮고, 걷히면서 새 그림이 나옴 |
| `pixelsort.glsl` | 그림 | `pixelsort` 픽셀소트 (크래시) | 지금 화면의 밝은 부분이 띠로 늘어나며 깨지고(가로, 세로, 회전, 확산), 깨진 채 멈췄다가 새 화면으로 뚝 끊어 넘어감 |
| `datamosh.glsl` | 그림 | `datamosh` 데이터모싱 (크래시) | 키프레임을 잃은 동영상처럼 지금 화면이 블록째 끌려가며(회전·확산) 녹고 새 화면의 윤곽이 비치다가, 깨진 채 멈췄다가 새 화면으로 뚝 끊어 넘어감 |

```renpy
e "아래에서 올라온다." (cps=30, effect="maskup")
e "빛이 지나간다." (cps=30, effect="sweep:u__color=#ffd54f")
e "둘을 겹친다." (cps=30, effect="maskup|sweep")

scene bg hall with img_fx.use("irisin")
show mina with img_fx.use("irisin", 1.2, x=0.3)
scene bg hall with img_fx.use("bands", 1.4, count=10, color="#c2185b")
scene bg hall with img_fx.use("pixelsort", 1.5, dir=3, length=600)
scene bg hall with img_fx.use("datamosh", 1.5, mode=1.0, strength=1.5)
```

`pixelsort`, `datamosh`는 셰이더가 바뀔 때의 전환으로도 씁니다. PyKaki 상자의 ◐ 셰이더 → 전환의 "시작할 때", "끝날 때"에서 고르면,
앞 상자의 마지막 화면이 깨진 채 멈췄다가 다음 상자의 첫 화면으로 끊어 넘어가고, 셰이더도 끊기는 순간에 바뀝니다(화면 효과 `screen_fx` 5.6부터).
원고로 직접 쓸 때는 이렇게 적습니다.

```renpy
$ screen_fx.shaders("glitch", "none", transition="pixelsort", duration=1.2)
scene bg room
with screen_fx.pending_with()
```

`pixelsort`는 진짜로 줄을 정렬하지 않고 정렬한 것처럼 보이는 띠를 그립니다. 띠가 길수록 그래픽 카드가 할 일이 늘어납니다.
`datamosh`는 동영상 코덱이 새 프레임을 받지 못할 때를 흉내 냅니다. 앞 그림을 블록마다 움직임 벡터(회전·확산 흐름 + 새 그림 밝기의 기울기)로 프레임마다 다시 끌어 오고(오류가 쌓임), 새 그림에서 더 또렷한 윤곽만 거칠게 얹습니다. 몇몇 블록은 옆 블록의 벡터를 잘못 읽고(`mismatch`), 몇몇은 움직이지 않고(`skip`), 몇몇 구역은 중간에 멈춥니다(`lost`). 윤곽의 세기는 `residual`.
둘 다 다음 화면과 섞지 않습니다. 시간의 앞쪽(`crash`, 기본 픽셀소트 0.4, 데이터모싱 0.45)에 깨지고 나머지는 멈춰 있다가, 끝에서 새 화면으로 바뀝니다.

그림 전환 파일에 `@set u__cut 값`(0~1)을 적으면 셰이더 전환으로 쓸 때 화면 셰이더가 그때 바뀝니다(없으면 0.5, 절반). 효과 코드도 `l__t >= u__cut`부터 새 그림을 그리게 맞춥니다.

## 적는 법

`@`로 시작하는 줄이 표시, 들여 쓴 줄이 GLSL 코드, 맨 앞에서 시작하는 `//` 줄은 설명입니다.
이름은 영어 소문자, 숫자, `_`만 쓰고, 이미 있는 이름(기본 효과, 렌파이 효과, 다른 파일의 효과)은 못 씁니다.

### 글자 등장 효과

기본 효과와 같은 형식입니다. 자세한 설명과 예시는 `ui_kit/engine/text_effects.glsl` 맨 위와 그 안의 효과들에 있습니다.

| 표시 | 뜻 |
|---|---|
| `@effect 이름 한글이름` | 효과의 시작 |
| `@cps` | 글자가 하나씩 나와야 보이는 효과 (PyKaki가 글자/초를 비우면 30으로 내보냄) |
| `@slow 식` | 다 나온 뒤 더 기다릴 시간(글자 수). 예: `u__duration` |
| `@redraw always` | 멈춰 있어도 계속 다시 그림 |
| `@set u__이름 값` | 값의 기본값. 대사에서 `effect="이름:u__이름=값"`으로 바꿈. 색은 `#rrggbb` |
| `@param u__이름 최소 최대 한글이름` | 그 값을 막대로 고칠 때의 범위와 이름 |
| `@variables` | uniform, attribute, varying 줄 |
| `@vertex_30`, `@fragment_350` ... | 렌파이 셰이더 조각. 숫자가 작은 것부터 이어 붙음 |
| `@use T`, `@use ROTATE` | 기본 효과 파일의 공용 조각 넣기 |

- `@use T`는 `l__t`(이 글자가 나온 정도 0→1)를 만듭니다.
- `@use ROTATE`는 `l__scale`, `l__ang`으로 글자를 키우고 돌립니다. 이 조각이 `l__p`, `l__c`, `l__s`를 쓰므로 효과 안에서 같은 이름을 쓰지 않습니다.
- `RAND(1.0)`은 글자마다 다른 0~1 값입니다.
- `u__`, `l__`, `v__`로 시작하는 이름은 렌파이가 효과마다 다른 이름으로 바꿔 줍니다.

### 그림 등장 효과

| 표시 | 뜻 |
|---|---|
| `@transition 이름 한글이름` | 전환의 시작 |
| `@time 초` | 걸리는 시간의 기본값. `img_fx.use("이름", 1.5)`로 바꿈 |
| `@set u__이름 값` | 값의 기본값. `img_fx.use("이름", count=10)`처럼 `u__`를 뺀 이름으로 바꿈 |
| `@param u__이름 최소 최대 한글이름` | 막대의 범위와 이름 |
| `@variables` | `@set`으로 적은 값의 uniform 줄 |
| `@fragment` | 점마다 색을 정하는 코드. 끝에 `gl_FragColor`에 넣음 |

`@fragment` 안에서 쓸 수 있는 값:

| 이름 | 뜻 |
|---|---|
| `l__t` | 진행 0 → 1 |
| `l__uv` | 이 점의 자리 (0~1, 왼쪽 위가 0, 0) |
| `l__size` | 화면의 가로, 세로 픽셀 |
| `l__old` | 앞 그림의 색 |
| `l__new` | 새 그림의 색 |

색은 투명도를 곱한 값입니다. 섞을 때는 `mix(l__old, l__new, 정도)`처럼 그대로 섞습니다.

그림을 옮기거나 뭉개려면 다른 자리의 색을 직접 읽습니다. `texture2D(tex0, 자리)`가 앞 그림, `texture2D(tex1, 자리)`가 새 그림입니다(자리는 `l__uv`처럼 0~1. 그 밖으로 나가지 않게 `clamp(자리, 0.0, 1.0)`). 효과 모음의 `slide`(옆으로 밀기), `mosaic`(모자이크로 바뀌기)이 이렇게 씁니다.

## 클로드에게 새 효과를 부탁할 때

아래 글을 복사해서, 만들고 싶은 모양(글이나 참고 영상)과 같이 줍니다.

```text
렌파이 게임의 pygaki 플러그인 효과 폴더(game/ui_kit/effects)에 넣을 효과 파일을 하나 만들어 줘.
- 형식은 game/ui_kit/effects/README.md의 "적는 법"을 따르고, 같은 폴더의 샘플 파일을 본보기로 해.
- 글자 효과는 @effect, 그림 효과는 @transition. 파일 하나에 효과 하나, 파일 이름은 효과 이름.glsl.
- 고칠 만한 값은 @set과 @param으로 꺼내 줘 (최소, 최대, 한글 이름).
- 다른 파일은 고치지 말고, 이 폴더에 파일 하나만 더해.
- 다 쓰면 렌파이 Lint를 돌리고 게임을 켜서 셰이더 오류가 없는지 확인해 줘.
만들 모양: (여기에 적기. 예: 글자가 왼쪽에서 접혀 있다가 펴지며 나옴, 0.5초)
```

## 알아 둘 것

- 파일에 틀린 표시가 있으면 그 파일만 건너뜁니다. 이유는 개발 모드에서 게임을 시작할 때 화면에 뜨고, 앱 아래쪽 알림에도 나옵니다.
- GLSL 코드 자체가 틀리면 그 효과를 처음 그릴 때 렌파이가 오류 화면을 띄웁니다. 새 효과는 앱 [효과] 화면의 샘플(코드가 틀리면 이유가 나옴)이나 시험 프로젝트에서 먼저 봅니다.
- 효과 파일을 빼면 그 효과를 쓰던 대사는 "모르는 텍스트 셰이더" 오류가 납니다. 빼기 전에 원고에서 그 이름을 찾아 바꿉니다. 그림 전환은 배포판에서 서서히 바뀌기로 돌아갑니다(개발 모드에서는 오류로 알림).
- 효과를 지우지 않고 목록에서만 감추려면 이 폴더의 `effects_off.txt`에 이름을 한 줄에 하나씩 적습니다(`#` 뒤는 설명, 파일이 없으면 모두 켠 것). 끈 효과는 고르는 목록에서만 빠지고, 이미 쓴 대사와 원고는 그대로 돕니다. 게임을 껐다 켜면 반영됩니다.
- 인터넷에서 받은 셰이더는 라이선스를 보고, 코드를 그대로 가져오지 말고 모양만 참고해서 새로 씁니다.
