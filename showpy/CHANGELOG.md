크게 키운 게임(레트로 해상도)에서 게임 안 편집 화면을 실제 화면 크기로(패널·고르기 창·이름표를 배율만큼 줄여 그림, 타이틀 항목·회전 손잡이·선택지 목록 점·그림 모서리 점의 크기와 집는 거리, `screen_fx` 줄기표 서랍도), 편집 화면이 열려 있을 때 게임 화면 밖 창의 빈 곳을 붉게 칠하는 여백 띠(F8, 앱 환경 설정, 실시간 연결 `bands`). pygaki 앱과 붙어 있을 때 게임 창 패널을 보이게 하면 짧은 판(자리 줄과 조작 안내만, 값만 고르는 탭은 탭 줄에서 뺌), 값 칸과 고르기 창은 그동안에도 앱에.
