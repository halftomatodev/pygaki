# 바뀐 기록

버전별 자세한 설명은 [docs/READ_ME_FIRST.md](docs/READ_ME_FIRST.md)와 폴더별 `README.md`에 있습니다.

## 4.22 (2026-11-04)

이름: 데스크톱 앱 이름을 **pygaki**로(예전 PyKaki). 런처 버튼 [pygaki로 편집] [pygaki로 새 프로젝트], 앱 툴바 [대본 편집] [GUI 편집]. 앱은 묶음의 `pygaki\app\pygaki.exe`. 설정과 자동 저장은 예전 자리(`%APPDATA%\PyKaki`) 그대로.

`screen_fx` 4.5:
- **셰이더가 바뀌는 줄** 목록(화면 효과 탭): 원고에서 셰이더를 바꾸는 줄마다 1번 + 2번과 전환(설정대로 / TV / 서서히 / 바로)을 고릅니다. 두 자리는 늘 같이 바뀝니다. 한 자리만 바꾸는 예전 줄(`use("gameboy")`, `set_overlay`, 대사 괄호 `fx=`, `fx_overlay=`)은 [두 자리로 바꾸기]로 `$ screen_fx.shaders(…)` 한 줄로 바꿉니다(대사 괄호는 지움). [여기에서부터 적용]에도 전환 고르기.
- "처음 상태, 전환" → "처음 상태": 처음 1번, 2번과 '설정대로' 전환만. TV 시간 막대, 기다림, 건너뛰기는 `screen_fx_config.rpy`에서.
- **커서와 셰이더 '여기에서부터'**: 커서/대사 소리 탭(앱 커서 칸)에서 [1번, 2번 다 받음 / 2번만 받음 / 셰이더 안 받음]을 고르고 줄을 골라 적용 → `$ screen_fx.set_cursor("top")`. 고르면 바로 미리 보기. 셰이더 줄과 커서 줄은 서로 지우지 않습니다.
- PyKaki가 만든 원고에서도 셰이더 줄, 커서 줄을 넣고 바꾸고 지웁니다(PyKaki 대본에 받아 적힘). 4.20~4.21에서는 PyKaki 원고에 저장되지 않았습니다.
- warp(처음 가는 줄로 건너뛰기) 뒤에 원고의 그 앞 셰이더, 커서 줄대로 화면을 맞춥니다. 고른 줄이 다른 파일에 남아 있으면 다시 지금 줄을 따라갑니다.

`ui_kit` 3.21:
- 대사 탭에서 글자 등장 효과, 줄마다 화면 효과·덮개·휘어짐·커서 줄을 뺐습니다("대사 효과는 PyKaki에서"). 원고에 이미 적힌 괄호는 그대로 돌아갑니다.
- 원고 쓰기 도구: 화면 효과 줄을 바꿀 때 사이의 빈 줄을 넘어 예전 줄을 찾음, PyKaki 원고의 `$ screen_fx.` 줄(`replace`, `insert`, 새 `remove` 기록).
- 커서/CTC 그림 폴더 안내(`game/gui/cursor/`, `game/gui/ctc/`). pygaki 새 프로젝트에 샘플 그림(`showpy/samples/gui`).
- 실시간 연결: `custom_ui.cursor_lines`, 명령 `custom_ui.cursor`.

PyKaki(pygaki 앱): GUI 편집 원고 칸을 파일 전체 스크롤로(게임 줄을 따라가다 직접 스크롤하면 멈춤, [지금 줄로]). 커서 칸에 "커서와 셰이더", 그림 칸 바둑판 배경, 미리보기 밝게/어둡게. 받는 기록에 `remove`.

## 4.20 (2026-11-04)

`screen_fx` 4.3:
- 인게임 셰이더를 **두 자리**로: 1번, 2번 모두 기본(아무것도 안 함) / 아스키 / VHS / 단말기(레트로 터미널) / 게임보이 중에서 고르고 겹칩니다. 스크립트는 `$ screen_fx.shaders("ascii", "vhs_crt")`, 전부 취소는 `$ screen_fx.shaders("none", "none")`. 예전 `use()`, `clear()`, 대사 괄호 `fx=`, `fx_overlay=`도 그대로 됩니다. `overlay=`에 효과 이름을 적을 수 있습니다(4.0에서 막았던 것).
- **타이틀 셰이더, 게임 내 메뉴 셰이더**: 타이틀(과 타이틀에서 연 화면), 게임 중 ESC 메뉴(와 거기서 연 화면)에는 인게임 셰이더 대신 따로 고른 두 자리(`screen_fx.title_shaders`, `screen_fx.menu_shaders`, 기본은 둘 다 "none")를 화면 전체에 씌웁니다. 효과의 `scope`(항상 / 게임 중에만 / 타이틀에서만)는 더 쓰지 않습니다.
- 편집기 "화면 효과" 탭: 첫 페이지 **"셰이더 고르기"** (1번, 2번, "전부 셰이더 적용 취소", 고르면 화면에 바로 미리 보기). 줄 목록의 세모(▶)가 게임의 지금 줄을 따라가고, 고른 줄도 따라갑니다. 세모를 두 번 누르면 그 줄로. **[여기에서부터 적용]** 하나로 고른 줄 위에 `$ screen_fx.shaders(…)`를 넣습니다(Ctrl+S). 효과 페이지의 "고칠 대상"은 **"세부 속성"**으로 이름을 바꾸고, "이 대사부터/이 줄부터 이 효과", "덮개 켜기", "이 대상 되돌리기", "모두 버리기", 켜기/범위, 효과마다 덮개 줄은 뺐습니다. "기본 효과, 전환"은 "처음 상태, 전환"(처음 1번, 2번).
- 편집기 탭 "타이틀 셰이더"(`title_fx`), "게임 내 메뉴 셰이더"(`pause_fx`). 저장하면 `screen_fx_layout.rpy`.

`ui_kit` 3.19:
- 타이틀 메뉴 **배경**: 기본은 검은 화면(렌파이 기본 GUI 그림과 반투명 판을 쓰지 않음). 그림이나 webm 영상을 고르면 그것(`tmenu.background`). ESC 메뉴 배경은 기본이 **투명**(어둡게 하지 않음), 그림이나 영상을 고를 수 있음(`tmenu.pause_background`).
- **제목, 부제 글자**(`tmenu.labels`, ESC 메뉴는 `tmenu.pause_labels`): 위치, 회전, 크기, 글꼴, 색, 글자 효과. 편집기에서 메뉴 항목처럼 끌어 옮김(Tab으로 고름).
- **글자 효과**: 대사 등장 효과(glitch, glow, vhs …)를 메뉴 항목, 제목, 부제에 `"effect"`로. 편집기 타이틀 메뉴 탭에 "글자 효과:" 줄.
- **회전 손잡이**: 타이틀 메뉴 탭에서 고른 글자 위의 분홍 네모를 끌면 돌아갑니다(Shift: 15도씩).
- 편집기 고르기 창 "배경"(그림, 영상). 실시간 연결: `state.title`에 제목, 부제(`kind: "label"`), `background`, `effects`, 명령 `title.background`, 파일 목록에 `movies`. 앱의 저장 수에 원고 줄 변경도 셉니다.
- PyKaki 앱: 왼쪽 목록에 "└ 타이틀 셰이더", "└ 게임 내 메뉴 셰이더". 타이틀 메뉴 칸에 배경, 글 내용, 글자 효과.
