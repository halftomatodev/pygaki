# PyKaki 연결 샘플

선택지 3개와 call 갈래가 있는 짧은 대본 "빈 병동"입니다. 그림과 소리는 시험용입니다.

## 렌파이에서 보기

1. 렌파이 런처에서 새 프로젝트를 만듭니다. (1280x720)
2. 이 폴더 `game` 안의 파일과, 저장소 `game` 안의 `ui_kit`, `screen_fx`, `hotkeys`, `splash`를 프로젝트의 `game`에 넣습니다.
3. 실행합니다.

## PyKaki에서 열기

pygaki 묶음의 런처에서 위 프로젝트를 고르고 [pygaki로 편집]으로 PyKaki를 연 뒤, [열기]로 `pykaki/sample.flow.json`을 가져옵니다. 이 대본은 pygaki 플러그인 연결이 켜져 있습니다.

| 상자 | 들어 있는 것 |
|---|---|
| n1 도입 | 배경, 음악, 내레이션, 캐릭터, 대사 |
| n2 노크 | 메모, 효과음, 덮개 휘어짐을 넣은 대사 |
| n3 고민 | 표정 대사, 선택지 3개 |
| n4 문을 연다 | 화면 효과 줄, 배경, 기타 그림, 숨기기, 효과 끄기 |
| n5 귀를 기울인다 | call로 n7에 갔다가 n3으로 돌아옴 |
| n6 달린다 | 숨기기, 음악 멈춤, `%`가 있는 대사 |
| n7 숨소리 | call로 불려 와서 return |
