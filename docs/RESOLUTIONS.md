# 해상도와 픽셀 퍼펙트

pygaki 새 프로젝트(런처 [+ Create New Project] → Pygaki)는 이름 다음에 해상도를 고릅니다. **레트로** 다섯 가지와 **고해상도** 두 가지가 있습니다.

| 이름 | 해상도 | 비율 | 어떤 화면 | 1920x1080 모니터에서 |
|---|---|---|---|---|
| GBC (retro) | 160x144 | 10:9 | 컬러 휴대용 게임기 | 창 ×6, 전체 화면 ×7 |
| SNES (retro) | 256x224 | 8:7 | 16비트 가정용 게임기 | 창 ×4, 전체 화면 ×4 |
| PC-98 (retro), 처음 골라져 있음 | 640x400 | 16:10 | 1980~90년대 일본 PC 어드벤처·비주얼 노벨 | 창 ×2, 전체 화면 ×2 |
| Y2K (retro) | 800x600 | 4:3 | 2000년 전후 PC 비주얼 노벨 | ×1 (×2는 1600x1200이라 안 들어감) |
| Millennial (retro) | 1024x768 | 4:3 | 2000년대 PC 게임 | ×1 |
| HD | 1280x720 | 16:9 | 지금의 비주얼 노벨 | 렌파이 기본(늘이기) |
| Full HD | 1920x1080 | 16:9 | 지금의 비주얼 노벨 | 렌파이 기본(늘이기) |
| 사용자 정의 | | | 레트로처럼 정수 배율 | |

창 배율은 작업 표시줄과 창 테두리를 뺀 크기 안에서 정합니다. 2560x1440 모니터에서는 Y2K가 ×2(1600x1200), 4K 모니터에서는 Millennial이 ×2입니다.

## 레트로를 고르면 (`game/pixel_perfect.rpy`)

레트로 해상도를 고르면 런처가 새 프로젝트에 이 파일을 넣습니다. 사용자 파일이라 [플러그인 올리기]가 건드리지 않습니다.

- **화면에 맞는 가장 큰 정수 배율**(`config.adjust_view_size`): 창이나 전체 화면에 들어가는 가장 큰 ×2, ×3 …으로 그리고, 남는 곳은 검은 띠로 둡니다. 창 크기를 바꾸면 그때마다 알아서 다시 맞춥니다. 지금 배율은 `pixel_perfect_scale`에 있습니다.
- **처음 창**: 처음 켤 때 모니터에 들어가는 가장 큰 정수 배율 크기로 열고, 작업 표시줄을 뺀 화면 가운데로 옮깁니다. 그 뒤로는 렌파이가 마지막 창 크기를 기억합니다.
- **고른 해상도의 픽셀 격자로 다시 뽑기**(`pixel_perfect_snap`): 게임 화면 전체(그림, 영상, 셰이더, 글자, 확대·회전한 것, 화면 전환)를 한 장으로 그린 뒤 고른 해상도의 픽셀 가운데 값만 집습니다. 그래서 1920x1080 영상을 넣거나 그림을 1.5배로 키우거나 VHS 같은 화면 효과를 걸어도 화면에는 고른 해상도의 픽셀로만 보입니다. 화면 효과(screen_fx)보다 바깥에 붙어서(`init 1500`) 효과까지 같은 격자로 뽑힙니다.
- **각진 픽셀**(`config.nearest_neighbor`): 그림을 흐리게 늘이지 않습니다.
- pygaki 편집 화면(Shift+M)은 맨 위 층이라 격자 뽑기에서 빠집니다.
- 끄려면 파일 안의 `pixel_perfect`를 `False`로, 정수 배율은 두고 격자 뽑기만 끄려면 `pixel_perfect_snap`을 `False`로 바꿉니다. 이미 있는 프로젝트에 넣고 싶으면 이 파일을 그 프로젝트 `game/`에 복사합니다.

## 알아 둘 것

- 그림은 고른 해상도 그대로 그립니다(PC-98이면 배경도 640x400).
- 글자도 고른 해상도의 픽셀로 뽑히므로, 작은 해상도에서는 보통 글꼴이 뭉개집니다. 레트로에는 픽셀 글꼴을 그 글꼴의 기준 크기(예: 8px, 12px, 16px)로 씁니다.
- 렌파이 기본 GUI(메인 메뉴, 대사창 크기)와 pygaki 타이틀 메뉴·스플래시(경고 화면)는 16:9, 1280x720 기준이라 GBC·SNES에서는 글이 겹치거나 화면 밖으로 넘칩니다. 작은 해상도용 GUI는 아직 없습니다.
- 게임 안 편집 화면(Shift+M)은 게임 배율과 상관없이 실제 화면 크기로 그립니다(`ui_kit` 4.20: 패널, 고르기 창, 이름표, 손잡이, 줄기표 서랍). 다만 GBC처럼 아주 작은 해상도에서는 창도 작아서(예: 960x864) 패널이 게임 화면 대부분을 가립니다. 편집 화면이 열려 있는 동안 남는 창의 검은 띠는 붉게 칠해집니다(F8로 끄고 켬).
