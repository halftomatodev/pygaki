# 효과 관리 탭 명세와 계획

2026-11-11 사용자와 정함. 앱 구조(Electron 앱 + 웹 버전 + 렌파이 플러그인)는 그대로 두고, 위쪽 메뉴에 **[효과]** 하나를 더합니다.
새 대화에서는 "docs/EFFECTS_TAB_SPEC.md ○단계 하자"로 시작하면 됩니다.

## 1. 정한 것

- 앱 구조는 그대로. 편집기를 렌파이 안으로 옮기거나 게임 창을 앱 안에 넣는 일은 하지 않는다(검토 결과는 6장).
- 위쪽 [대본 편집] / [GUI 편집] 옆에 **[효과]**.
- **[렌파이에서 보기]는 없앤다**(대사 줄의 실시간 미리보기, `pykaki_preview.json`).
- 끈 효과는 고르는 목록에서만 빠지고, 이미 쓴 대사는 그대로 돈다.

## 2. 낱말

| 낱말 | 뜻 |
|---|---|
| 글자 효과 | 대사 글자가 나오는 모양. 파일 안의 `@effect` |
| 그림 효과 | 배경·캐릭터가 나타나는 모양. 파일 안의 `@transition` |
| 기본 효과 | `ui_kit/engine/text_effects.glsl` 한 파일에 든 것. 뺄 수 없고 끄기만 됨 |
| 프로젝트 효과 | 이 게임의 `game/ui_kit/effects/*.glsl`. 파일 하나에 효과 하나 |
| 효과 모음 | pygaki와 같이 오는 효과 파일들. 아직 이 게임에 넣지 않은 것도 보임 |

글자용인지 그림용인지는 파일이 정합니다. [넣기]를 누르면 맞는 쪽 목록에 들어갑니다.

## 3. 화면

```
[ 글자 효과 | 그림 효과 ]   [찾기]   [파일 넣기] [새 효과 요청문 복사]
┌ 왼쪽: 효과 카드 목록 ────────────┐ ┌ 오른쪽: 샘플 ───────────────┐
│ 이 프로젝트에 있는 것             │ │ (고른 효과가 도는 모습)      │
│  ☑ 아래에서 올라오기  [빼기]      │ │ 샘플 글: [안녕, 반가워!   ]  │
│  ☐ 빛 지나가기 (끔)   [빼기]      │ │ 샘플 그림: [고르기]          │
│  ☑ 흔들림 (기본)                  │ │ [다시 보기]                  │
│ 효과 모음 (아직 안 넣은 것)       │ │ 세부 값 막대 (@param)        │
│  ＋ 타자기 번쩍       [넣기]      │ │ 쓰인 곳: 대사 3줄 [보기]     │
└──────────────────────────────────┘ └──────────────────────────────┘
```

- **카드**: 한글 이름, 영어 이름, 어디 것인지(기본 / 프로젝트 / 모음), 쓰인 줄 수.
- **켜기/끄기**(체크): 끈 효과는 [대본 편집]의 고르는 목록과 게임 안 GUI 편집기 목록에서만 빠진다. 셰이더는 그대로 등록된다.
- **넣기**: 모음의 파일을 `game/ui_kit/effects/`에 복사. 같은 이름이 있으면 묻는다.
- **빼기**: 프로젝트 효과 파일을 지운다. 먼저 대본에서 쓰인 줄을 세어 보여 주고, 쓰이고 있으면 [다른 효과로 바꾸고 빼기] / [그냥 빼기] / [취소]. 지운 파일은 프로젝트 폴더의 `ui_kit_backup/effects/`에 남긴다(원고 백업과 같은 폴더라 배포판에서 빠짐. 2단계에서 `game/` 안에서 여기로 바꿈).
- **파일 넣기**: 가진 `.glsl` 파일을 고르면 형식을 검사해서 넣는다. 틀리면 넣지 않고 이유를 쉬운 말로.
- **새 효과 요청문 복사**: `effects/README.md`의 요청문을 클립보드에. 앱은 밖으로 통신하지 않는다.
- **샘플**: 고른 효과를 샘플 글·그림으로 돌려 본다. 막대를 움직이면 바로 다시 돈다. 여기서 맞춘 값은 저장하지 않는다(값은 대사 줄마다 정함). 글자 효과는 지금의 앱 미리보기(`FxCanvas`), 그림 효과는 앱에서 같은 셰이더 코드로 그린다(4단계).
- 프로젝트 폴더를 연결하지 않았으면 기본 효과와 모음을 구경만 할 수 있고, 넣기·빼기·끄기 버튼은 "프로젝트를 연결하면 쓸 수 있어요"로 막는다.

## 4. 저장과 형식 (LINK.md 8장에 더할 것)

- 끈 효과 목록: `game/ui_kit/effects/effects_off.txt`. 한 줄에 효과 이름 하나, `#` 줄은 설명. 파일이 없으면 다 켠 것.
  - 게임(`text_effects.rpy`, `image_effects.rpy`)은 등록은 다 하고, GUI 편집기에 내놓는 목록에서만 뺀다.
  - 앱은 `scanFolder` 때 읽어 `EFFECTS`, `TRANSITIONS`에서 뺀다. 이미 그 효과를 쓴 줄은 칸에 이름이 그대로 보인다(지운 효과와 같은 처리).
- 효과 모음: 저장소 `showpy/effects_library/*.glsl`(새 폴더). 앱은 빌드할 때 가져가서 앱 안에 들어간다(사본 없음. 처음 계획의 묶음 `pygaki/effects/` 폴더는 읽는 곳이 없어 두지 않음, 5단계). 프로젝트마다 들어가는 샘플 여섯은 그대로.
- 대본(`.flow.json`)에 새 값이 생기지 않으므로 `FEATURE`는 그대로. 플러그인은 `ui_kit` 4.4.
- 앱에 파일 지우기 길이 없다(`main.cjs`에 `list` `stat` `read` `write`뿐) → `pygaki:remove`를 더한다(프로젝트 폴더 안, `ui_kit/effects/*.glsl`만). 웹은 폴더 손잡이의 `removeEntry`.

### 한 것

- 0, 1단계: 플러그인 쪽 (`ui_kit` 4.4)
- 2단계: `pykaki/src/effectsLib.ts`(목록, 켬/끔, 쓰인 줄, 넣기, 빼기, 바꾸기), 앱 `pygaki:remove`, `showpy/effects_library/`(아직 비어 있음). 플러그인이 있는 게임을 연결하면 그 게임의 효과 폴더에 있는 파일만 목록에 나온다(게임에서 뺀 샘플은 모음으로). 화면이 없어서 `window.pykakiEffects`와 `app/smoke.cjs`로 확인. 파일 검사는 표시와 이름까지이고 GLSL 코드가 맞는지는 3단계 샘플 화면에서 본다

- 3단계: `pykaki/src/EffectsView.tsx`([효과] 화면), 툴바의 [효과](웹에도 나옴), `showpyLive.ts`의 `view`에 `effects`. 카드 목록, 켜기/끄기, 넣기, 빼기 창(바꾸고 빼기 / 그냥 빼기), 파일 넣기, 요청문 복사, 글자 효과 샘플과 막대, 쓰인 곳 [보기]. 아직 넣지 않은 모음의 효과도 샘플로 돌린다(`previewPack`). 그림 효과 칸은 안내 글만(4단계). 확인은 웹 개발 서버(연결 없이 구경)와 `app/smoke.cjs`(진짜 앱에서 눌러서 한 바퀴)

- 4단계: `pykaki/src/fx/TransitionCanvas.tsx`(그림 효과를 게임과 같은 셰이더 코드로 WebGL에 그리기). [효과] 화면의 그림 효과 칸에 샘플(앞 그림 → 새 그림, 그림 파일 고르기), 걸리는 시간과 세부 값 막대, "원고에 적는 법"(`with img_fx.use(...)`, 복사). 플레이 화면은 `PlayStage.tsx`의 `SceneFx`가 앞 장면과 새 장면을 그림 한 장씩으로 만들어 같은 그리기로 덮는다(못 그리면 서서히 바뀌기). 확인은 웹 개발 서버(샘플 둘, 플레이)와 `app/smoke.cjs`(샘플 둘이 오류 없이 도는지). 게임과 나란히 놓고 같은 모양인지는 사용자의 눈으로

- 5단계: 사용자가 "모음은 비운 채로 마무리"로 정함(2026-11-11). 모음에 보이는 것은 게임에서 뺀 샘플 여섯뿐이고, 새 효과는 나중에 `showpy/effects_library/`에 하나씩 더한다. `make_bundle.py`는 읽어주세요에 [효과] 한 줄만 더함(효과 폴더와 샘플은 템플릿의 `ui_kit`과 같이 들어가고, 모음은 앱 안에 있고, `ui_kit_backup`은 원래 빠짐). 효과 폴더 README에 [효과] 화면 안내. 이것으로 효과 탭 0~5단계 끝

### 남은 것 (하고 싶을 때)

- 모음에 새 효과 더하기. 그림 효과 셋(`slide` 옆으로 밀기, `mosaic` 모자이크로 바뀌기, `blinds` 가로 블라인드)은 넣음. 세션 38에 `pixelsort`, `datamosh`는 셰이더 전환에 쓰려고 프로젝트 샘플(`ui_kit/effects`, 여덟)로 넣음. 더 넣을 것은 사용자와 정함
- 4.2에서 목록에서 뺀 글자 효과(`melt`, `mosh`, `flipin`, `led`, `split`)를 모음으로 되살릴지. 예전 코드가 기록에 있는지, 왜 뺐는지부터 봐야 함
- (끝남) 그림 효과의 값(초, 세부 값)을 [대본 편집]의 배경·보이기·숨기기 줄에서 막대로 정하기: "나타나는 방식" 옆 [세부 값] (`LineFields.tsx`, `stage.ts parseImageFx`)

### 다 됐다고 볼 기준

- 모음의 효과를 넣으면 앱을 다시 켜지 않아도 [대본 편집] 목록에 나오고, 게임을 다시 켜면 게임에서 돈다.
- 끈 효과는 목록에 없지만 그 효과를 쓴 예전 대사는 오류 없이 돈다.
- 쓰이고 있는 효과를 빼려 하면 쓰인 줄 수가 보이고, 바꾸고 빼면 내보낸 원고에 예전 이름이 남지 않는다.
- 틀린 파일을 넣으면 프로젝트 폴더가 바뀌지 않는다.

### 시작 전에 사용자가 정할 것

1. 효과 모음에 처음 넣을 효과(5단계). 비워 두고 시작해도 화면은 만들 수 있다.
2. 기본 효과 26개도 카드마다 샘플을 미리 돌려 보일지, 고른 것만 돌릴지(많이 돌리면 느릴 수 있음. 이 명세는 "고른 것만").

## 6. 미뤄 둔 것: 렌파이 코드 개조 검토 (2026-11-11)

- 렌파이 8.5.3은 런처(`launcher/game`), 공용 스크립트(`renpy/common`), 엔진의 파이썬 부분(`renpy/*.py`)까지 컴파일 없이 고칠 수 있다. 컴파일된 부분(그리기, GL)은 빌드 도구가 따로 필요하다. 라이선스는 MIT + 일부 LGPL이라 고친 판을 나눠 줄 수 있다.
- 편집기를 전부 렌파이로 옮기는 것은 되지만 권하지 않았다: 렌파이 입력 칸에 글 골라 잡기·복사·되돌리기가 없어 한글 대사 쓰기와 태그 상자를 새로 만들어야 하고, 상자 캔버스도 새로 만들어야 한다.
- 대신 생각한 길(게임 창을 앱 안의 한 칸으로 붙이고, 묶음의 렌파이를 pygaki 전용으로 고침)은 사용자가 "앱 구조는 그대로"로 정해서 하지 않는다. 다시 꺼낼 때 먼저 볼 것: 게임 창 붙이기(게임 쪽 `ctypes`로 창 주인 바꾸기)는 필요한 함수가 있는 것만 확인했고 해 보지는 않았다.
