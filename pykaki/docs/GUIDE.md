# PyKaki 사용 가이드

상자와 선으로 렌파이 대본을 쓰고, 렌파이 스크립트(`.rpy`)로 내보내는 도구예요.

**여는 곳**: pygaki 묶음의 렌파이 런처에서 프로젝트를 고르고 **[pygaki로 편집]**. 웹 버전(사이트, 웹앱 설치)은 2026-11-12에 없앴어요.

---

## 1. 화면 둘러보기

- **위쪽 줄 왼쪽**: 프로젝트 제목(눌러서 고쳐요), 큰 탭 **[대본 편집 | GUI 편집 | 효과 | 셰이더]**, 앱에서는 그 옆에 **게임 연결 단추**(게임과 붙어 있으면 옅은 파란색 "● 게임과 연결됨", 아니면 회색. 누르면 GUI 편집으로).
- **위쪽 줄 오른쪽 끝(초록 단추)**: 게임 돌려보기. **[▶ 렌파이에서 실행]**과 [게임 줄 따라가기].
- **위쪽 둘째 줄 메뉴**(왼쪽부터): 되돌리기 ↶ ↷, **[집중]**(옅은 보라색 단추), 설정, 그다음 파일 새로/열기/저장, 프로젝트 폴더(다시 읽기, 폴더 열기, 다른 프로젝트), 버전, 내보내기. 평소에는 흐릿하고 마우스를 올리면 또렷해져요.
- **왼쪽**: label(장면, 아래에 상자와 정렬 단추), 캐릭터, **검사**(내보낼 때 걸리는 오류와 경고. 누르면 그 상자로), 렌파이 프로젝트 정보(프로젝트, 대본 파일, 저장 상태, 찾은 그림·소리 수), **스크립트**(내보낼 원고. [펼치기]로 보고 [복사], [.rpy 내보내기]), 설정, 사용법. 묶음마다 둥근 카드로 나뉘어 있어요.
- **오른쪽**: 탭 없이 왼쪽과 같은 카드예요. 상자를 누르면 상자, 글자 효과, 대사, 다음 흐름 카드가, ◐ 셰이더를 누르면 셰이더, 전환 카드가 나와요.
- **칸 크기**: 왼쪽 칸이나 오른쪽 칸과 캔버스 사이 경계에 마우스를 대면 커서가 ↔로 바뀌어요. 끌면 그 칸의 너비가 바뀌고, 경계를 더블클릭하면 그 칸만 처음 크기로 돌아가요. 왼쪽 "설정"의 **[처음 크기]**는 양쪽을 한 번에 되돌리고, **[잠금]**을 누르면 끌어도 바뀌지 않아요. 크기와 잠금은 이 브라우저(앱)에 기억돼요.
- **가운데 캔버스**: 상자와 선. 마우스 휠로 확대/축소하고, 빈 곳을 끌어서 이동해요. 캔버스 위쪽 양 끝의 작은 **‹ ›** 버튼으로 왼쪽 칸과 오른쪽 칸을 따로 접고 펴요(접은 것은 다음에 열어도 그대로예요).

처음 열면 예제 대본("비 오는 날")이 들어 있어요. [새로]를 누르면 빈 대본으로 시작해요.

## 2. 기본 개념

| 용어 | 뜻 |
|---|---|
| **상자** | 대사 묶음. 안에 여러 줄을 쓸 수 있어요. |
| **줄** | 내레이션, 캐릭터 대사, 연출(배경·보이기·숨기기·음악·효과음), 직접 명령(⚙), 메모(#) 중 하나 |
| **선** | 상자 다음에 어디로 가는지 |
| **label(장면)** | 상자 여러 개를 묶는 단위. 렌파이의 `label` 하나가 돼요. 같은 label의 상자는 같은 배경색이에요. |

## 3. 대본 쓰기

### 캐릭터 등록
왼쪽 **캐릭터 [+ 추가]**를 눌러요.
- **색**: 이름 색 (내보낼 때 `Character(..., color=)`로)
- **id**: 렌파이 변수 이름. 영문, 숫자, `_`만 써요. 예: `a`, `alice`
- **이름**: 화면에 보이는 이름. 예: 앨리스

내레이션은 등록하지 않아도 돼요.

### 상자 만들기
- 캔버스 **빈 곳을 더블클릭**하면 새 상자가 생겨요. label 배경 안에서 더블클릭하면 그 label에 들어가요.
- 왼쪽 "상자와 정렬"의 **[+ 상자]**로도 만들 수 있어요.

### 상자 안에서 글쓰기
- 상자를 **더블클릭**하면 화면이 그 상자로 부드럽게 다가가며 확대되고, 더블클릭한 줄에 커서가 생겨요. 상자 모양은 볼 때와 똑같고 글자를 그 자리에서 바로 고치면 돼요.
- 커서가 있는 줄 **왼쪽 바깥**에 작은 단추 묶음이 붙어요.
  - **⠿** 끌어서 줄 순서 바꾸기
  - **줄 종류**: 내레이션, 캐릭터, 연출, ⚙ 명령, # 메모
  - **표정**(캐릭터 대사일 때): 예: `smile` → `a smile "대사"`
  - **＋** 아래에 새 줄, **✕** 줄 삭제
- 연출 줄(🖼 배경, 🎵 음악 등)을 누르면 **오른쪽 바깥**에 입력칸이 붙어요.
- 상자 **오른쪽 바깥**에는 반투명한 **다음 흐름** 창이 붙어요. 오른쪽 칸을 열지 않아도(집중 모드에서도) 흐름 종류(다음 상자, 선택지, call, 끝)와 이어지는 상자를 여기서 정해요. 항목이 모두 펼쳐져 있어서 누르기만 하면 돼요.
  - **Alt+Enter**: 키보드로 다음 흐름 창에 들어가요. **↑↓**로 고르고 **Enter**(또는 →)로 정해요. "이어지는 곳"을 고르면 상자 목록이 나오고, 글자를 치면 상자 이름으로 찾아요. **←**로 한 단계 뒤로, **Esc**나 **Alt+Enter**를 다시 누르면 쓰던 글로 돌아가요.
  - **＋ 새 상자에 이어 쓰기**: 아직 이어지지 않은 곳에 새 상자를 만들어 잇고, 그 상자로 넘어가 바로 글을 써요.
  - **Ctrl+Shift+Enter**: 다음 상자로 이어 쓰기. 이어진 상자가 있으면 그리로, 없으면 새 상자를 만들어서 넘어가요. 계속 누르면 상자를 하나씩 이어 가며 쓸 수 있어요.
- **Ctrl+Enter**: 같은 화자로 아래에 새 줄
- **Esc**나 빈 곳 클릭: 편집 끝. 화면이 원래 보던 곳으로 돌아가요.

### 글 꾸미기와 멈춤 (태그 상자)
- 대사나 내레이션 글 칸에 커서가 있으면 **태그 상자**가 떠요. 상자 안에서 쓸 때는 상자 **오른쪽 위 바깥**에, 오른쪽 칸에서 쓸 때는 글자 효과 칸 위쪽에 나와요.
- 글을 고르고 단추를 누르면 그 부분만 렌파이 텍스트 태그로 감싸요. 고른 글이 없으면 태그 짝을 넣고 커서를 그 사이에 둬요.
  - **B I U S**: 굵게 `{b}`, 기울임 `{i}`, 밑줄 `{u}`, 취소선 `{s}`. 단축키 **Ctrl+B / Ctrl+I / Ctrl+U**. 이미 그 태그 안이면 다시 눌러서 빼요(가운데만 고르면 그 부분만 빠져요).
  - **크기**: **가−**, **가+**는 10씩 작게, 크게(`{size=-10}`, `{size=+10}`, 누를 때마다 바뀜). 가운데 칸에 `30`(그 크기), `+10`, `-10`, `*1.5`(1.5배)를 적고 Enter.
  - **색**: 팔레트가 펼쳐져요. 기본 색 32칸, 이 프로젝트 색(대사창 기본 글자 색, 캐릭터 이름 색), 최근에 쓴 색 8칸, `#rrggbb` 칸과 [직접 고르기]. ←↑→↓로 옮기고 Enter로 골라요. 이미 색 태그 안이면 색 값만 바뀌고, [색 빼기]로 뺄 수 있어요.
  - **멈춤**: [클릭 대기] `{w}`, [잠깐] `{w=0.5}`(넣으면 숫자가 골라져 있어서 바로 초를 고쳐 쓸 수 있어요), [줄 바꾸며 대기] `{p}`, [자동 넘김] `{nw}`(글 끝에 들어가요), [여기까지 한 번에] `{fast}`
  - **속도**: 고른 글만 [느리게] `{cps=*0.5}`, [빠르게] `{cps=*2}`, [보통]으로 빼기
  - **더 보기 ▾**: 속도 줄 오른쪽 끝. 누르면 아래 줄들이 펼쳐지고, 다시 누르면 접혀요(펼친 채로 기억해요).
    - **투명도**: 막대를 끌어서 고른 글을 흐리게 `{alpha=0.5}`. 맨 오른쪽(1)에 놓거나 [빼기]를 누르면 태그가 빠져요.
    - **자간**: [좁게], [넓게]는 글자 사이를 1씩 `{k=1}`, 가운데 칸에 숫자를 적고 Enter(0은 빼기).
    - **외곽선 색**: 글자 색과 같은 팔레트 `{outlinecolor=#rrggbb}`. 게임의 글자 스타일에 외곽선(`outlines`)이 있을 때만 보여요.
    - **글꼴**: 게임 폴더를 연결하면 `game`과 `game/fonts`의 글꼴 파일을 골라 고른 글만 바꿔요 `{font=파일}`.
    - **효과**: 고른 글에만 등장 효과를 걸어요 `{shader=shake}글{/shader}`. 목록에는 켜 둔 글자 효과가 나오고, 다시 열어 [효과 태그 빼기]를 고르면 빠져요. 줄의 다른 글자는 그 줄의 글자 효과로 나오고, 줄에 효과가 없으면 한 글자씩 나와요(내보낼 때 그 줄에 `effect="typewriter"`가 저절로 붙어요. 이게 없으면 렌파이가 그 줄에서 멈춰요). 색 잔상, 외곽선 채우기처럼 외곽선 겹을 쓰는 효과는 줄 전체에만 걸 수 있어서 목록에 없어요. 효과를 고르면 옆에 **[세부 값]** 단추가 나오고, 누르면 그 효과의 막대가 열려요. 막대를 움직였다 놓으면 태그 안에 `{shader=wave:u__amplitude=8}`처럼 적히고, ↺를 누르면 그 값만 기본값으로 돌아가요(커서가 그 태그 안에 있으면 돼요). 선택지 글에는 쓸 수 없어요(왼쪽 [검사] 카드이 알려 줘요).
    - **넣기**: [가로 띄우기] `{space=30}`, [세로 띄우기] `{vspace=30}`(숫자가 골라져 있어서 바로 고쳐 써요), [{ 글자] `{{`, [루비], 글 속 그림 `{image=이름}`(게임 폴더를 연결했을 때 목록에서).
    - **루비**: 고른 글 위에 작은 글을 올려요 `{rb}글{/rb}{rt}읽는 법{/rt}`. 고른 글이 없으면 바로 앞 글자 위에 올려요. 렌파이 기본 루비 글은 본문과 같은 크기, 같은 자리라서 그대로 두면 글에 겹쳐 보여요. 게임 쪽에 크기와 자리를 정해 주세요. 예: `style ruby_text:` 아래에 `size 12`, `yoffset -22`를 적고, 줄 사이가 좁으면 `style say_dialogue:` 아래에 `line_leading 12`.
- 태그 글자는 글 칸에 그대로 보여요. 결과는 글자 효과 칸 미리보기와 게임에서 봐요(미리보기는 고른 글에만 건 효과도 게임과 같은 셰이더로 그려요. 루비는 위에 올리지 않고 작은 글로, 띄우기와 글 속 그림은 안 보여요). 편집을 끝낸 상자에서는 태그가 흐리게 보이고 안쪽 글에 굵게, 기울임, 밑줄, 색, 투명도가 입혀져요(크기는 상자 모양이 바뀌지 않게 그대로).
- 글자 효과 칸의 크기, 색, 글꼴, 글자/초는 **줄 전체**에, 태그 상자는 **고른 부분만** 걸려요.
- 태그가 다른 태그와 엇갈리게 고르면(예: `{b}`의 안과 밖에 걸치게) 넣지 않고 알려 줘요.
- 왼쪽 설정에서 텍스트 태그를 끄면 태그 상자에 [켜기]만 나와요.

### 연출 (배경, 캐릭터, 음악, 효과음)
렌파이 명령을 몰라도 줄 종류에서 **연출**을 고르고 칸만 채우면 돼요. 칸 아래 초록 글씨로 실제로 내보낼 렌파이 명령이 보여요.

| 줄 종류 | 채울 칸 | 내보내는 명령 |
|---|---|---|
| 🖼 **배경** | 배경 이름, 나타나는 방식 | `scene bg room with fade` (화면의 이미지를 모두 지우고 배경을 깔아요. 이름을 비우면 검은 화면) |
| 🧍 **보이기** | 캐릭터/배경/기타 중 고르기, 이름(캐릭터면 표정), 위치, 나타나는 방식 | `show a smile at left with dissolve` |
| 🙈 **숨기기** | 캐릭터/배경/기타 중 고르기, 이름 | `hide a with dissolve` |
| 🎵 **음악** | 틀기/멈추기, 파일 이름 | `play music "audio/rain.ogg"` · `stop music fadeout 1.0` |
| 🔊 **효과음** | 파일 이름 | `play sound "audio/door.ogg"` |

- **이미지 파일**은 게임의 `game/images/` 폴더에 이름을 맞춰 넣어요.
  - 배경: `bg 이름.png` (예: `bg room.png`)
  - 캐릭터: `캐릭터id 표정.png` (예: 캐릭터 id가 `a`면 `a smile.png`)
  - 이미지 이름은 영문 소문자, 숫자, `_`로 쓰는 게 안전해요.
- **소리 파일**은 `game/audio/` 폴더에 넣고 파일 이름만 적어요. (예: `rain.ogg`)
- 캐릭터 대사의 **속성**(표정)도 같은 그림을 써요. `a smile "대사"`는 `a smile.png`로 바꿔 보여 줘요.

### 셰이더 (상자와 label에 걸기)
게임 화면 전체에 씌우는 셰이더(아스키, VHS, 게임보이 …)를 상자나 label 단위로 걸어요. pygaki 플러그인이 든 프로젝트에서만 돼요(왼쪽 [설정]의 "pygaki 플러그인 연결").

- 상자나 label 틀 오른쪽 위의 **◐ 셰이더**를 누르면 오른쪽 칸이 셰이더 고르기로 바뀌어요. 한 번 더 누르거나 [← 상자 편집으로]로 돌아가요.
- **[이 상자에 정하기]**: 1번, 2번을 골라요. 두 자리가 겹쳐서 보여요. 둘 다 "없음"이면 그 상자에서는 셰이더를 꺼요.
- **label에 정하면** 그 label의 상자 모두에 걸려요. 상자에 따로 정한 것이 있으면 그쪽이 먼저예요. 상자도 label도 안 정했으면 게임 설정대로 보여요.
- 버튼 색으로 알 수 있어요: 채워진 색은 여기에 정한 것, 점선 테두리는 label 것을 따르는 상자.
- **전환**: 앞 상자와 셰이더가 달라지는 상자가 시작하는 상자예요. 그 상자의 "시작할 때" 전환으로 바뀌어요. 전환은 셰이더처럼 목록에서 **TV 꺼짐·켜짐**과 **없음**(바로 바뀜) 중에 골라요. TV를 고르면 그 아래 **[세부 값]**에서 꺼지는 시간, 검은 화면, 켜지는 시간, 가로선 두께, 빛남, 지직거림, 소리 크기를 이 상자(label)에서만 바꿔요. "끝날 때"는 그 셰이더가 끝나고 셰이더가 없는 상자로 넘어갈 때 써요(다음 상자에 셰이더가 있으면 그 상자의 "시작할 때"가 먼저). 같은 셰이더가 이어지는 상자 사이에는 전환이 없어요. 예전 판에서 "서서히"나 "게임 설정대로"로 정해 둔 곳은 그대로 돌고, 칸에 "예전 값"이라고 보여요. 둘 중 하나를 고르면 바뀌어요.
- 고르는 목록은 연결한 게임 폴더에 있는 셰이더예요(연결하지 않았으면 기본 셰이더). 게임에 새 셰이더를 넣었으면 게임을 한 번 켠 뒤 [다시 읽기]를 누르면 목록에 나와요.
- 셰이더 칸은 카드 셋이에요: **셰이더**(1번, 2번), **전환**, **script_flow.rpy에 들어가는 줄**(내보낼 때 그 상자 첫 줄에 적히는 코드).
- **세부 값**: 1번, 2번에서 셰이더를 고르면 바로 아래 **[세부 값]**을 펼쳐 막대로 바꿔요. 바꾼 값은 이 상자(label)에서만 쓰고, ↺로 그 값만 기본으로 돌아가요. 바꾸지 않은 값은 게임 설정대로예요(그 처음 값은 [GUI 편집] → 셰이더 기본 값에서 게임 화면을 보면서 고쳐요). 다른 셰이더로 바꾸면 그 자리의 값은 지워져요. pygaki 플러그인 화면 효과(screen_fx) 5.5부터 돼요.
- 위쪽 **[셰이더]** 화면에서 셰이더마다 샘플과 막대를 구경하고(저장 안 함) 켜고 꺼요. [전환]에서는 TV 꺼짐·켜짐 모양을 비슷하게 돌려 봐요.
- 셰이더 카드 맨 아래 **[⚠ 모든 상자에 적용]**은 지금 걸린 셰이더를 모든 label에 걸어요(상자마다 따로 정한 것은 지워져요). **[⚠ 전부 삭제]**는 대본 전체에서 셰이더를 지워요. 둘 다 묻고 하고, ↶로 되돌려요.

### 대사 소리와 속도, 커서와 클릭 대기 (상자와 label에 걸기)
◐ 셰이더 칸의 셰이더 카드 아래에 카드 둘이 더 있어요. 셰이더처럼 상자나 label마다 정해요. pygaki 플러그인(ui_kit 4.7부터)이 든 프로젝트에서 돼요(텍스트 속도는 플러그인 없이도 돼요).
- 값마다 **[따름]**(label 것, label에도 없으면 게임 처음 값) / **[이 상자에]**를 골라요. 게임 처음 값은 [GUI 편집] → 게임 처음 값 → 커서, 클릭 대기, 대사 소리에서 바꿔요.
- **텍스트 속도**: 1초에 나오는 글자 수(0이면 한 번에). 줄마다 정한 속도가 먼저예요.
- **대사 소리**: audio 폴더의 소리, 또는 끔. ▶로 들어 봐요.
- **클릭 대기, 커서**: game/gui/ctc, game/gui/cursor 안의 폴더 하나가 그림 묶음 하나예요(폴더 안 그림을 이름 차례로 돌려요). 게임 처음 값에서 켜 둔 것만 바뀌고, 커서는 소프트웨어 커서일 때만 바뀌어요.
- 카드 맨 아래 **[⚠ 모든 상자에 적용]**, **[⚠ 전부 삭제]**는 셰이더 카드와 같아요.

### 배경, 그림, 소리 카드
상자를 누르면 대사 카드 아래에 **배경(그림, 영상)**, **그림, 영상**, **효과음, 음악** 카드가 있어요. 렌파이 프로젝트를 연결했으면 그림과 소리를 눌러서 바로 넣어요(소리는 ▶로 들어 봐요). 연결하지 않았으면 이름을 쳐서 넣어요. **지금 쓰고 있는 줄 바로 앞**에 들어가요(쓰는 줄이 없으면 상자 끝). 자리는 대사 카드에서 줄을 끌어 바꿔요. 카드 위에는 이 상자에 이미 있는 그 줄들이 나오고, 누르면 그 줄로 가요.

### 렌파이에서 여기로 이동, 위치 옮기기 (앱)
게임을 [▶ 렌파이에서 실행]으로 켜서 앱과 연결돼 있으면:
- 상자 카드의 **[렌파이에서 여기로 이동]**: 게임이 이 상자의 첫 줄로 가요.
- 대사 카드의 줄마다(마우스를 올리면 보여요) **[여기로 이동]**: 게임이 그 줄로 가요. 대사·내레이션 줄에는 **[위치 옮기기]**도 있어요. 누르면 게임이 그 줄로 가고 GUI 편집기의 대사 탭이 열려요. 게임 창에서 끌어서 옮기고 [저장]하면 위치가 대본에 받아 적혀요. [끝내기]로 편집기를 닫아요.
- 다음 흐름이 선택지면 **[위치 옮기기]**로 선택지 위치를 같은 방법으로 정해요. 게임이 상자의 마지막 줄로 가니까 한 번 넘기면 선택지가 나와요.
- 게임과 연결 안 돼 있으면 상자 카드 단추는 회색이고 줄마다 단추는 안 보여요.

### 카드 접기
왼쪽, 오른쪽, GUI 편집 칸의 카드는 제목 오른쪽 회색 **[접기]**를 누르면 이름만 한 줄로 접혀요(하늘색). **[펼치기]**로 다시 열어요. 왼쪽 칸 카드는 켤 때마다 모두 접혀서 시작하고, 오른쪽 칸 카드는 접은 것을 기억해요. 칸 맨 위 오른쪽의 **[모두 접기]**(모두 접혀 있으면 [모두 펼치기])로 그 칸의 카드를 한 번에 접고 펴요. 왼쪽 칸 스크롤바는 왼쪽에 있어요.
- 예전에 넣은 "✨ 화면 효과" 줄은 그대로 돌아가지만, 상자 셰이더를 하나라도 쓰면 상자마다 첫 줄에서 셰이더를 다시 맞추니 한쪽만 쓰는 게 좋아요.

### 오른쪽 칸의 줄 모양
상자를 한 번 클릭하면 오른쪽 칸에도 같은 줄들이 나와요. 줄마다 **왼쪽 칸**에 줄 종류와 손잡이(⠿), 삭제(✕)가 있고, **오른쪽 칸**에 글이 있어요.

### 줄 순서 바꾸기
**⠿ 손잡이를 끌어서** 다른 줄 위/아래에 놓으면 순서가 바뀌어요. 상자 안 편집(왼쪽 바깥 단추 묶음)과 오른쪽 칸 모두에서 돼요.

### 직접 명령과 메모
- **⚙ 직접 명령**: 위 연출로 안 되는 렌파이 명령을 그대로 적어요. 예: `with vpunch`, `$ renpy.pause(1.0)`
- **# 메모**: 작가용 메모예요. 스크립트에는 주석(`#`)으로 들어가서 게임에는 안 보여요.

## 4. 흐름 잇기

상자를 **한 번 클릭**하면 오른쪽 **편집** 탭에서 "다음 흐름"을 정해요.

| 종류 | 뜻 |
|---|---|
| **→ 다음 상자로** | 다음 상자로 이어져요. |
| **◆ 선택지** | 선택지마다 다른 상자로 가요. |
| **⤷ call 후 계속** | 다른 장면을 불렀다가 끝나면 돌아와서 "복귀 후" 상자로 이어져요. 공통 장면을 여러 번 쓸 때 편해요. |
| **■ 끝 (return)** | 여기서 끝나요. call로 불린 장면이면 부른 곳으로 돌아가요. |

### 선으로 잇기
- 상자 아래(선택지는 오른쪽)의 **점(●)을 끌어서** 다른 상자에 놓으면 연결돼요.
- **빈 곳에 놓으면** 새 상자가 생기면서 연결돼요. 대본을 이어 쓸 때 가장 빨라요.
- 선을 클릭하고 **Delete**를 누르면 연결이 끊겨요.
- "다음" 선을 **더블클릭**하면 call로 바뀌고, call 선을 더블클릭하면 다시 "다음"으로 바뀌어요.
- 오른쪽 칸의 목록에서 대상을 골라도 돼요.

### 시작 상자
초록색 **시작** 표시가 붙은 상자에서 게임이 시작돼요. 다른 상자를 시작으로 하려면 그 상자를 클릭하고 **[시작 상자로]**를 눌러요.

## 5. label(장면) 관리

- 왼쪽 **label 목록**에서 이름, 표시 제목, 색을 바꿔요.
  - **이름**은 렌파이 label 이름이라 영문, 숫자, `_`만 써요. 예: `chapter1_rain`
  - **표시 제목**은 한글로 자유롭게 써요.
- 숫자 버튼을 누르면 그 label의 상자들로 화면이 이동해요.
- 상자를 다른 label로 옮기려면 오른쪽 칸의 **label**에서 골라요. **[+ 새 label로 분리]**도 있어요.
- 여러 상자를 **Shift+드래그**로 고르면 오른쪽에서 **같은 label로 묶기**를 할 수 있어요.
- **[label의 첫 상자로]**: 그 label이 시작되는 상자를 정해요.

## 6. 정리(자동 정렬)

왼쪽 "상자와 정렬" 칸에 있어요.

- **[전체 정렬]**: 시작부터 흐름 순서대로 위→아래로 정리해요. 같은 label 상자는 한 덩어리로 모여요.
- **[label 정렬]**: 고른 상자가 속한 label만 정리해요.
- **[선택 정렬]**: Shift+드래그로 고른 상자들만 정리해요.
- 방향(위→아래 / 왼→오른)을 바꿀 수 있어요.
- 마음에 안 들면 **Ctrl+Z**로 되돌려요.

## 7. 게임에서 확인하기, 글자 효과

PyKaki 안에서 돌려 보는 플레이 화면은 없앴어요. 대본은 렌파이 게임으로 켜서 봐요.

- **[▶ 렌파이에서 실행]**: 지금 대본을 내보내고 렌파이로 게임을 바로 켜요. 게임이 이미 켜져 있으면 다시 켜지 않고 대본만 내보내요(게임이 저절로 다시 불러와요). 누를 때마다 하나 더 켜려면 [설정]의 "게임이 이미 켜져 있으면 무시"를 꺼요. 렌파이 SDK 묶음 안에 든 앱에서 돼요. 렌파이를 못 찾으면 알려 주니 런처의 [프로젝트 실행]으로 켜세요.
- **[렌파이에서 여기로 이동]**: 게임을 그 상자나 줄로 옮겨요(6장 "렌파이에서 여기로 이동, 위치 옮기기").
- **글자 효과 칸**: 오른쪽 칸 상자 카드 아래에 있고, 지금 쓰는 대사 줄을 따라가요. 크기, 색, 글꼴, 글자/초, 등장 효과를 줄마다 골라요. 비워 두면 게임 설정을 따라요. 집중 모드에서는 패널과 함께 숨어요.
  - **효과 1번, 2번**: 등장 효과는 "1번", "2번" 두 줄이에요. 줄마다 효과를 고르고 ✕로 빼요. 둘 다 고르면 두 효과가 같이 돌아요(예: 미끄러져 멈춤 + 살짝 흔들림).
  - **세부 값**: 효과 옆 [세부 값]을 누르면 그 효과의 값(걸리는 시간, 거리, 세기, 색 등)을 막대로 고쳐요. 미리보기에 바로 보이고, ↺로 기본값으로 돌려요. 고친 값이 있으면 버튼에 개수가 보여요.
  - **글 상자**: [상자 없음]을 [말풍선]이나 [둥근 테두리]로 바꾸면 대사 글을 상자가 둘러싸요. 말풍선은 꼬리 방향(아래, 위, 왼쪽, 오른쪽, 없음)을, 둘 다 기울기(도)를 고를 수 있어요. 말풍선은 글 색을 따로 안 정하면 어두운 글자로 나와요. 미리보기는 비슷하게 흉내 낸 것이라 정확한 모양은 렌파이에서 보세요. pygaki 플러그인이 있는 게임에서만 내보내요.
  - **효과 폴더**: 게임의 `game/ui_kit/effects` 폴더에 효과 파일(`.glsl`)을 넣으면 등장 효과 목록 끝과, 배경/보이기 줄의 "나타나는 방식" 목록 끝에 나와요. 파일을 빼면 목록에서 없어져요(샘플도 같아요). 넣고 빼고 감추는 일은 **[효과] 화면**(7-1장)에서 눌러서 할 수 있어요. 손으로 하려면, 지우지 않고 목록에서만 감출 때 그 폴더의 `effects_off.txt`에 효과 이름을 한 줄에 하나씩 적어요. 감춘 효과를 이미 쓴 줄은 그대로 돌아요. 샘플로 아래에서 올라오기, 뿅 튀어나오기, 자간이 좁아지며, 빛 지나가기(글자), 원으로 열리기, 띠로 덮였다 열리기(그림)가 들어 있어요. 그림 쪽은 [효과] 화면 샘플과 게임에서 봐요. 새 효과를 만드는 법은 그 폴더의 `README.md`에 있어요.
  - **미리보기**: 맨 위 칸에 이 줄의 글자가 효과대로 나와요. 렌파이를 켜지 않아도 돼요. 등장 효과는 렌파이와 같은 셰이더 코드로 그려요. 값을 바꾸면 다시 나오고, 칸을 누르거나 ↺를 누르면 다시 볼 수 있어요. 글자는 칸에 꽉 차게 맞추므로 크기 칸의 값은 여기에 안 보여요.
  - **등장 효과**: 렌파이 기본 효과(서서히, 뒤집히며, 커지며, 떨림, 물결)와 pygaki 플러그인 효과(흩어졌다 모이기, 떨어지기, 회전하며, 무작위 순서, 색 번쩍, 크게 찍히기, 커서 타자기, 색 잔상, 글리치, 빛 번짐, 흐렸다 또렷해지기, 위에서 그려지기, 블록 글리치, 일렁임, VHS 지직거림, 떠오르기, 기울며 들어오기, 늘어나며 들어오기, 미끄러져 멈춤, 살짝 흔들림, 외곽선 채우기, 글자마다 상자, 도장, 튀어나오는 줌, 찌그러졌다 튕김, 입체 글자)가 있어요. pygaki 플러그인 효과는 pygaki 플러그인이 있는 게임에서만 내보내요. 예전 대본에 목록에서 뺀 효과(타자기, 흐리게 대기, 녹아내림, 데이터모싱, 뒤집으며 나오기, LED 전광판, 위아래 갈라짐)가 남아 있으면 이름 그대로 칸에 보이고, 게임에서는 한 글자씩 나와요.
  - **글자/초 기본값**: 글자가 하나씩 나와야 보이는 효과(떨림, 물결, 빛 번짐, 일렁임, VHS 지직거림을 뺀 모든 효과)는 칸을 비워 두면 30으로 나오고, 그대로 내보내요. 다른 값을 적으면 그 값을 써요.
  - **렌파이 견본**: 효과를 고르면 그 효과를 렌파이에서 찍은 짧은 영상이 나와요. 문장은 예시예요.
  - 한 자씩 타이핑하듯: 효과 없음에 글자/초만 적기 (예: 30)
  - 한 번에 나온 뒤 흔들림: 글자/초 비움, 효과 `떨림`

## 7-1. 효과 관리 ([효과] 화면)

툴바 왼쪽에서 **[효과]**를 누르면 글자 효과(대사 글자가 나오는 모양)와 그림 효과(배경, 캐릭터가 나타나는 모양)를 한곳에서 봐요. **[대본 편집]**을 누르면 돌아가요.

- **[셰이더] 칸**: 위의 [글자 효과 | 그림 효과 | 셰이더]에서 셰이더를 누르면 화면 전체에 씌우는 셰이더(상자와 label의 ◐ 셰이더에서 고르는 것) 목록이 나와요. 체크를 끄면 고르는 목록에서만 빠지고(이미 건 상자는 그대로 돌아요), 오른쪽에는 **샘플**(게임과 같은 셰이더 코드로 샘플 그림에 씌운 모습, [고르기]로 내 그림도 돼요)과 **세부 값 막대**, 쓰인 곳이 보여요. 막대로 맞춘 값은 구경용이라 저장하지 않아요. [보기]를 누르면 그 상자의 셰이더 칸으로 가요. 아스키는 게임이 글자 그림을 만들어 넣어야 해서 앱에서는 샘플을 볼 수 없어요.
- **왼쪽 목록**: 위의 [글자 효과 | 그림 효과]로 바꾸고, 찾기 칸에 이름을 적어 걸러요. 줄마다 한글 이름, 영어 이름, 대본에서 쓴 줄 수, 어디 것인지(렌파이 / 기본 / 프로젝트 / 모음)가 보여요.
- **켜기/끄기**: 줄 앞의 체크를 끄면 그 효과가 [대본 편집]과 게임 안 GUI 편집기의 고르는 목록에서만 빠져요. 이미 쓴 대사는 그대로 돌아요. 목록이 길 때 안 쓰는 효과를 감추는 데 써요.
- **넣기**: "효과 모음 (아직 안 넣은 것)"의 [넣기]를 누르면 그 효과 파일이 게임의 `game/ui_kit/effects` 폴더에 들어가고, 바로 [대본 편집] 목록에 나와요. 게임은 껐다 켜야 반영돼요. 모음에는 그림 효과 셋(`slide` 옆으로 밀기, `mosaic` 모자이크로 바뀌기, `blinds` 가로 블라인드)이 들어 있어요.
- **빼기**: 프로젝트 효과의 [빼기]를 누르면 그 효과를 대본 몇 줄에서 쓰는지 먼저 보여 줘요. 쓰고 있으면 [다른 효과로 바꾸고 빼기]로 그 줄들을 다른 효과로 바꾸거나, [그냥 빼기]를 골라요(그냥 빼면 그 줄은 게임에서 오류가 나요). 뺀 파일은 프로젝트 폴더의 `ui_kit_backup/effects`에 남아요. 기본 효과는 뺄 수 없고 끄기만 돼요.
- **파일 넣기**: 가지고 있는 `.glsl` 효과 파일을 골라 넣어요. 형식이 틀리면 넣지 않고 이유를 알려 줘요.
- **새 효과 요청문 복사**: 클로드에게 새 효과를 부탁할 때 같이 줄 글을 복사해요. 만들고 싶은 모양을 덧붙여서 주면 돼요. 앱이 밖으로 보내는 것은 없어요.
- **오른쪽 샘플**: 고른 글자 효과가 샘플 글로 돌아요. 샘플 글을 바꿀 수 있고, 칸을 누르거나 [다시 보기]로 다시 봐요. **세부 값** 막대를 움직이면 바로 다시 돌아요. 여기서 맞춘 값은 저장하지 않아요(값은 [대본 편집]의 대사 줄마다 정해요). 아직 넣지 않은 모음의 효과도 미리 돌려 볼 수 있어요.
- **그림 효과 샘플**: 고른 그림 효과가 "앞 그림"에서 "새 그림"으로 바뀌는 모습으로 돌아요(게임과 같은 셰이더 코드로 그려요). [고르기]로 가진 그림 파일을 새 그림 자리에 넣어 볼 수 있어요(저장하지 않아요). 막대에는 걸리는 시간도 있어요. **원고에 적는 법** 줄에 지금 맞춘 값이 `with img_fx.use("bands", 1.4, count=10)`처럼 나오니, 직접 명령 줄에 쓰려면 [복사]해요. 배경·보이기·숨기기 줄에서는 "나타나는 방식"에서 그림 효과를 고른 뒤 옆의 **[세부 값]**을 눌러 걸리는 시간과 값을 막대로 정해요(그 줄에만 적용돼요).
- **쓰인 곳**: 그 효과를 쓴 줄이 나오고, [보기]를 누르면 [대본 편집]의 그 상자로 가요.
- 렌파이 폴더(pygaki 플러그인이 있는 게임)를 연결하지 않았으면 구경만 할 수 있어요. 넣기, 빼기, 끄기는 연결한 뒤에 돼요.

## 8. 검사와 내보내기

- **검사** 탭: 연결 안 된 선, 빈 대사, 잘못된 이름처럼 렌파이에서 문제가 될 것들을 보여 줘요. 항목을 누르면 그 상자로 가요.
- **스크립트** 탭: 내보낼 `.rpy`를 미리 보고 복사할 수 있어요.
- **[.rpy 내보내기]**: 저장 위치로 게임 폴더의 **`game/` 폴더**를 고르세요. 파일 이름은 `script_flow.rpy`를 추천해요. 기존 `script.rpy`와 겹치지 않게 하려는 거예요.
- 한 번 내보낸 뒤에는 **Ctrl+E**(또는 [같은 곳에 다시])로 바로 덮어써요.
- 렌파이를 켜 둔 상태에서 **Shift+R**을 누르면 바뀐 스크립트를 다시 불러와요.
- **자동 내보내기** (렌파이 폴더를 연결했을 때, pygaki 플러그인 ui_kit 4.2부터): 대본을 고치고 잠깐 멈추면 Ctrl+E를 누르지 않아도 `script_flow.rpy`가 저절로 써지고, 개발 모드로 켜 둔 게임이 저절로 다시 불러와요. 왼쪽 [검사] 카드에 오류가 있으면 고칠 때까지 내보내지 않아요.
- **[게임 줄 따라가기]** (툴바): 켜 두면 다시 불러온 게임이 지금 쓰는 줄로 가요(지나온 줄이면 되감고, 아니면 그 줄까지 건너뛰어요). 여러 곳을 고친 뒤 처음부터 훑어보고 싶으면 꺼 두세요. 끄면 게임은 있던 자리에 그대로 있어요.

> **주의**: 내보낸 `.rpy`를 VSCode에서 직접 고치면, 다음 내보내기 때 덮어써져요. 대본은 항상 이 도구에서 고치세요.

### 대사 안의 특수문자
- `[`는 자동으로 글자 그대로 나오게 바꿔 줘요(`[[`).
- `{b}굵게{/b}` 같은 렌파이 텍스트 태그는 그대로 쓸 수 있어요(태그 상자로 넣어도 돼요). 끄려면 왼쪽 **설정**에서 바꿔요.
- 태그 짝이 안 맞으면 왼쪽 [검사] 카드에 떠요. 여는 태그 없이 `{/b}`만 있으면 렌파이가 멈춰서 오류, 닫지 않은 태그와 렌파이가 모르는 태그는 경고예요.
- `%`는 그대로 두면 렌파이가 멈춰요. 새 대본은 자동으로 `%%`로 바꿔요. 예전 대본에서 왼쪽 [검사] 카드에 `%` 오류가 뜨면 **설정 → % 를 글자 그대로**를 켜세요.

## 9. 저장과 백업 (중요)

| 방법 | 설명 |
|---|---|
| **자동 저장** | 고칠 때마다 브라우저 안에 저장돼요. 탭을 닫아도 다시 열면 이어서 쓸 수 있어요. |
| **[버전 저장]** | 메모를 붙여 그 시점을 남겨요. **[버전 목록]**에서 되돌릴 수 있어요. 열기, 새로, 복원 전에는 자동으로 백업돼요. |
| **자동 저장본** | 바뀐 것이 있으면 5분마다 [버전 목록]에 남아요. 최근 30개만 둬요. |
| **[저장] (Ctrl+S)** | `.flow.json` 파일로 저장해요. **이게 진짜 백업이에요.** |

- 자동 저장과 버전은 **그 브라우저 안에만** 있어요. 브라우저 데이터를 지우거나, 다른 브라우저나 컴퓨터로 옮기면 사라져요.
- 그래서 중요한 시점에는 꼭 **Ctrl+S**로 파일을 저장하고, 그 파일을 **Dropbox 같은 동기화 폴더**에 두세요.
- 크롬/엣지에서는 한 번 저장한 뒤 Ctrl+S를 누르면 같은 파일에 바로 덮어써요.
- 다른 컴퓨터나 브라우저에서 이어 쓰려면 **[열기]**로 `.flow.json`을 불러와요.
- 왼쪽 "렌파이 프로젝트 정보"의 파일 저장 줄에 뜨는 **주황색 ●**는 "파일로 저장하지 않은 변경이 있음"이라는 뜻이에요. 자동 저장한 때도 그 아래에 보여요.

## 9-1. pygaki 플러그인과 함께 쓰기

[pygaki 플러그인](https://github.com/halftomatodev/pygaki/tree/main/showpy)는 게임을 실행한 채 마우스로 화면을 고치는 렌파이 플러그인이에요. **글과 글자 모양은 여기서, 그림과 영상, 소리, 위치, 화면 효과는 렌파이에서** 맞출 수 있어요.

왼쪽 "렌파이 프로젝트 정보"의 **[렌파이 프로젝트 연결]**을 누르고 프로젝트 폴더를 고르면 끝이에요. 연결한 뒤에는 위쪽 줄에 [폴더 바꾸기] [다시 읽기] [끊기]가 생겨요.

- `game` 폴더를 찾아서 연결하고, pygaki 플러그인이 있으면 연결을 켜요.
- `game/script_flow.rpy`를 바로 만들어요. 렌파이에서 실행하면 첫 상자부터 시작해요. `script.rpy`는 그대로 둬도 돼요.
- 그다음부터는 **Ctrl+E**로 내보내요.
- 렌파이 편집기에서 그림이나 소리를 넣고 이 창으로 돌아오면, 넣은 줄이 대본에 나타나요.
- **대본 파일도 그 프로젝트 폴더에 저장돼요**: `프로젝트이름.flow.json`. Ctrl+S, Ctrl+E를 누를 때 써져요. 폴더에 대본 파일이 이미 있으면 그 대본을 열지, 지금 대본을 쓸지 물어요.
- 브라우저를 다시 열면 권한을 한 번 다시 허용해야 해요.
- `game` 폴더를 바로 고르면 대본 파일은 폴더에 저장하지 않아요. 앱에서 이어 쓰려면 game 위의 프로젝트 폴더를 고르세요.
- 캐릭터 id를 `e`로 쓰면 `script.rpy`의 `define e`와 겹쳐요. 다른 id를 쓰세요.

연결을 켜면 달라지는 점:
- 대사와 이름의 **위치**, 줄마다 바꾸는 **화면 효과**는 렌파이 편집기(Shift+M)의 대사 탭에서 정해요. 저장하고 이 창으로 돌아오면 글자 효과 칸에 값이 보이고, 다시 내보내도 남아요.
- 연출 줄 칸에 폴더의 파일 이름이 추천 목록으로 나와요.
- 그림 위치 칸이 사라져요. 위치는 렌파이 편집기에서 끌어서 정해요.
- **다른 대본의 원고는 덮어쓰지 않아요**: 창을 열고 처음 내보낼 때 폴더의 `script_flow.rpy`에 지금 대본에 없는 상자가 많으면, 자동 내보내기는 멈추고 아래쪽에 알려요. 이 대본으로 덮어쓰려면 Ctrl+E를 누르고 [확인]을 골라요. 덮어쓰기 전 원고는 `script_flow.rpy.bak`으로 남아요.
- pygaki 플러그인이 없는 게임에서는 이 연결이 꺼진 채로 내보내요. 글자 모양, 속도, 등장 효과는 그래도 적용돼요.

자세한 순서와 문제 해결은 [pygaki 플러그인 커스텀 가이드](https://github.com/halftomatodev/pygaki/blob/main/showpy/docs/CUSTOM_GUIDE.md)를 보세요.

## 9-2. 데스크톱 앱 (렌파이 묶음)

pygaki 묶음의 렌파이 런처에서 프로젝트를 고르고 **[pygaki로 편집]**를 누르면 PyKaki가 앱으로 열려요.

- 그 프로젝트의 대본이 바로 열려요. 폴더 연결, 권한 창이 없어요.
- 대본은 프로젝트 폴더 맨 위의 `프로젝트이름.flow.json`에 **고칠 때마다 자동 저장**돼요. 이 파일이 대본의 원본이에요.
- Ctrl+E로 내보내면 `game/script_flow.rpy`에 바로 써져요.
- 게임 안 GUI 편집기에서 넣은 그림, 소리 줄은 저장되자마자 대본에 받아 적혀요.
- 위쪽 줄의 [폴더 열기]는 프로젝트 폴더를, [다른 프로젝트]는 다른 프로젝트를 새 창으로 열어요. [다시 읽기]는 폴더의 그림·소리와 GUI 편집기가 넣은 줄을 다시 읽어요.
- [열기]로 다른 `.flow.json`을 고르면 두 대본(상자 수, 줄 수, 저장한 때)을 보여 주고, [확인]을 누르면 그 내용을 이 프로젝트 대본으로 가져와요. [새로]는 이 프로젝트 대본을 비워요(지금 대본은 버전 목록에 백업돼요).
- 프로젝트 폴더에 `.flow.json`이 여러 개면 처음 열 때 어느 것을 열지 골라요. 다음부터는 고른 파일을 열고, 왼쪽 "렌파이 프로젝트 정보"의 [다른 대본 파일 고르기]로 다시 골라요.

### 예전 웹 버전에서 쓴 대본
웹 버전은 없앴어요. 웹에서 Ctrl+S로 저장한 `.flow.json`이 있으면 앱의 [열기]로 가져와요. 대본 파일에는 어느 판에서 저장했는지가 남고, 앱보다 새 판에서 쓴 대본이면 왼쪽 칸에 "더 새 판" 경고가 떠요.

### [GUI 편집] 화면 (게임과 나란히)

툴바 왼쪽의 **[대본 편집 | GUI 편집 | 효과 | 셰이더]**에서 **GUI 편집**을 누르면 게임 화면 꾸미기로 바뀌어요. 렌파이 런처에서 [프로젝트 실행]으로 게임을 켜 두면(개발 모드) 저절로 이어지고, 위쪽 게임 연결 단추가 옅은 파란색이 돼요. 맨 위 한 줄에 짧은 안내가 있어요. 게임 창과 앱 창을 나란히 놓고 써요.

- **가운데**: 게임이 지금 어느 화면에 있고 원고 몇 번째 줄을 실행 중인지, 그 앞뒤 줄을 보여줘요. PyKaki로 쓴 대본이면 [PyKaki 상자: …]를 눌러 그 상자로 가요. 원고의 줄을 누르면 게임이 그 줄로 가요(지나온 줄이면 되감기, 아니면 게임을 다시 시작해서 그 줄까지 건너뜀). [표시 숨기기: 켬/끔]으로 `# @l:` 같은 표시를 화면에서만 가려요(줄 번호와 원고 파일은 그대로예요). 게임의 pygaki 플러그인이 새 판(`ui_kit` 4.5부터)이면 표시가 줄마다 윗줄에 따로 있지 않고 `"대사"  # @l:l1`처럼 줄 끝에 붙어서 원고가 훨씬 짧아요. 예전 플러그인을 쓰는 게임에는 전처럼 내보내요.
- **왼쪽**: 고칠 것 목록을 묶음 카드로: 스플래시(로고, 경고, 조작 방법과 직접 만든 페이지가 하나씩. 누르면 게임 안 편집기도 그 페이지로) / 타이틀 메뉴(타이틀 메뉴, 타이틀 셰이더, 셰이더 기본 값) / 게임 내 메뉴(ESC 메뉴, 게임 내 메뉴 셰이더) / 확인 창, UI 글 / **게임 처음 값**(대사 상자, 선택지, 그림·영상 배치, 커서·클릭 대기·대사 소리). 상자마다 바꾸는 것은 [대본 편집]에서 해요(대사·선택지 위치는 [위치 옮기기], 그림·소리는 상자의 배경·그림·소리 카드, 대사 소리·속도·커서·클릭 대기는 ◐ 셰이더 칸). 오른쪽 칸도 왼쪽처럼 카드예요(저장과 GUI 편집기 / 고치는 칸).
- **오른쪽**: 고르는 칸.
  - **타이틀 메뉴, 게임 내 메뉴**: 맨 위 **배경**에서 game 폴더의 그림이나 webm 영상을 골라요. 안 고르면 타이틀은 검은 화면, ESC 메뉴는 투명(뒤 게임 화면이 보임)이에요. 목록 맨 아래 **제목, 부제**를 고르면 글 내용을 적을 수 있어요(비우면 안 보여요). 항목이나 글자를 고르고 위치, 회전, 기울기, 확대, 글자 크기, 색, 글꼴, **글자 효과**(대사 등장 효과와 같은 목록)를 바꿔요. 게임 화면에서 고른 글자 위의 분홍 네모를 끌면 돌아가요(Shift: 15도씩). (pygaki 플러그인 4.20, ui_kit 3.19 이상) 게임 화면에서 항목을 끌어도 숫자가 같이 바뀌어요. [평소/선택됐을 때], [이 항목만/모든 항목 공통]도 여기서 골라요. 게임이 그 화면에 없으면 [타이틀로 가기], [ESC 메뉴 열기]가 나와요.
  - **커서, 클릭 대기(CTC), 대사 소리**: 텍스트 속도, 대사 소리와 음량([들어보기]는 게임에서 소리가 나요), 클릭 대기 표시와 커서의 켬/끔, 그림 12칸, 1프레임마다/2프레임마다, 커서 방식과 클릭 기준점, 퀵메뉴를 여기서 바꿔요. 칸을 누르면 아래에 게임 폴더의 그림이 나오고, 그림을 누르면 그 칸에 들어가고 다음 칸으로 넘어가요. 맨 아래 미리보기에서 글자 속도와 그림이 도는 모양을 봐요. 커서나 클릭 대기 표시를 켜고 끈 것은 저장하면 게임이 다시 불러온 뒤 보여요. 그림은 커서는 `game/gui/cursor/`, 클릭 대기 표시는 `game/gui/ctc/`에 넣어요(1번부터 순서대로, 64×64 권장. pygaki 새 프로젝트에는 샘플이 들어 있어요). 그림 칸은 바둑판 바탕이라 흰 그림도 보여요. **커서와 셰이더**: 커서가 셰이더를 받을지(1번, 2번 다 받음 / 2번만 받음 / 셰이더 안 받음) 고르고, 셰이더 칸처럼 줄을 골라 [여기에서부터 적용]해요. (pygaki 플러그인 ui_kit 3.15 이상, 커서와 셰이더는 4.22 이상)
  - **타이틀 셰이더, 게임 내 메뉴 셰이더**: 그 화면에만 걸리는 셰이더 1번, 2번을 이 게임의 셰이더(기본, 아스키, VHS, 일렁임 …) 중에서 골라요. 두 자리가 겹쳐요. "전부 셰이더 적용 취소"는 둘 다 기본으로. 게임 내 메뉴 셰이더는 ESC 메뉴를 연 채로 골라요(게임 중이면 [ESC 메뉴 열기]가 나와요).
  - **셰이더 기본 값**: 칸을 열면 바로 1번, 2번이에요. 고르면 게임 화면에 바로 보이고, 고른 효과의 세부 속성(글자 빼기, 프리셋, 막대)이 그 줄 바로 아래에 나와요(줄 끝 [세부 속성 접기]). 여기서는 셰이더의 **모양**을 게임 화면을 보면서 고치고 [저장]해요. **어느 장면에 걸지는 [대본 편집]에서** 상자나 label 오른쪽 위의 ◐ 셰이더로 정해요(3장 "셰이더"). 게임을 시작할 때 셰이더는 맨 아래 [처음 상태 펴기]. 패널의 줄 목록과 [여기에서부터 적용]은 게임 안 편집기와 같은 것이고, PyKaki로 쓰는 대본에서는 상자 셰이더를 쓰는 쪽이 쉬워요(둘을 섞으면 상자 첫 줄의 셰이더가 먼저 걸려요). 줄기표는 앱에서는 펴지 않아요(게임 창의 편집기에서 G).
  - **대사, 선택지, 그림 배치, 종료 메시지와 버튼 글**: 게임 안 편집기 패널과 똑같은 버튼, 막대, 입력칸이 여기 나와요. 글꼴, 색, 그림 고르기 창도 칸 맨 위에 떠요. 게임 화면에서 끌어서 옮기는 것과 단축키(R 다시 보기 같은)는 게임 창에서 해요. 타이틀에 있을 때 대사, 그림 칸을 고르면 [게임 시작]이, 게임 중에 타이틀 셰이더를 고르면 [타이틀로 가기]가 나와요. (pygaki 플러그인 ui_kit 3.16 이상. 예전 판이면 "게임 안" 표시가 붙고 게임 안 패널로 열려요)
  - **스플래시**: 페이지를 고르고 바탕색, 바탕·로고 그림, 제목·본문 글자, 위치, 넘어가는 때, 시간을 바꿔요. [이 페이지 보기]를 누르면 게임 창에 그 페이지가 떠요(클릭하면 닫힘). 저장하면 `splash/splash_layout.rpy`에 적혀요. 제목, 본문 문장은 `splash/splash_config.rpy`에서 고쳐요. (pygaki 플러그인 4.18, splash 1.2 이상) 맨 위 "게임 켤 때" [보이기] [안 보이기]로 페이지를 넣고 빼고, 그 아래 줄에서 지금 게임을 켤 때 나오는지와 안 나오는 까닭을 봐요. [다시 보이게]는 "다음부터 보지 않기"와 본 기록을 지워요. (splash 2.1 이상)
- **[저장]**(또는 Ctrl+S)은 게임 안 편집기의 저장과 같아요. 값은 게임 폴더의 `*_layout.rpy`나 원고에 저장돼요.
- 앱과 이어져 있는 동안 게임 창의 GUI 편집기 패널은 숨어요. 게임 창에도 보이게 하려면 위쪽 [게임 창의 GUI 편집기: 숨김] 버튼을 누르거나 **F9**를 눌러요(앱 어디서나, 게임 창에서 편집기가 열려 있을 때도). 다시 누르면 숨어요. 앱이 기억했다가 다음에 게임에 붙을 때도 그대로예요. 게임 창에 보이는 동안은 고치는 칸이 게임 창으로 가요. 단축키는 설정 → 단축키에서 바꿔요.
  - **글 칸**: 긴 글 칸(스플래시 글, UI 글 등)은 패널 폭 가득 세 줄로 나와요. 칸 옆 [넓게]/[좁게]로 칸마다 바꿀 수 있고, 앱이 기억해요. Enter 끝내기, Esc 취소, 줄바꿈은 `\n`.
  - **확인 창, UI 글**: 종료 확인 창("종료하겠습니까?"), [네] [아니오], 퀵메뉴·메뉴 버튼 글자를 바꿔요. 확인 창은 [이 창 보기]로 바로 보고, 버튼 글자는 저장하면 게임이 다시 불러온 뒤 바뀌어요. (pygaki 플러그인 ui_kit 3.23 이상)
  - **그림, 영상 배치**: [images 폴더 열기], 그림 고르기 창의 폴더 열기 버튼으로 탐색기를 열어 파일을 넣어요.
- **편집 중에는 게임이 안 넘어가요**: 칸을 고르면 게임 안 편집기가 열리고, 그동안 게임 화면의 클릭과 키는 편집기로 가요(끌어서 옮기기용). 게임 화면 위에 "편집 중 | Esc로 닫기"가 보이면 그 상태예요. 게임을 진행하려면 게임 창에서 Esc를 누르거나 앱의 [편집기 닫기]를 눌러요. [대본] 화면으로 가면 저절로 닫혀요. 커서/대사 소리 칸은 편집기를 열지 않아요.
- pygaki 플러그인(ui_kit) 3.14 이상이 들어 있는 게임에서만 이어져요.

## 10. 집중 모드와 환경 설정

### 집중 모드
**Ctrl+\\** (한국어 자판에서는 **Ctrl+₩**, 또는 툴바의 **[집중]**)를 누르면 툴바, 왼쪽, 오른쪽, 미니맵이 모두 숨고 캔버스만 남아요. 한 번 더 누르면 다시 나와요.

- 상자를 더블클릭해서 글을 쓰는 동안에는 **밑줄 모양 커서**가 깜박여요. 화면이 비어 있어도 지금 쓰는 중인지, 어디에 쓰는지 알 수 있어요.
- 집중 모드에서 상자 안에 글을 쓰는 동안에는 **커서가 있는 줄만 또렷하고**, 같은 상자의 다른 줄은 흐리게, 다른 상자와 선은 더 흐리게 보여요. 흐린 상자에 마우스를 올리면 잠깐 또렷해져요. 흐린 정도는 [설정]에서 골라요.
- 집중 모드에서도 단축키(저장, 새 줄 등)는 그대로 돼요.

### 환경 설정
툴바 오른쪽 **[설정]**에서 바꿔요. 이 설정은 그 브라우저에만 저장되고 대본 파일에는 들어가지 않아요.

- **텍스트 색**(설정 맨 위): 글자색을 골라요. 어느 테마에서든 상자와 label 위 글자까지 모두 그 색이 돼요. **[자동 (테마 색)]**을 누르면 테마가 바탕 밝기에 맞춰 정하는 색으로 돌아가요.
- **화면 테마**: **사과 스타일**(처음 값), **사과 컬러풀**, **밝게**, **어둡게**, **1비트**, **1비트 흰 바탕**, **직접 고르기** 중에서 골라요.
  - **사과 스타일**: Apple의 디자인을 참고한 테마예요. 흰색 톤에 파랑·회색 강조색. 경계선 없이 둥근 흰 카드(상자)와 바탕색 차이로만 구분하고, label 배경은 왼쪽 label 목록의 색으로 칠해요.
  - **사과 컬러풀**: 사과 스타일에 label 색을 또렷하게 입혀요. label마다 바탕색이 달라서 상자가 어느 장면인지 한눈에 보여요.
  - **밝게 / 어둡게**: **바탕 색**과 **끝 색** 두 가지만 고르면, 두 색 사이를 이어서 바탕 → label 배경 → 상자 순서로 자동으로 칠해요. 이 두 테마에서는 상자를 따로 칠할 수 없고 모두 그라데이션 색을 따라요. 처음 값은 밝게가 흰색 → 회색, 어둡게가 검정 → 보라예요. [처음 색]으로 되돌려요.
  - **1비트**: 모든 것이 같은 바탕색이고 경계선만 흰색(흰 바탕은 검은색) 선으로 그려요. 색을 칠하지 않아요.
  - **직접 고르기**: 바탕, 면, 상자 색을 하나씩 골라요. (글자색은 맨 위 텍스트 색에서)
- **label 경계선**(0~6px, 처음 3px): 같은 label 상자를 묶는 선의 굵기예요. 0이면 선이 안 보여요.
- **글꼴**: **Pretendard 400**(처음 값), **Pretendard 500**, **Pretendard 600**, **Neo둥근모** 중에서 골라요. Pretendard는 숫자가 클수록 굵어요. 화면 전체에 적용되고, 사이트 파일 안에 들어 있어서 인터넷이 없어도 보여요.
- **집중 모드 흐림**: 끄기, 약하게, 보통, 강하게
- **단축키**: 바꿀 동작의 키 칸을 누르고 새 키를 눌러요. Esc를 누르면 취소돼요.
  - 글자를 칠 때 겹치지 않게 Ctrl이나 Alt를 함께 눌러야 해요. F1~F12는 혼자 써도 돼요.
  - 다른 동작에 쓰던 키를 고르면 그쪽 단축키는 비워져요.
  - **[기본값으로]**를 누르면 처음 키로 돌아가요.
- **[모든 설정을 처음 값으로]**(설정 창 맨 아래): 화면 테마, 글꼴, 집중 모드 흐림, 단축키를 모두 처음 값으로 되돌려요. 대본과 상자 색은 그대로예요.

## 11. 단축키 (기본값)

| 키 | 동작 |
|---|---|
| 상자 더블클릭 | 상자 안에서 편집 |
| 빈 곳 더블클릭 | 새 상자 |
| Ctrl+\\ | 집중 모드 켜기/끄기 |
| Ctrl+Enter | (편집 중) 같은 화자로 새 줄 |
| Ctrl+Shift+Enter | (편집 중) 다음 상자로 이어 쓰기 (없으면 새 상자) |
| Alt+Enter | (편집 중) 다음 흐름 창을 키보드로 열기/닫기 (↑↓ 고르기, Enter 정하기, ← 뒤로, Esc 닫기) |
| Ctrl+B / Ctrl+I / Ctrl+U | (대사 글 칸에서) 고른 글 굵게 / 기울임 / 밑줄 태그 |
| Esc | 상자 편집 끝 |
| Delete | 고른 상자/선 삭제 |
| Shift+드래그 | 여러 상자 선택 |
| Ctrl+S / Ctrl+Shift+S | 저장 / 다른 이름으로 저장 |
| Ctrl+E | `.rpy` 같은 곳에 다시 내보내기 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Alt+N | 새 상자 |

Esc, Delete, 더블클릭 말고는 [설정]에서 바꿀 수 있어요.

## 12. 자주 묻는 것

- **상자에서 편집이 안 돼요** → Ctrl+F5로 새로고침해 보세요. 예전 버전이 남아 있을 수 있어요.
- **렌파이에서 오류가 나요** → 먼저 **검사** 탭의 ⛔ 항목을 확인하세요. label 이름이나 캐릭터 id에 한글이나 공백이 있으면 오류가 나요.
- **다른 사람에게 공유해도 되나요?** → 사이트 주소를 보내면 돼요. 각자 쓴 대본은 각자 브라우저와 파일에만 있어서 서로 보이지 않아요. 대본을 주고받으려면 `.flow.json` 파일을 보내세요.
