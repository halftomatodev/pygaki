# はじめに

## pygaki でできること

Ren'Py のコードを覚えなくてもゲームを作れるようにする、ツール一式です。

* **pygaki**(pygaki アプリの [スクリプト編集]):ボックスと線でシナリオを書くエディターです。セリフ、選択肢、背景、画像、サウンド、画面シェーダーを決めると、Ren'Py のスクリプト(`game/script_flow.rpy`)に書き出します。
* **pygaki プラグイン**:Ren'Py ゲームの `game/` フォルダーに入れる 4 つのプラグイン(`ui_kit`、`screen_fx`、`hotkeys`、`splash`)です。タイトルメニュー、選択肢、セリフのスタイルと登場エフェクト、画面全体のシェーダー、スプラッシュ画面を変えます。ゲームを動かしたままマウスで直せる**ゲーム内編集画面**も入っています。
* **pygaki アプリ**:上の 6 つのタブに分かれています。[スクリプト編集] はシナリオを書く、[GUI編集] は動いているゲームとつながってゲーム内編集画面をアプリから操作、[画面] は選ぶ画面と HUD を作る、[エフェクト]・[シェーダー] はエフェクトの見本と非表示、[フォント] はゲームのフォント管理です。
* **pygaki パック**:Ren'Py SDK + プラグインのテンプレート + ランチャーのボタン + pygaki アプリを、Windows 用のフォルダー 1 つにまとめたものです。

画面の言語:pygaki アプリの右上の言語ボタンで、スクリプト編集の画面とアプリの [ヘルプ] を日本語・英語にできます。ゲーム内編集画面はパネルの [言語] ボタンで、ランチャーに加わる pygaki のボタンはランチャーの言語設定で日本語・英語になります。この案内書では、韓国語の画面で見たときのボタン名に訳を添えています。

| やりたいこと | どこで |
| --- | --- |
| セリフ、選択肢、物語の流れを書く | pygaki [スクリプト編集] |
| フラグ(変数)と条件で分かれる物語 | pygaki 右の欄のいちばん上のフラグカード、ボックスの次の流れ「条件分岐」(流れバブル、Alt+→) |
| セリフの文字サイズ、フォント、色、速度、登場エフェクト | pygaki セリフ行の文字エフェクトカード、テキスト欄のタグボックス |
| ボックス・場面ごとの画面シェーダー、トランジション、セリフ音、カーソル・クリック待ち | pygaki ボックスや label の ◐ シェーダー |
| 画像、webm 動画、BGM、効果音を入れる | pygaki ボックスの背景 / 画像・動画 / 効果音・BGM カード |
| セリフ・選択肢・画像の位置 | 行の [位置を移動] → ゲーム画面でドラッグ → [保存] |
| タイトルメニュー、カーソルなどゲーム全体の見た目 | pygaki アプリ [GUI編集](ゲーム内編集画面と同じ) |
| エフェクト・シェーダーを見る、一覧から隠す | pygaki アプリ [エフェクト]、[シェーダー] |
| 設定ファイルの値でもっと細かく | この案内書の「プラグイン カスタムガイド」の章 |

## ダウンロードと最初のプロジェクト

1. ダウンロード [github.com/halftomatodev/pygaki/releases/latest](https://github.com/halftomatodev/pygaki/releases/latest) から pygaki パックの zip を受け取り、好きなフォルダーに展開します(リポジトリ:[github.com/halftomatodev/pygaki](https://github.com/halftomatodev/pygaki))。
2. `renpy.exe` でランチャーを起動します。
3. ランチャー左下の **[+ Create New Project]**(新しいプロジェクトを作成)で **Pygaki** を選び、名前と解像度を決めます。解像度はレトロ 3 つ(PC-98 640x400、Y2K 800x600、Millennial 1024x768)と高解像度 2 つ(1280x720、1920x1080)、ユーザー定義があります。レトロとユーザー定義は、ウィンドウに収まるいちばん大きい整数倍で拡大し、選んだ解像度のピクセルで描きます(ピクセルパーフェクト、プロジェクトの `game/pixel_perfect.rpy`)。高さが 720 より小さいと、文字の大きさと pygaki の設定値をその解像度に合わせて作り、高さ 600 未満(PC-98 など)には韓国語ピクセルフォント Galmuri を入れます。
   * Pygaki テンプレートは韓国語のプロジェクトとして作られます(サンプルのスクリプト、共通の文言)。ゲームの言語は Ren'Py の設定(`game/options.rpy`、`game/tl/`)で変えます。
4. 左の一覧でプロジェクトを選んで **[pygaki로 편집]**(pygaki で編集)を押すと、pygaki アプリがそのプロジェクトを開きます。シナリオはプロジェクトフォルダーの `プロジェクト名.flow.json` に自動で保存されます。
5. アプリ上のタブ列の右にある **[Ren'Pyで実行]** でゲームを起動して確認します。ランチャーの [Launch Project] で起動しても、アプリがゲームにつながります(タブの横のボタンが薄い青の「● ゲームと接続中」に変わります)。

初めてアプリを起動したとき、Windows が「PC が保護されました」画面を出したら [詳細情報] → [実行] を押します(アプリに署名がないためです)。この案内書は、ランチャーの **[pygaki 안내서]**(pygaki 案内書)ボタンや、パックの `pygaki/pygaki_guide_ja.html` からいつでも開けます。

## プラグインに入っているもの

Ren'Py の標準テンプレートの `screens.rpy` を直さず、フォルダーを `game/` に入れるだけで画面を変える 4 つのプラグインです。Ren'Py 8.6.1 で試しています(8.5.3 でも動きます)。必要なものだけ選んで入れてもかまいません(互いになくても動きます)。

| フォルダー | すること | 直すファイル |
| --- | --- | --- |
| `ui_kit` | タイトルメニュー、選択肢、カーソル・クリック待ち表示・セリフ音・テキスト速度・クイックメニュー、セリフ 1 行ごとのスタイル・名前の位置・速度・登場エフェクト・ルビ、画像・動画の配置、エフェクトフォルダー(`ui_kit/effects/`)、ゲーム内編集画面 | `title_menu_config.rpy`、`choice_menu_config.rpy`、`custom_ui_config.rpy`、`say_style_config.rpy`、`stage_config.rpy` |
| `screen_fx` | 画面全体のシェーダー。1 番(基本エフェクト)の上に 2 番(オーバーレイ)を重ねる。場面ごとの切り替えとトランジション、文字の除外、タイトルのゆらぎ | `screen_fx_config.rpy`、シェーダーごとの `<名前>_config.rpy` |
| `hotkeys` | ショートカットキーの追加・解除、操作方法画面の説明 | `hotkeys_config.rpy` |
| `splash` | タイトルの前に出るロゴ・注意・操作方法のページ | `splash_config.rpy` |

## 入れたときの初期状態

* `ui_kit`:タイトルは左側に少しずつ傾いた例の配置、選択肢は Ren'Py 標準と同じ形(ふわっと現れる)、カーソルなどはオフ、セリフのスタイルはオン、画像と動画はオン(`bg` がいちばん後ろ、`movies/` の動画を登録)。
* `screen_fx`:基本エフェクトなし、VHS オーバーレイはオン、タイトルにゆらぎシェーダー。pygaki パックで作った新しいプロジェクトは最初からオーバーレイがオフです。オンにするには `game/screen_fx/screen_fx_config.rpy` の `define screen_fx.overlay = False` を `True` に変えます。
* `hotkeys`:変わるものはありません。
* `splash`:オン。例のページが 3 つ(作者名、注意、操作方法)出ます。

機能ごとに設定ファイルのスイッチ(`enabled`)で個別にオフにでき、オフにすると Ren'Py 標準とまったく同じに見えます。

## プラグインだけを入れる

パックを使わず、既存の Ren'Py プロジェクトに入れる場合です。

1. リポジトリの `showpy/game/` から使いたいフォルダーを、プロジェクトの `game/` フォルダーの中にコピーします。古い版があれば、先にそのフォルダーを `.rpyc` ごと消します。**同じプラグインを 2 つ入れると** "given a default a second time" のようなエラーになります。
2. 各フォルダーの `*_config.rpy` を直します。エンジンのファイルは直しません。
3. ランチャーで Lint を実行します。

詳しい設定は各フォルダーの `README.md`(韓国語)にあります。`README.md` はゲームを配布用にビルドするとき自動で除かれます。

## 外す・新しい版にする

* 外す:フォルダーを `.rpyc` ファイルごと丸ごと消すと Ren'Py 標準に戻ります。`.rpyc` が残っていると、消したコードが動き続けます。
* 新しい版に:新しいパックのランチャーの最初の画面の **[플러그인 올리기]**(プラグインを更新)。左でプロジェクトを選んで押すと「今の版 → 新しい版」を表示し、エンジン・エディターのファイルだけを入れ替えます。自分で直した `*_config.rpy`、エディターで保存した `*_layout.rpy`、非表示リスト `*_off.txt` はそのまま残し(ない設定ファイルだけ新しく入れる)、古い版にしかなかったファイルは片づけ、`.rpyc` を消します。入れ替える前のプラグインはプロジェクトフォルダーの `ui_kit_backup/plugins/日付_時刻/` に残ります。ゲームを閉じてから行います。手作業のときは `ui_kit`、`screen_fx`、`hotkeys`、`splash` フォルダーを丸ごと入れ替えて `.rpyc` を消します(自分で直した `*_config.rpy` とエディターで保存した `*_layout.rpy` は別に取っておいて戻します)。アプリも同じ版にします(新しいアプリで保存したシナリオは、古いアプリで「より新しい版」の警告が出ます)。版ごとの変更点はリポジトリの `showpy/CHANGELOG.md` にあります。
