# ひと目で:文書とファイルの場所

ダウンロードしたパック、作ったゲームのプロジェクト、リポジトリのどこに何があるかをまとめました。「このファイルは消していいか」「自分の作業はどこに保存されるか」が気になったときに見ます。

## 自分の作業が保存される場所

| 何 | 場所 | 知っておくこと |
| --- | --- | --- |
| シナリオ(元データ) | プロジェクトフォルダー直下の `プロジェクト名.flow.json` | 直すたびに自動保存。**これが元データ**なので、バックアップのときは必ず含めます。ゲームの配布版には入りません |
| 書き出したスクリプト | `game/script_flow.rpy` | シナリオから作られる結果物です。書き出し直すと上書きされるので、このファイルを直接直しません |
| 保存版(バージョン一覧) | このパソコンの pygaki アプリの中 | 変更があれば 5 分ごと、書き出すとき、取り込む前に自動で残ります(自動保存版は最近の 30 個)。ほかのパソコンには移りません |
| 画像の位置 | `game/ui_kit/stage_layout.rpy` | 行の [位置を移動] で保存した位置。保存版では元に戻りません |
| ゲーム内編集画面で保存した値 | 各プラグインフォルダーの `*_layout.rpy`(例:`ui_kit/title_menu_layout.rpy`、`screen_fx/screen_fx_layout.rpy`) | 設定ファイル(`*_config.rpy`)の同じ値より優先されます。新しい版にするときは別に取っておいて戻します |
| 自分で直した設定 | 各プラグインフォルダーの `*_config.rpy` | エンジンのファイル(`engine/`、`editor/`)は直しません |
| スクリプトを直す前の元、更新前のプラグイン | プロジェクトフォルダーの `ui_kit_backup/` | ゲーム内編集画面がスクリプトの括弧を変える前に、ランチャーの [플러그인 올리기](プラグインを更新)が入れ替える前に(`plugins/`)残します。開発用なので配布版から除きます |
| ゲームとアプリがやり取りするファイル | `game/showpy_inbox.json`、`game/showpy_live.json`、`game/pykaki_preview.json`、`game/pykaki_goto.json` | 開発中だけできる連携ファイルです。ゲームの配布版には入れません(消してもまたできます) |

ゲームを配布用にビルドするときは、`*.flow.json`、`ui_kit_backup/`、上の連携ファイルを除いてください。各プラグインの `README.md` はビルド時に自動で除かれます。

## ダウンロードしたパックの中

| 場所 | 何 |
| --- | --- |
| `renpy.exe`、`launcher/`、`renpy/`、`lib/` … | Ren'Py SDK そのまま(追加用 zip にはなし) |
| `launcher/game/pygaki_launcher.rpy` | ランチャーの最初の画面の [pygaki로 편집](pygaki で編集)、[pygaki 안내서](pygaki 案内書)、[플러그인 올리기](プラグインを更新)ボタンと、新しいプロジェクト作成の「기본 (Vanilla)」/「Pygaki」の選択。Ren'Py 本来のファイルは直さず、このファイル 1 つだけを足します |
| `pygaki/template/` | Pygaki の新規プロジェクトにのせるプラグインのテンプレート |
| `pygaki/app/pygaki.exe` | pygaki デスクトップアプリ。アプリだけを起動すると、プロジェクトフォルダーを選ぶ画面が出ます |
| `pygaki/pygaki_안내서.html`、`pygaki_guide_ja.html`、`pygaki_guide_en.html` | この案内書(韓国語、日本語、英語) |
| `pygaki/읽어주세요.txt` | 短い使い方(韓国語) |
| `pygaki/LICENSE-pygaki.txt` | pygaki のライセンス(MIT) |
| `pygaki_넣는법.txt` | (追加用のみ)SDK フォルダーへの入れ方、外し方(韓国語) |

追加分を外すには、`launcher/game/pygaki_launcher.rpy`(と `.rpyc`)、`pygaki` フォルダーを消します。

## 新しく作ったゲームプロジェクトの中

| 場所 | 何 |
| --- | --- |
| `プロジェクト名.flow.json` | シナリオ(アプリが保存) |
| `game/script.rpy` | Ren'Py 標準のスクリプト。そのままでかまいません(ゲーム開始がシナリオの最初のボックスにつながる) |
| `game/script_flow.rpy` | pygaki が書き出したスクリプト |
| `game/images/`、`game/movies/`、`game/audio/` | 画像、webm 動画、サウンド。アプリの選択画面に出ます。ファイル名は英字、数字、`_` で |
| `game/gui/cursor/`、`game/gui/ctc/` | カーソルとクリック待ち表示の画像(サンプル入り) |
| `game/ui_kit/` | タイトル・選択肢・セリフ・カーソル・画像配置・ゲーム内編集画面のプラグイン。`effects/` に文字エフェクトと画像トランジションのファイル(`.glsl`) |
| `game/screen_fx/` | 画面シェーダーのプラグイン。シェーダーごとの `<名前>_config.rpy`、一覧から隠す名前は `shaders_off.txt` |
| `game/hotkeys/`、`game/splash/` | ショートカットキー、スプラッシュ |
| `game/tl/None/common.rpym` | Ren'Py の共通の文言(終了確認画面など)の韓国語 |

## リポジトリの中(手を入れたい人向け)

| 場所 | 何 |
| --- | --- |
| `README.md` | リポジトリの紹介 |
| `pykaki/` | pygaki の画面(React + TypeScript)。`src/` がコード |
| `pykaki/app/` | デスクトップアプリ(Electron)。画面は `pykaki/` をビルドしたものをそのまま使います |
| `pykaki/docs/GUIDE.md` | アプリの [ヘルプ](F1)。この案内書の「pygaki でシナリオを書く」の章の元 |
| `pykaki/docs/SPEC.md` | pygaki の構造の説明(手を入れる人向け) |
| `pykaki/public/effects/` | 文字エフェクトの見本動画(この案内書の「エフェクト見本」の章に入る) |
| `pykaki/i18n/` | 画面の言語ボタンの辞書(`strings.tsv`) |
| `showpy/i18n/` | ゲーム内編集画面の辞書にない文字を探す(`extract_editor.py`)。辞書は `showpy/game/ui_kit/editor/editor_lang.tsv` |
| `pykaki/licenses/` | アプリに同梱したフォント・ライブラリのライセンス |
| `showpy/game/` | pygaki プラグインの 4 フォルダー(ゲームの `game/` に入れるそのままの形) |
| `showpy/docs/CUSTOM_GUIDE.md` | 設定値の早見表。この案内書の「プラグイン カスタムガイド」の章の元 |
| `showpy/docs/READ_ME_FIRST.md` | 版ごとの変更点、導入・削除、注意 |
| `showpy/docs/SPEC.md`、`DEV_RULES.md` | プラグインの構造と作業ルール(手を入れる人向け) |
| `showpy/CHANGELOG.md` | 版ごとに直したこと |
| `showpy/game/*/README.md` | プラグインごとの設定名の詳しい説明 |
| `showpy/samples/`、`showpy/examples/` | カーソル・クリック待ちのサンプル画像、pygaki スクリプトの例 |
| `docs/LINK.md` | 2 つのプログラムが互いに合わせる形式(シナリオファイル、スクリプトの印、リアルタイム連携、エフェクトファイル) |
| `bundle/` | パック作り(`make_bundle.py`)、ランチャーのボタン(`launcher/`)、この案内書(`guide/`) |
| `.github/workflows/` | アプリの確認・Windows ビルド、タグを上げると Releases の下書き |

リポジトリの文書は韓国語です。この案内書の日本語・英語は `bundle/guide/ja/`、`bundle/guide/en/` にあります。

## 文書を読む順番

| 自分は | 読むもの |
| --- | --- |
| 初めてダウンロードした | この案内書の「はじめに」→「pygaki でシナリオを書く」 |
| シナリオは書いたので、ゲーム画面を整えたい | 「プラグイン カスタムガイド」の「pygaki と一緒に使う」 |
| 設定ファイルで見た目を変えたい | 「プラグイン カスタムガイド」の「ひと目で探す」→ 各プラグインの `README.md` |
| エフェクトを選びたい | 「エフェクト見本」 |
| エフェクト・コードを足したい | 「自分で手を入れる」→ `showpy/docs/DEV_RULES.md`、`ui_kit/effects/README.md` |
| 古い版から移る | `showpy/docs/READ_ME_FIRST.md`、`showpy/CHANGELOG.md` |
