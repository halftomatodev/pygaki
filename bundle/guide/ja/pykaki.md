# pygaki 使い方ガイド

ボックスと線で Ren'Py のシナリオを書き、Ren'Py スクリプト(`.rpy`)に書き出すツールです。

**開き方**:pygaki パックの Ren'Py ランチャーでプロジェクトを選び **[pygaki로 편집]**(pygaki で編集)。Web 版(サイト、Web アプリのインストール)は 2026-11-12 に廃止しました。

アプリ内の [ヘルプ](F1)はこの文書の韓国語版です。画面のボタン名は、言語ボタンで日本語にしたときの名前で書いています。

---

## 1. 画面を見て回る

- **上の段の左**:大きなタブ **[スクリプト編集 | GUI編集 | 画面 | エフェクト | シェーダー | フォント]**。アプリではその横に **ゲーム接続ボタン**(ゲームとつながっていれば薄い青の「● ゲームと接続中」、ゲームが変わったスクリプトを読み直している間は黄色の「◐ ゲーム更新中」(終われば自動でまたつながる)、それ以外は灰色。押すと GUI編集へ)。
- **ピンクのまとまり**(タブの段、ゲーム接続ボタンの右):プロジェクトのタイトル(押して直す)、**[Ren'Pyで実行]**、**[スクリプトを追う]**。青いタブのまとまりと同じ段に別々に浮かんでいます。オンのボタンは薄いピンクの背景です。[Ren'Pyで実行] はゲームが起動していると薄くなり押せません(「実行中」)。[スクリプトを追う] は押すたびにオン/オフが切り替わります。
- **上の 2 段目のメニュー**(左から):元に戻す・やり直しの矢印、**[集中]**(薄紫のボタン)、設定、**ヘルプ**、続いてファイルの新規/開く/保存、プロジェクトフォルダー(再読み込み、フォルダ管理、別のプロジェクト)、バージョン、書き出し。タブのまとまりと一緒に中央に半透明のまとまりで浮かび、ボタンにマウスをのせると白い背景が敷かれます。
- **左**:label(場面。下にボックスと整列のボタン)、キャラクター、**チェック**(書き出しで引っかかるエラーと警告。押すとそのボックスへ)、Ren'Py プロジェクトの情報(プロジェクト、シナリオファイル、保存状態、見つかった画像・サウンドの数)、**スクリプト**(書き出すスクリプト。[開く] で見て [コピー]、[.rpy書き出し])、設定。まとまりごとに角の丸いカードに分かれています。
- **右**:タブなしで左と同じカードです。ボックスを押すとボックス、文字エフェクト、セリフ、次の流れのカードが、◐ シェーダーを押すとシェーダー、トランジションのカードが出ます。
- **欄の大きさ**:左や右の欄とキャンバスの境目にマウスを当てるとカーソルが ↔ に変わります。ドラッグするとその欄の幅が変わり、境目をダブルクリックするとその欄だけ最初の大きさに戻ります。[GUI編集]、[エフェクト]、[シェーダー] 画面の欄の境目も同じようにドラッグします。左の「設定」の **[初めの大きさ]** はすべての画面の欄を一度に戻し、**[ロック]** を押すとドラッグしても変わりません。大きさとロックはこのブラウザー(アプリ)に記憶されます。
- **中央のキャンバス**:ボックスと線。マウスホイールで拡大/縮小し、空いたところをドラッグして移動します。左上の「キャンバス操作」の横の **＋ − ⛶** ボタンでも拡大・縮小し、ボックスがすべて見えるように合わせます。その下にミニマップがあります。キャンバス上の両端の小さな **‹ ›** ボタンで左の欄と右の欄を別々に折りたたみ・展開します(たたんだものは次に開いてもそのまま)。

最初に開くと例のシナリオ(「雨の日」)が入っています。[新規] を押すと空のシナリオで始まります。

### ヘルプと ⓘ
- 画面には長い説明を置きません。欄の名前の横の小さな **ⓘ** にマウスをのせると 1〜2 行の説明が出て、押すとこのヘルプのその項目が開きます。
- 上の 2 段目のメニューの **[ヘルプ]** や **F1** で、いつでもこのヘルプを開けます。左に目次、上に検索欄があります。Esc や [閉じる] で閉じます。
- ヘルプはリポジトリの `pykaki/docs/GUIDE.md` と同じ文章です(アプリを作るときにそのまま入れる。韓国語)。
- ボタンにマウスをのせると、そのボタンがすることも短く出ます。

### キャンバス操作のまとめ
キャンバス左上の **キャンバス操作 ⓘ** にも同じものがあります。
- ボックスを **ダブルクリック** すると、ボックスの中ですぐに文字を書けます。セリフ行・タイトル・選択肢をダブルクリックするとその欄へ移ります。Esc か空いたところのクリックで終わります。
- ボックスを 1 回クリックすると、右で label、次の流れなど残りの設定を変えます。
- キャンバスの空いたところを **ダブルクリック** すると新しいボックスができます。
- ボックスの下の点(●)をドラッグしてほかのボックスに落とすとつながります。空いたところに落とすと新しいボックスができてつながります。
- 線を **ダブルクリック** すると jump ↔ call が切り替わります。
- **Shift+ドラッグ** で複数のボックスを選び、**Delete** で消します。
- 同じ label(場面)のボックスは同じ色です。label は左の一覧で管理します。
- ボックスや label の右上の **◐ シェーダー** を押すと、右で画面シェーダーを決めます。セリフ音と速度はセリフ行ごとに、カーソルとクリック待ちはボックスごとに、ボックス編集欄のカードで決めます。
- カードのタイトルを押すと、名前だけ残してたたまれます。

## 2. 基本の考え方

| 用語 | 意味 |
|---|---|
| **ボックス** | セリフのまとまり。中に複数の行を書けます。 |
| **行** | ナレーション、キャラクターのセリフ、演出(背景・表示・隠す・BGM・効果音・一時停止・揺らす)、フラグの変更(⚑)、直接コマンド(⚙)、メモ(#)のどれか |
| **線** | ボックスの次にどこへ行くか |
| **label(場面)** | ボックスをいくつかまとめる単位。Ren'Py の `label` 1 つになります。同じ label のボックスは同じ背景色です。 |

## 3. シナリオを書く

### キャラクターの登録
左の **キャラクター [+ 追加]** を押します。
- **色**:名前の色(書き出すとき `Character(..., color=)` に)
- **id**:Ren'Py の変数名。英字、数字、`_` だけを使います。例:`a`、`alice`
- **名前**:画面に出る名前。例:アリス

ナレーションは登録しなくてかまいません。

### ボックスを作る
- キャンバスの **空いたところをダブルクリック** すると新しいボックスができます。label の背景の中でダブルクリックすると、その label に入ります。
- 左の「ボックスと整列」の **[+ ボックス]** でも作れます。
- **ボックスのコピー**:ボックスを選び(複数ならドラッグで選ぶ)**Ctrl+C**、キャンバスでマウスを置いた位置に **Ctrl+V** で貼り付けます。**Ctrl+D** は選んだボックスをすぐ横に複製します。一緒にコピーしたボックス同士の線は新しいボックス同士でつなぎ直され、ほかのボックスへの線は元のボックスをそのまま指します。新しいボックスは新しい名前(n07 など)をもらうので、スクリプトで重なりません。テキスト欄にカーソルがあるときは、Ctrl+C/V は文字だけをコピーします。シナリオのウィンドウ 2 つの間でも貼り付けられます(ほかのシナリオにないボックスへの線は切れます)。Ctrl+Z 1 回で貼り付けたものがすべてなくなります。

### ボックスの中で書く
- ボックスを **ダブルクリック** すると、画面がそのボックスになめらかに近づいて拡大し、ダブルクリックした行にカーソルが出ます。ボックスの見た目は見るときと同じで、文字をその場ですぐ直せます。
- カーソルがある行の **左の外側** に、小さなボタンのまとまりが付きます。
  - **⠿** ドラッグして行の順番を変える
  - **行の種類**:ナレーション、キャラクター、演出、⚙ コマンド、# メモ
  - **＋** 下に新しい行、**✕** 行を削除
- 選択肢や条件分岐の行にカーソルがあるときも、左の外側に **⠿ ◆ 選択肢(◇ 条件)＋ ✕** のまとまりが付きます。⠿ でドラッグして順番を変え(線は付いたまま)、＋ ですぐ下にもう 1 つ入れ、✕ で消します。最後の 1 つを ✕ で消すと選択肢(条件分岐)がなくなり、**→ 次のボックスへ** に戻ります(つながっていたボックスへつながる。Ctrl+Z で戻せる)。マウスをのせると、見るときも行の左に ⠿ が見えます。
- 演出の行(🖼 背景、🎵 BGM など)を押すと、**右の外側** に入力欄が付きます。
- ボックスの **右の外側** には半透明の **次の流れ** ウィンドウが付きます。右の欄を開かなくても(集中モードでも)5 つをカードで選べます:**次のボックスへ**、**終了 (return)**、**選択肢**(選ぶと最初の選択肢の欄へ)、**条件分岐**(選ぶと最初の条件の欄へ)、**次のボックスへ続けて書く**(つながったボックスがあればそこへ、なければ新しいボックスを作ってつなぐ。選択肢・条件分岐なら、まだつながっていない最初の枝へ)。カードにマウスをのせるか方向キーで選ぶと、横に説明と動く見本、書き出すスクリプトが出ます。どのボックスへつなぐかはキャンバスで線をドラッグして付けます。call は線を 2 回押して切り替えます。
  - **Alt+Enter**:キーボードで次の流れのウィンドウに入ります。**方向キー** で選び **Enter** で決めます。**Esc** か **Alt+Enter** をもう一度押すと、書いていた文字に戻ります。
  - **＋ 新しいボックスに続けて書く**:まだつながっていないところに新しいボックスを作ってつなぎ、そのボックスに移ってすぐ書きます。
  - **Ctrl+Shift+Enter**:次のボックスへ続けて書く。つながったボックスがあればそこへ、なければ新しいボックスを作って移ります。押し続けると、ボックスを 1 つずつつなぎながら書けます。
- **Ctrl+Enter**:同じ話し手で下に新しい行
- **Esc** か空いたところのクリック:編集の終わり。画面が元に見ていたところへ戻ります。

### 文字の装飾と進行(タグボックス)
- セリフやナレーションのテキスト欄にカーソルがあると **タグボックス** が出ます。ボックスの中で書くときはボックスの **右上の外側** に、右の欄で書くときは文字エフェクト欄の上に出ます。
- タグボックスはまとまりごとにカード 1 枚(文字、進行、速度、もっと見るの形・フォントとエフェクト・入れる)で、行ごとに名前が色のバブルで付いています。
- 進行、速度、不透明度、字間、入れるボタンにマウスを少しのせると、**ツールチップ** に入るタグ、説明、そして見本の文にそのタグを入れて 1 文字ずつ出る様子が流れます(クリック待ちは ▼ を見せて自動で進む)。スライダーをドラッグしている間は、その値で見本が流れます。
- 文字を選んでボタンを押すと、その部分だけを Ren'Py のテキストタグで囲みます。選んだ文字がなければタグの組を入れ、カーソルをその間に置きます。
  - **B I U S**:太字 `{b}`、斜体 `{i}`、下線 `{u}`、取り消し線 `{s}`。ショートカット **Ctrl+B / Ctrl+I / Ctrl+U**。すでにそのタグの中なら、もう一度押すと外れます(真ん中だけを選ぶとその部分だけ外れる)。
  - **サイズ**:**가−**、**가+** は 10 ずつ小さく、大きく(`{size=-10}`、`{size=+10}`、押すたびに変わる)。真ん中の欄に `30`(そのサイズ)、`+10`、`-10`、`*1.5`(1.5 倍)を書いて Enter。
  - **色**:パレットが開きます。基本の色 32 マス、このプロジェクトの色(セリフ窓の基本の文字色、キャラクター名の色)、最近使った色 8 マス、`#rrggbb` の欄と [自分で選ぶ]。←↑→↓ で動かして Enter で選びます。すでに色タグの中なら色の値だけが変わり、[色を外す] で外せます。
  - **進行**:[クリック待ち] `{w}`、[一時] `{w=0.5}`(入れると数字が選ばれているので、すぐ秒を書き換えられる)、[改行して待つ] `{p}`、[オート] `{nw}`(文の終わりに入る)、[ここまで一度に] `{fast}`、[消して続ける] `{clear}`
    - **消して続ける**:ここまで出たらクリックを待ち、前の文を **場所は残したまま見えなく** してから、同じ人が続けて話します。シナリオに書いた改行と空白のまま、次の文が元の位置(2 行目、3 行目 …)に出ます。例:`1行目{clear}`(改行)`2行目{clear}`(改行)`3行目` なら 1 行目が出て、クリックすると 1 行目は消えて 2 行目が 2 行目の位置に、もう一度クリックすると 3 行目だけが 3 行目の位置に出ます。スクリプトには、その場所で同じ話し手のセリフ複数行に分けて書き出します。太字・色・速度のようにまたがったタグは分けた行ごとに付け直し、文字エフェクト・セリフ音のような行の設定も分けた行ごとに同じく付きます。[Ren'Pyでここへ移動] は最初のかけらへ移り、ゲーム内編集画面でセリフの位置を変えて pygaki に取り込むのは最初のかけらだけでできます。
  - **速度**:スライダーをドラッグするか数字の欄に書いて Enter。選んだ文字だけが **1 秒にその文字数** で出ます `{cps=20}`(セリフ欄のテキスト速度と同じ単位)。[普通] を押すとタグが外れます。以前入れた倍率のタグ `{cps=*2}` は横に「普通の 2 倍」と表示され、スライダーを動かすと文字数に変わります
  - **もっと見る ▾**:速度の行の右端。押すと下の行が開き、もう一度押すとたたまれます(開いたまま記憶)。
    - **不透明度**:スライダーをドラッグするか数字を書いて、選んだ文字を薄く `{alpha=0.5}`。1 ならタグが外れます。
    - **字間**:スライダーをドラッグするか数字(ピクセル)を書いて、文字の間を広げる(負の数は狭く)`{k=2}`。0 ならタグが外れます。
    - **縁取りの色**:文字の色と同じパレット `{outlinecolor=#rrggbb}`。ゲームの文字スタイルに縁取り(`outlines`)があるときだけ見えます。
    - **フォント**:ゲームフォルダーをつなぐと、`game` と `game/fonts` のフォントファイルを選んで、選んだ文字だけを変えます `{font=ファイル}`。
    - **エフェクト**:選んだ文字だけに登場エフェクトをかけます `{shader=shake}文字{/shader}`。一覧にはオンにしてある文字エフェクトが出て、もう一度開いて [エフェクトタグを外す] を選ぶと外れます。行のほかの文字はその行の文字エフェクトで出て、行にエフェクトがなければ 1 文字ずつ出ます(書き出すとき、その行に `effect="typewriter"` が自動で付く。これがないと Ren'Py がその行で止まる)。色の残像のように縁取りの層を使うエフェクトは行全体にしかかけられないので、一覧にありません。エフェクトを選ぶと横に **[詳細値]** ボタンが出て、押すとそのエフェクトのスライダーが開きます。スライダーを動かして離すとタグの中に `{shader=wave:u__amplitude=8}` のように書かれ、↺ を押すとその値だけが初期値に戻ります(カーソルがそのタグの中にあれば OK)。選択肢の文には使えません(左の [チェック] カードが知らせます)。
    - **入れる**:[横の間隔] `{space=30}`、[縦の間隔] `{vspace=30}`(数字が選ばれているのですぐ書き換えられる)、[{ 文字] `{{`、[ルビ]、文中の画像 `{image=名前}`(ゲームフォルダーをつないだとき一覧から)。
    - **ルビ**:選んだ文字の上に小さな文字をのせます `{rb}文字{/rb}{rt}読み方{/rt}`。選んだ文字がなければ直前の文字の上にのせます。ルビの文字の中にカーソルを置くと **[ルビ文字]** の行が出て、サイズと色をその場で決めます `{rt}{size=14}{color=#ffcc00}読み方{/color}{/size}{/rt}`([デフォルト] は両方外す)。位置は pygaki プラグイン(ui_kit 4.9)がセリフ行ごとに本文のすぐ上に合わせ、文字エフェクトのあるセリフでも止まらないように、ルビに同じエフェクトを入れます。ゲームで `style ruby_text` の `yoffset` を別に決めていれば、その値を使います。
- タグの文字はテキスト欄にそのまま見えます。結果は文字エフェクト欄のプレビューとゲームで見ます(プレビューは選んだ文字だけにかけたエフェクトも、ゲームと同じシェーダーで描く。ルビは上にのせず小さな文字で、文中の画像は見えない。間隔はおおよその大きさで)。編集を終えたボックスではタグが薄く見え、中の文字に太字、斜体、下線、色、不透明度がかかります(サイズはボックスの形が変わらないようにそのまま)。
- 文字エフェクト欄のサイズ、色、フォント、文字/秒は **行全体** に、タグボックスは **選んだ部分だけ** にかかります。
- タグがほかのタグと食い違うように選ぶと(例:`{b}` の中と外にまたがる)、入れずに知らせます。
- 左の設定でテキストタグをオフにすると、タグボックスには [オンにする] だけが出ます。

### 演出(背景、キャラクター、BGM、効果音、一時停止、揺らす)
Ren'Py のコマンドを知らなくても、行の種類で **演出** を選んで欄を埋めるだけです。欄の下に、実際に書き出す Ren'Py のコマンドが緑の字で見えます。

| 行の種類 | 埋める欄 | 書き出すコマンド |
|---|---|---|
| 🖼 **背景** | 背景の名前、現れ方 | `scene bg room with fade`(画面の画像をすべて消して背景を敷く。名前を空にすると黒い画面) |
| 🧍 **表示** | キャラクター/背景/その他から選ぶ、名前(キャラクターなら表情)、位置、現れ方、前後 | `show a smile at left with dissolve` · `show a smile zorder 10` · `show ghost behind a` |
| 🙈 **隠す** | キャラクター/背景/その他から選ぶ、名前 | `hide a with dissolve` |
| 🎵 **BGM** | 再生/続けて再生/停止、ファイル名、フェードインの秒、繰り返し | `play music "audio/rain.ogg" fadein 2.0 noloop` · `queue music "audio/b.ogg"` · `stop music fadeout 1.0` |
| 🔊 **効果音** | 再生/停止、1 つずつ/重ねて鳴る、ファイル名 | `play sound "audio/door.ogg"` · `play audio "audio/door.ogg"` · `stop sound fadeout 1.0` |
| ⏸ **一時停止** | 秒(空ならクリックするまで) | `pause 1.5` · `pause` |
| 💥 **揺らす** | 縦に揺らす / 横に揺らす / 白いフラッシュ | `with vpunch` · `with hpunch` · `with Fade(0.1, 0.0, 0.5, color="#fff")` |

**現れ方** はボタンを押すと選択画面が開きます。上に見本(マウスをのせたエフェクトで前の画像から新しい画像へ変わる様子)、下に基本(すぐ、ふわっと、黒くフェード)と [エフェクト] 画面の画像エフェクトの一覧があります。ゲームのエフェクトフォルダーにあるものだけが出て、[エフェクト] 画面で隠したエフェクトは出ません。

- **前後**(表示):画像が重なるとき、どちらが前かです。**前後 デフォルト** はあとで表示した画像が前です。**最前面 (数値)** は数字が大きいほど前(ほかの画像は 0)、**この画像の後ろに** は書いたタグ(例:`mina`)の画像の後ろに置きます。位置はゲーム内編集画面で決めます。
- **BGM**:**再生** は今の曲を切ってすぐ、**続けて再生** は今の曲が終わったら流します。**フェードイン** は音が大きくなる秒(空ならすぐ)、**繰り返し** はゲームの基本(BGM は繰り返し)・オン・オフです。**停止** のフェードアウトは空なら 1 秒、0 ならすぐ止まります。
- **効果音**:**1 つずつ**(sound)は新しい効果音が前の効果音を切り、**重ねて鳴る**(audio)は複数の音が一緒に鳴ります。停止は選んだ方の音を止めます。効果音・BGM カードの [効果音を止める]/[BGM を止める] でも入れられます。
- **一時停止、揺らす** は、セリフカードの [+ 一時停止]、[+ 揺らす] で今書いている行のすぐ後ろに入れるか、話し手の欄で選びます。

- **画像ファイル** は、ゲームの `game/images/` フォルダーに名前を合わせて入れます。
  - 背景:`bg 名前.png`(例:`bg room.png`)
  - キャラクター:`キャラクターid 表情.png`(例:キャラクターの id が `a` なら `a smile.png`)
  - 画像の名前は英小文字、数字、`_` で書くのが安全です。
- **サウンドファイル** は `game/audio/` フォルダーに入れて、ファイル名だけを書きます。(例:`rain.ogg`)
- キャラクターのセリフの **属性**(表情)も同じ画像を使います。`a smile "セリフ"` は `a smile.png` に替えて見せます。

### ボイス
キャラクターのセリフごとにボイスファイルをつなぎます。ボックスを押して、右の **[ボイス]** カードで **[ボイスを使う]** を押します(シナリオ全体でオンになる)。

- オンにすると、キャラクターのセリフごとに label 内の **番号** が付きます(セリフカードの行の右 `🎙012`)。番号は一度付くと行を入れたり動かしたりしてもそのままで、新しいセリフはその label のいちばん大きい番号の次をもらいます。
- **ファイル名の決まり**:`キャラクターid_label名_番号`(例:キャラクター `mina`、label `ward`、12 番 → `mina_ward_012.ogg`)。この名前で `game/audio/voice` フォルダーに入れると自動でつながります(大文字小文字は問わない)。カードで行ごとに **名前どおり / ボイスなし / ファイルを自分で選ぶ** を決め、▶ で聞きます。
- カードの下の **ボイスのないセリフ** を開くと、シナリオ全体でファイルのないセリフが出ます(録音するリスト)。押すとその行へ移ります。
- **[番号を振り直す]**:label ごとに 1 から順に振り直します。すでに名前どおりに作ったファイルは、名前が合わなくなることがあります。
- スクリプトにはセリフのすぐ前に `voice "audio/voice/mina_ward_012.ogg"` が入ります。`{clear}` で分けたセリフは最初のかけらで音が鳴ります。ナレーションはボイスをつなぎません。

### シェーダー(ボックスと label にかける)
ゲーム画面全体にかぶせるシェーダー(アスキー、VHS、ゲームボーイ …)を、ボックスや label 単位でかけます。pygaki プラグインの入ったプロジェクトでだけ使えます(左の [設定] の「pygaki プラグイン連携」)。

- ボックスや label の枠の右上の **◐ シェーダー** を押すと、右の欄がシェーダーの選択に変わります。もう一度押すか [← ボックス編集へ] で戻ります。
- **[このボックスに設定]**:1 番、2 番を選びます。2 つの枠が重なって見えます。両方「なし」なら、そのボックスではシェーダーをオフにします。
- **label に設定すると**、その label のボックスすべてにかかります。ボックスに別に設定したものがあれば、そちらが優先です。ボックスも label も設定していなければ、ゲームの設定どおりに見えます。
- ボタンの色でわかります:塗りつぶしの色はここで設定したもの、点線の枠は label のものに従うボックス。
- **トランジション**:ボックスが始まるときと終わるときのトランジションです。ボックスからボックスへ移るときは、次のボックスの「始まるとき」を先に使い、それが **なし** なら前のボックスの「終わるとき」を使います。シェーダーが同じでも選んだトランジションが流れます。両方 **なし** のときだけ、トランジションなしでそのままつながります。ボックスにシェーダーを初めて設定すると、両方 **なし** で始まります。トランジションはシェーダーと同じく一覧から **TV オフ・オン**、**ピクセルソート**、**データモッシュ**、**TV ノイズ**、**調整画面**、**テープの伸び**、**点滅**、**なし**(すぐ変わる)から選びます。TV ノイズ(ノイズがかぶさって晴れる)、調整画面(放送の調整画面が少し出る)、テープの伸び(画面が波打って伸びる)、点滅(何回か点滅する)は、前のボックスの最後の画面からこのボックスの最初の画面へ移る間に流れ、シェーダーはノイズがいちばん濃いとき、調整画面が終わるとき、いちばん伸びたとき、真ん中の点滅のときに変わります。この 4 つも、ゲームのエフェクトフォルダーに同じ名前のエフェクトファイルが必要です。画像トランジションを選ぶと、その下にそのエフェクトの詳細値が出ます。点滅なら **色**、**回数**、**点いている割合**、**ゆっくり消える**、**覆う度合い** を選び、下の **画像トランジションの時間**(0.1 秒から)と合わせて「1 回の点滅 0.20 秒」のように見えます。ピクセルソートとデータモッシュは **クラッシュ** です。前のボックスの最後の画面(そのボックスの行を最後まで描いた画面。セリフのあとに表示しただけの画像も入る)が壊れ、壊れたまま少し止まってから、このボックスの最初の画面(冒頭の背景、表示の行まで描いた画面)へぷつっと切れて移ります。2 つの画面を混ぜず、シェーダーも切れる瞬間に変わります。かかる時間は下の **画像トランジションの時間** スライダーで決めます(前の 40〜45% が壊れる時間、残りが止まる時間。1.4 秒なら約 0.6 秒壊れて 0.8 秒止まる)。選んだトランジションのすぐ下の **方向** で壊れる方向を選びます:データモッシュ(キーフレームを失った動画のように前の画面がブロックごと引きずられて溶け、このボックスの最初の画面の輪郭がその上に透ける)は **回転**(ブロックごと渦巻く)と **拡散**(中央から外へ引きずられる)、ピクセルソートは **横**、**縦**、**回転**(円周に沿った帯)、**拡散**(中央から外への帯)。ボックス冒頭の背景、表示、隠すの行をすべて描いたあとにトランジションが流れ、それらの行の「現れ方」は使いません。この 2 つは、ゲームのエフェクトフォルダーに `pixelsort`、`datamosh` のエフェクトファイルが必要です(新しいプロジェクトには入っている。なければ [エフェクト] 画面で入れる)。TV を選ぶと、その下の **[詳細値]** で消える時間、黒い画面、点く時間、横線の太さ、光、ノイズ、音量をこのボックス(label)でだけ変えます。シェーダーを設定していないボックスへ移るときも、前のボックスの「終わるとき」が流れます。古い版で「ふわっと」や「ゲームの設定どおり」に設定してあったところはそのまま流れ、欄に「以前の値」と表示されます。どちらかを選ぶと変わります。
- 選択の一覧は、つないだゲームフォルダーにあるシェーダーです(つないでいなければ基本のシェーダー)。ゲームに新しいシェーダーを入れたら、ゲームを一度起動してから [再読み込み] を押すと一覧に出ます。
- シェーダー欄はカード 3 枚です:**シェーダー**(1 番、2 番)、**トランジション**、**script_flow.rpy に入る行**(書き出すとき、そのボックスの最初の行に書かれるコード)。
- シェーダーを設定していないボックスは、カードの下に「今:label の …」または「今:ゲームの設定どおり」と、今かかっているものを見せます。
- 古いプラグインを使うゲームなら、欄にオレンジの字で知らせます:詳細値は画面エフェクト(screen_fx)5.5 から、ピクセルソート・データモッシュは 5.6 からです。使えないものは TV オフ・オンで書き出します。
- **詳細値**:1 番、2 番でシェーダーを選ぶと、すぐ下の **[詳細値]** を開いてスライダーで変えます。変えた値はこのボックス(label)でだけ使い、↺ でその値だけ初期値に戻ります。変えていない値はゲームの設定どおりです(その最初の値は [GUI編集] → シェーダーの初期値で、ゲーム画面を見ながら直す)。ほかのシェーダーに変えると、その枠の値は消えます。pygaki プラグインの画面エフェクト(screen_fx)5.5 から使えます。
- 上の **[シェーダー]** 画面で、シェーダーごとに見本とスライダーを見て(保存しない)オン・オフします。[トランジション] では TV オフ・オンの様子を似た形で流してみて、ピクセルソートとデータモッシュは見本の画像で流してみます。
- シェーダーカードのいちばん下の **[⚠ すべてのボックスに適用]** は、今かかっているシェーダーをすべての label にかけます(ボックスごとに別に設定したものは消える)。**[⚠ すべて削除]** はシナリオ全体からシェーダーを消します。どちらも確認してから行い、↶ で戻せます。

### セリフ音と速度(セリフ 1 行ごと)
ボックス編集欄の **文字エフェクト** カードの下の **セリフ音と速度** カードは、今書いているセリフ・ナレーションの行 1 つにかかります。
- 値ごとに **[従う]** / **[このセリフに]** を選びます。従うなら、テキスト速度はゲームの設定(登場エフェクトを選べばそのエフェクトの基本の速度)、セリフ音はキャラクターに設定した音 → ゲームの初期値([GUI編集] → ゲームの初期値 → カーソル、クリック待ち、セリフ音)です。
- **テキスト速度**:1 秒に出る文字数(0 なら一度に)。プラグインなしでも使えます。
- **セリフ音**:audio フォルダーの音、またはオフ。▶ で聞きます。pygaki プラグイン連携をオンにすると書き出します。
- **[このボックスのすべてのセリフに]**:この行の速度と音を、同じボックスのほかのセリフ・ナレーションの行にも同じくかけます(この行で [従う] の値は、それらの行でも消す)。↶ で戻せます。

### カーソルとクリック待ち(ボックスごと)
ボックス編集欄の **カーソルとクリック待ち (CTC)** カードは、そのボックスにだけかかります。設定していないボックスは前のボックスのものを引き継がず、ゲームの初期値に戻ります。pygaki プラグイン(ui_kit 4.7 から)の入ったプロジェクトで使えます。
- 値ごとに **[ゲームの初期値]** / **[このボックスに]** を選びます。
- **クリック待ち、カーソル**:game/gui/ctc、game/gui/cursor の中のフォルダー 1 つが画像のセット 1 つです(フォルダーの中の画像を名前の順に流す)。ゲームの初期値でオンにしてあるものだけが変わり、カーソルはソフトウェアカーソルのときだけ変わります。
- カードのいちばん下の **[⚠ すべてのボックスに適用]** はこのボックスの値をすべてのボックスにかけ、**[⚠ すべて削除]** はシナリオ全体から消します。どちらも確認してから行い、↶ で戻せます。
- 古い版でボックスや label に設定したセリフ音・速度は、シナリオを開くときにそのボックスのセリフ行へ、label に設定したカーソル・クリック待ちはその label のボックスへ書き移されます。

### 背景、画像、サウンドのカード
ボックスを押すと、セリフカードの下に **背景(画像、動画)**、**画像、動画**、**効果音、BGM** カードがあります。Ren'Py プロジェクトをつないでいれば、画像とサウンドを押してすぐ入れられます(サウンドは ▶ で聞く)。カードのいちばん上の **[📂 ファイルを選ぶ]** を押すと、エクスプローラーの画面が game/images(サウンドは game/audio)フォルダーで開きます。ゲームフォルダーの外のファイルを選ぶと、game/images(webm 動画は movies、サウンドは audio)にコピーするか尋ね、コピーして入れます(同じ名前があれば _2 を付ける)。背景カードはファイル名が bg で始まる必要があります(例:"bg room.png")。つないでいなければ名前を打って入れます。**今書いている行のすぐ前** に入ります(書いている行がなければボックスの終わり)。位置はセリフカードで行をドラッグして変えます。カードの上には、このボックスにすでにあるその種類の行が出て、押すとその行へ移ります。

**セリフの行は文字だけを直します。** キャラクターの画像(表情)はセリフの行に付けず、**[画像、動画] カード** で選びます。キャラクターのセリフを書いていると、このカードのいちばん上にそのキャラクターの画像(例:`a smile.png`、`a angry.png`)が出て、押すとそのセリフのすぐ前に表示の行(`show a smile`)が入ります。画像がなければ表情の名前を打って入れます。古い版でセリフの行に入れた表情は、行の横に「表情 smile ✕」と表示されてそのまま書き出します(押すと外す)。

**使用中のカード**:今書いている行とつながったカードには、薄い緑の背景と「使用中」の印が付きます。セリフを書いていればセリフ・文字エフェクトのカード、背景の行なら背景カード、表示・隠すの行なら画像カード、サウンドの行なら効果音カードです。印のないカードは、今書いている行とは関係ありません。

### Ren'Pyでここへ移動、位置を移動(アプリ)
ゲームを [▶ Ren'Pyで実行] で起動してアプリとつながっていれば:
- ボックスカードの **[Ren'Pyでここへ移動]**:ゲームがこのボックスの最初の行へ移ります。
- セリフカードの行にマウスをのせると、カードの左の外側に小さなボタンのまとまりが飛び出します。**[ここへ移動]**:ゲームがその行へ移ります。セリフ・ナレーションの行には **[位置を移動]** もあります。押すとゲームがその行へ移り、ゲーム内編集画面のセリフタブが開きます。ゲーム画面でドラッグして動かし、その行の下の [保存] を押すと位置がシナリオに書き込まれます(括弧の中の数字は保存するものの数)。[終了] でエディターを閉じます。
- 背景・表示の行(セリフカードのその行と、背景・画像カードの上の行の一覧)にも **[位置を移動]** があります。ゲームがその行へ移り、ゲーム内編集画面の画像/動画タブがその行を選んで開きます。ゲーム画面で画像をドラッグして動かすかトランジションを変えて [保存] すると、シナリオに書き込まれます(pygaki プラグイン ui_kit 4.8 からその行を選んでくれる)。隠すの行は位置がないのでボタンがありません。
- 次の流れが選択肢なら、**[位置を移動]** で選択肢の位置を同じ方法で決めます。ゲームがボックスの最後の行へ移るので、1 回進めると選択肢が出ます。
- ゲームとつながっていなければ、ボックスカードのボタンは灰色で、行ごとのボタンは見えません。

### カードを折りたたむ
左、右、GUI編集の欄のカードは、**タイトルの行を押すと** 名前だけの 1 行にたたまれます(水色、名前の長さだけの幅)。もう一度押すと中の行が一つずつ飛び出して開きます。左の欄のカードは起動するたびにすべてたたまれて始まり、右の欄のカードはたたんだものを記憶します。欄のいちばん上の右の、折り紙アイコンの **[すべて折りたたむ]**(すべてたたまれていれば [すべて開く])で、その欄のカードを一度にたたんだり開いたりします。左の欄のスクロールバーは左側にあります。
- 以前入れた「✨ 画面エフェクト」の行はそのまま動きますが、ボックスのシェーダーを 1 つでも使うと、ボックスごとに最初の行でシェーダーを合わせ直すので、どちらか一方だけを使うのがおすすめです。

### 右の欄の行の形
ボックスを 1 回クリックすると、右の欄にも同じ行が出ます。行ごとに **左の欄** に行の種類とハンドル(⠿)、削除(✕)があり、**右の欄** に文字があります。

### 行の順番を変える
**⠿ ハンドルをドラッグして** ほかの行の上/下に置くと順番が変わります。右の欄でも、キャンバスのボックスの中でもできます(ボックスの中では、行にマウスをのせると行の左に ⠿ が見える。文字を直している最中でなくてもよい)。

左右の欄はキャンバスの上に浮いています。カードの間や、カードをたたんで空いたところは透けて後ろのシナリオが見え、そこを押してもキャンバスを動かします。欄の中はカードの上でホイールでスクロールします。

### 直接コマンドとメモ
- **⚙ 直接コマンド**:上の演出でできない Ren'Py のコマンドをそのまま書きます。例:`show eileen at truecenter`、`$ renpy.pause(1.0, hard=True)`
- **# メモ**:作者用のメモです。スクリプトにはコメント(`#`)として入り、ゲームには見えません。
- **⚑ フラグの変更**:この場所でフラグを変えます(例:`met_alice` をオン、`love` +1)。セリフカードの [+ フラグ変更] で入れるか、話し手の欄で選びます。下の「フラグ」を参照。

## 4. 流れをつなぐ

ボックスを **1 回クリック** すると、右の **編集** タブで「次の流れ」を決めます。

| 種類 | 意味 |
|---|---|
| **→ 次のボックスへ** | 次のボックスへつながります。 |
| **◆ 選択肢** | 選択肢ごとに違うボックスへ行きます。ボックスの中で書くときは、左の外側のまとまりの **✕** か、空の選択肢で **BackSpace** で消します。右の [次の流れ] のいちばん上の行に **質問のセリフ**(話し手と文、例:「傘を貸そうか?」)を書くと、選択肢が出ている間セリフ窓に残ります(`menu:` のすぐ下のセリフ行)。空にすると質問なしで選択肢だけが出ます。 |
| **◇ 条件分岐** | 条件によって違うボックスへ行きます。**もし** の行で [フラグを選ぶ] でフラグを選び、オン/オフのフラグは **オンなら・オフなら**、数値のフラグは数と **以上・以下・より大きければ・より小さければ・なら・でなければ**、文字のフラグは文字と **なら・でなければ** を選びます。[+ 条件を足す] で条件を足すと **かつ**(すべて合う必要あり)か **または**(1 つ合えばよい)でまとまります。`{ }` を押すと Ren'Py の条件式を直接書けます(例:`love >= 5 and (met_alice or rich)`。選ぶ欄で表せない式はテキスト欄で表示)。[+ 条件] で **でなく** の行を足し、上の条件がすべて違えば **それ以外** のボックスへ行きます。 |
| **▣ 画面を呼ぶ** | [画面] タブで作った画面を出し、押したボタンの **返す値** ごとに違うボックスへ行きます。枝は画面のボタンの値に合わせて自動ででき(同じ値のボタンは 1 つの枝)、どの値にも合わなければ **それ以外** へ行きます。下の「画面を作る」を参照。 |
| **⤷ callして続ける** | ほかの場面を呼び、終わったら戻ってきて「戻った後」のボックスへつながります。共通の場面を何度も使うときに便利です。 |
| **■ 終了 (return)** | ここで終わります。call で呼ばれた場面なら、呼んだところへ戻ります。 |

### 線でつなぐ
- ボックスの下(選択肢と条件分岐は行ごとの右)の **点(●)をドラッグして** ほかのボックスに置くとつながります。
- **空いたところに置くと** 新しいボックスができてつながります。シナリオを続けて書くときにいちばん速い方法です。
- 線をクリックして **Delete** を押すと、つながりが切れます。
- 「次」の線を **ダブルクリック** すると call に変わり、call の線をダブルクリックするとまた「次」に変わります。
- 右の欄の一覧で行き先を選んでもかまいません。

### フラグ(物語が覚えておく値)
「アリスに会ったか」「好感度」のように、物語が覚えておいてあとで枝を分ける値です。Ren'Py の変数と同じです。
- **フラグカード**:右の欄のいちばん上にいつもあります。[+ 追加] で作り(下の「フラグの使い方の例」)、名前(英字・数字・_)、種類(**オン/オフ**、**数値**、**文字**)、初期値、メモを書きます。下には **使用箇所** が出て(✎ 変えるところ、? 見るところ)、押すとそのボックスへ移ります。名前を変えると、使用箇所の名前も一緒に変わります。
- **変える**:選択肢の行の **⚑** を押し、**選んだら** で [+ フラグ変更]。フラグを選んで、オン・オフ・反転(オン/オフ)、足す・引く・決める(数値)、文字(文字)を決めます。ボックスの中のどこかで変えるなら **⚑ フラグの変更** の行を入れます。`{ }` を押すと式で直接書けます(例:`love += 2`)。
- **見る**:選択肢の **表示条件** に条件を書くと、その条件のときだけ選択肢が見えます(空ならいつも見える)。次の流れの **◇ 条件分岐** で自動で枝を分けることもできます。条件は条件分岐と同じくフラグを選んで作ります。
- 書き出すと、スクリプトのいちばん上に `default love = 0` のように初期値が、変えるところには `$ love += 1` が、選択肢には `"文言" if love >= 5:` が入ります。フラグカードにない名前を条件に使うと [チェック] が知らせます(ゲームのほかのファイルで作った変数なら、そのまま使ってかまいません)。
- **見た目**: フラグごとに値が形で表示されます。数値は **レベルインジケーター**(連続バー、区切りバー、星)か **スライダー**、オン/オフは **スイッチ**、文字は **プルダウン** か **コンボボックス**(一覧にない文字も入力できる)です。右の [見た目 ▾] で選び、数値は最小値・最大値、文字は選べる値(台本で見つけた文字は + チップで出ます)を決めます。**カスタマイズ** では部品(塗り、背景、つまみ、目盛り、オンの背景など)ごとに色かゲームフォルダーの画像を入れます。**角** は丸く(最初)、角ばる、カプセル(高さの半分だけ丸く)から選びます(星は除く)。HUD に持っていったゲーム画面の見た目も同じ角で描きます。
- **試しの値**: 見た目をマウスでドラッグする(矢印キーでも可)か、レベルインジケーター・スライダーの横の数値欄に値を入力する(最小値〜最大値に収めます)か、スイッチを押すと値が変わり、その下に **この値のとき** 台本がどうなるかが出ます。選択肢は表示/非表示、◇ 条件分岐はどの分岐に進んでどんなセリフが出るか、変えるところは変えたあとの値です。試しの値は保存されず、[初期値に戻す] で戻します。
- **条件の目盛り**: 数値フラグと比べる条件(選択肢の表示条件、◇ 条件分岐)があると、見た目の上に番号の丸が付きます。試しの値が基準を超えると ✓ になり、下の一覧にその選択肢が **開いた**/**ロック**、分岐が **この分岐** と出ます。丸を横にドラッグすると、その条件の基準値(例: `courage >= 3` の 3)が変わります。元に戻す 1 回で戻ります。
- **判定**: フラグカードの下のほうに、数値フラグで分岐する ◇ 条件分岐ボックスがまとまって出ます。使うフラグの見た目(ドラッグで試しの値)、分岐ごとの条件(if、elif)と行き先のボックスがあり、今の値で進む分岐が緑になって、そのボックスの最初のセリフが出ます。いちばん下で判定の種類(**すべて十分なら**、**どれか 1 つでも十分なら**、**合計が十分なら**、**いちばん大きければ**)、フラグ、基準を選んで [+ 判定を追加] を押すと、いちばん下の分岐として追加されます(つなぐボックスはキャンバスで線をつなぎます)。↑ で分岐の順番を変えます(上の分岐から調べます)。まだフラグを使っていない ◇ ボックスは [+ ◇ ボックスを開く] で開きます。

### フラグの使い方の例
フラグカードの **[+ 追加]** を押すと、フラグ作成メニューが開きます。好感度、一度見た場面のようによく使うやり方(使い方の例)を選んでフラグを作ります。

- いちばん上の検索欄に言葉(例:好感、鍵)を入れると例が絞り込まれます。**↑ ↓** で選び、**Enter** で作ります。**Esc** か外側を押すと閉じます。
- 行にマウスをのせるか矢印で選ぶと、横に **説明カード** が出ます。何をする例か、動く見本(フラグの見た目が値に合わせて変わり、その下にその値を作った式とセリフ・選択肢)、フラグを変えるところ(✎)と見るところ(?)、書き出すスクリプト数行が出ます。
- 選ぶと、その例のフラグが初期値とメモまで入った状態で作られ、名前欄に移ります。同じ名前があれば `love_2` のように番号が付きます。元に戻す 1 回で消えます。
- メニューが作るのはフラグだけです。選択肢の「選んだら」、表示条件、◇ 条件分岐は説明カードを見て自分で入れます。
- **空のフラグ** は、名前、種類、初期値を自分で決めるときに使います。

### フラグをたどってみる
フラグカードの **[▶ たどってみる]**(シナリオの最初から)やボックスカードの **[▶ たどってみる]**(そのボックスから、フラグは初期値)を押すと、キャンバスの下にウィンドウが出ます。シナリオは変わりません。

- 今のボックスとそこで変わったフラグ(`kindness 0 → 1`)、これまで通ってきた道、すべてのフラグの今の値が見えます。キャンバスもそのボックスへ移ります。
- **選択肢**:表示条件が偽の選択肢は薄くふさがれ、選ぶと「選んだら」の変更を当てはめてそのボックスへ行きます。
- **条件分岐**:今の値で合う枝に緑の枠が付きます。ほかの枝も押して行ってみられます。
- call は、呼ばれた場面が終了(return)すると「戻った後」のボックスへ戻ります。**↶** で 1 歩戻り、**[最初から]** でやり直します。
- 計算する式は数値・文字・オン/オフ、足し算・引き算のような計算、比較、and/or/not までです。関数やゲームのほかの変数が入った式は「わからない」と表示され、そのときは自分で選びます。直接コマンドの行の `$ 名前 += 値` も計算します。

### フラグ設計
フラグカードの **[設計]** を押すと、キャンバスの下に表が付きます。フラグごとにどのボックスで変えて、どこで見るかを一目で確かめ、その場で直せます。上のキャンバスはそのまま使えます。

- 行はフラグ(名前、種類、シナリオのどこかで取りうる値)、列はシナリオの流れの順のボックスです。最初はフラグを使うボックスだけで、**[すべてのボックス]** をオンにすると全部出ます。シナリオの最初から届かないボックスは薄い斜体です。
- セルには変える場所 **✎**(`+1`、`オン`)と見る場所 **?**(`≥ 2`、`オン`)が出ます。ボックス名を押すとキャンバスがそのボックスへ移ります。
- セルを押すとポップオーバーが出ます。変更行、選択肢の「選んだら」、表示条件、条件分岐を選ぶ欄で直し、下の **追加** でボックスの最後の変更行、選択肢の「選んだら」、表示条件、条件分岐にこのフラグを入れます。空のセルも押して追加できます。元に戻すは一回で戻ります。
- **黄色の表示**: まだ使っていないフラグ、変えるだけで見る場所がないフラグ、見るだけで変える場所がないフラグ(常に初期値)、常に表示される・常に表示されない選択肢、常に真・常に偽の条件。値はすべての分岐と選択肢を通ると見て計算するので、確かなときだけ示します。値が多くなりすぎると(繰り返す流れなど)「いろいろな値」となり示しません。
- **[テンプレートから作成]**:表の右にウィザードが付きます。**テンプレート → フラグ → 変える場所 → 見る場所 → 確認** の順に選びます。
  - テンプレートはフラグ用例の6つです(好感度、一度見た場面、アイテムの入手・使用、ロックされた選択肢、ルート決定、複数エンディング)。フラグ名は変えられ、同じ名前・種類のフラグがあればそれを使います。
  - **変える場所**:上げる(オンにする)選択肢を選びます。一度見た場面はオンにするボックスを選んでボックスの最後に変更行を入れ、ルート決定は選択肢ごとに記憶する文字を、複数エンディングは選択肢ごとにどのフラグを上げるかを選びます。キャンバスで選んだボックスは濃く表示されます。
  - **見る場所**:条件分岐で分かれるボックスと基準値、分岐ごとの行き先ボックスを選びます(次のボックスへ進むか終わるボックス、すでに条件分岐のボックス)。アイテムの入手・使用とロックされた選択肢は、条件をつける選択肢を選びます。
  - **確認** で入れるものをすべて見て、常に真・常に偽のような黄色い表示が出るならあらかじめ知らせます。**[作成]** は一度に入れ、元に戻す一回ですべて戻ります。
- **Esc** でポップオーバー、もう一度で表を閉じます。保存形式はそのままなので、シナリオファイルとスクリプトは変わりません。

### 開始ボックス
緑の **開始** の印が付いたボックスからゲームが始まります。ほかのボックスを開始にするには、そのボックスをクリックして **[開始ボックスに]** を押します。

### 検索・置換
上の **[検索]** か **Ctrl+F**。セリフ・ナレーション、選択肢、選択肢の質問、ボックスのタイトルから文字を探します(チェックで選び、**Aa** をオンにすると大文字小文字を区別)。Enter で次、Shift+Enter で前、一覧を押すとそのボックスへ移ります。**[置換]** は今見つけた 1 か所、**[すべて置換]** は見つけたところすべてを置き換え、Ctrl+Z 1 回で戻せます。Esc で閉じます。

## 4-1. 画面を作る([画面] タブ)

上の **[画面]** タブで、ボタンをドラッグして置いて Ren'Py の画面(screen)を作ります。部屋選び、地図、物選びのように、選択肢の代わりに画像を押させたいときに使います。

- 左の **[+ 新しい画面]** で作り、中央上の **[+ テキストボタン] [+ 画像ボタン] [+ テキスト] [+ 画像]** で入れます。中央はゲーム画面の大きさのまま(縮小して)見えます。ドラッグして動かし、選んだものは方向キーで 1px(Shift は 10px)ずつ動かします。
- 右の **画面** カード:タイトル、名前(Ren'Py の screen 名、英字)、**背景**(なしならゲームの下の画面がそのまま見え、色や画像の名前を選べる)。
- 選んだものカード:文字、画像の名前(`images` フォルダーの名前、例:`door`)、画像ボタンは **ホバー時** の画像(例:`door hover`)、文字のサイズと色、位置。ボタンには **返す値**(例:`door`)を必ず書きます。
- シナリオのボックスの次の流れで **▣ 画面を呼ぶ** を選んで画面を選ぶと、ボタンの値ごとに枝の点ができます。線でつなぎます。
- 書き出すと `game/pykaki_screens.rpy` に画面が、スクリプトには `call screen 名前` の次に `if _return == "door":` の枝が入ります。画面だけを直しても、自動書き出しが画面のスクリプトを書き直します。
- いちばん下のカードで、書き出す文をあらかじめ見ます。画面を消すと、呼んでいたボックスは「画面なし」になり、[チェック] が知らせます。

### HUD(show screen)
画面カードの **種類** は二つです。**全画面**(`call screen`)はセリフを覆ってボタンを押すまで止まります。**HUD**(`show screen`。ゲーム画面の上に出ている情報ウィンドウ)はセリフが流れているあいだ隅に出ています。好感度バー、カバン、ミニマップ、時計などはこれで作ります。下の動画は Ren'Py で実際に撮った見本です(選択肢とボタンは自動で押されるようにして撮影。動画の中の文字は韓国語です)。

#### [画面] タブでHUDを作る
- 左の **[+ HUDのひな形から]**:**インベントリ**(オン/オフのフラグ `has_key` などがオンの物だけ)、**好感度バー**(数値フラグ `love`)、**ミニマップ**(場所ボタン、現在地はテキストフラグ `place`)、**アイテムを使う**(鍵をドラッグしてドアに置くと `door_open` がオン)から選びます。メニューの行にカーソルを合わせると、横のカードに Ren'Py で撮った動画とスクリプトが出ます(↑↓で選び Enter で作成、Esc で閉じる)。必要なフラグも一緒に作り、同じ名前があればそれを使います。今ある画面は画面カードの **種類** を **HUD** に変えてもかまいません。
- 画面カード:**サイズ**(px)、**配置**(9マス:左上、上中央 … 右下)、**移動**(配置からの px)、**前後**(`zorder`、大きいほど手前)、**背景** と **濃さ**。中央のステージでHUDの空いた所をドラッグしても動きます。項目の位置はHUDの左上から測ります。
- **スクロール**:画面カードでオンにして **内側の大きさ** をHUDより大きくすると、ゲームでドラッグやマウスホイールでスクロールします(広いミニマップなど)。項目は内側の左上から測り、ステージでもスクロールします。空いた所を押したりホイールを回したりしてもセリフは進みません。
- **ゲームで直す**:ゲーム内編集画面(Shift+M)の **[画面]** タブ(アプリ [GUI編集] の「画面とHUDの配置」)で画面を選ぶと、ゲーム画面の上に項目が描かれます。項目をドラッグで移動し、HUDの空いた所をドラッグしてHUDを移動し、固定位置と大きさ、テキストを直します。Ctrl+S で保存すると `pykaki_screens.rpy` が直り、台本にも取り込まれます。項目の追加・削除、ボタンの動作、見た目・バーの大きさはこの [画面] タブで行います。
- **[+ バー]**:数値フラグの値をバーで見せます。フラグ、満タンの値、サイズ、満ち側・空き側の色を選びます。
- **[+ フラグの見た目]**:フラグカードで作った見た目(レベルインジケーター、スライダー、スイッチ、プルダウン・コンボ)とカスタマイズ(色・画像)をそのまま持ってきます。ここではフラグと位置、大きさだけを決め、見た目を変えると HUD にもすぐ反映されます。ゲームでは値を表示するだけです(バーは値が変わるとなめらかに動き、星は DejaVuSans フォントで、文字フラグは値を文字で)。**[ゲームで変更できる]** をオンにすると、プレイヤーが見た目で値を変えます:スライダー・連続バーはドラッグ、区切りバー・星はマスを押す(最初のマスをもう一度押すと最小値)、スイッチは押す、プルダウンは開いて選ぶ、コンボは選ぶか一番下の欄を押して文字を打ち Enter。セリフ中に押してもセリフは進まず、ロールバックすると変えた値も戻ります。キーボードでも操作できます:矢印で見た目を選び(選んだ見た目は明るくなります)Enter で押します。バーとスライダーは Enter でつかみ ←→ で変えてからもう一度 Enter。ステージの見た目には ✋ が付きます。角はフラグカードの [見た目 ▾] の **角** にしたがって画像なしで丸く描きます(画像を入れた部品は画像のまま)。
- **テキスト** に `[フラグ名]` を入れると、ゲームでその値が出ます(例:`好感度 [love]`)。横の **[フラグ ▾]** で入れます。ステージはフラグの初期値で描きます。
- 項目ごとの **表示条件**:選択肢の条件と同じ欄です(例:`has_key` がオンなら)。ステージでは今は見えない項目を薄く、条件のある項目に緑の **?** を付けます。
- ボタンの **押すと**:**フラグ変更**(変更式をいくつでも。セリフはそのまま続きます)、**ボックスへ移動**(そのボックスへ jump)、**HUDを開閉**(ほかのHUDを出したり消したり)。全画面では **値を返す** も使えます(これまでどおり分岐)。
- **ドラッグ&ドロップ**:テキスト・画像の項目で **ドラッグ可** をオンにすると、ゲームでドラッグして動かせます(離すと元の位置に戻ります)。**[+ 置き場所]** で枠を入れ、**受け取るもの**(ドラッグできるもの一つ、またはどれでも)と **置くと**(ボタンの「押すと」と同じ)を選びます。全画面では、置くと値を返して分岐させることもできます。ドラッグするものはその画面の枠の中だけで動きます。ステージでは、ドラッグできるものに **✋**、置き場所は点線の枠で出ます。
- **ゲーム中ずっと表示** をオンにすると、HUD行なしで常に出ています(`config.overlay_screens`)。
- シナリオでは、ボックス右上の **[♡ HUD]**(◐ シェーダーの隣)を押し、右の **HUD** カードで HUD ごとに **そのまま / 表示**(`show screen 名前`)**/ 隠す**(`hide screen 名前`)を選びます。ボックスが始まるときに出したり下げたりします。一度出すと、次のボックスへ進んでも隠すまで出たままです(そのままなら前のボックスのものが続きます)。セリフ行の一覧には出ません。
- **▶ たどってみる** は、いま出ているHUDを今のフラグの値で小さく見せます。フラグカードには、そのフラグを使う画面が **?**(表示)、**✎**(ボタンが変更)で出て、フラグ設計表の黄色い表示もHUDでの使用を数えます。

#### HUDのひな形の見本
[+ HUDのひな形から] で作った画面を直さずに Ren'Py で動かした動画です(押す・ドラッグは自動で行うようにして撮影。動画の中の文字は韓国語です)。ひな形メニューのカードにも同じ動画が出ます。

**インベントリ**:フラグがオンになるたびに、その物が現れます(表示条件 `has_key`、`has_map`)。
<!-- clip hud-inventory -->

**好感度バー**:`love` が上がると、バーと数字がなめらかに追いかけて変わります。
<!-- clip hud-love -->

**ミニマップ**:場所ボタンがそのボックスへ移り(`Jump`)、ボックスで `place` を変えると「現在地:」の文字も変わります。
<!-- clip hud-map -->

**アイテムを使う(ドラッグ&ドロップ)**:ほかの所に置いた鍵は元の位置に戻り、ドアに置くと `door_open` がオンに、`has_key` がオフになります。ドラッグ中にセリフは進みません。
<!-- clip hud-use -->

```
draggroup:
    if has_key:
        drag:
            drag_name "鍵"
            dragged _PkBack(24, 64)      # 離すと元の位置へ
            text "鍵"
    drag:
        draggable False
        dropped _PkDrop("鍵", [SetVariable("door_open", True), SetVariable("has_key", False)])
        text "ドア(ここに置く)"
```

以下は Ren'Py でHUDがどう動くかと、スクリプトに出る形です。

| | call screen([画面] タブ) | show screen(HUD) |
|---|---|---|
| セリフ | 画面が閉じるまで止まる | 画面が出たまま流れ続ける |
| 大きさ | ふつうは画面全体(`modal True`) | 隅に小さく。位置と大きさを決める |
| 閉じる | ボタンを押すと値を返して閉じる(`Return`) | `hide screen`、またはボタンで開け閉め(`ToggleScreen`) |
| 結果 | 返した値 `_return` で分岐 | ボタンがフラグを変えたり(`SetVariable`)別の場所へ行ったり(`Jump`) |
| 使いどころ | 場所を選ぶ地図、大きなメニュー | ステータス、ミニマップ、カバン、時計 |

#### call screen と show screen をくらべる
<!-- clip screen-compare -->
前半は [画面] タブが作る形です。画面がセリフを覆い、どれかを選ぶまで進みません。後半はHUDです。一度出すとセリフを何行か進めてもそのまま残り、`hide screen` で閉じます。

```
call screen big_map          # 選ぶまで止まる
if _return == "cafe":
    jump cafe

show screen mini_map         # 出たままセリフは続く
e "地図は右上にずっと出てるよ。"
e "セリフを進めても消えないよ。"
hide screen mini_map
```

#### 好感度バー(フラグを見せるHUD)
<!-- clip screen-hud -->
HUDはフラグをそのまま読んで描きます。選ぶたびに `love` が上がると、バーと数字も自動でついてきます。シナリオで別に直すところはありません。

```
screen love_hud():
    frame:
        xpos 16 ypos 70
        vbox:
            text "ミナの好感度"
            bar value AnimatedValue(love, 5, 0.6)
            text "[love] / 5"

label cafe:
    show screen love_hud
```

#### カバン(インベントリ)
<!-- clip screen-bag -->
いつも出ている [カバン] ボタンがカバンのウィンドウを開け閉めします。カバンの中はオン/オフのフラグで持っている物だけを見せ、物のボタンはフラグを変えます。シナリオはそのフラグを見て続きます。

```
screen bag_button():
    textbutton "カバン":
        action ToggleScreen("bag_panel")

screen bag_panel():
    frame:
        vbox:
            if has_key:
                textbutton "鍵(使う)":
                    action SetVariable("door_open", True)
            text "メモ"

if door_open:
    "鍵を使うと扉が開いた。"
```

#### ミニマップ
<!-- clip screen-map -->
場所のボタンを押すとその場面へすぐ行きます(`Jump`)。今いる場所は文字のフラグ `place` で覚えておき、地図はその値を見て今の場所を塗ります。

```
default place = "home"

screen mini_map():
    frame:
        xalign 1.0 ypos 70
        vbox:
            for key, nm in (("home", "家"), ("cafe", "カフェ")):
                textbutton nm:
                    action Jump("map_" + key)
                    selected place == key

label map_cafe:
    $ place = "cafe"
    scene bg cafe
```

#### HUDで使う言葉
| Ren'Py | 意味 |
|---|---|
| `show screen 名前` / `hide screen 名前` | シナリオで出す・閉じる(ボックスの **[♡ HUD]**) |
| `config.overlay_screens` | ゲーム中ずっと出しておく(画面カード「ゲーム中ずっと表示」) |
| `zorder` | ほかの画面と重なったときの上下 |
| `text "[love]"`、`bar value …` | フラグの値を文字やバーで |
| `if has_key:` / `showif` | 条件のときだけ見せる |
| `SetVariable`、`ToggleVariable` | ボタンがフラグを変える |
| `Jump("label")` | ボタンがその場面へ行く |
| `ToggleScreen("名前")` | ほかのHUDを開け閉めする |
| `Return("値")` | call screen を閉じて値を返す([画面] タブの「返す値」) |
| `draggroup`、`drag` | ドラッグ&ドロップ([画面] タブの「ドラッグ可」「置き場所」) |

- フラグは pygaki のフラグカードで作ったものをそのまま使います(`default love = 0` は書き出しのときに入ります)。
- [画面] タブで作ったHUDは `pykaki_screens.rpy` に入ります(直接直すと次の書き出しで上書きされます)。タブで作れないもの(`for` の繰り返し、`selected`)は `game` フォルダーに新しい `.rpy` ファイル(例:`my_screens.rpy`)で直接書きます。

## 5. label(場面)の管理

- 左の **label 一覧** で名前、表示タイトル、色を変えます。
  - **名前** は Ren'Py の label 名なので、英字、数字、`_` だけを使います。例:`chapter1_rain`
  - **表示タイトル** は自由に書けます。
- 数字のボタンを押すと、その label のボックスへ画面が移ります。
- ボックスをほかの label へ移すには、右の欄の **label** で選びます。**[+ 新しい label に分ける]** もあります。
- 複数のボックスを **Shift+ドラッグ** で選ぶと、右で **同じ label にまとめる** ことができます。
- **[label の最初のボックスに]**:その label が始まるボックスを決めます。

## 6. 整理(自動整列)

左の「ボックスと整列」の欄にあります。

- **[全体を整列]**:開始から流れの順に上→下へ整理します。同じ label のボックスは 1 つの塊に集まります。
- **[label を整列]**:選んだボックスが属する label だけを整理します。
- **[選択を整列]**:Shift+ドラッグで選んだボックスだけを整理します。
- 向き(上→下 / 左→右)を変えられます。
- 気に入らなければ **Ctrl+Z** で戻します。

## 7. ゲームで確かめる、文字エフェクト

pygaki の中で動かしてみるプレイ画面は廃止しました。シナリオは Ren'Py のゲームで起動して見ます。

- **[▶ Ren'Pyで実行]**:今のシナリオを書き出し、Ren'Py ですぐゲームを起動します。ゲームがすでに起動していれば起動し直さず、シナリオだけを書き出します(ゲームが自動で読み直す)。押すたびにもう 1 つ起動したいなら、[設定] の「ゲームがすでに起動していれば無視」をオフにします。Ren'Py SDK パックに入ったアプリで使えます。Ren'Py が見つからなければ知らせるので、ランチャーの [Launch Project] で起動してください。
- **ゲームのウィンドウの横へ**:[設定] の「ゲームとつながったらこのウィンドウをゲームのウィンドウの横へ動かす」をオンにすると、ゲームとつながるたびにこのウィンドウをゲームのウィンドウの横の空いたところ(右、場所がなければ左)へ動かします。ゲームのウィンドウはそのままです。横が狭ければ画面の端に重ねて置きます(Windows のみ)。
- **[Ren'Pyでここへ移動]**:ゲームをそのボックスや行へ移します(3 章「Ren'Pyでここへ移動、位置を移動」)。
- **文字エフェクト欄**:右の欄のボックスカードの下にあり、今書いているセリフの行についていきます。サイズ、色、フォント、文字/秒、登場エフェクトを行ごとに選びます。空にしておくとゲームの設定に従います。集中モードではパネルと一緒に隠れます。
  - **エフェクト 1 番、2 番**:登場エフェクトは「1 番」「2 番」の 2 行です。行ごとにエフェクトを選び、✕ で外します。両方選ぶと 2 つのエフェクトが一緒に動きます(例:滑って止まる + 軽い揺れ)。
  - **詳細値**:エフェクトの横の [詳細値] を押すと、そのエフェクトの値(かかる時間、距離、強さ、色など)をスライダーで直します。プレビューにすぐ見え、↺ で初期値に戻します。直した値があれば、ボタンに数が見えます。
  - **テキストボックス**:[ボックスなし] を [吹き出し] や [丸い枠] に変えると、セリフの文字をボックスが囲みます。吹き出しはしっぽの向き(下、上、左、右、なし)を、どちらも傾き(度)を選べます。吹き出しは文字の色を別に決めなければ暗い文字で出ます。プレビューは似せたものなので、正確な形は Ren'Py で見てください。pygaki プラグインのあるゲームでだけ書き出します。
  - **画像/動画ボックス**:[画像/動画] を選ぶと、セリフの文字の後ろに画像や動画(webm など)を敷きます。文字の中央が基準で、基本のセリフ欄と名前欄の背景はなくなり、画像がセリフ欄の代わりになります。ファイルは欄に game フォルダ基準のパス(例: `images/say/cloud.png`)を打つか、[📂] で選びます(game の外のファイルは確認してから `images` か `movies` にコピーします)。[文字に合わせる] は文字の大きさに合わせて伸ばし、[画像サイズのまま] は画像の大きさのまま敷きます。**位置・サイズ・回転はゲームで**: ゲーム内編集画面(Shift+M)のセリフタブで [編集対象: 画像] を押し、画像をドラッグで動かし、ホイール(または A/D)で大きさ、Q/E で回してから Ctrl+S で保存すると、台本エディターが書き写します(欄の横に [画像 移動 · 倍 · 度 ✕]、✕ で元に戻す)。プレビューにも画像が敷かれます。 右の編集タブだけでなく、ボックスの中でセリフを編集するときも、文字欄の横に出るタグボックスのいちばん下の [テキストボックス] 欄で同じものを選べます。 動画なら [透過動画] のチェックが出ます。左に色、右に透明度を入れた動画(名前が `mask_` で始まれば自動でオン)を透明にして敷きます。透過 webm やグリーンバック動画は欄の横の [🎞] で変換して入れます(7-3)。[透明度] 欄(0~1)は画像を薄くします。
  - **選択肢の後ろの画像/動画**:[次の流れ] の選択肢の行の [🖼] を押すと、[通常]、[ホバー時](マウスをのせたとき、キーボードで選んだとき)、[決定時](押したあと少し見せてから進む。秒は横の欄、既定 0.5 秒)に画像や動画を入れます。位置・サイズ・回転はセリフと同じく、ゲーム内編集画面の選択肢タブの [編集対象: 後ろの画像] で決め、三つの画像に同じく使います。画像を使う選択肢は基本のボタン背景がなくなり、文字の大きさに合わせて小さくなります。pygaki プラグイン連携をオンにしたゲームでだけ書き出し、ゲームのプラグインが古い版ならチェックタブが [プラグインを更新] するよう知らせます。
  - **エフェクトフォルダー**:ゲームの `game/ui_kit/effects` フォルダーにエフェクトファイル(`.glsl`)を入れると、登場エフェクトの一覧の終わりと、背景/表示の行の「現れ方」の一覧の終わりに出ます。ファイルを抜くと一覧からなくなります(サンプルも同じ)。入れる・抜く・隠すは **[エフェクト] 画面**(7-1 章)で押してできます。手でするなら、消さずに一覧からだけ隠すとき、そのフォルダーの `effects_off.txt` にエフェクト名を 1 行に 1 つずつ書きます。隠したエフェクトをすでに使った行はそのまま動きます。サンプルとして、下から上がってくる、字間が狭まりながら、光が通り過ぎる(文字)、円で開く、帯で覆って開く(画像)が入っています。画像の方は [エフェクト] 画面のサンプルとゲームで見ます。新しいエフェクトの作り方は、そのフォルダーの `README.md` にあります。
  - **プレビュー**:いちばん上の欄に、この行の文字がエフェクトどおりに出ます。Ren'Py を起動しなくてもかまいません。登場エフェクトは Ren'Py と同じシェーダーのコードで描きます。値を変えるとまた出て、欄を押すか ↺ を押すともう一度見られます。文字は欄いっぱいに合わせるので、サイズ欄の値はここには見えません。
  - **登場エフェクト**:Ren'Py の基本エフェクト(ふわっと、裏返りながら、大きくなりながら、震え、波)と pygaki プラグインのエフェクト(散らばって集まる、落ちる、ランダムな順番、色のフラッシュ、大きく押される、カーソルタイプライター、色の残像、グリッチ、ぼやけてからくっきり、ブロックグリッチ、ゆらぎ、VHS ノイズ、浮かび上がる、傾いて入る、伸びて入る、滑って止まる、軽い揺れ、文字ごとのボックス、スタンプ、つぶれて弾む、立体文字)があります。pygaki プラグインのエフェクトは、pygaki プラグインのあるゲームでだけ書き出します。古いシナリオに、一覧から外したエフェクト(タイプライター、ぼかして待つ、溶け落ちる、データモッシュ、裏返して出る、LED 電光掲示板、上下に割れる、回転しながら、光のにじみ、上から描かれる、縁取りを塗る、飛び出すズーム、ぽんと飛び出す)が残っていれば、名前のまま欄に見え、ゲームでは 1 文字ずつ出ます。
  - **文字/秒の初期値**:文字が 1 つずつ出てはじめて見えるエフェクト(震え、波、ゆらぎ、VHS ノイズを除くすべてのエフェクト)は、欄を空にしておくと 30 で出て、そのまま書き出します。ほかの値を書けばその値を使います。
  - **Ren'Py の見本**:エフェクトを選ぶと、そのエフェクトを Ren'Py で撮った短い動画が出ます。文は例です。
  - 1 文字ずつタイピングするように:エフェクトなしで文字/秒だけ書く(例:30)
  - 一度に出たあと揺れる:文字/秒は空、エフェクト `震え`

## 7-1. エフェクトの管理([エフェクト] 画面)

ツールバーの左で **[エフェクト]** を押すと、文字エフェクト(セリフの文字が出る形)と画像エフェクト(背景、キャラクターが現れる形)を 1 か所で見られます。**[スクリプト編集]** を押すと戻ります。

- **[シェーダー] 欄**:上の [文字エフェクト | 画像エフェクト | シェーダー] でシェーダーを押すと、画面全体にかぶせるシェーダー(ボックスと label の ◐ シェーダーで選ぶもの)の一覧が出ます。**[非表示]** を押すと選択の一覧からだけ外れ(すでにかけたボックスはそのまま動く)、**[非表示を解除]** でまた出ます。右には **サンプル**(ゲームと同じシェーダーのコードでサンプル画像にかぶせた様子。[選ぶ] で自分の画像も可)と **詳細値のスライダー**、使用箇所が見えます。スライダーで合わせた値は見るためのものなので保存しません。[見る] を押すと、そのボックスのシェーダー欄へ移ります。アスキーはゲームが文字の画像を作って入れる必要があるので、アプリではサンプルを見られません。
- **ギャラリー / 一覧**:左上の **[▦ ギャラリー]**(初期値)は、エフェクトごとにプレビュー画像のあるカードを碁盤のように並べて見せるので、いくつものエフェクトの形を一緒に見ながらスクロールできます。文字エフェクトは文字が半分ほど出た瞬間、画像エフェクトは変わる途中、シェーダーはサンプル画像にかぶせた様子です。カードにマウスをのせるとそのカードだけが動き、押すと右の欄で詳細値を合わせます。**[▶ 動かす]** を押すと、画面に見えるカードが 6 つまで動き続けます(スクロールすると新しく見えたカードが引き継ぐ)。パソコンが少し多く働くので、[❚❚ 止める] で止まった画像に戻ります。カードの画像は 1 つずつ作るので、作っている間はその横に **「画像を作成中 12/35」** と進行バーが見え、できあがると消えます。**[☰ 一覧]** は名前だけを 1 行ずつ見せます。[シェーダー] 画面も同じです。
- **左の一覧**:上の [文字エフェクト | 画像エフェクト] で切り替え、検索欄に名前を書いて絞り込みます。行ごとに表示名、英語の名前、シナリオで使った行数、どこのものか(Ren'Py / 基本 / プロジェクト)が見えます。
- **非表示 / 非表示を解除**:カードの **[非表示]** を押すと、そのエフェクトが [スクリプト編集] とゲーム内編集画面の選択の一覧からだけ外れます(カードに「非表示」の印)。すでに使ったセリフはそのまま動きます。**[非表示を解除]** を押すとまた出ます。エフェクトファイルは消しません。一覧が長いとき、使わないエフェクトを隠すのに使います。
- **非表示は下へ**:上の **[非表示は下へ]** がオン(最初はオン)なら、隠したエフェクトが一覧・ギャラリーのいちばん下に集まります。非表示を押すと、そのカードがすぐ下へ下がります。オフにすると元の順番で混ざって見えます。ボタンの数字は隠した数です。[シェーダー] 欄にも同じボタンがあります。
- **エフェクトファイル**:エフェクトはゲームの `game/ui_kit/effects` フォルダーに入っているものだけが見えます。pygaki プラグインを新しい版にすると、新しいエフェクトも一緒に入ります。アプリでエフェクトファイルを入れたり抜いたりはしません。エフェクトファイルを手で消したゲームでも、そのエフェクトを使った行は止まらず、基本の形(文字は 1 文字ずつ、画像はふわっと、シェーダーはなし)で動きます。
- **新しいエフェクトの依頼文をコピー**:Claude に新しいエフェクトを頼むとき、一緒に渡す文をコピーします。作りたい形を書き足して渡せば OK です。アプリが外へ送るものはありません。
- **右のサンプル**:選んだ文字エフェクトがサンプルの文で流れます。サンプルの文は変えられ、欄を押すか [もう一度見る] でもう一度見ます。**詳細値** のスライダーを動かすとすぐにまた流れます。ここで合わせた値は保存しません(値は [スクリプト編集] のセリフ行ごとに決める)。
- **画像エフェクトのサンプル**:選んだ画像エフェクトが「前の画像」から「新しい画像」へ変わる様子で流れます(ゲームと同じシェーダーのコードで描く)。[選ぶ] で手持ちの画像ファイルを新しい画像の位置に入れてみられます(保存しない)。スライダーにはかかる時間もあります。**スクリプトでの書き方** の行に、今合わせた値が `with img_fx.use("bands", 1.4, count=10)` のように出るので、直接コマンドの行に書くなら [コピー] します。背景・表示・隠すの行では、「現れ方」で画像エフェクトを選んでから横の **[詳細値]** を押し、かかる時間と値をスライダーで決めます(その行にだけ当てはまる)。
- **使用箇所**:そのエフェクトを使った行が出て、[見る] を押すと [スクリプト編集] のそのボックスへ移ります。
- Ren'Py のフォルダー(pygaki プラグインのあるゲーム)をつないでいなければ、見るだけです。非表示はつないだあとにできます。

## 7-2. フォントの管理([フォント] 画面、アプリ)

ツールバーの **[フォント]** を押すと、ゲームに入っているフォントを見たり、新しいフォントを入れたり、ゲーム全体の標準フォントを決めたりできます。

- **フォントの追加**: **[+ フォントを追加]** でフォントファイル(.ttf, .otf, .ttc)を選ぶか、この画面にファイルをドロップします。`game/fonts` にコピーされます。入れたフォントはセリフ行のフォント欄、タグボックスの `{font=}`、ゲーム内編集画面のフォント選びにも出ます。
- **標準フォント**: 左上に、セリフ・名前・メニュー/ボタン・選択肢が今どのフォントかが出ます(`game/gui.rpy` の `gui.text_font` などの値)。フォントを選んで右の **[標準フォントに]** で場所を押すと、その行だけが変わります。初めて変えるとき、元の `gui.rpy` をプロジェクトフォルダーの `ui_kit_backup/gui/` に残します。起動中のゲームは Shift+R で再読み込みします。1行だけ変えるなら、セリフ行のフォント欄か `{font=}` タグを使います。
- **見本**: 選んだフォントで見本の文(変えられます)と韓国語・日本語・英語の行を描きます。フォントにない文字はゲームと同じく **□** で表示されます。
- **収録文字**: 英数字、ハングル、かな、漢字が何字入っているか、**台本で使った文字のうち、このフォントにない文字** を知らせます。Ren'Py はない文字を四角で描くので、ここに出た文字は別のフォントを使うか書き換えます。
- **情報とライセンス**: ファイルサイズとフォントに書かれたライセンスを見せます。SIL Open Font License(OFL)はゲームに入れて配布でき、Windows付属のフォントは配布できない場合があると知らせます。配布前に必ずライセンスを確認してください。
- **使用箇所と外す**: 標準フォントの場所、台本の行([表示] でそのボックスへ)、ゲームコードのファイルでの使用箇所が出ます。どこにも使っていない `game/fonts` のフォントだけ **[フォントを外す]** で外せます。ファイルは `ui_kit_backup/fonts/` に残ります。

## 7-3. 透過動画を作る(アプリ)

Ren'Py 8.5.3 は透明な部分がある webm をそのまま再生できません(透明な部分が黒くなります)。Ren'Py が使う透過動画は、**左に色、右に透明度(白が見える部分)**を並べて入れた動画です。pygaki アプリがこの形に変換します。ffmpeg などほかのプログラムはいりません。

- **開く場所**: 画像/動画欄(セリフのテキストボックス、選択肢の後ろの画像)の横の **[🎞]**、または [画像・動画] カードの **[🎞 透過動画を作る]**。
- **入れられるもの**: 透過 webm、動く GIF・WebP・PNG、**PNG 連番画像**(何枚かをまとめて選ぶと名前の数字順)、**グリーンバック動画**(mp4、webm)。ファイルをウィンドウにドラッグしてもかまいません。
- **透明にする部分**: [元の透明度] は元のファイルの透明度をそのまま使います。[色を外す] はグリーンバックのように 1 色で敷かれた背景を抜きます。元に透明な部分がなく、縁に同じ色が敷かれていれば、自動で [色を外す] にしてその色を選んでおきます。**強さ**を上げると背景に近い色までもっと抜け、**端**を上げると境目がやわらかく透けます。[縁に残った背景色を取る] は髪のまわりなどに残る緑っぽさを減らします。人物の服に背景と同じ色があるとそこも抜けるので、強さを下げます。
- **プレビュー**: チェック柄の上に結果が出ます。下のバーでフレームを選んで見ます。その下の小さい絵は実際に保存される形(左が色、右が透明度)です。
- **サイズ、1 秒の枚数**: 大きい動画は高さ 1080・720 などに縮めるとゲームが軽くなります。1 秒の枚数は、動画なら元の値が入り、PNG 連番なら決めます。減らすとファイルが小さくなります。
- **保存**: [作成] を押すと `game/movies/mask_名前.webm` に保存します(同じ名前があれば確認します)。終わると透明に合わせた様子が再生され、[この欄に入れる](画像/動画欄から開いたとき)か [表示の行を入れる]([画像・動画] カードから開いたとき)ですぐ使えます。
- **ゲームでは**: 名前が `mask_` で始まる動画は pygaki プラグインが透過動画として扱います。`movies` フォルダの動画は名前でそのまま表示(`show 名前`、前の `mask_` は除く)、テキストボックスと選択肢の後ろの画像も自動で透明になります(プラグイン ui_kit 4.16。古い版でも台本エディターが `media_mask=True` を書きます)。プラグインなしで使うときは `Movie(play="movies/mask_名前.webm", side_mask=True)` です。

## 8. チェックと書き出し

- **チェック** タブ:つながっていない線、空のセリフ、間違った名前のように、Ren'Py で問題になりそうなものを見せます。項目を押すとそのボックスへ移ります。
- **画像名のチェック**:Ren'Py プロジェクトをつないでいれば、背景・表示の行の画像がゲームにあるかを見ます。画像の名前は「タグ 属性」(例:`mina smile`)なので、`images`(動画は `movies`)フォルダーのファイル名とゲームのコードの `image` 定義のうち、そのタグの画像で、行に書いた属性をすべて持つものがなければ警告します(そのタグの画像の名前も見せる)。警告するだけで、書き出しは止めません。`layeredimage` で作ったタグは属性を問いません。
- **スクリプト** タブ:書き出す `.rpy` をあらかじめ見てコピーできます。
- **[.rpy書き出し]**:保存場所にはゲームフォルダーの **`game/` フォルダー** を選んでください。ファイル名は `script_flow.rpy` がおすすめです。もとの `script.rpy` と重ならないようにするためです。
- 一度書き出したあとは、**Ctrl+E**(または [同じ場所に再書き出し])ですぐ上書きします。
- Ren'Py を起動したまま **Shift+R** を押すと、変わったスクリプトを読み直します。
- **自動書き出し**(Ren'Py のフォルダーをつないだとき、pygaki プラグイン ui_kit 4.2 から):シナリオを直して少し手を止めると、Ctrl+E を押さなくても `script_flow.rpy` が自動で書かれ、開発モードで起動しているゲームが自動で読み直します。左の [チェック] カードにエラーがあれば、直すまで書き出しません。
- **[スクリプトを追う]**(タブの段のピンクのまとまり、以前の名前はゲームの行を追う):オンにしておくと、読み直したゲームが今書いている行へ移ります(通り過ぎた行なら巻き戻し、そうでなければその行まで飛ばす)。何か所も直したあと最初から見通したいならオフにしてください。オフにすると、ゲームは元の場所にそのままいます。

> **注意**:書き出した `.rpy` を VSCode で直接直すと、次の書き出しのときに上書きされます。シナリオはいつもこのツールで直してください。

### セリフの中の特殊文字
- `[` は自動で文字のまま出るように変えます(`[[`)。
- `{b}太字{/b}` のような Ren'Py のテキストタグはそのまま使えます(タグボックスで入れてもよい)。オフにするには左の **設定** で変えます。
- タグの組が合わなければ、左の [チェック] カードに出ます。開くタグなしで `{/b}` だけあると Ren'Py が止まるのでエラー、閉じていないタグと Ren'Py の知らないタグは警告です。
- `%` はそのままだと Ren'Py が止まります。新しいシナリオは自動で `%%` に変えます。古いシナリオで左の [チェック] カードに `%` のエラーが出たら、**設定 → % を文字のまま** をオンにしてください。

## 9. 保存とバックアップ(重要)

| 方法 | 説明 |
|---|---|
| **自動保存** | 直すたびにブラウザーの中に保存されます。タブを閉じても、また開けば続きを書けます。 |
| **[バージョン保存]** | メモを付けてその時点を残します。**[バージョン一覧]** で戻せます。開く、新規、復元の前には自動でバックアップされます。 |
| **自動保存版** | 変更があれば 5 分ごとに [バージョン一覧] に残ります。最近の 30 個だけを置きます。 |
| **[保存] (Ctrl+S)** | `.flow.json` ファイルに保存します。**これが本当のバックアップです。** |

- 自動保存とバージョンは **そのブラウザーの中にだけ** あります。ブラウザーのデータを消したり、ほかのブラウザーやパソコンに移ったりすると消えます。
- なので大事な時点では必ず **Ctrl+S** でファイルを保存し、そのファイルを **Dropbox のような同期フォルダー** に置いてください。
- Chrome/Edge では、一度保存したあとに Ctrl+S を押すと同じファイルにすぐ上書きします。
- ほかのパソコンやブラウザーで続きを書くには、**[開く]** で `.flow.json` を読み込みます。
- 左の「Ren'Py プロジェクトの情報」のファイル保存の行に出る **オレンジの ●** は、「ファイルに保存していない変更がある」という意味です。自動保存した時刻もその下に見えます。

## 9-1. pygaki プラグインと一緒に使う

[pygaki プラグイン](https://github.com/halftomatodev/pygaki/tree/main/showpy) は、ゲームを実行したままマウスで画面を直す Ren'Py プラグインです。**文と文字の形はここで、画像と動画、サウンド、位置、画面エフェクトは Ren'Py で** 合わせられます。

左の「Ren'Py プロジェクトの情報」の **[Ren'Py プロジェクトをつなぐ]** を押してプロジェクトフォルダーを選べば終わりです。つないだあとは、上の行に [フォルダーを変える] [再読み込み] [切断] が出ます。

- `game` フォルダーを探してつなぎ、pygaki プラグインがあれば連携をオンにします。
- `game/script_flow.rpy` をすぐに作ります。Ren'Py で実行すると最初のボックスから始まります。`script.rpy` はそのままでかまいません。
- そのあとは **Ctrl+E** で書き出します。
- Ren'Py のエディターで画像やサウンドを入れてこのウィンドウに戻ると、入れた行がシナリオに現れます。
- **シナリオファイルもそのプロジェクトフォルダーに保存されます**:`プロジェクト名.flow.json`。Ctrl+S、Ctrl+E を押すときに書かれます。フォルダーにシナリオファイルがすでにあれば、そのシナリオを開くか、今のシナリオを使うかを尋ねます。
- ブラウザーを開き直すと、権限をもう一度許可する必要があります。
- `game` フォルダーを直接選ぶと、シナリオファイルはフォルダーに保存しません。アプリで続きを書くなら、game の上のプロジェクトフォルダーを選んでください。
- キャラクターの id を `e` にすると、`script.rpy` の `define e` と重なります。ほかの id を使ってください。

連携をオンにすると変わる点:
- セリフと名前の **位置**、行ごとに変える **画面エフェクト** は、Ren'Py のエディター(Shift+M)のセリフタブで決めます。保存してこのウィンドウに戻ると文字エフェクト欄に値が見え、書き出し直しても残ります。
- 演出の行の欄に、フォルダーのファイル名がおすすめの一覧として出ます。
- 画像の位置の欄がなくなります。位置は Ren'Py のエディターでドラッグして決めます。
- **ほかのシナリオのスクリプトは上書きしません**:ウィンドウを開いて最初に書き出すとき、フォルダーの `script_flow.rpy` に今のシナリオにないボックスが多ければ、自動書き出しは止まって下に知らせます。このシナリオで上書きするなら Ctrl+E を押して [OK] を選びます。上書きする前のスクリプトは `script_flow.rpy.bak` として残ります。
- pygaki プラグインのないゲームでは、この連携をオフにしたまま書き出します。文字の形、速度、登場エフェクトはそれでも当てはまります。

詳しい手順と問題の解決は [pygaki プラグイン カスタムガイド](https://github.com/halftomatodev/pygaki/blob/main/showpy/docs/CUSTOM_GUIDE.md)(この案内書の「プラグイン カスタムガイド」の章)を見てください。

## 9-2. デスクトップアプリ(Ren'Py パック)

pygaki パックの Ren'Py ランチャーでプロジェクトを選び、**[pygaki로 편집]**(pygaki で編集)を押すと pygaki アプリが開きます。

- そのプロジェクトのシナリオがすぐ開きます。フォルダーの連携、権限の画面はありません。
- シナリオはプロジェクトフォルダー直下の `プロジェクト名.flow.json` に **直すたびに自動保存** されます。このファイルがシナリオの元データです。
- Ctrl+E で書き出すと `game/script_flow.rpy` にすぐ書かれます。
- ゲーム内編集画面で入れた画像、サウンドの行は、保存されるとすぐシナリオに書き込まれます。
- 上の行の [フォルダ管理] を押すと、機能ごとのフォルダ(画像、動画、BGM・効果音、ボイス、フォント、UI 画像、カーソル、クリック待ち、文字エフェクト、画面シェーダー、Ren'Py セーブ、アプリ設定)の一覧が出ます。選ぶとエクスプローラーで開き、まだない game の中のフォルダは作ってから開きます。検索欄に打つと絞り込まれ、矢印キーと Enter でも選べます。[別のプロジェクト] はほかのプロジェクトを新しいウィンドウで開きます。[再読み込み] はフォルダーの画像・サウンドと、ゲーム内編集画面が入れた行を読み直します。
- [開く] でほかの `.flow.json` を選ぶと 2 つのシナリオ(ボックスの数、行の数、保存した時刻)を見せ、[OK] を押すとその内容をこのプロジェクトのシナリオに持ってきます。[新規] はこのプロジェクトのシナリオを空にします(今のシナリオはバージョン一覧にバックアップされる)。
- プロジェクトフォルダーに `.flow.json` が複数あれば、最初に開くときどれを開くかを選びます。次からは選んだファイルを開き、左の「Ren'Py プロジェクトの情報」の [ほかのシナリオファイルを選ぶ] で選び直します。

### 以前の Web 版で書いたシナリオ
Web 版は廃止しました。Web で Ctrl+S で保存した `.flow.json` があれば、アプリの [開く] で取り込みます。シナリオファイルにはどの版で保存したかが残り、アプリより新しい版で書いたシナリオなら、左の欄に「より新しい版」の警告が出ます。

### [GUI編集] 画面(ゲームと並べて)

ツールバー左の **[スクリプト編集 | GUI編集 | エフェクト | シェーダー]** で **GUI編集** を押すと、ゲーム画面の装飾に変わります。Ren'Py ランチャーの [Launch Project] でゲームを起動しておくと(開発モード)自動でつながり、上のゲーム接続ボタンが薄い青になります。いちばん上の「GUI編集 ⓘ」に短い案内があり、左の欄のカードごとの ⓘ にその欄の説明があります。ゲームのウィンドウとアプリのウィンドウを並べて使います。

- **中央**:ゲームが今どの画面にいて、スクリプトの何行目を実行中か、その前後の行を見せます。pygaki で書いたシナリオなら [シナリオのボックス: …] を押してそのボックスへ移ります。スクリプトの行を押すとゲームがその行へ移ります(通り過ぎた行なら巻き戻し、そうでなければゲームを始め直してその行まで飛ばす)。[印を隠す: オン/オフ] で `# @l:` のような印を画面上だけ隠します(行番号とスクリプトファイルはそのまま)。ゲームの pygaki プラグインが新しい版(`ui_kit` 4.5 から)なら、印が行ごとに上の行に別にあるのではなく `"セリフ"  # @l:l1` のように行末に付くので、スクリプトがずっと短くなります。古いプラグインを使うゲームには以前どおり書き出します。
- **左**:直すものの一覧をまとまりのカードで:スプラッシュ(ロゴ、注意、操作案内画面と自作のページが 1 つずつ。押すとゲーム内エディターもそのページへ。操作案内画面のすぐ下にショートカット編集)/ タイトルメニュー(タイトルメニュー、タイトルシェーダー、シェーダーの初期値)/ ゲーム内メニュー(ESC メニュー、ゲーム内メニューのシェーダー)/ 確認画面、UI テキスト / **ゲームの初期値**(セリフのボックス、選択肢、画像・動画の配置、カーソル・クリック待ち・セリフ音)。ボックスごとに変えるものは [スクリプト編集] で行います(セリフ・選択肢の位置は [位置を移動]、画像・サウンドはボックスの背景・画像・サウンドのカード、セリフ音・速度はセリフ行のカード、カーソル・クリック待ちはボックスのカード)。右の欄も左と同じくカードです(保存とゲーム内編集画面 / 直す欄)。
- **右**:選ぶ欄。
  - **タイトルメニュー、ゲーム内メニュー**:いちばん上の **背景** で game フォルダーの画像や webm 動画を選びます。選ばなければタイトルは黒い画面、ESC メニューは透明(後ろのゲーム画面が見える)です。一覧のいちばん下の **タイトル、サブタイトル** を選ぶと文の内容を書けます(空なら見えない)。項目や文字を選んで、位置、回転、傾き、拡大、文字サイズ、色、フォント、**文字エフェクト**(セリフの登場エフェクトと同じ一覧)を変えます。ゲーム画面で、選んだ文字の上のピンクの四角をドラッグすると回ります(Shift:15 度ずつ)。(pygaki プラグイン 4.20、ui_kit 3.19 以上)ゲーム画面で項目をドラッグしても数字が一緒に変わります。[通常/選択時]、[この項目だけ/すべての項目共通] もここで選びます。ゲームがその画面にいなければ、[タイトルへ]、[ESC メニューを開く] が出ます。
  - **カーソル、クリック待ち(CTC)、セリフ音**:テキスト速度、セリフ音と音量([試聴] はゲームで音が鳴る)、クリック待ち表示とカーソルのオン/オフ、画像 12 マス、1 フレームごと/2 フレームごと、カーソルの方式とクリックの基準点、クイックメニューをここで変えます。マスを押すと下にゲームフォルダーの画像が出て、画像を押すとそのマスに入って次のマスへ進みます。いちばん下のプレビューで文字の速度と画像が回る様子を見ます。カーソルやクリック待ち表示のオン・オフは、保存するとゲームが読み直したあとに見えます。画像は、カーソルは `game/gui/cursor/`、クリック待ち表示は `game/gui/ctc/` に入れます(1 番から順に、64×64 推奨。pygaki の新しいプロジェクトにはサンプル入り)。画像のマスは市松模様の下地なので、白い画像も見えます。**カーソルとシェーダー**:カーソルがシェーダーを受けるか(1 番、2 番とも受ける / 2 番だけ受ける / シェーダーを受けない)を選び、シェーダー欄と同じく行を選んで [ここから適用] します。(pygaki プラグイン ui_kit 3.15 以上、カーソルとシェーダーは 4.22 以上)
  - **タイトルシェーダー、ゲーム内メニューのシェーダー**:その画面だけにかかるシェーダー 1 番、2 番を、このゲームのシェーダー(基本、アスキー、VHS、ゆらぎ …)から選びます。2 つの枠が重なります。「シェーダーの適用をすべて取り消す」は両方を基本に。ゲーム内メニューのシェーダーは ESC メニューを開いたまま選びます(ゲーム中なら [ESC メニューを開く] が出る)。
  - **シェーダーの初期値**:欄を開くとすぐ 1 番、2 番です。選ぶとゲーム画面にすぐ見え、選んだエフェクトの詳細属性(文字の除外、プリセット、スライダー)がその行のすぐ下に出ます(行末の [詳細属性をたたむ])。ここではシェーダーの **見た目** をゲーム画面を見ながら直して [保存] します。**どの場面にかけるかは [スクリプト編集] で**、ボックスや label の右上の ◐ シェーダーで決めます(3 章「シェーダー」)。ゲーム開始時のシェーダーはいちばん下の [最初の状態を開く]。パネルの行の一覧と [ここから適用] はゲーム内エディターと同じもので、pygaki で書くシナリオではボックスのシェーダーを使う方が簡単です(2 つを混ぜると、ボックスの最初の行のシェーダーが先にかかる)。系統図はアプリでは開きません(ゲームのウィンドウのエディターで G)。
  - **セリフ、選択肢、画像の配置、終了メッセージとボタンの文字**:ゲーム内エディターのパネルとまったく同じボタン、スライダー、入力欄がここに出ます。フォント、色、画像の選択画面も欄のいちばん上に出ます。ゲーム画面でドラッグして動かすことと、ショートカット(R でもう一度見る など)はゲームのウィンドウで行います。タイトルにいるときにセリフ、画像の欄を選ぶと [ゲーム開始] が、ゲーム中にタイトルシェーダーを選ぶと [タイトルへ] が出ます。(pygaki プラグイン ui_kit 3.16 以上。古い版なら「ゲーム内」の印が付き、ゲーム内のパネルで開く)
  - **スプラッシュ**:ページを選んで、背景色、背景・ロゴの画像、タイトル・本文の文字、位置、進むとき、時間を変えます。[このページを見る] を押すと、ゲームのウィンドウにそのページが出ます(クリックで閉じる)。保存すると `splash/splash_layout.rpy` に書かれます。タイトル、本文の文は `splash/splash_config.rpy` で直します。(pygaki プラグイン 4.18、splash 1.2 以上)いちばん上の「ゲーム起動時」の [表示] [非表示] でページを入れたり抜いたりし、その下の行で、今ゲームを起動したとき出るかどうかと、出ない理由を見ます。[また表示する] は「次から表示しない」と見た記録を消します。(splash 2.1 以上)
  - **ショートカット編集**(スプラッシュの操作案内画面の下):行ごとに機能名とキーボタンがあります。Ren'Py 標準の機能(セリフ送り、スキップ、スクリーンショット …)と決まった動作(クイックセーブ、環境設定を開く …)が最初から入っています。キーボタンを押してゲームウィンドウで新しいキーを押すと変わります(Esc はやめる、Ctrl だけ押して離すと Ctrl)。[+] はキーをもう 1 つ。機能名を押すと [키 단추로](キーボタンで、アプリで選ぶとき)、[키 빼기](キーを外す)、[처음 키로](最初のキーに)、説明欄が出ます。ほかの機能が使っているキーを押すと警告と案内が出て、[그쪽에서 빼고 바꾸기](あちらから外して変える)を押すと変わります。**[안내 화면으로 내보내기](案内画面へ書き出す)** を押すとスプラッシュの操作案内画面の表がこの設定に従い、表示する機能は操作案内画面の欄の一覧で押して選びます。ESC の操作方法画面の一覧にも変えたキーが自動で入ります。直すとすぐゲームにかかり、保存すると `hotkeys/hotkeys_layout.rpy` に書かれます。(pygaki プラグイン hotkeys 1.2、splash 2.5 以上)
- **[保存]**(または Ctrl+S)はゲーム内エディターの保存と同じです。値はゲームフォルダーの `*_layout.rpy` やスクリプトに保存されます。
- アプリとつながっている間、ゲームのウィンドウの編集画面パネルは隠れます。ゲームのウィンドウにも見せるには、上の [ゲームのウィンドウの編集画面: 非表示] ボタンを押すか **F9** を押します(アプリのどこでも、ゲームのウィンドウでエディターが開いているときも)。もう一度押すと隠れます。アプリが覚えておき、次にゲームにつながるときもそのままです。ゲームのウィンドウに見えている間は、直す欄がゲームのウィンドウへ移ります。ショートカットは設定 → ショートカットで変えます。
  - **テキスト欄**:長いテキスト欄(スプラッシュの文、UI テキストなど)はパネルの幅いっぱいに 3 行で出ます。欄の横の [広く]/[狭く] で欄ごとに変えられ、アプリが覚えます。Enter で終わり、Esc で取り消し、改行は `\n`。
  - **確認画面、UI テキスト**:終了確認画面(「終了しますか?」)、[はい] [いいえ]、クイックメニュー・メニューボタンの文字を変えます。確認画面は [この画面を見る] ですぐ見られ、ボタンの文字は保存するとゲームが読み直したあとに変わります。(pygaki プラグイン ui_kit 3.23 以上)
  - **画像、動画の配置**:[images フォルダーを開く]、画像の選択画面のフォルダーを開くボタンでエクスプローラーを開いてファイルを入れます。
- **編集中はゲームが進みません**:欄を選ぶとゲーム内エディターが開き、その間ゲーム画面のクリックとキーはエディターへ行きます(ドラッグで動かすため)。ゲーム画面の上に「編集中 | Esc で閉じる」が見えればその状態です。ゲームを進めるには、ゲームのウィンドウで Esc を押すか、アプリの [エディターを閉じる] を押します。[シナリオ] 画面へ行くと自動で閉じます。カーソル/セリフ音の欄はエディターを開きません。
- pygaki プラグイン(ui_kit)3.14 以上が入っているゲームでだけつながります。

## 10. 集中モードと環境設定

### 集中モード
**Ctrl+\\**(韓国語キーボードでは **Ctrl+₩**、または ツールバーの **[集中]**)を押すと、ツールバー、左、右、ミニマップがすべて隠れてキャンバスだけが残ります。もう一度押すとまた出ます。

- ボックスをダブルクリックして書いている間は **下線の形のカーソル** が点滅します。画面が空いていても、今書いている最中か、どこに書いているかがわかります。
- 集中モードでボックスの中に書いている間は、**カーソルのある行だけがくっきり** して、同じボックスのほかの行は薄く、ほかのボックスと線はもっと薄く見えます。薄いボックスにマウスをのせると少しの間くっきりします。薄さは [設定] で選びます。
- 集中モードでもショートカット(保存、新しい行など)はそのまま使えます。

### 言語(Language)
上の行の **한국어 / 日本語 / English** で、スクリプトエディターの画面の文字の言語を変えます。選んだ言語はこのパソコンに記憶されます。このヘルプ(F1)もその言語に変わります(pygaki 案内書の日本語版・英語版と同じ文)。シナリオ(セリフ、ボックスのタイトル)とスクリプトは変わりません。まだ訳のない文字は韓国語で見えます。

ほかの場所の言語:
- **ゲーム内編集画面**(Shift+M):パネルの **[言語]** ボタンを押すたびに 한국어 → 日本語 → English。選んだ言語はそのゲームに記憶され、最初はゲームの言語に合わせます。変わるのは編集画面の文字だけで、ゲーム画面(セリフ、メニュー、編集中の文字)はそのままです
- **Ren'Py ランチャーの pygaki ボタン**([pygaki で編集]、[pygaki 案内書]、[プラグインを更新])とお知らせの文:ランチャーの言語設定(Preferences → Language)に合わせます。韓国語なら韓国語、日本語なら日本語、それ以外は英語。[pygaki 案内書] もその言語版を開きます

### 環境設定
ツールバー右の **[設定]** で変えます。この設定はそのブラウザーにだけ保存され、シナリオファイルには入りません。

- **画面のテーマ**:**リンゴスタイル** 1 つです(パステルの背景の上に半透明のツールバー)。以前の暗め、自分で選ぶ、文字色の選択はなくしました。
- **label の境界線**(0〜6px、初期値 3px):同じ label のボックスを囲む線の太さです。0 なら線は見えません。
- **ボックスの色(このシナリオに保存)**:選んだボックスを塗ります。色のマスを押して選ぶか、hex コード(#RRGGBB または #RGB)を直接書きます。[label の色に戻す] で消します。選んだ色はシナリオファイルに保存され、Ctrl+Z で戻せます。画面の設定のうちシナリオファイルに入るのはこれだけです。
- **フォント**:Pretendard 500 の 1 つです。アプリの中に入っているので、インターネットがなくても見えます(日本語の文字はパソコンのフォントで表示)。
- **Ren'Py で実行**(アプリ):「ゲームがすでに起動していれば無視」をオンにしておくと、ゲームが起動しているときに [▶ Ren'Pyで実行] を押しても、シナリオだけを書き出してゲームはそのままにします。オフにすると押すたびにゲームをもう 1 つ起動します。起動しているかどうかは、pygaki プラグインの入ったゲームとの接続と、このアプリで起動したゲームでわかります。
- **集中モードのぼかし**:オフ、弱め、普通、強め
- **ショートカット**:変えたい動作のキーの欄を押して、新しいキーを押します。Esc を押すと取り消しです。Esc(編集の終わり)、Delete(削除)、F1(ヘルプ)は変えられません。
  - 文字を打つときと重ならないよう、Ctrl か Alt を一緒に押す必要があります。F2〜F12 は単独で使えます(F1 はヘルプ)。
  - ほかの動作に使っていたキーを選ぶと、そちらのショートカットは空になります。
  - **[デフォルトに戻す]** を押すと最初のキーに戻ります。
- **[すべての設定を初期値に]**(設定画面のいちばん下):画面のテーマ、フォント、集中モードのぼかし、ショートカットをすべて初期値に戻します。シナリオとボックスの色はそのままです。

## 11. ショートカット(初期値)

| キー | 動作 |
|---|---|
| ボックスをダブルクリック | ボックスの中で編集 |
| 空いたところをダブルクリック | 新しいボックス |
| Ctrl+\\ | 集中モードのオン/オフ |
| Ctrl+Enter | (編集中)同じ話し手で新しい行 |
| Ctrl+Shift+Enter | (編集中)次のボックスへ続けて書く(なければ新しいボックス) |
| Alt+Enter | (編集中)次の流れのウィンドウをキーボードで開く/閉じる(方向キーで選ぶ、Enter で決める、Esc で閉じる) |
| Ctrl+B / Ctrl+I / Ctrl+U | (セリフのテキスト欄で)選んだ文字を太字 / 斜体 / 下線のタグに |
| Esc | ボックスの編集を終える |
| Delete | 選んだボックス/線を削除 |
| Shift+ドラッグ | 複数のボックスを選択 |
| Ctrl+S / Ctrl+Shift+S | 保存 / 名前を付けて保存 |
| Ctrl+E | `.rpy` を同じ場所に再書き出し |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す(テキスト欄の中でも。設定画面とフラグ名の欄はその欄の文字だけ) |
| Alt+N | 新しいボックス |
| Ctrl+C / Ctrl+V | (テキスト欄の外で)選んだボックスをコピー / マウスの位置に貼り付け |
| Ctrl+D | 選んだボックスを複製 |
| Ctrl+F | 検索・置換(開いていれば検索する文字の欄へ) |
| F1 | ヘルプ |

Esc、Delete、ダブルクリック以外は [設定] で変えられます。

## 12. よくある質問

- **ボックスで編集ができません** → Ctrl+F5 で再読み込みしてみてください。古いバージョンが残っていることがあります。
- **Ren'Py でエラーが出ます** → まず **チェック** タブの ⛔ の項目を確かめてください。label 名やキャラクターの id に英数字以外の文字や空白があるとエラーになります。
- **ほかの人と共有してもいいですか?** → シナリオをやり取りするなら `.flow.json` ファイルを送ってください。受け取った人はアプリの [開く] で取り込みます。
- **説明が見えません** → 欄の名前の横の ⓘ にマウスをのせるか、[ヘルプ](F1)を開いて検索欄に言葉を書いてみてください。
