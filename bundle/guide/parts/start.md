# 시작하기

## pygaki가 하는 일

렌파이(Ren'Py) 코드를 배우지 않아도 게임을 만들 수 있게 돕는 도구 묶음입니다.

* **pygaki**(pygaki 앱의 [대본 편집]): 상자와 선으로 대본을 쓰는 편집기입니다. 대사, 선택지, 배경, 그림, 소리, 화면 셰이더를 정하면 렌파이 원고(`game/script_flow.rpy`)로 내보냅니다.
* **pygaki 플러그인**: 렌파이 게임의 `game/` 폴더에 넣는 플러그인 넷(`ui_kit`, `screen_fx`, `hotkeys`, `splash`)입니다. 타이틀 메뉴, 선택지, 대사 스타일과 등장 효과, 화면 전체 셰이더, 스플래시 화면을 바꾸고, 게임을 켠 채로 마우스로 고치는 **pygaki editor(게임 안 편집 화면)**가 들어 있습니다.
* **pygaki 앱**: 위쪽 탭 여섯 개로 나뉩니다. [대본 편집]은 대본 쓰기, [GUI 편집]은 실행 중인 게임과 이어져 pygaki editor를 앱에서 조종, [화면]은 고르는 화면과 HUD 만들기, [효과]·[셰이더]는 효과 구경과 숨기기, [글꼴]은 게임 글꼴 관리입니다.
* **pygaki 묶음**: 렌파이 SDK + 플러그인 템플릿 + 런처 버튼 + pygaki 앱을 윈도우용 폴더 하나로 묶은 것입니다.

| 하고 싶은 것 | 어디서 |
| --- | --- |
| 대사, 선택지, 이야기 흐름 쓰기 | pygaki [대본 편집] |
| 플래그(변수)와 조건에 따라 갈라지는 이야기 | pygaki 오른쪽 칸 맨 위 플래그 카드, 상자의 다음 흐름 "조건 분기"(흐름 버블, Alt+→) |
| 대사 글자 크기, 글꼴, 색, 속도, 등장 효과 | pygaki 대사 줄의 글자 효과 카드, 글 칸의 태그 상자 |
| 상자·장면마다 화면 셰이더, 전환, 대사 소리, 커서·클릭 대기 | pygaki 상자나 label의 ◐ 셰이더 |
| 그림, webm 영상, 음악, 효과음 넣기 | pygaki 상자의 배경 / 그림·영상 / 효과음·음악 카드 |
| 대사·선택지·그림의 위치 | 줄의 [위치 옮기기] → 게임 화면에서 끌기 → [저장] |
| 타이틀 메뉴, 커서 등 게임 전체 모양 | pygaki 앱 [GUI 편집] (pygaki editor와 같음) |
| 효과·셰이더 구경, 목록에서 숨기기 | pygaki 앱 [효과], [셰이더] |
| 설정 파일의 값으로 더 자세히 | 이 안내서의 "플러그인 커스텀 가이드" 장 |

## 받기와 첫 프로젝트

1. 다운로드 [github.com/halftomatodev/pygaki/releases/latest](https://github.com/halftomatodev/pygaki/releases/latest)에서 pygaki 묶음 zip을 받아 아무 폴더에 풉니다(저장소: [github.com/halftomatodev/pygaki](https://github.com/halftomatodev/pygaki)).
2. `renpy.exe`로 런처를 켭니다(영어로 나오면 preferences → Language → 한국어).
3. 런처 왼쪽 아래 **[+ Create New Project]**(새 프로젝트 만들기)에서 **Pygaki**를 고르고 이름과 해상도를 정합니다. 해상도는 레트로 셋(PC-98 640x400, Y2K 800x600, Millennial 1024x768)과 고해상도 둘(1280x720, 1920x1080), 사용자 정의가 있습니다. 레트로와 사용자 정의는 창에 맞는 가장 큰 정수 배율로 키우고 고른 해상도의 픽셀로 그립니다(픽셀 퍼펙트, 프로젝트의 `game/pixel_perfect.rpy`). 높이가 720보다 작으면 글 크기와 pygaki 설정 값을 그 해상도에 맞춰 만들고, 새 프로젝트마다 한글 픽셀 글꼴 갈무리 세트가 `game/fonts`에 들어가고, 레트로 해상도는 갈무리9를 기본 글꼴로 씁니다(글 크기는 10px의 배수. 다른 크기는 픽셀이 깨집니다).
4. 왼쪽 목록에서 프로젝트를 고르고 **[pygaki로 편집]**을 누르면 pygaki 앱이 그 프로젝트를 엽니다. 대본은 프로젝트 폴더의 `프로젝트이름.flow.json`에 저절로 저장됩니다.
5. 앱 위쪽 탭 줄 오른쪽의 **[렌파이에서 실행]**으로 게임을 켜서 봅니다. 런처의 [Launch Project]로 켜도 앱이 게임에 붙습니다(탭 옆 단추가 옅은 파란색 "● 게임과 연결됨"으로 바뀜).

처음 앱을 켤 때 윈도우가 "PC 보호" 창을 띄우면 [추가 정보] → [실행]을 누릅니다(앱에 서명이 없어서 그렇습니다). 이 안내서는 런처의 **[pygaki 안내서]** 단추나 묶음의 `pygaki/pygaki_안내서.html`로 다시 열 수 있습니다.

## 플러그인에 들어 있는 것

렌파이 기본 템플릿의 `screens.rpy`를 고치지 않고, 폴더를 `game/` 안에 넣는 것만으로 화면을 바꾸는 플러그인 넷입니다. 렌파이 8.6.1에서 시험했고(8.5.3에서도 동작), 필요한 것만 골라 넣어도 됩니다(서로 없어도 동작).

| 폴더 | 하는 일 | 고치는 파일 |
| --- | --- | --- |
| `ui_kit` | 타이틀 메뉴, 선택지, 커서·클릭 대기 표시·대사 소리·텍스트 속도·퀵메뉴, 대사 한 줄 스타일·이름 위치·속도·등장 효과·루비, 이미지·영상 배치, 효과 폴더(`ui_kit/effects/`), pygaki editor | `title_menu_config.rpy`, `choice_menu_config.rpy`, `custom_ui_config.rpy`, `say_style_config.rpy`, `stage_config.rpy` |
| `screen_fx` | 화면 전체 셰이더. 1번(기본 효과) 위에 2번(덮개)을 겹침. 장면마다 바꾸기와 전환, 글자 빼기, 타이틀 일렁임 | `screen_fx_config.rpy`, 셰이더마다 `<이름>_config.rpy` |
| `hotkeys` | 단축키 추가·해제, 조작방법 화면 설명 | `hotkeys_config.rpy` |
| `splash` | 타이틀 전에 나오는 로고·경고·조작 방법 페이지 | `splash_config.rpy` |

## 넣었을 때 기본 상태

* `ui_kit`: 타이틀은 왼쪽에 조금씩 기울어진 예시 배치, 선택지는 렌파이 기본과 같은 모양(서서히 나타남), 커서 등은 꺼짐, 대사 스타일은 켜짐, 이미지와 영상은 켜짐(`bg` 맨 뒤, `movies/` 영상 등록).
* `screen_fx`: 기본 효과 없음에 VHS 덮개 켬, 타이틀에 일렁임 셰이더. pygaki 묶음으로 만든 새 프로젝트는 처음부터 덮개가 꺼져 있습니다. 켜려면 `game/screen_fx/screen_fx_config.rpy`의 `define screen_fx.overlay = False`를 `True`로 바꿉니다.
* `hotkeys`: 바뀌는 것이 없습니다.
* `splash`: 켜짐. 예시 페이지 3개(만든 사람 이름, 경고, 조작 방법)가 나옵니다.

기능마다 설정 파일의 스위치(`enabled`)로 따로 끌 수 있고, 끄면 렌파이 기본과 똑같이 보입니다.

## 플러그인만 따로 넣기

묶음 없이 이미 있는 렌파이 프로젝트에 넣을 때입니다.

1. 저장소 `showpy/game/`에서 쓰고 싶은 폴더를 프로젝트의 `game/` 폴더 안에 복사합니다. 예전 판이 있으면 먼저 그 폴더를 `.rpyc`까지 지웁니다. **같은 플러그인을 두 벌 넣으면** "given a default a second time" 같은 오류가 납니다.
2. 각 폴더의 `*_config.rpy`를 고칩니다. 엔진 파일은 고치지 않습니다.
3. 런처에서 Lint를 실행합니다.

자세한 설정은 각 폴더의 `README.md`에 있습니다. `README.md`는 게임을 배포용으로 빌드할 때 저절로 빠집니다.

## 빼기와 새 판으로 바꾸기

* 빼기: 폴더를 `.rpyc` 파일까지 통째로 지우면 렌파이 기본으로 돌아갑니다. `.rpyc`가 남아 있으면 지운 코드가 계속 실행됩니다.
* 새 판으로: 새 묶음의 런처 첫 화면의 **[플러그인 올리기]**: 왼쪽에서 프로젝트를 고르고 누르면 지금 판 → 새 판을 보여 주고, 엔진·편집기 파일만 바꿉니다. 내가 고친 `*_config.rpy`, 편집기에서 저장한 `*_layout.rpy`, 숨김 목록 `*_off.txt`는 그대로 두고(없는 설정 파일만 새로 넣음), 예전 판에만 있던 파일은 치우고, `.rpyc`를 지웁니다. 바꾸기 전 플러그인은 프로젝트 폴더의 `ui_kit_backup/plugins/날짜_시각/`에 남습니다. 게임을 끄고 합니다. 손으로 할 때는 `ui_kit`, `screen_fx`, `hotkeys`, `splash` 폴더를 통째로 바꿔 넣고 `.rpyc`를 지웁니다(내가 고친 `*_config.rpy`와 편집기에서 저장한 `*_layout.rpy`는 따로 두었다가 다시 넣음). 앱도 같은 판으로 바꿉니다(새 앱에서 저장한 대본은 예전 앱이 "더 새 판" 경고를 띄웁니다). 판마다 무엇이 바뀌었는지는 저장소의 `showpy/CHANGELOG.md`에 있습니다.
