# 시작하기

## pygaki가 하는 일

렌파이(Ren'Py) 코드를 배우지 않아도 게임을 만들 수 있게 돕는 도구 묶음입니다.

* **PyKaki**(pygaki 앱의 [대본 편집]): 상자와 선으로 대본을 쓰는 편집기입니다. 대사, 선택지, 배경, 그림, 소리, 화면 셰이더를 정하면 렌파이 원고(`game/script_flow.rpy`)로 내보냅니다.
* **pygaki 플러그인**: 렌파이 게임의 `game/` 폴더에 넣는 플러그인 넷(`ui_kit`, `screen_fx`, `hotkeys`, `splash`)입니다. 타이틀 메뉴, 선택지, 대사 스타일과 등장 효과, 화면 전체 셰이더, 스플래시 화면을 바꾸고, 게임을 켠 채로 마우스로 고치는 **GUI 편집기**가 들어 있습니다.
* **pygaki 앱**: [대본 편집](PyKaki) + [GUI 편집](실행 중인 게임과 이어져서 GUI 편집기를 앱에서 조종) + [효과], [셰이더](효과 구경과 숨기기).
* **pygaki 묶음**: 렌파이 SDK + 플러그인 템플릿 + 런처 버튼 + pygaki 앱을 윈도우용 폴더 하나로 묶은 것입니다.

| 하고 싶은 것 | 어디서 |
| --- | --- |
| 대사, 선택지, 이야기 흐름 쓰기 | PyKaki [대본 편집] |
| 대사 글자 크기, 글꼴, 색, 속도, 등장 효과 | PyKaki 대사 줄의 글자 효과 카드, 글 칸의 태그 상자 |
| 상자·장면마다 화면 셰이더, 전환, 대사 소리, 커서·클릭 대기 | PyKaki 상자나 label의 ◐ 셰이더 |
| 그림, webm 영상, 음악, 효과음 넣기 | PyKaki 상자의 배경 / 그림·영상 / 효과음·음악 카드 |
| 대사·선택지·그림의 위치 | 줄의 [위치 옮기기] → 게임 화면에서 끌기 → [저장] |
| 타이틀 메뉴, 커서 등 게임 전체 모양 | pygaki 앱 [GUI 편집] (게임 안 GUI 편집기와 같음) |
| 효과·셰이더 구경, 목록에서 숨기기 | pygaki 앱 [효과], [셰이더] |
| 설정 파일의 값으로 더 자세히 | 이 안내서의 "플러그인 커스텀 가이드" 장 |

## 받기와 첫 프로젝트

1. GitHub 저장소의 Releases에서 pygaki 묶음을 받습니다. 렌파이가 없으면 렌파이까지 든 zip(`pygaki-…-renpy-….zip`)을 아무 폴더에 풀고, 렌파이 SDK가 이미 있으면 덧붙임 zip(`pygaki-…-addon.zip`) 안의 `launcher`, `pygaki`를 SDK 폴더(`renpy.exe`가 있는 곳)에 넣습니다.
2. `renpy.exe`로 런처를 켭니다(영어로 나오면 preferences → Language → 한국어).
3. 런처 왼쪽 아래 **[+ Create New Project]**(새 프로젝트 만들기)에서 **Pygaki**를 고르고 이름, 해상도, 색을 정합니다. pygaki 플러그인과 커서·클릭 대기 샘플 그림이 들어 있는 한국어 프로젝트가 생깁니다. "기본 (Vanilla)"을 고르면 렌파이 원래 새 프로젝트입니다. VHS 덮개는 처음에는 꺼져 있습니다.
4. 왼쪽 목록에서 프로젝트를 고르고 **[pygaki로 편집]**을 누르면 pygaki 앱이 그 프로젝트를 엽니다. 대본은 프로젝트 폴더의 `프로젝트이름.flow.json`에 저절로 저장됩니다.
5. 앱 오른쪽 위 **[▶ 렌파이에서 실행]**으로 게임을 켜서 봅니다. 런처의 [Launch Project]로 켜도 앱의 [GUI 편집]이 게임에 붙습니다(초록 점).

처음 앱을 켤 때 윈도우가 "PC 보호" 창을 띄우면 [추가 정보] → [실행]을 누릅니다(앱에 서명이 없어서 그렇습니다). 이 안내서는 런처의 **[pygaki 안내서]** 단추나 묶음의 `pygaki/pygaki_안내서.html`로 다시 열 수 있습니다.

## 플러그인에 들어 있는 것

렌파이 기본 템플릿의 `screens.rpy`를 고치지 않고, 폴더를 `game/` 안에 넣는 것만으로 화면을 바꾸는 플러그인 넷입니다. 렌파이 8.5.3에서 만들고 시험했고, 필요한 것만 골라 넣어도 됩니다(서로 없어도 동작).

| 폴더 | 하는 일 | 고치는 파일 |
| --- | --- | --- |
| `ui_kit` | 타이틀 메뉴, 선택지, 커서·클릭 대기 표시·대사 소리·텍스트 속도·퀵메뉴, 대사 한 줄 스타일·이름 위치·속도·등장 효과·루비, 이미지·영상 배치, 효과 폴더(`ui_kit/effects/`), 게임 안 GUI 편집기 | `title_menu_config.rpy`, `choice_menu_config.rpy`, `custom_ui_config.rpy`, `say_style_config.rpy`, `stage_config.rpy` |
| `screen_fx` | 화면 전체 셰이더. 1번(기본 효과) 위에 2번(덮개)을 겹침. 장면마다 바꾸기와 전환, 글자 빼기, 타이틀 일렁임 | `screen_fx_config.rpy`, 셰이더마다 `<이름>_config.rpy` |
| `hotkeys` | 단축키 추가·해제, 조작방법 화면 설명 | `hotkeys_config.rpy` |
| `splash` | 타이틀 전에 나오는 로고·경고·조작 방법 페이지 | `splash_config.rpy` |

## 넣었을 때 기본 상태

* `ui_kit`: 타이틀은 왼쪽에 조금씩 기울어진 예시 배치, 선택지는 렌파이 기본과 같은 모양(서서히 나타남), 커서 등은 꺼짐, 대사 스타일은 켜짐, 이미지와 영상은 켜짐(`bg` 맨 뒤, `movies/` 영상 등록).
* `screen_fx`: 기본 효과 없음에 VHS 덮개 켬, 타이틀에 일렁임 셰이더. pygaki 묶음으로 만든 새 프로젝트는 처음부터 덮개가 꺼져 있습니다. 켜려면 `game/screen_fx/screen_fx_config.rpy`의 `define screen_fx.overlay = False`를 `True`로 바꿉니다.
* `hotkeys`: 바뀌는 것이 없습니다.
* `splash`: 켜짐. 예시 페이지 3개(만든 사람 이름, 경고, 조작 방법)가 나옵니다.

기능마다 설정 파일의 스위치(`enabled`)로 따로 끌 수 있고, 끄면 렌파이 기본과 똑같이 보입니다.

## 플러그인만 따로 넣기

묶음 없이 이미 있는 렌파이 프로젝트에 넣을 때입니다.

1. 저장소 `showpy/game/`에서 쓰고 싶은 폴더를 프로젝트의 `game/` 폴더 안에 복사합니다. 예전 판이 있으면 먼저 그 폴더를 `.rpyc`까지 지웁니다. **같은 플러그인을 두 벌 넣으면** "given a default a second time" 같은 오류가 납니다.
2. 각 폴더의 `*_config.rpy`를 고칩니다. 엔진 파일은 고치지 않습니다.
3. 런처에서 Lint를 실행합니다.

자세한 설정은 각 폴더의 `README.md`에 있습니다. `README.md`는 게임을 배포용으로 빌드할 때 저절로 빠집니다.

## 빼기와 새 판으로 바꾸기

* 빼기: 폴더를 `.rpyc` 파일까지 통째로 지우면 렌파이 기본으로 돌아갑니다. `.rpyc`가 남아 있으면 지운 코드가 계속 실행됩니다.
* 새 판으로: `ui_kit`, `screen_fx`, `hotkeys`, `splash` 폴더를 통째로 바꿔 넣고 `.rpyc`를 지웁니다. 내가 고친 `*_config.rpy`와 편집기에서 저장한 `*_layout.rpy`는 따로 두었다가 다시 넣습니다. 앱도 같은 판으로 바꿉니다(새 앱에서 저장한 대본은 예전 앱이 "더 새 판" 경고를 띄웁니다). 판마다 무엇이 바뀌었는지는 저장소의 `showpy/CHANGELOG.md`에 있습니다.
