1시작하기

pygaki가 하는 일

렌파이(Ren'Py) 코드를 배우지 않아도 게임을 만들 수 있게 돕는 도구 묶음입니다.

  • PyKaki(pygaki 앱의 [대본 편집]): 상자와 선으로 대본을 쓰는 편집기입니다. 대사, 선택지, 배경, 그림, 소리, 화면 셰이더를 정하면 렌파이 원고(game/script_flow.rpy)로 내보냅니다.
  • pygaki 플러그인: 렌파이 게임의 game/ 폴더에 넣는 플러그인 넷(ui_kit, screen_fx, hotkeys, splash)입니다. 타이틀 메뉴, 선택지, 대사 스타일과 등장 효과, 화면 전체 셰이더, 스플래시 화면을 바꾸고, 게임을 켠 채로 마우스로 고치는 GUI 편집기가 들어 있습니다.
  • pygaki 앱: [대본 편집](PyKaki) + [GUI 편집](실행 중인 게임과 이어져서 GUI 편집기를 앱에서 조종) + [효과], [셰이더](효과 구경과 숨기기).
  • pygaki 묶음: 렌파이 SDK + 플러그인 템플릿 + 런처 버튼 + pygaki 앱을 윈도우용 폴더 하나로 묶은 것입니다.

받기와 첫 프로젝트

  1. GitHub 저장소의 Releases에서 pygaki 묶음을 받습니다. 렌파이가 없으면 렌파이까지 든 zip(pygaki-…-renpy-….zip)을 아무 폴더에 풀고, 렌파이 SDK가 이미 있으면 덧붙임 zip(pygaki-…-addon.zip) 안의 launcher, pygaki를 SDK 폴더(renpy.exe가 있는 곳)에 넣습니다.
  2. renpy.exe로 런처를 켭니다(영어로 나오면 preferences → Language → 한국어).
  3. 런처 왼쪽 아래 [+ Create New Project](새 프로젝트 만들기)에서 Pygaki를 고르고 이름, 해상도, 색을 정합니다. pygaki 플러그인과 커서·클릭 대기 샘플 그림이 들어 있는 한국어 프로젝트가 생깁니다. "기본 (Vanilla)"을 고르면 렌파이 원래 새 프로젝트입니다. VHS 덮개는 처음에는 꺼져 있습니다.
  4. 왼쪽 목록에서 프로젝트를 고르고 [pygaki로 편집]을 누르면 pygaki 앱이 그 프로젝트를 엽니다. 대본은 프로젝트 폴더의 프로젝트이름.flow.json에 저절로 저장됩니다.
  5. 앱 오른쪽 위 [▶ 렌파이에서 실행]으로 게임을 켜서 봅니다. 런처의 [Launch Project]로 켜도 앱의 [GUI 편집]이 게임에 붙습니다(초록 점).

처음 앱을 켤 때 윈도우가 "PC 보호" 창을 띄우면 [추가 정보] → [실행]을 누릅니다(앱에 서명이 없어서 그렇습니다). 이 안내서는 런처의 [pygaki 안내서] 단추나 묶음의 pygaki/pygaki_안내서.html로 다시 열 수 있습니다.

플러그인에 들어 있는 것

렌파이 기본 템플릿의 screens.rpy를 고치지 않고, 폴더를 game/ 안에 넣는 것만으로 화면을 바꾸는 플러그인 넷입니다. 렌파이 8.5.3에서 만들고 시험했고, 필요한 것만 골라 넣어도 됩니다(서로 없어도 동작).

폴더하는 일고치는 파일
ui_kit타이틀 메뉴, 선택지, 커서·클릭 대기 표시·대사 소리·텍스트 속도·퀵메뉴, 대사 한 줄 스타일·이름 위치·속도·등장 효과·루비, 이미지·영상 배치, 효과 폴더(ui_kit/effects/), 게임 안 GUI 편집기title_menu_config.rpy, choice_menu_config.rpy, custom_ui_config.rpy, say_style_config.rpy, stage_config.rpy
screen_fx화면 전체 셰이더. 1번(기본 효과) 위에 2번(덮개)을 겹침. 장면마다 바꾸기와 전환, 글자 빼기, 타이틀 일렁임screen_fx_config.rpy, 셰이더마다 <이름>_config.rpy
hotkeys단축키 추가·해제, 조작방법 화면 설명hotkeys_config.rpy
splash타이틀 전에 나오는 로고·경고·조작 방법 페이지splash_config.rpy

넣었을 때 기본 상태

  • ui_kit: 타이틀은 왼쪽에 조금씩 기울어진 예시 배치, 선택지는 렌파이 기본과 같은 모양(서서히 나타남), 커서 등은 꺼짐, 대사 스타일은 켜짐, 이미지와 영상은 켜짐(bg 맨 뒤, movies/ 영상 등록).
  • screen_fx: 기본 효과 없음에 VHS 덮개 켬, 타이틀에 일렁임 셰이더. pygaki 묶음으로 만든 새 프로젝트는 처음부터 덮개가 꺼져 있습니다. 켜려면 game/screen_fx/screen_fx_config.rpy의 define screen_fx.overlay = False를 True로 바꿉니다.
  • hotkeys: 바뀌는 것이 없습니다.
  • splash: 켜짐. 예시 페이지 3개(만든 사람 이름, 경고, 조작 방법)가 나옵니다.

기능마다 설정 파일의 스위치(enabled)로 따로 끌 수 있고, 끄면 렌파이 기본과 똑같이 보입니다.

플러그인만 따로 넣기

묶음 없이 이미 있는 렌파이 프로젝트에 넣을 때입니다.

  1. 저장소 showpy/game/에서 쓰고 싶은 폴더를 프로젝트의 game/ 폴더 안에 복사합니다. 예전 판이 있으면 먼저 그 폴더를 .rpyc까지 지웁니다. 같은 플러그인을 두 벌 넣으면 "given a default a second time" 같은 오류가 납니다.
  2. 각 폴더의 *_config.rpy를 고칩니다. 엔진 파일은 고치지 않습니다.
  3. 런처에서 Lint를 실행합니다.

자세한 설정은 각 폴더의 README.md에 있습니다. README.md는 게임을 배포용으로 빌드할 때 저절로 빠집니다.

빼기와 새 판으로 바꾸기

  • 빼기: 폴더를 .rpyc 파일까지 통째로 지우면 렌파이 기본으로 돌아갑니다. .rpyc가 남아 있으면 지운 코드가 계속 실행됩니다.
  • 새 판으로: ui_kit, screen_fx, hotkeys, splash 폴더를 통째로 바꿔 넣고 .rpyc를 지웁니다. 내가 고친 *_config.rpy와 편집기에서 저장한 *_layout.rpy는 따로 두었다가 다시 넣습니다. 앱도 같은 판으로 바꿉니다(새 앱에서 저장한 대본은 예전 앱이 "더 새 판" 경고를 띄웁니다). 판마다 무엇이 바뀌었는지는 저장소의 showpy/CHANGELOG.md에 있습니다.

2한눈에: 문서와 파일 자리

받은 묶음, 만든 게임 프로젝트, 저장소에 무엇이 어디 있는지 모았습니다. "이 파일은 지워도 되나", "내 작업은 어디 저장되나"가 궁금할 때 봅니다.

내 작업이 저장되는 곳

무엇자리알아 둘 것
대본(원본)프로젝트 폴더 맨 위 프로젝트이름.flow.json고칠 때마다 저절로 저장. 이것이 원본이니 백업할 때 꼭 챙깁니다. 게임 배포판에는 들어가지 않습니다
내보낸 원고game/script_flow.rpy대본에서 만들어지는 결과물입니다. 다시 내보내면 덮어써지니 이 파일을 직접 고치지 않습니다
저장본(버전 목록)이 컴퓨터의 pygaki 앱 안바뀐 것이 있을 때 5분마다, 내보낼 때, 받아 적기 전에 저절로 남습니다(자동 저장본은 최근 30개). 다른 컴퓨터로 옮겨지지 않습니다
그림 위치game/ui_kit/stage_layout.rpy줄의 [위치 옮기기]로 저장한 자리. 저장본으로 되돌아가지 않습니다
GUI 편집기에서 저장한 값각 플러그인 폴더의 *_layout.rpy (예: ui_kit/title_menu_layout.rpy, screen_fx/screen_fx_layout.rpy)설정 파일(*_config.rpy)의 같은 값보다 먼저 쓰입니다. 새 판으로 바꿀 때 따로 두었다가 다시 넣습니다
내가 고친 설정각 플러그인 폴더의 *_config.rpy엔진 파일(engine/, editor/)은 고치지 않습니다
원고를 고치기 전 원본프로젝트 폴더의 ui_kit_backup/GUI 편집기가 원고 괄호를 바꾸기 전에 남깁니다. 개발용이라 배포판에서 뺍니다
게임과 앱이 주고받는 파일game/showpy_inbox.json, game/showpy_live.json, game/pykaki_preview.json, game/pykaki_goto.json개발 중에만 생기는 연결 파일입니다. 게임 배포판에는 넣지 않습니다(지워도 다시 생깁니다)

게임을 배포용으로 빌드할 때는 *.flow.json, ui_kit_backup/, 위의 연결 파일을 빼 주세요. 각 플러그인의 README.md는 빌드할 때 저절로 빠집니다.

3PyKaki로 대본 쓰기

원본: pykaki/docs/GUIDE.md

상자와 선으로 렌파이 대본을 쓰고, 렌파이 스크립트(.rpy)로 내보내는 도구예요.

여는 곳: pygaki 묶음의 렌파이 런처에서 프로젝트를 고르고 [pygaki로 편집]. 웹 버전(사이트, 웹앱 설치)은 2026-11-12에 없앴어요.

1. 화면 둘러보기

  • 위쪽 줄 왼쪽: 프로젝트 제목(눌러서 고쳐요), 큰 탭 [대본 편집 | GUI 편집 | 효과 | 셰이더], 앱에서는 그 옆에 게임 연결 단추(게임과 붙어 있으면 옅은 파란색 "● 게임과 연결됨", 게임이 바뀐 원고를 다시 읽는 동안은 노란색 "◐ 게임 수정 중"(끝나면 저절로 다시 붙어요), 아니면 회색. 누르면 GUI 편집으로).
  • 위쪽 줄 오른쪽 끝(초록 단추): 게임 돌려보기. [▶ 렌파이에서 실행]과 [게임 줄 따라가기].
  • 위쪽 둘째 줄 메뉴(왼쪽부터): 되돌리기 ↶ ↷, [집중](옅은 보라색 단추), 설정, 도움말, 그다음 파일 새로/열기/저장, 프로젝트 폴더(다시 읽기, 폴더 열기, 다른 프로젝트), 버전, 내보내기. 평소에는 흐릿하고 마우스를 올리면 또렷해져요.
  • 왼쪽: label(장면, 아래에 상자와 정렬 단추), 캐릭터, 검사(내보낼 때 걸리는 오류와 경고. 누르면 그 상자로), 렌파이 프로젝트 정보(프로젝트, 대본 파일, 저장 상태, 찾은 그림·소리 수), 스크립트(내보낼 원고. [펼치기]로 보고 [복사], [.rpy 내보내기]), 설정. 묶음마다 둥근 카드로 나뉘어 있어요.
  • 오른쪽: 탭 없이 왼쪽과 같은 카드예요. 상자를 누르면 상자, 글자 효과, 대사, 다음 흐름 카드가, ◐ 셰이더를 누르면 셰이더, 전환 카드가 나와요.
  • 칸 크기: 왼쪽 칸이나 오른쪽 칸과 캔버스 사이 경계에 마우스를 대면 커서가 ↔로 바뀌어요. 끌면 그 칸의 너비가 바뀌고, 경계를 더블클릭하면 그 칸만 처음 크기로 돌아가요. [GUI 편집], [효과], [셰이더] 화면의 칸 경계도 똑같이 끌어요. 왼쪽 "설정"의 [처음 크기]는 모든 화면의 칸을 한 번에 되돌리고, [잠금]을 누르면 끌어도 바뀌지 않아요. 크기와 잠금은 이 브라우저(앱)에 기억돼요.
  • 가운데 캔버스: 상자와 선. 마우스 휠로 확대/축소하고, 빈 곳을 끌어서 이동해요. 캔버스 위쪽 양 끝의 작은 ‹ › 버튼으로 왼쪽 칸과 오른쪽 칸을 따로 접고 펴요(접은 것은 다음에 열어도 그대로예요).

처음 열면 예제 대본("비 오는 날")이 들어 있어요. [새로]를 누르면 빈 대본으로 시작해요.

도움말과 ⓘ

  • 화면에는 긴 설명을 두지 않아요. 칸 이름 옆의 작은 ⓘ에 마우스를 올리면 한두 줄 설명이 뜨고, 누르면 이 도움말의 그 항목이 열려요.
  • 위쪽 둘째 줄 메뉴의 [도움말]이나 F1로 언제든 이 도움말을 열어요. 왼쪽에 목차, 위쪽에 찾기 칸이 있어요. Esc나 [닫기]로 닫아요.
  • 도움말은 저장소의 pykaki/docs/GUIDE.md와 같은 글이에요(앱을 만들 때 그대로 넣어요).
  • 단추 위에 마우스를 올리면 그 단추가 하는 일도 짧게 떠요.

캔버스 조작 한눈에

캔버스 왼쪽 위 캔버스 조작 ⓘ에도 같은 것이 있어요.

  • 상자를 더블클릭하면 상자 안에서 바로 글을 써요. 대사 줄·제목·선택지를 더블클릭하면 그 칸으로 가요. Esc나 빈 곳 클릭으로 끝내요.
  • 상자를 한 번 클릭하면 오른쪽에서 label, 다음 흐름 같은 나머지 설정을 바꿔요.
  • 캔버스 빈 곳을 더블클릭하면 새 상자가 생겨요.
  • 상자 아래 점(●)을 끌어 다른 상자에 놓으면 연결돼요. 빈 곳에 놓으면 새 상자가 생기며 연결돼요.
  • 선을 더블클릭하면 jump ↔ call이 바뀌어요.
  • Shift+드래그로 여러 상자를 고르고, Delete로 지워요.
  • 같은 label(장면)의 상자는 같은 색이에요. label은 왼쪽 목록에서 관리해요.
  • 상자나 label 오른쪽 위의 ◐ 셰이더를 누르면 오른쪽에서 화면 셰이더를 정해요. 대사 소리와 속도는 대사 줄마다, 커서와 클릭 대기는 상자마다 상자 편집 칸의 카드에서 정해요.
  • 카드 제목 오른쪽 [접기]를 누르면 이름만 남기고 접혀요.

3. 대본 쓰기

캐릭터 등록

왼쪽 캐릭터 [+ 추가]를 눌러요.

  • 색: 이름 색 (내보낼 때 Character(..., color=)로)
  • id: 렌파이 변수 이름. 영문, 숫자, _만 써요. 예: a, alice
  • 이름: 화면에 보이는 이름. 예: 앨리스

내레이션은 등록하지 않아도 돼요.

상자 만들기

  • 캔버스 빈 곳을 더블클릭하면 새 상자가 생겨요. label 배경 안에서 더블클릭하면 그 label에 들어가요.
  • 왼쪽 "상자와 정렬"의 [+ 상자]로도 만들 수 있어요.

상자 안에서 글쓰기

  • 상자를 더블클릭하면 화면이 그 상자로 부드럽게 다가가며 확대되고, 더블클릭한 줄에 커서가 생겨요. 상자 모양은 볼 때와 똑같고 글자를 그 자리에서 바로 고치면 돼요.
  • 커서가 있는 줄 왼쪽 바깥에 작은 단추 묶음이 붙어요.
    • ⠿ 끌어서 줄 순서 바꾸기
    • 줄 종류: 내레이션, 캐릭터, 연출, ⚙ 명령, # 메모
    • ＋ 아래에 새 줄, ✕ 줄 삭제
  • 연출 줄(🖼 배경, 🎵 음악 등)을 누르면 오른쪽 바깥에 입력칸이 붙어요.
  • 상자 오른쪽 바깥에는 반투명한 다음 흐름 창이 붙어요. 오른쪽 칸을 열지 않아도(집중 모드에서도) 다섯 가지를 카드로 골라요: 다음 상자로, 끝 (return), 선택지(고르면 첫 선택지 칸으로), 조건 분기(고르면 첫 조건 칸으로), 다음 상자로 이어 쓰기(이어진 상자가 있으면 그리로, 없으면 새 상자를 만들어 이어요. 선택지·조건 분기면 아직 안 이어진 첫 갈래로). 어느 상자로 이어지는지는 캔버스에서 선을 끌어 붙여요. call은 선을 두 번 눌러 바꿔요.
    • Alt+Enter: 키보드로 다음 흐름 창에 들어가요. 방향키로 고르고 Enter로 정해요. Esc나 Alt+Enter를 다시 누르면 쓰던 글로 돌아가요.
    • ＋ 새 상자에 이어 쓰기: 아직 이어지지 않은 곳에 새 상자를 만들어 잇고, 그 상자로 넘어가 바로 글을 써요.
    • Ctrl+Shift+Enter: 다음 상자로 이어 쓰기. 이어진 상자가 있으면 그리로, 없으면 새 상자를 만들어서 넘어가요. 계속 누르면 상자를 하나씩 이어 가며 쓸 수 있어요.
  • Ctrl+Enter: 같은 화자로 아래에 새 줄
  • Esc나 빈 곳 클릭: 편집 끝. 화면이 원래 보던 곳으로 돌아가요.

글 꾸미기와 멈춤 (태그 상자)

  • 대사나 내레이션 글 칸에 커서가 있으면 태그 상자가 떠요. 상자 안에서 쓸 때는 상자 오른쪽 위 바깥에, 오른쪽 칸에서 쓸 때는 글자 효과 칸 위쪽에 나와요.
  • 상자는 묶음마다 카드 한 장(글자, 멈춤, 속도, 더 보기의 모양·글꼴과 효과·넣기)이고, 줄마다 이름이 색 버블로 붙어 있어요.
  • 멈춤, 속도, 투명도, 자간, 넣기 단추 위에 마우스를 잠깐 올리면 툴팁에 넣는 태그, 설명, 그리고 견본 글에 그 태그를 넣어 한 글자씩 나오는 모습이 돌아요(클릭 대기는 ▼를 보이고 저절로 넘어가요). 막대를 끄는 동안에는 그 값으로 견본이 돌아요.
  • 글을 고르고 단추를 누르면 그 부분만 렌파이 텍스트 태그로 감싸요. 고른 글이 없으면 태그 짝을 넣고 커서를 그 사이에 둬요.
    • B I U S: 굵게 {b}, 기울임 {i}, 밑줄 {u}, 취소선 {s}. 단축키 Ctrl+B / Ctrl+I / Ctrl+U. 이미 그 태그 안이면 다시 눌러서 빼요(가운데만 고르면 그 부분만 빠져요).
    • 크기: 가−, 가+는 10씩 작게, 크게({size=-10}, {size=+10}, 누를 때마다 바뀜). 가운데 칸에 30(그 크기), +10, -10, *1.5(1.5배)를 적고 Enter.
    • 색: 팔레트가 펼쳐져요. 기본 색 32칸, 이 프로젝트 색(대사창 기본 글자 색, 캐릭터 이름 색), 최근에 쓴 색 8칸, #rrggbb 칸과 [직접 고르기]. ←↑→↓로 옮기고 Enter로 골라요. 이미 색 태그 안이면 색 값만 바뀌고, [색 빼기]로 뺄 수 있어요.
    • 멈춤: [클릭 대기] {w}, [잠깐] {w=0.5}(넣으면 숫자가 골라져 있어서 바로 초를 고쳐 쓸 수 있어요), [줄 바꾸며 대기] {p}, [자동 넘김] {nw}(글 끝에 들어가요), [여기까지 한 번에] {fast}
    • 속도: 막대를 끌거나 숫자 칸에 적고 Enter. 고른 글만 1초에 그 글자 수로 나와요 {cps=20}(대사 칸의 텍스트 속도와 같은 단위). [보통]을 누르면 태그가 빠져요. 예전에 넣은 배율 태그 {cps=*2}는 옆에 보통의 2배로 보이고, 막대를 움직이면 글자 수로 바뀌어요
    • 더 보기 ▾: 속도 줄 오른쪽 끝. 누르면 아래 줄들이 펼쳐지고, 다시 누르면 접혀요(펼친 채로 기억해요).
      • 투명도: 막대를 끌거나 숫자를 적어서 고른 글을 흐리게 {alpha=0.5}. 1이면 태그가 빠져요.
      • 자간: 막대를 끌거나 숫자(픽셀)를 적어서 글자 사이를 넓히거나(음수는 좁게) {k=2}. 0이면 태그가 빠져요.
      • 외곽선 색: 글자 색과 같은 팔레트 {outlinecolor=#rrggbb}. 게임의 글자 스타일에 외곽선(outlines)이 있을 때만 보여요.
      • 글꼴: 게임 폴더를 연결하면 game과 game/fonts의 글꼴 파일을 골라 고른 글만 바꿔요 {font=파일}.
      • 효과: 고른 글에만 등장 효과를 걸어요 {shader=shake}글{/shader}. 목록에는 켜 둔 글자 효과가 나오고, 다시 열어 [효과 태그 빼기]를 고르면 빠져요. 줄의 다른 글자는 그 줄의 글자 효과로 나오고, 줄에 효과가 없으면 한 글자씩 나와요(내보낼 때 그 줄에 effect="typewriter"가 저절로 붙어요. 이게 없으면 렌파이가 그 줄에서 멈춰요). 색 잔상처럼 외곽선 겹을 쓰는 효과는 줄 전체에만 걸 수 있어서 목록에 없어요. 효과를 고르면 옆에 [세부 값] 단추가 나오고, 누르면 그 효과의 막대가 열려요. 막대를 움직였다 놓으면 태그 안에 {shader=wave:u__amplitude=8}처럼 적히고, ↺를 누르면 그 값만 기본값으로 돌아가요(커서가 그 태그 안에 있으면 돼요). 선택지 글에는 쓸 수 없어요(왼쪽 [검사] 카드이 알려 줘요).
      • 넣기: [가로 띄우기] {space=30}, [세로 띄우기] {vspace=30}(숫자가 골라져 있어서 바로 고쳐 써요), [{ 글자] {{, [루비], 글 속 그림 {image=이름}(게임 폴더를 연결했을 때 목록에서).
      • 루비: 고른 글 위에 작은 글을 올려요 {rb}글{/rb}{rt}읽는 법{/rt}. 고른 글이 없으면 바로 앞 글자 위에 올려요. 루비 글 안에 커서를 두면 [루비 글] 줄이 떠서 크기와 색을 그 자리에서 정해요 {rt}{size=14}{color=#ffcc00}읽는 법{/color}{/size}{/rt}([기본]은 둘 다 빼기). 자리는 pygaki 플러그인(ui_kit 4.9)이 대사 줄마다 본문 바로 위로 맞추고, 글자 효과가 있는 대사에서도 멈추지 않게 루비에 같은 효과를 넣어요. 게임에서 style ruby_text의 yoffset을 따로 정했으면 그 값을 써요.
  • 태그 글자는 글 칸에 그대로 보여요. 결과는 글자 효과 칸 미리보기와 게임에서 봐요(미리보기는 고른 글에만 건 효과도 게임과 같은 셰이더로 그려요. 루비는 위에 올리지 않고 작은 글로, 글 속 그림은 안 보여요. 띄우기는 대강의 크기로). 편집을 끝낸 상자에서는 태그가 흐리게 보이고 안쪽 글에 굵게, 기울임, 밑줄, 색, 투명도가 입혀져요(크기는 상자 모양이 바뀌지 않게 그대로).
  • 글자 효과 칸의 크기, 색, 글꼴, 글자/초는 줄 전체에, 태그 상자는 고른 부분만 걸려요.
  • 태그가 다른 태그와 엇갈리게 고르면(예: {b}의 안과 밖에 걸치게) 넣지 않고 알려 줘요.
  • 왼쪽 설정에서 텍스트 태그를 끄면 태그 상자에 [켜기]만 나와요.

렌파이 명령을 몰라도 줄 종류에서 연출을 고르고 칸만 채우면 돼요. 칸 아래 초록 글씨로 실제로 내보낼 렌파이 명령이 보여요.

줄 종류채울 칸내보내는 명령
🖼 배경배경 이름, 나타나는 방식scene bg room with fade (화면의 이미지를 모두 지우고 배경을 깔아요. 이름을 비우면 검은 화면)

셰이더 (상자와 label에 걸기)

게임 화면 전체에 씌우는 셰이더(아스키, VHS, 게임보이 …)를 상자나 label 단위로 걸어요. pygaki 플러그인이 든 프로젝트에서만 돼요(왼쪽 [설정]의 "pygaki 플러그인 연결").

  • 상자나 label 틀 오른쪽 위의 ◐ 셰이더를 누르면 오른쪽 칸이 셰이더 고르기로 바뀌어요. 한 번 더 누르거나 [← 상자 편집으로]로 돌아가요.
  • [이 상자에 정하기]: 1번, 2번을 골라요. 두 자리가 겹쳐서 보여요. 둘 다 "없음"이면 그 상자에서는 셰이더를 꺼요.
  • label에 정하면 그 label의 상자 모두에 걸려요. 상자에 따로 정한 것이 있으면 그쪽이 먼저예요. 상자도 label도 안 정했으면 게임 설정대로 보여요.
  • 버튼 색으로 알 수 있어요: 채워진 색은 여기에 정한 것, 점선 테두리는 label 것을 따르는 상자.
  • 전환: 상자가 시작할 때와 끝날 때의 전환이에요. 상자에서 상자로 넘어갈 때는 다음 상자의 "시작할 때"를 먼저 쓰고, 그게 없음이면 앞 상자의 "끝날 때"를 써요. 셰이더가 같아도 고른 전환이 돌아요. 둘 다 없음이어야 전환 없이 그대로 이어져요. 상자에 셰이더를 처음 정하면 둘 다 없음으로 시작해요. 전환은 셰이더처럼 목록에서 TV 꺼짐·켜짐, 픽셀소트, 데이터모싱, TV 지직, 조정 화면, 테이프 늘어짐, 점멸, 없음(바로 바뀜) 중에 골라요. TV 지직(노이즈가 덮였다 걷힘), 조정 화면(방송 조정 화면이 잠깐 나옴), 테이프 늘어짐(화면이 출렁이며 늘어짐), 점멸(몇 번 깜빡임)은 앞 상자의 마지막 화면에서 이 상자의 첫 화면으로 넘어가는 동안 돌고, 셰이더는 노이즈가 가장 짙을 때, 조정 화면이 끝날 때, 가장 늘어졌을 때, 가운데 깜빡임 때 바뀌어요. 이 넷도 게임의 효과 폴더에 같은 이름의 효과 파일이 있어야 해요. 그림 전환을 고르면 그 아래에 그 효과의 세부 값이 나와요. 점멸이면 색, 횟수, 켜져 있는 비율, 서서히 꺼짐, 덮는 정도를 고르고, 아래 그림 전환 시간(0.1초부터)과 합쳐 "한 번 깜빡임 0.20초"처럼 보여요. 픽셀소트와 데이터모싱은 크래시예요. 앞 상자의 마지막 화면(그 상자의 줄을 끝까지 그린 화면. 대사 뒤에 보이기만 한 그림도 들어가요)이 깨지고, 깨진 채 잠깐 멈췄다가, 이 상자의 첫 화면(첫머리의 배경, 보이기 줄까지 그린 화면)으로 뚝 끊어 넘어가요. 두 화면을 섞지 않고, 셰이더도 끊기는 순간에 바뀌어요. 걸리는 시간은 아래 그림 전환 시간 막대로 정해요(앞쪽 40~45%가 깨지는 시간, 나머지가 멈춘 시간. 1.4초면 약 0.6초 깨지고 0.8초 멈춤). 고른 전환 바로 아래 방향에서 깨지는 방향을 골라요: 데이터모싱(키프레임을 잃은 동영상처럼 앞 화면이 블록째 끌려가며 녹고, 이 상자 첫 화면의 윤곽이 그 위에 비쳐요)은 회전(블록째 소용돌이)과 확산(가운데에서 바깥으로 끌려감), 픽셀소트는 가로, 세로, 회전(원 둘레로 띠), 확산(가운데에서 바깥으로 띠). 상자 첫머리의 배경, 보이기, 숨기기 줄을 다 그린 뒤에 전환이 돌고, 그 줄들의 "나타나는 방식"은 쓰지 않아요. 이 둘은 게임의 효과 폴더에 pixelsort, datamosh 효과 파일이 있어야 해요(새 프로젝트에는 들어 있음, 없으면 [효과] 화면에서 넣음). TV를 고르면 그 아래 [세부 값]에서 꺼지는 시간, 검은 화면, 켜지는 시간, 가로선 두께, 빛남, 지직거림, 소리 크기를 이 상자(label)에서만 바꿔요. 셰이더를 정하지 않은 상자로 넘어갈 때도 앞 상자의 "끝날 때"가 돌아요. 예전 판에서 "서서히"나 "게임 설정대로"로 정해 둔 곳은 그대로 돌고, 칸에 "예전 값"이라고 보여요. 둘 중 하나를 고르면 바뀌어요.
  • 고르는 목록은 연결한 게임 폴더에 있는 셰이더예요(연결하지 않았으면 기본 셰이더). 게임에 새 셰이더를 넣었으면 게임을 한 번 켠 뒤 [다시 읽기]를 누르면 목록에 나와요.
  • 셰이더 칸은 카드 셋이에요: 셰이더(1번, 2번), 전환, script_flow.rpy에 들어가는 줄(내보낼 때 그 상자 첫 줄에 적히는 코드).
  • 셰이더를 정하지 않은 상자는 카드 아래에 "지금: label의 …" 또는 "지금: 게임 설정대로"로 지금 걸린 것을 보여 줘요.
  • 예전 플러그인을 쓰는 게임이면 칸에 주황 글씨로 알려요: 세부 값은 화면 효과(screen_fx) 5.5부터, 픽셀소트·데이터모싱은 5.6부터예요. 안 되는 것은 TV 꺼짐·켜짐으로 내보내요.
  • 세부 값: 1번, 2번에서 셰이더를 고르면 바로 아래 [세부 값]을 펼쳐 막대로 바꿔요. 바꾼 값은 이 상자(label)에서만 쓰고, ↺로 그 값만 기본으로 돌아가요. 바꾸지 않은 값은 게임 설정대로예요(그 처음 값은 [GUI 편집] → 셰이더 기본 값에서 게임 화면을 보면서 고쳐요). 다른 셰이더로 바꾸면 그 자리의 값은 지워져요. pygaki 플러그인 화면 효과(screen_fx) 5.5부터 돼요.
  • 위쪽 [셰이더] 화면에서 셰이더마다 샘플과 막대를 구경하고(저장 안 함) 켜고 꺼요. [전환]에서는 TV 꺼짐·켜짐 모양을 비슷하게 돌려 보고, 픽셀소트와 데이터모싱은 샘플 그림으로 돌려 봐요.
  • 셰이더 카드 맨 아래 [⚠ 모든 상자에 적용]은 지금 걸린 셰이더를 모든 label에 걸어요(상자마다 따로 정한 것은 지워져요). [⚠ 전부 삭제]는 대본 전체에서 셰이더를 지워요. 둘 다 묻고 하고, ↶로 되돌려요.

상자 편집 칸의 커서와 클릭 대기 (CTC) 카드는 그 상자에만 걸려요. 정하지 않은 상자는 앞 상자 것을 이어받지 않고 게임 처음 값으로 돌아가요. pygaki 플러그인(ui_kit 4.7부터)이 든 프로젝트에서 돼요.

  • 값마다 [게임 처음 값] / [이 상자에]를 골라요.
  • 클릭 대기, 커서: game/gui/ctc, game/gui/cursor 안의 폴더 하나가 그림 묶음 하나예요(폴더 안 그림을 이름 차례로 돌려요). 게임 처음 값에서 켜 둔 것만 바뀌고, 커서는 소프트웨어 커서일 때만 바뀌어요.
  • 카드 맨 아래 [⚠ 모든 상자에 적용]은 이 상자의 값을 모든 상자에 걸고, [⚠ 전부 삭제]는 대본 전체에서 지워요. 둘 다 묻고 하고, ↶로 되돌려요.
  • 예전 판에서 상자나 label에 정한 대사 소리·속도는 대본을 열 때 그 상자의 대사 줄로, label에 정한 커서·클릭 대기는 그 label의 상자로 옮겨 적혀요.

배경, 그림, 소리 카드

상자를 누르면 대사 카드 아래에 배경(그림, 영상), 그림, 영상, 효과음, 음악 카드가 있어요. 렌파이 프로젝트를 연결했으면 그림과 소리를 눌러서 바로 넣어요(소리는 ▶로 들어 봐요). 카드 맨 위 [📂 파일 고르기]를 누르면 탐색기 창이 game/images(소리는 game/audio) 폴더에서 열려요. 게임 폴더 밖의 파일을 고르면 game/images(webm 영상은 movies, 소리는 audio)로 복사할지 묻고 복사해서 넣어요(같은 이름이 있으면 _2를 붙여요). 배경 카드는 파일 이름이 bg로 시작해야 해요(예: "bg room.png"). 연결하지 않았으면 이름을 쳐서 넣어요. 지금 쓰고 있는 줄 바로 앞에 들어가요(쓰는 줄이 없으면 상자 끝). 자리는 대사 카드에서 줄을 끌어 바꿔요. 카드 위에는 이 상자에 이미 있는 그 줄들이 나오고, 누르면 그 줄로 가요.

대사 줄은 글만 고쳐요. 캐릭터 그림(표정)은 대사 줄에 붙이지 않고 [그림, 영상] 카드에서 골라요. 캐릭터 대사를 쓰고 있으면 이 카드 맨 위에 그 캐릭터의 그림(예: a smile.png, a angry.png)이 나오고, 누르면 그 대사 바로 앞에 보이기 줄(show a smile)이 들어가요. 그림이 없으면 표정 이름을 쳐서 넣어요. 예전 판에서 대사 줄에 넣은 표정은 줄 옆에 "표정 smile ✕"로 보이고 그대로 내보내요(누르면 빼요).

사용 중 카드: 지금 쓰고 있는 줄과 이어진 카드는 옅은 녹색 배경과 "사용 중" 표시가 붙어요. 대사를 쓰면 대사·글자 효과 카드, 배경 줄이면 배경 카드, 보이기·숨기기 줄이면 그림 카드, 소리 줄이면 효과음 카드예요. 표시가 없는 카드는 지금 쓰는 줄과 상관없어요.

렌파이에서 여기로 이동, 위치 옮기기 (앱)

게임을 [▶ 렌파이에서 실행]으로 켜서 앱과 연결돼 있으면:

  • 상자 카드의 [렌파이에서 여기로 이동]: 게임이 이 상자의 첫 줄로 가요.
  • 대사 카드의 줄에 마우스를 올리면 카드 왼쪽 바깥에 작은 단추 묶음이 튀어나와요. [여기로 이동]: 게임이 그 줄로 가요. 대사·내레이션 줄에는 [위치 옮기기]도 있어요. 누르면 게임이 그 줄로 가고 GUI 편집기의 대사 탭이 열려요. 게임 창에서 끌어서 옮기고 그 줄 아래 [저장]을 누르면 위치가 대본에 받아 적혀요(괄호 안 숫자는 저장할 것 수). [끝내기]로 편집기를 닫아요.
  • 배경·보이기 줄(대사 카드의 그 줄과, 배경·그림 카드 위의 줄 목록)에도 [위치 옮기기]가 있어요. 게임이 그 줄로 가고 GUI 편집기의 이미지/영상 탭이 그 줄을 골라 열려요. 게임 창에서 그림을 끌어 옮기거나 전환을 바꾸고 [저장]하면 대본에 받아 적혀요(pygaki 플러그인 ui_kit 4.8부터 그 줄을 골라 줘요). 숨기기 줄은 자리가 없어서 단추가 없어요.
  • 다음 흐름이 선택지면 [위치 옮기기]로 선택지 위치를 같은 방법으로 정해요. 게임이 상자의 마지막 줄로 가니까 한 번 넘기면 선택지가 나와요.
  • 게임과 연결 안 돼 있으면 상자 카드 단추는 회색이고 줄마다 단추는 안 보여요.

카드 접기

왼쪽, 오른쪽, GUI 편집 칸의 카드는 제목 오른쪽 회색 [접기]를 누르면 이름만 한 줄로 접혀요(하늘색). [펼치기]로 다시 열어요. 왼쪽 칸 카드는 켤 때마다 모두 접혀서 시작하고, 오른쪽 칸 카드는 접은 것을 기억해요. 칸 맨 위 오른쪽의 [모두 접기](모두 접혀 있으면 [모두 펼치기])로 그 칸의 카드를 한 번에 접고 펴요. 왼쪽 칸 스크롤바는 왼쪽에 있어요.

  • 예전에 넣은 "✨ 화면 효과" 줄은 그대로 돌아가지만, 상자 셰이더를 하나라도 쓰면 상자마다 첫 줄에서 셰이더를 다시 맞추니 한쪽만 쓰는 게 좋아요.

오른쪽 칸의 줄 모양

상자를 한 번 클릭하면 오른쪽 칸에도 같은 줄들이 나와요. 줄마다 왼쪽 칸에 줄 종류와 손잡이(⠿), 삭제(✕)가 있고, 오른쪽 칸에 글이 있어요.

줄 순서 바꾸기

⠿ 손잡이를 끌어서 다른 줄 위/아래에 놓으면 순서가 바뀌어요. 오른쪽 칸에서도, 캔버스의 상자 안에서도 돼요(상자 안에서는 줄에 마우스를 올리면 줄 왼쪽에 ⠿가 보여요. 글을 고치는 중이 아니어도 돼요).

좌우 칸은 캔버스 위에 떠 있어요. 카드 사이와 카드를 접어서 빈 곳은 비쳐서 뒤 대본이 보이고, 거기를 눌러도 캔버스를 움직여요. 칸 안은 카드 위에서 휠로 스크롤해요.

직접 명령과 메모

  • ⚙ 직접 명령: 위 연출로 안 되는 렌파이 명령을 그대로 적어요. 예: with vpunch, $ renpy.pause(1.0)
  • # 메모: 작가용 메모예요. 스크립트에는 주석(#)으로 들어가서 게임에는 안 보여요.

4. 흐름 잇기

상자를 한 번 클릭하면 오른쪽 편집 탭에서 "다음 흐름"을 정해요.

종류뜻
→ 다음 상자로다음 상자로 이어져요.
◆ 선택지선택지마다 다른 상자로 가요.
◇ 조건 분기조건에 따라 다른 상자로 가요. 만약 줄에 렌파이 조건을 그대로 써요(예: love >= 5, met_alice, not rich). [+ 조건]으로 아니고 줄을 더하고, 위 조건이 모두 아니면 그 밖 상자로 가요. 변수는 명령 줄에 $ love += 1처럼 써서 바꿔요.
⤷ call 후 계속다른 장면을 불렀다가 끝나면 돌아와서 "복귀 후" 상자로 이어져요. 공통 장면을 여러 번 쓸 때 편해요.
■ 끝 (return)여기서 끝나요. call로 불린 장면이면 부른 곳으로 돌아가요.

선으로 잇기

  • 상자 아래(선택지와 조건 분기는 줄마다 오른쪽)의 점(●)을 끌어서 다른 상자에 놓으면 연결돼요.
  • 빈 곳에 놓으면 새 상자가 생기면서 연결돼요. 대본을 이어 쓸 때 가장 빨라요.
  • 선을 클릭하고 Delete를 누르면 연결이 끊겨요.
  • "다음" 선을 더블클릭하면 call로 바뀌고, call 선을 더블클릭하면 다시 "다음"으로 바뀌어요.
  • 오른쪽 칸의 목록에서 대상을 골라도 돼요.

시작 상자

초록색 시작 표시가 붙은 상자에서 게임이 시작돼요. 다른 상자를 시작으로 하려면 그 상자를 클릭하고 [시작 상자로]를 눌러요.

5. label(장면) 관리

  • 왼쪽 label 목록에서 이름, 표시 제목, 색을 바꿔요.
    • 이름은 렌파이 label 이름이라 영문, 숫자, _만 써요. 예: chapter1_rain
    • 표시 제목은 한글로 자유롭게 써요.
  • 숫자 버튼을 누르면 그 label의 상자들로 화면이 이동해요.
  • 상자를 다른 label로 옮기려면 오른쪽 칸의 label에서 골라요. [+ 새 label로 분리]도 있어요.
  • 여러 상자를 Shift+드래그로 고르면 오른쪽에서 같은 label로 묶기를 할 수 있어요.
  • [label의 첫 상자로]: 그 label이 시작되는 상자를 정해요.

6. 정리(자동 정렬)

왼쪽 "상자와 정렬" 칸에 있어요.

  • [전체 정렬]: 시작부터 흐름 순서대로 위→아래로 정리해요. 같은 label 상자는 한 덩어리로 모여요.
  • [label 정렬]: 고른 상자가 속한 label만 정리해요.
  • [선택 정렬]: Shift+드래그로 고른 상자들만 정리해요.
  • 방향(위→아래 / 왼→오른)을 바꿀 수 있어요.
  • 마음에 안 들면 Ctrl+Z로 되돌려요.

7. 게임에서 확인하기, 글자 효과

PyKaki 안에서 돌려 보는 플레이 화면은 없앴어요. 대본은 렌파이 게임으로 켜서 봐요.

  • [▶ 렌파이에서 실행]: 지금 대본을 내보내고 렌파이로 게임을 바로 켜요. 게임이 이미 켜져 있으면 다시 켜지 않고 대본만 내보내요(게임이 저절로 다시 불러와요). 누를 때마다 하나 더 켜려면 [설정]의 "게임이 이미 켜져 있으면 무시"를 꺼요. 렌파이 SDK 묶음 안에 든 앱에서 돼요. 렌파이를 못 찾으면 알려 주니 런처의 [프로젝트 실행]으로 켜세요.
  • [렌파이에서 여기로 이동]: 게임을 그 상자나 줄로 옮겨요(6장 "렌파이에서 여기로 이동, 위치 옮기기").
  • 글자 효과 칸: 오른쪽 칸 상자 카드 아래에 있고, 지금 쓰는 대사 줄을 따라가요. 크기, 색, 글꼴, 글자/초, 등장 효과를 줄마다 골라요. 비워 두면 게임 설정을 따라요. 집중 모드에서는 패널과 함께 숨어요.
    • 효과 1번, 2번: 등장 효과는 "1번", "2번" 두 줄이에요. 줄마다 효과를 고르고 ✕로 빼요. 둘 다 고르면 두 효과가 같이 돌아요(예: 미끄러져 멈춤 + 살짝 흔들림).
    • 세부 값: 효과 옆 [세부 값]을 누르면 그 효과의 값(걸리는 시간, 거리, 세기, 색 등)을 막대로 고쳐요. 미리보기에 바로 보이고, ↺로 기본값으로 돌려요. 고친 값이 있으면 버튼에 개수가 보여요.
    • 글 상자: [상자 없음]을 [말풍선]이나 [둥근 테두리]로 바꾸면 대사 글을 상자가 둘러싸요. 말풍선은 꼬리 방향(아래, 위, 왼쪽, 오른쪽, 없음)을, 둘 다 기울기(도)를 고를 수 있어요. 말풍선은 글 색을 따로 안 정하면 어두운 글자로 나와요. 미리보기는 비슷하게 흉내 낸 것이라 정확한 모양은 렌파이에서 보세요. pygaki 플러그인이 있는 게임에서만 내보내요.
    • 효과 폴더: 게임의 game/ui_kit/effects 폴더에 효과 파일(.glsl)을 넣으면 등장 효과 목록 끝과, 배경/보이기 줄의 "나타나는 방식" 목록 끝에 나와요. 파일을 빼면 목록에서 없어져요(샘플도 같아요). 넣고 빼고 감추는 일은 [효과] 화면(7-1장)에서 눌러서 할 수 있어요. 손으로 하려면, 지우지 않고 목록에서만 감출 때 그 폴더의 effects_off.txt에 효과 이름을 한 줄에 하나씩 적어요. 감춘 효과를 이미 쓴 줄은 그대로 돌아요. 샘플로 아래에서 올라오기, 자간이 좁아지며, 빛 지나가기(글자), 원으로 열리기, 띠로 덮였다 열리기(그림)가 들어 있어요. 그림 쪽은 [효과] 화면 샘플과 게임에서 봐요. 새 효과를 만드는 법은 그 폴더의 README.md에 있어요.
    • 미리보기: 맨 위 칸에 이 줄의 글자가 효과대로 나와요. 렌파이를 켜지 않아도 돼요. 등장 효과는 렌파이와 같은 셰이더 코드로 그려요. 값을 바꾸면 다시 나오고, 칸을 누르거나 ↺를 누르면 다시 볼 수 있어요. 글자는 칸에 꽉 차게 맞추므로 크기 칸의 값은 여기에 안 보여요.
    • 등장 효과: 렌파이 기본 효과(서서히, 뒤집히며, 커지며, 떨림, 물결)와 pygaki 플러그인 효과(흩어졌다 모이기, 떨어지기, 무작위 순서, 색 번쩍, 크게 찍히기, 커서 타자기, 색 잔상, 글리치, 흐렸다 또렷해지기, 블록 글리치, 일렁임, VHS 지직거림, 떠오르기, 기울며 들어오기, 늘어나며 들어오기, 미끄러져 멈춤, 살짝 흔들림, 글자마다 상자, 도장, 찌그러졌다 튕김, 입체 글자)가 있어요. pygaki 플러그인 효과는 pygaki 플러그인이 있는 게임에서만 내보내요. 예전 대본에 목록에서 뺀 효과(타자기, 흐리게 대기, 녹아내림, 데이터모싱, 뒤집으며 나오기, LED 전광판, 위아래 갈라짐, 회전하며, 빛 번짐, 위에서 그려지기, 외곽선 채우기, 튀어나오는 줌, 뿅 튀어나오기)가 남아 있으면 이름 그대로 칸에 보이고, 게임에서는 한 글자씩 나와요.
    • 글자/초 기본값: 글자가 하나씩 나와야 보이는 효과(떨림, 물결, 일렁임, VHS 지직거림을 뺀 모든 효과)는 칸을 비워 두면 30으로 나오고, 그대로 내보내요. 다른 값을 적으면 그 값을 써요.
    • 렌파이 견본: 효과를 고르면 그 효과를 렌파이에서 찍은 짧은 영상이 나와요. 문장은 예시예요.
    • 한 자씩 타이핑하듯: 효과 없음에 글자/초만 적기 (예: 30)
    • 한 번에 나온 뒤 흔들림: 글자/초 비움, 효과 떨림

7-1. 효과 관리 ([효과] 화면)

툴바 왼쪽에서 [효과]를 누르면 글자 효과(대사 글자가 나오는 모양)와 그림 효과(배경, 캐릭터가 나타나는 모양)를 한곳에서 봐요. [대본 편집]을 누르면 돌아가요.

  • [셰이더] 칸: 위의 [글자 효과 | 그림 효과 | 셰이더]에서 셰이더를 누르면 화면 전체에 씌우는 셰이더(상자와 label의 ◐ 셰이더에서 고르는 것) 목록이 나와요. [숨김]을 누르면 고르는 목록에서만 빠지고(이미 건 상자는 그대로 돌아요) [숨김 해제]로 다시 나와요, 오른쪽에는 샘플(게임과 같은 셰이더 코드로 샘플 그림에 씌운 모습, [고르기]로 내 그림도 돼요)과 세부 값 막대, 쓰인 곳이 보여요. 막대로 맞춘 값은 구경용이라 저장하지 않아요. [보기]를 누르면 그 상자의 셰이더 칸으로 가요. 아스키는 게임이 글자 그림을 만들어 넣어야 해서 앱에서는 샘플을 볼 수 없어요.
  • 갤러리 / 목록: 왼쪽 위의 [▦ 갤러리](처음 값)는 효과마다 미리보기 그림이 있는 카드를 바둑판으로 보여 줘서 여러 효과의 모양을 같이 보며 내려 볼 수 있어요. 글자 효과는 글자가 반쯤 나온 순간, 그림 효과는 바뀌는 도중, 셰이더는 샘플 그림에 씌운 모습이에요. 카드에 마우스를 올리면 그 카드만 움직이고, 누르면 오른쪽 칸에서 세부 값을 맞춰요. [▶ 움직이기]를 누르면 화면에 보이는 카드가 6개까지 계속 움직여요(스크롤하면 새로 보인 카드가 이어받아요). 컴퓨터가 조금 더 일하니 [❚❚ 멈추기]로 멈춘 그림으로 돌아가요. 카드 그림은 하나씩 만들어서, 만드는 동안 그 옆에 "그림 만드는 중 12/35"와 진행 막대가 보이고 다 되면 사라져요. [☰ 목록]은 이름만 한 줄씩 보여요. [셰이더] 화면도 같아요.
  • 왼쪽 목록: 위의 [글자 효과 | 그림 효과]로 바꾸고, 찾기 칸에 이름을 적어 걸러요. 줄마다 한글 이름, 영어 이름, 대본에서 쓴 줄 수, 어디 것인지(렌파이 / 기본 / 프로젝트)가 보여요.
  • 숨김 / 숨김 해제: 카드의 [숨김]을 누르면 그 효과가 [대본 편집]과 게임 안 GUI 편집기의 고르는 목록에서만 빠져요(카드에 "숨김" 표시). 이미 쓴 대사는 그대로 돌아요. [숨김 해제]를 누르면 다시 나와요. 효과 파일은 지우지 않아요. 목록이 길 때 안 쓰는 효과를 감추는 데 써요.
  • 효과 파일: 효과는 게임의 game/ui_kit/effects 폴더에 든 것만 보여요. pygaki 플러그인을 새 판으로 바꾸면 새 효과도 같이 들어와요. 앱에서 효과 파일을 넣거나 빼지는 않아요. 효과 파일을 손으로 지운 게임에서도 그 효과를 쓴 줄은 멈추지 않고 기본 모양(글자는 한 글자씩, 그림은 서서히, 셰이더는 없음)으로 돌아요.
  • 새 효과 요청문 복사: 클로드에게 새 효과를 부탁할 때 같이 줄 글을 복사해요. 만들고 싶은 모양을 덧붙여서 주면 돼요. 앱이 밖으로 보내는 것은 없어요.
  • 오른쪽 샘플: 고른 글자 효과가 샘플 글로 돌아요. 샘플 글을 바꿀 수 있고, 칸을 누르거나 [다시 보기]로 다시 봐요. 세부 값 막대를 움직이면 바로 다시 돌아요. 여기서 맞춘 값은 저장하지 않아요(값은 [대본 편집]의 대사 줄마다 정해요).
  • 그림 효과 샘플: 고른 그림 효과가 "앞 그림"에서 "새 그림"으로 바뀌는 모습으로 돌아요(게임과 같은 셰이더 코드로 그려요). [고르기]로 가진 그림 파일을 새 그림 자리에 넣어 볼 수 있어요(저장하지 않아요). 막대에는 걸리는 시간도 있어요. 원고에 적는 법 줄에 지금 맞춘 값이 with img_fx.use("bands", 1.4, count=10)처럼 나오니, 직접 명령 줄에 쓰려면 [복사]해요. 배경·보이기·숨기기 줄에서는 "나타나는 방식"에서 그림 효과를 고른 뒤 옆의 [세부 값]을 눌러 걸리는 시간과 값을 막대로 정해요(그 줄에만 적용돼요).
  • 쓰인 곳: 그 효과를 쓴 줄이 나오고, [보기]를 누르면 [대본 편집]의 그 상자로 가요.
  • 렌파이 폴더(pygaki 플러그인이 있는 게임)를 연결하지 않았으면 구경만 할 수 있어요. 숨김은 연결한 뒤에 돼요.

8. 검사와 내보내기

  • 검사 탭: 연결 안 된 선, 빈 대사, 잘못된 이름처럼 렌파이에서 문제가 될 것들을 보여 줘요. 항목을 누르면 그 상자로 가요.
  • 스크립트 탭: 내보낼 .rpy를 미리 보고 복사할 수 있어요.
  • [.rpy 내보내기]: 저장 위치로 게임 폴더의 **game/ 폴더**를 고르세요. 파일 이름은 script_flow.rpy를 추천해요. 기존 script.rpy와 겹치지 않게 하려는 거예요.
  • 한 번 내보낸 뒤에는 Ctrl+E(또는 [같은 곳에 다시])로 바로 덮어써요.
  • 렌파이를 켜 둔 상태에서 Shift+R을 누르면 바뀐 스크립트를 다시 불러와요.
  • 자동 내보내기 (렌파이 폴더를 연결했을 때, pygaki 플러그인 ui_kit 4.2부터): 대본을 고치고 잠깐 멈추면 Ctrl+E를 누르지 않아도 script_flow.rpy가 저절로 써지고, 개발 모드로 켜 둔 게임이 저절로 다시 불러와요. 왼쪽 [검사] 카드에 오류가 있으면 고칠 때까지 내보내지 않아요.
  • [게임 줄 따라가기] (툴바): 켜 두면 다시 불러온 게임이 지금 쓰는 줄로 가요(지나온 줄이면 되감고, 아니면 그 줄까지 건너뛰어요). 여러 곳을 고친 뒤 처음부터 훑어보고 싶으면 꺼 두세요. 끄면 게임은 있던 자리에 그대로 있어요.
주의: 내보낸 .rpy를 VSCode에서 직접 고치면, 다음 내보내기 때 덮어써져요. 대본은 항상 이 도구에서 고치세요.

대사 안의 특수문자

  • [는 자동으로 글자 그대로 나오게 바꿔 줘요([[).
  • {b}굵게{/b} 같은 렌파이 텍스트 태그는 그대로 쓸 수 있어요(태그 상자로 넣어도 돼요). 끄려면 왼쪽 설정에서 바꿔요.
  • 태그 짝이 안 맞으면 왼쪽 [검사] 카드에 떠요. 여는 태그 없이 {/b}만 있으면 렌파이가 멈춰서 오류, 닫지 않은 태그와 렌파이가 모르는 태그는 경고예요.
  • %는 그대로 두면 렌파이가 멈춰요. 새 대본은 자동으로 %%로 바꿔요. 예전 대본에서 왼쪽 [검사] 카드에 % 오류가 뜨면 설정 → % 를 글자 그대로를 켜세요.

9-1. pygaki 플러그인과 함께 쓰기

pygaki 플러그인는 게임을 실행한 채 마우스로 화면을 고치는 렌파이 플러그인이에요. 글과 글자 모양은 여기서, 그림과 영상, 소리, 위치, 화면 효과는 렌파이에서 맞출 수 있어요.

왼쪽 "렌파이 프로젝트 정보"의 [렌파이 프로젝트 연결]을 누르고 프로젝트 폴더를 고르면 끝이에요. 연결한 뒤에는 위쪽 줄에 [폴더 바꾸기] [다시 읽기] [끊기]가 생겨요.

  • game 폴더를 찾아서 연결하고, pygaki 플러그인이 있으면 연결을 켜요.
  • game/script_flow.rpy를 바로 만들어요. 렌파이에서 실행하면 첫 상자부터 시작해요. script.rpy는 그대로 둬도 돼요.
  • 그다음부터는 Ctrl+E로 내보내요.
  • 렌파이 편집기에서 그림이나 소리를 넣고 이 창으로 돌아오면, 넣은 줄이 대본에 나타나요.
  • 대본 파일도 그 프로젝트 폴더에 저장돼요: 프로젝트이름.flow.json. Ctrl+S, Ctrl+E를 누를 때 써져요. 폴더에 대본 파일이 이미 있으면 그 대본을 열지, 지금 대본을 쓸지 물어요.
  • 브라우저를 다시 열면 권한을 한 번 다시 허용해야 해요.
  • game 폴더를 바로 고르면 대본 파일은 폴더에 저장하지 않아요. 앱에서 이어 쓰려면 game 위의 프로젝트 폴더를 고르세요.
  • 캐릭터 id를 e로 쓰면 script.rpy의 define e와 겹쳐요. 다른 id를 쓰세요.

연결을 켜면 달라지는 점:

  • 대사와 이름의 위치, 줄마다 바꾸는 화면 효과는 렌파이 편집기(Shift+M)의 대사 탭에서 정해요. 저장하고 이 창으로 돌아오면 글자 효과 칸에 값이 보이고, 다시 내보내도 남아요.
  • 연출 줄 칸에 폴더의 파일 이름이 추천 목록으로 나와요.
  • 그림 위치 칸이 사라져요. 위치는 렌파이 편집기에서 끌어서 정해요.
  • 다른 대본의 원고는 덮어쓰지 않아요: 창을 열고 처음 내보낼 때 폴더의 script_flow.rpy에 지금 대본에 없는 상자가 많으면, 자동 내보내기는 멈추고 아래쪽에 알려요. 이 대본으로 덮어쓰려면 Ctrl+E를 누르고 [확인]을 골라요. 덮어쓰기 전 원고는 script_flow.rpy.bak으로 남아요.
  • pygaki 플러그인이 없는 게임에서는 이 연결이 꺼진 채로 내보내요. 글자 모양, 속도, 등장 효과는 그래도 적용돼요.

자세한 순서와 문제 해결은 pygaki 플러그인 커스텀 가이드를 보세요.

9-2. 데스크톱 앱 (렌파이 묶음)

pygaki 묶음의 렌파이 런처에서 프로젝트를 고르고 [pygaki로 편집]를 누르면 PyKaki가 앱으로 열려요.

  • 그 프로젝트의 대본이 바로 열려요. 폴더 연결, 권한 창이 없어요.
  • 대본은 프로젝트 폴더 맨 위의 프로젝트이름.flow.json에 고칠 때마다 자동 저장돼요. 이 파일이 대본의 원본이에요.
  • Ctrl+E로 내보내면 game/script_flow.rpy에 바로 써져요.
  • 게임 안 GUI 편집기에서 넣은 그림, 소리 줄은 저장되자마자 대본에 받아 적혀요.
  • 위쪽 줄의 [폴더 열기]는 프로젝트 폴더를, [다른 프로젝트]는 다른 프로젝트를 새 창으로 열어요. [다시 읽기]는 폴더의 그림·소리와 GUI 편집기가 넣은 줄을 다시 읽어요.
  • [열기]로 다른 .flow.json을 고르면 두 대본(상자 수, 줄 수, 저장한 때)을 보여 주고, [확인]을 누르면 그 내용을 이 프로젝트 대본으로 가져와요. [새로]는 이 프로젝트 대본을 비워요(지금 대본은 버전 목록에 백업돼요).
  • 프로젝트 폴더에 .flow.json이 여러 개면 처음 열 때 어느 것을 열지 골라요. 다음부터는 고른 파일을 열고, 왼쪽 "렌파이 프로젝트 정보"의 [다른 대본 파일 고르기]로 다시 골라요.

예전 웹 버전에서 쓴 대본

웹 버전은 없앴어요. 웹에서 Ctrl+S로 저장한 .flow.json이 있으면 앱의 [열기]로 가져와요. 대본 파일에는 어느 판에서 저장했는지가 남고, 앱보다 새 판에서 쓴 대본이면 왼쪽 칸에 "더 새 판" 경고가 떠요.

[GUI 편집] 화면 (게임과 나란히)

툴바 왼쪽의 [대본 편집 | GUI 편집 | 효과 | 셰이더]에서 GUI 편집을 누르면 게임 화면 꾸미기로 바뀌어요. 렌파이 런처에서 [프로젝트 실행]으로 게임을 켜 두면(개발 모드) 저절로 이어지고, 위쪽 게임 연결 단추가 옅은 파란색이 돼요. 맨 위 "GUI 편집 ⓘ"에 짧은 안내가 있고, 왼쪽 칸 카드마다 ⓘ에 그 칸의 설명이 있어요. 게임 창과 앱 창을 나란히 놓고 써요.

  • 가운데: 게임이 지금 어느 화면에 있고 원고 몇 번째 줄을 실행 중인지, 그 앞뒤 줄을 보여줘요. PyKaki로 쓴 대본이면 [PyKaki 상자: …]를 눌러 그 상자로 가요. 원고의 줄을 누르면 게임이 그 줄로 가요(지나온 줄이면 되감기, 아니면 게임을 다시 시작해서 그 줄까지 건너뜀). [표시 숨기기: 켬/끔]으로 # @l: 같은 표시를 화면에서만 가려요(줄 번호와 원고 파일은 그대로예요). 게임의 pygaki 플러그인이 새 판(ui_kit 4.5부터)이면 표시가 줄마다 윗줄에 따로 있지 않고 "대사" # @l:l1처럼 줄 끝에 붙어서 원고가 훨씬 짧아요. 예전 플러그인을 쓰는 게임에는 전처럼 내보내요.
  • 왼쪽: 고칠 것 목록을 묶음 카드로: 스플래시(로고, 경고, 조작 방법과 직접 만든 페이지가 하나씩. 누르면 게임 안 편집기도 그 페이지로) / 타이틀 메뉴(타이틀 메뉴, 타이틀 셰이더, 셰이더 기본 값) / 게임 내 메뉴(ESC 메뉴, 게임 내 메뉴 셰이더) / 확인 창, UI 글 / 게임 처음 값(대사 상자, 선택지, 그림·영상 배치, 커서·클릭 대기·대사 소리). 상자마다 바꾸는 것은 [대본 편집]에서 해요(대사·선택지 위치는 [위치 옮기기], 그림·소리는 상자의 배경·그림·소리 카드, 대사 소리·속도는 대사 줄의 카드, 커서·클릭 대기는 상자의 카드). 오른쪽 칸도 왼쪽처럼 카드예요(저장과 GUI 편집기 / 고치는 칸).
  • 오른쪽: 고르는 칸.
    • 타이틀 메뉴, 게임 내 메뉴: 맨 위 배경에서 game 폴더의 그림이나 webm 영상을 골라요. 안 고르면 타이틀은 검은 화면, ESC 메뉴는 투명(뒤 게임 화면이 보임)이에요. 목록 맨 아래 제목, 부제를 고르면 글 내용을 적을 수 있어요(비우면 안 보여요). 항목이나 글자를 고르고 위치, 회전, 기울기, 확대, 글자 크기, 색, 글꼴, 글자 효과(대사 등장 효과와 같은 목록)를 바꿔요. 게임 화면에서 고른 글자 위의 분홍 네모를 끌면 돌아가요(Shift: 15도씩). (pygaki 플러그인 4.20, ui_kit 3.19 이상) 게임 화면에서 항목을 끌어도 숫자가 같이 바뀌어요. [평소/선택됐을 때], [이 항목만/모든 항목 공통]도 여기서 골라요. 게임이 그 화면에 없으면 [타이틀로 가기], [ESC 메뉴 열기]가 나와요.
    • 커서, 클릭 대기(CTC), 대사 소리: 텍스트 속도, 대사 소리와 음량([들어보기]는 게임에서 소리가 나요), 클릭 대기 표시와 커서의 켬/끔, 그림 12칸, 1프레임마다/2프레임마다, 커서 방식과 클릭 기준점, 퀵메뉴를 여기서 바꿔요. 칸을 누르면 아래에 게임 폴더의 그림이 나오고, 그림을 누르면 그 칸에 들어가고 다음 칸으로 넘어가요. 맨 아래 미리보기에서 글자 속도와 그림이 도는 모양을 봐요. 커서나 클릭 대기 표시를 켜고 끈 것은 저장하면 게임이 다시 불러온 뒤 보여요. 그림은 커서는 game/gui/cursor/, 클릭 대기 표시는 game/gui/ctc/에 넣어요(1번부터 순서대로, 64×64 권장. pygaki 새 프로젝트에는 샘플이 들어 있어요). 그림 칸은 바둑판 바탕이라 흰 그림도 보여요. 커서와 셰이더: 커서가 셰이더를 받을지(1번, 2번 다 받음 / 2번만 받음 / 셰이더 안 받음) 고르고, 셰이더 칸처럼 줄을 골라 [여기에서부터 적용]해요. (pygaki 플러그인 ui_kit 3.15 이상, 커서와 셰이더는 4.22 이상)
    • 타이틀 셰이더, 게임 내 메뉴 셰이더: 그 화면에만 걸리는 셰이더 1번, 2번을 이 게임의 셰이더(기본, 아스키, VHS, 일렁임 …) 중에서 골라요. 두 자리가 겹쳐요. "전부 셰이더 적용 취소"는 둘 다 기본으로. 게임 내 메뉴 셰이더는 ESC 메뉴를 연 채로 골라요(게임 중이면 [ESC 메뉴 열기]가 나와요).
    • 셰이더 기본 값: 칸을 열면 바로 1번, 2번이에요. 고르면 게임 화면에 바로 보이고, 고른 효과의 세부 속성(글자 빼기, 프리셋, 막대)이 그 줄 바로 아래에 나와요(줄 끝 [세부 속성 접기]). 여기서는 셰이더의 모양을 게임 화면을 보면서 고치고 [저장]해요. 어느 장면에 걸지는 [대본 편집]에서 상자나 label 오른쪽 위의 ◐ 셰이더로 정해요(3장 "셰이더"). 게임을 시작할 때 셰이더는 맨 아래 [처음 상태 펴기]. 패널의 줄 목록과 [여기에서부터 적용]은 게임 안 편집기와 같은 것이고, PyKaki로 쓰는 대본에서는 상자 셰이더를 쓰는 쪽이 쉬워요(둘을 섞으면 상자 첫 줄의 셰이더가 먼저 걸려요). 줄기표는 앱에서는 펴지 않아요(게임 창의 편집기에서 G).
    • 대사, 선택지, 그림 배치, 종료 메시지와 버튼 글: 게임 안 편집기 패널과 똑같은 버튼, 막대, 입력칸이 여기 나와요. 글꼴, 색, 그림 고르기 창도 칸 맨 위에 떠요. 게임 화면에서 끌어서 옮기는 것과 단축키(R 다시 보기 같은)는 게임 창에서 해요. 타이틀에 있을 때 대사, 그림 칸을 고르면 [게임 시작]이, 게임 중에 타이틀 셰이더를 고르면 [타이틀로 가기]가 나와요. (pygaki 플러그인 ui_kit 3.16 이상. 예전 판이면 "게임 안" 표시가 붙고 게임 안 패널로 열려요)
    • 스플래시: 페이지를 고르고 바탕색, 바탕·로고 그림, 제목·본문 글자, 위치, 넘어가는 때, 시간을 바꿔요. [이 페이지 보기]를 누르면 게임 창에 그 페이지가 떠요(클릭하면 닫힘). 저장하면 splash/splash_layout.rpy에 적혀요. 제목, 본문 문장은 splash/splash_config.rpy에서 고쳐요. (pygaki 플러그인 4.18, splash 1.2 이상) 맨 위 "게임 켤 때" [보이기] [안 보이기]로 페이지를 넣고 빼고, 그 아래 줄에서 지금 게임을 켤 때 나오는지와 안 나오는 까닭을 봐요. [다시 보이게]는 "다음부터 보지 않기"와 본 기록을 지워요. (splash 2.1 이상)
  • [저장](또는 Ctrl+S)은 게임 안 편집기의 저장과 같아요. 값은 게임 폴더의 *_layout.rpy나 원고에 저장돼요.
  • 앱과 이어져 있는 동안 게임 창의 GUI 편집기 패널은 숨어요. 게임 창에도 보이게 하려면 위쪽 [게임 창의 GUI 편집기: 숨김] 버튼을 누르거나 F9를 눌러요(앱 어디서나, 게임 창에서 편집기가 열려 있을 때도). 다시 누르면 숨어요. 앱이 기억했다가 다음에 게임에 붙을 때도 그대로예요. 게임 창에 보이는 동안은 고치는 칸이 게임 창으로 가요. 단축키는 설정 → 단축키에서 바꿔요.
    • 글 칸: 긴 글 칸(스플래시 글, UI 글 등)은 패널 폭 가득 세 줄로 나와요. 칸 옆 [넓게]/[좁게]로 칸마다 바꿀 수 있고, 앱이 기억해요. Enter 끝내기, Esc 취소, 줄바꿈은 \n.
    • 확인 창, UI 글: 종료 확인 창("종료하겠습니까?"), [네] [아니오], 퀵메뉴·메뉴 버튼 글자를 바꿔요. 확인 창은 [이 창 보기]로 바로 보고, 버튼 글자는 저장하면 게임이 다시 불러온 뒤 바뀌어요. (pygaki 플러그인 ui_kit 3.23 이상)
    • 그림, 영상 배치: [images 폴더 열기], 그림 고르기 창의 폴더 열기 버튼으로 탐색기를 열어 파일을 넣어요.
  • 편집 중에는 게임이 안 넘어가요: 칸을 고르면 게임 안 편집기가 열리고, 그동안 게임 화면의 클릭과 키는 편집기로 가요(끌어서 옮기기용). 게임 화면 위에 "편집 중 | Esc로 닫기"가 보이면 그 상태예요. 게임을 진행하려면 게임 창에서 Esc를 누르거나 앱의 [편집기 닫기]를 눌러요. [대본] 화면으로 가면 저절로 닫혀요. 커서/대사 소리 칸은 편집기를 열지 않아요.
  • pygaki 플러그인(ui_kit) 3.14 이상이 들어 있는 게임에서만 이어져요.

10. 집중 모드와 환경 설정

집중 모드

Ctrl+\\ (한국어 자판에서는 Ctrl+₩, 또는 툴바의 [집중])를 누르면 툴바, 왼쪽, 오른쪽, 미니맵이 모두 숨고 캔버스만 남아요. 한 번 더 누르면 다시 나와요.

  • 상자를 더블클릭해서 글을 쓰는 동안에는 밑줄 모양 커서가 깜박여요. 화면이 비어 있어도 지금 쓰는 중인지, 어디에 쓰는지 알 수 있어요.
  • 집중 모드에서 상자 안에 글을 쓰는 동안에는 커서가 있는 줄만 또렷하고, 같은 상자의 다른 줄은 흐리게, 다른 상자와 선은 더 흐리게 보여요. 흐린 상자에 마우스를 올리면 잠깐 또렷해져요. 흐린 정도는 [설정]에서 골라요.
  • 집중 모드에서도 단축키(저장, 새 줄 등)는 그대로 돼요.

환경 설정

툴바 오른쪽 [설정]에서 바꿔요. 이 설정은 그 브라우저에만 저장되고 대본 파일에는 들어가지 않아요.

  • 텍스트 색(설정 맨 위): 글자색을 골라요. 어느 테마에서든 상자와 label 위 글자까지 모두 그 색이 돼요. [자동 (테마 색)]을 누르면 테마가 바탕 밝기에 맞춰 정하는 색으로 돌아가요.
  • 화면 테마: 사과 스타일(처음 값), 어둡게, 직접 고르기 중에서 골라요.
    • 사과 스타일: Apple의 디자인을 참고한 테마예요. 흰색 톤에 파랑·회색 강조색. 경계선 없이 둥근 흰 카드(상자)와 바탕색 차이로만 구분하고, label 배경은 왼쪽 label 목록의 색으로 칠해요.
    • 어둡게: 바탕 색과 끝 색 두 가지만 고르면, 두 색 사이를 이어서 바탕 → label 배경(30%) → 상자(55%) 순서로 자동으로 칠해요. 이 테마에서는 상자를 따로 칠할 수 없고 모두 그라데이션 색을 따라요(칠해 둔 상자 색은 다른 테마에서 보여요). 처음 값은 검정 → 보라예요. [처음 색]으로 되돌려요.
    • 직접 고르기: 바탕, 면, 상자 색을 하나씩 골라요. (글자색은 맨 위 텍스트 색에서)
  • label 경계선(0~6px, 처음 3px): 같은 label 상자를 묶는 선의 굵기예요. 0이면 선이 안 보여요.
  • 상자 색 (이 대본에 저장): 고른 상자를 칠해요. 색 칸을 눌러 고르거나 hex 코드(#RRGGBB 또는 #RGB)를 직접 적어요. [label 색으로 되돌리기]로 지워요. 고른 색은 대본 파일에 저장되고 Ctrl+Z로 되돌려요. 화면 설정 가운데 대본 파일에 들어가는 것은 이것뿐이에요.
  • 글꼴: Pretendard 500 하나예요. 앱 안에 들어 있어서 인터넷이 없어도 보여요.
  • 렌파이에서 실행 (앱): "게임이 이미 켜져 있으면 무시"를 켜 두면, 게임이 켜져 있을 때 [▶ 렌파이에서 실행]을 눌러도 대본만 내보내고 게임은 그대로 둬요. 끄면 누를 때마다 게임을 하나 더 켜요. 켜져 있는지는 pygaki 플러그인이 든 게임과의 연결, 그리고 이 앱에서 켠 게임으로 알아요.
  • 집중 모드 흐림: 끄기, 약하게, 보통, 강하게
  • 단축키: 바꿀 동작의 키 칸을 누르고 새 키를 눌러요. Esc를 누르면 취소돼요. Esc(편집 끝내기), Delete(삭제), F1(도움말)은 바꿀 수 없어요.
    • 글자를 칠 때 겹치지 않게 Ctrl이나 Alt를 함께 눌러야 해요. F2~F12는 혼자 써도 돼요(F1은 도움말).
    • 다른 동작에 쓰던 키를 고르면 그쪽 단축키는 비워져요.
    • [기본값으로]를 누르면 처음 키로 돌아가요.
  • [모든 설정을 처음 값으로](설정 창 맨 아래): 화면 테마, 글꼴, 집중 모드 흐림, 단축키를 모두 처음 값으로 되돌려요. 대본과 상자 색은 그대로예요.

PyKaki는 상자와 선으로 대본을 쓰는 에디터입니다. pygaki 묶음의 데스크톱 앱으로 나오고, 렌파이 런처에서 프로젝트를 고르고 [pygaki로 편집]을 누르면 열립니다(웹 버전은 5.1에서 없앴습니다). 두 프로그램을 함께 쓰면 글은 PyKaki에서, 화면은 렌파이에서 맞춥니다. 렌파이 코드를 몰라도 됩니다. 앱 쓰는 법은 앱의 [도움말](F1)에 있습니다.

처음 한 번만 하는 준비

  1. pygaki 묶음의 renpy.exe로 런처를 켜고 [+ Create New Project](새 프로젝트 만들기)에서 Pygaki를 골라 만듭니다. pygaki 플러그인과 커서·클릭 대기 샘플 그림이 처음부터 들어 있습니다. (이미 있는 프로젝트라면 플러그인 폴더들을 game에 넣습니다)
  2. 프로젝트를 고르고 [pygaki로 편집]을 누릅니다.

이것으로 끝입니다. 앱이 그 프로젝트의 대본(프로젝트이름.flow.json)을 열고, 고칠 때마다 저장하고, game/script_flow.rpy로 내보냅니다. 렌파이에서 실행하면 PyKaki의 첫 상자부터 시작합니다.

script.rpy는 그대로 둬도 됩니다. 내보낸 파일에 아래 줄이 들어 있어서 게임 시작이 첫 상자로 이어지고, script.rpy의 label start:는 실행되지 않습니다.

init python:
    config.label_overrides["start"] = "prologue"

PyKaki 새 대본의 첫 label 이름은 prologue입니다. 다른 이름으로 바꾸거나 시작 상자를 옮기면 내보낼 때 그 값을 따라갑니다.

알아 둘 것:

  • 캐릭터 id를 e로 쓰면 script.rpy의 define e와 겹칩니다. Lint에 경고가 나오고 어느 쪽 이름이 쓰일지 보장되지 않으니, 다른 id를 쓰거나 script.rpy를 지우세요.
  • 대본에 이름이 start인 label을 직접 만들면 script.rpy의 label start:와 겹쳐서 렌파이가 오류를 냅니다. 이 경우에만 그 파일의 label start:를 지웁니다.

값 한눈에 보기

하고 싶은 일페이지에 적는 값
바탕"background": 색 "#202020", 그림 "gui/splash/bg.png", 영상 "movies/bg.webm" (반복 재생). 그 아래 색은 "color"
가운데 로고"image" (그림이나 side_mask 영상), 따로 놓으려면 "image_pos": (640, 200), 크기 "image_zoom"
글자"title", "body"(\n으로 줄바꿈), 조작 방법 표 "keys": [ (키, 설명), … ] 또는 "auto"(조작방법 화면과 같은 목록)
넘어가는 때"duration": 초 / None(클릭할 때까지) / "movie"(영상이 끝날 때까지)
실수로 넘기지 않게"min_time"(다 나타난 뒤 이 시간은 클릭 무시), 못 넘기게 "skippable": False와 "duration"을 함께
나타나고 사라지는 시간"fade_in", "fade_out" (페이지 사이는 검은 화면)
처음 한 번만"once": True
플레이어가 끌 수 있게"dont_show_again": _("다음부터 보지 않기") (오른쪽 아래 체크 버튼)
조건부로"show_if": "not persistent.cleared"
소리"sound"(한 번), "music"(반복. 타이틀 음악과 같은 파일이면 이어짐)
글자 묶음 위치"xalign", "yalign", 최대 폭 "width", 간격 "spacing"
글자 모양"title_font", "title_size", "body_color", "body_text_align", "prompt_yalign" …
전체 설정뜻
splash.enabled끄면 바로 타이틀
splash.movie_wait영상이 이 시간(초) 안에 시작되지 않으면 다음 페이지로 (기본 5.0)
splash.developer_skipTrue면 개발 모드에서는 건너뜀 (배포판에서는 항상 나옴)
splash.start_delay, splash.gap첫 페이지 전, 페이지 사이 검은 화면(초)
splash.end_transition마지막 페이지 뒤 타이틀이 나타나는 전환 (기본 Dissolve(0.6))
splash.min_time_oncemin_time은 처음 볼 때만
splash.music_fadeout스플래시 음악이 타이틀 음악과 다를 때 서서히 끄는 시간
  • 타이틀 메뉴에서 다시 보기: 항목의 "action": splash.ShowPage("controls"). 본 기록·보지 않기를 지우는 버튼은 splash.Reset().
  • 스크립트에 이미 label splashscreen:이 있으면 그 안에 call splash_play를 넣습니다.
  • 스플래시는 게임을 처음 켤 때만 나오고 Shift+R로는 다시 나오지 않습니다. 껐다 켜거나 콘솔(Shift+O)에서 splash.preview().
  • 설정 오류(없는 파일, 파일 이름 대소문자, 틀린 이름)는 Lint에서 splash:로 시작하는 줄로 알려줍니다.

  4. 타이틀 메뉴 탭에서는 3번으로 "이 항목만" ↔ "모든 항목 공통"을 바꿉니다. 대사 탭에서는 Tab으로 "대사" ↔ "이름"을 바꾸고, 속도·효과 버튼을 누르면 그 줄을 다시 보여줍니다(R로도 다시 보기).
  5. 글꼴과 색은 패널의 버튼으로 고릅니다. 글꼴 목록은 game 폴더의 글꼴 파일을 모두 보여주고, 색은 막대·색 코드·자주 쓰는 색으로 고릅니다.

선택지와 대사는 Ctrl+S를 누르면 원고(.rpy)의 그 줄 괄호에 바로 저장되고, 게임이 다시 불러와져 같은 장면으로 돌아옵니다. 원래 적혀 있던 값과 줄 뒤의 with dissolve 등은 그대로 두고 바꾼 값만 고칩니다. 고치기 전 원본은 프로젝트 폴더의 ui_kit_backup/에 남습니다.

줄기표로 구간에 셰이더 넣기 (screen_fx 5.2)

스크립트를 직접 적지 않고, 게임을 켠 채 마우스로 넣는 방법입니다.

  1. 게임을 개발 모드로 켜고 Shift+M → "화면 효과" 탭 → G(또는 [G 줄기표 펴기]). 게임 화면 옆에 줄기표가 나옵니다. 왼쪽 숫자가 원고 줄 번호, 노란 네모가 label, 옆으로 갈라지는 노란 가지가 선택지와 if, -> 이름이 jump입니다. 오른쪽 색 띠는 그 줄에 덮인 셰이더(왼쪽 1번, 오른쪽 2번)입니다.
  2. 셰이더를 넣고 싶은 첫 줄의 마디를 누른 채 끝 줄까지 끕니다. 구간이 분홍색으로 칠해집니다.
  3. 패널에서 1번, 2번 셰이더를 고르고 [이 구간에 적용] → Ctrl+S. 원고가 이렇게 바뀝니다. 
        $ screen_fx.shaders("glitch", "vhs_crt")   # 구간 시작 줄 위
    e "세 번째 대사."
    ...
    $ screen_fx.shaders("ascii", "none")       # 구간 끝 다음 줄 위: 원래 두 자리로
    e "가지가 합쳐진 대사."
  4. 전환 바꾸기: 줄기표 오른쪽 끝 네모 점(셰이더가 바뀌는 곳)을 눌러 고르고, 패널 "고른 전환 점"에서 설정대로 / TV / 서서히 / 바로. 여러 점을 한 번에 바꿀 수 있습니다. 저장하면 transition="fade" 같은 값이 들어갑니다.
  5. 구간 끝이 선택지 가지 안이면 다른 가지로 간 사람은 끝 다음 줄을 지나지 않습니다. 패널에서 되돌리는 곳을 가지가 합쳐지는 곳(메뉴가 끝난 다음 줄)으로 고를 수 있습니다.
  6. 지우기: 구간을 끌어 고르거나 네모 점을 고른 뒤 Delete → Ctrl+S. 그 셰이더 줄이 원고에서 빠지고 점도 없어집니다. 앞에서 켠 셰이더가 있으면 그 구간은 그 셰이더로 이어져 보입니다(메시지로 알려 줌).
  7. 마디를 끌지 않고 누르기만 하면 그 줄로 게임이 옮겨 갑니다. 다시 G를 누르면 줄기표가 들어갑니다.
  8. pygaki 앱에서는 줄기표를 펴지 않습니다(앱 [GUI 편집]의 칸 이름은 "셰이더"). PyKaki 대본이면 [대본 편집]에서 상자나 label 오른쪽 위의 ◐ 셰이더로 겁니다.

    "on_sound": None,       # 예: "audio/tv_on.ogg"  (켜지기 시작할 때)
    "volume": 1.0,          # 두 소리의 음량 (0~1). 환경설정의 효과음 음량도 같이 따름

VHS 덮개 — screen_fx/vhs_crt_config.rpy (4.0)

덮개는 켬 / 끔만 고르고, 모양은 vhs_crt.settings 값으로 정합니다. 왜곡에 관계된 값:

define vhs_crt.settings = {
    "warp_amount": 1.0,              # 가장자리 휘어짐 (0 = 평평, 1 = 기본, 3 이상 = 크게 휨. 0~5)
    "distort_intensity": 0.05,       # 띠가 지나갈 때 화면이 옆으로 밀리는 정도 (0~0.2)
    "aberration": 0.03,              # 색 번짐 (빨강·초록 어긋남)
    "roll": True,                    # 위아래로 흐르는 띠
    "noise_opacity": 0.4,            # 띠를 따라 생기는 지직거림 (0~1)
    "vignette_opacity": 0.5,         # 가장자리 어둡기 (0~1)
    "strength": 1.0,                 # 덮개 전체 세기 (0이면 안 보임)
    # … 전체 값은 vhs_crt_config.rpy와 screen_fx/README.md 11-2
}

## 효과마다 덮개를 기본으로 켤지 (각 효과 설정 파일)
define ascii.overlay = True         # 켬 (배포 설정)
define gameboy.overlay = True       # 켬 (배포 설정). False면 평평한 LCD만

$ screen_fx.set_warp(3.0, duration=1.0)                  # 휘어짐만 1초 동안 3으로

글자 빼기는 효과를 씌우지 않을 글자를 고르는 것입니다. 기본은 글자까지 전부 씌웁니다(ASCII만 글자 전부 빼기가 기본). 뺀 글자는 원래 모습 그대로 또렷하게 남습니다.

이름빼는 것
"say"대사·이름 (대사창, NVL 화면)
"choice"선택지
"screens"메뉴·화면 (퀵메뉴, 저장·불러오기·환경설정 화면, show screen으로 띄운 화면)

ASCII — screen_fx/ascii_config.rpy (2.5)

화면을 글자 칸으로 나누고, 칸마다 밝기에 맞는 글자로 다시 그립니다. 글자 하나가 픽셀 하나 역할을 합니다(옛날 텍스트 화면·던전 크롤 콘솔). 글자 그림은 글자 목록과 글꼴로 게임 중에 직접 만들어서 이미지를 따로 준비할 필요가 없습니다. 기본 글꼴은 플러그인에 들어 있는 Neo둥근모(screen_fx/fonts/neodgm.ttf, SIL OFL 1.1)입니다.

게임보이 — screen_fx/gameboy_config.rpy (2.7)

옛날 휴대용 게임기의 LCD 화면처럼 바꿉니다. 화면을 큰 점으로 나누고, 밝기에 따라 4가지 색(또는 2가지 색)으로만 칠합니다. 색과 색 사이의 밝기를 그리는 방법은 두 가지 중에 고릅니다.

표현 방식색 사이의 밝기어울리는 그림
"dither" 디더링 (기본)점 무늬(바둑판·격자)로 섞어서 부드럽게 넘어감사진 같은 CG, 어두운 장면, 빛
"pixel" 픽셀화가장 가까운 색으로 딱 끊어서 계단처럼단순한 그림, 도트 그림, 넓은 면

글자는 기본으로 4색만 입히고 점으로 쪼개지 않아서 작은 대사도 그대로 읽힙니다("text_pixel": False). 참고: Retro dither(CC0)의 디더링 무늬, Gameboy Classic Shader(GPL)의 LCD 모습 (코드는 가져오지 않고 새로 씀).

define gameboy.exclude = ()     # 글자 빼기 (기본: 안 뺌 → 대사도 게임보이 색. 모양은 그대로라 읽힘)

define gameboy.settings = {
    "mode": "dither",           # 표현 방식: "dither" 디더링(점 무늬로 섞기) / "pixel" 픽셀화(딱 끊기)
    "pixel_size": 4.0,          # 점 하나의 크기(픽셀). 1280×720에서 4 = 가로 320점, 6 = 213점, 2 = 640점
    "dither": "4x4",            # 디더링 무늬: "4x4" 굵은 무늬 / "8x8" 고운 무늬
    "dither_strength": 1.0,     # 디더링 세기 (0.5 = 색이 바뀌는 근처에만 무늬, 0 = 픽셀화와 같음)
    "text_pixel": False,        # True면 글자도 점으로 쪼갬 (큰 글자나 픽셀 글꼴일 때만)
    "colors": 4,                # 색 수: 4 또는 2 (2면 1번과 4번 색만 씀)
    "color1": "#1c3f04",        # 1번: 가장 어두운 색
    "color2": "#456306",        # 2번: 어두운 색
    "color3": "#74870a",        # 3번: 밝은 색
    "color4": "#939f06",        # 4번: 가장 밝은 색 (꺼진 LCD 바탕)
    "gamma": 1.0,               # 감마 (0.6~0.8 = 어두운 곳이 밝아짐. 어두운 CG가 뭉개질 때)

다른 코드가 대사창을 못 찾음그 코드가 layer="screens"로 대사창을 찾고 있음. define screen_fx.split_text_layers = False
레트로 터미널 + VHS 덮개에서 화면이 두 번 휨retro_term.overlay = False(기본)로 두거나, 덮개를 켤 거면 이 효과의 "crt": False
게임보이 화면이 점 무늬로 가득함어두운 CG는 1번·2번 색 사이를 무늬로 섞음. "gamma"를 0.6~0.8로, "dither_strength"를 0.5로, 또는 "mode": "pixel"
게임보이에서 대사가 안 읽힘"text_pixel": True이면 글자도 점으로 쪼개짐. False로 하거나 exclude=("say",)
게임보이에서 메뉴 화면 속 그림이 점으로 안 바뀜메뉴·화면 층은 색만 바뀜("text_pixel": False). 효과에서 "screens"를 빼고 그 그림에 at screen_fx.scene
ASCII가 너무 어두움"color_boost"·"bg_tint"·"brightness" 올리기. VHS를 덮었다면 ascii.preset("glow")
ASCII 글자가 흐릿함 / 네모로 나옴"crisp": True에 "cell" 16의 배수 / 글자 목록의 글자가 글꼴에 없음
스크린에 넣은 그림에 효과가 안 걸림효과에서 "screens"(메뉴·화면)를 뺐음. 그림에 at screen_fx.scene
덮개가 사라짐 / 다시 켜짐use()는 부를 때마다 덮개를 설정대로 다시 정함. 이어 가려면 overlay=를 적기
VHS가 안 보임screen_fx.overlay가 True인지 (3.x 설정 파일의 None이 남아 있지 않은지), 지금 효과의 <이름>.overlay, fx_overlay=False를 쓰지 않았는지
화면 효과 탭에서 저장했는데 화면이 그대로그 탭은 효과의 설정값을 고침. 지금 장면에 쓰려면 "이 대사부터 이 효과" 버튼이나 대사 탭 → Ctrl+S
"'mono'라는 효과가 없습니다" 오류4.0에서 흑백을 지움. 원고의 use("mono"), fx="mono"를 바꾸거나 screen_fx/README.md 12-1의 견본으로 다시 넣기
효과를 처음 바꿀 때 한 번 멈칫함그 셰이더를 처음 쓸 때 그래픽 카드가 준비하는 시간. 같은 실행 중에는 다시 안 멈춤
TV 전환 없이 바로 바뀜건너뛰기 중, 되감기·불러오기 직후, 편집기를 열어 둔 동안은 원래 바로 바뀜. screen_fx.transition도 확인
전환 중에 대사가 먼저 나옴screen_fx.wait = False이거나 use(…, wait=False)
편집기에 "VHS 효과" 탭이 없음2.4부터 "화면 효과" 탭 안의 "VHS" 버튼

bundle/렌파이 SDK + 플러그인 + 앱을 윈도우용 묶음으로 만드는 스크립트, 런처 버튼, 이 안내서(guide/)

이 안내서도 저장소 문서에서 만들어집니다. "PyKaki로 대본 쓰기"는 pykaki/docs/GUIDE.md, "플러그인 커스텀 가이드"는 showpy/docs/CUSTOM_GUIDE.md를 그대로 읽고, 나머지 장은 bundle/guide/parts/의 글, "효과 견본"은 효과 파일과 견본 영상에서 만듭니다. 고친 뒤 python bundle/guide/build_guide.py를 돌리면 bundle/guide/pygaki_안내서.html이 다시 생기고, 묶음을 만들 때도 저절로 다시 만들어 넣습니다.

준비

  • 렌파이 SDK 8.5.3: 플러그인을 시험하고 Lint를 돌립니다. pygaki 묶음을 받았다면 그 폴더가 SDK입니다.
  • Node.js(PyKaki를 고칠 때): pykaki/와 pykaki/app/에서 npm ci를 한 번 합니다.
  • Python 3(묶음을 만들 때): bundle/make_bundle.py를 돌립니다.
  • 시험용 렌파이 프로젝트를 하나 만들어 둡니다(런처의 새 프로젝트 → Pygaki). 진짜 게임에서 바로 고치지 않습니다.

플러그인 고치기

  1. 저장소의 showpy/game/ 아래 파일을 고칩니다.
  2. 시험 프로젝트의 game/에 그 폴더를 복사하고 **.rpyc 파일을 지웁니다.** 남아 있으면 지운 코드가 계속 실행됩니다. 시험 프로젝트에서 저장한 *_layout.rpy(편집기에서 저장한 값)는 지우지 않아도 됩니다.
  3. 런처에서 Lint를 돌리고, 게임을 켜서 화면을 봅니다. 오류가 나면 프로젝트 폴더의 traceback.txt, errors.txt, log.txt를 읽습니다.
  4. 플러그인은 따로 넣어도 돌아야 합니다. ui_kit 없이 screen_fx만, screen_fx 없이 ui_kit만 넣고도 Lint를 돌려 봅니다.

지킬 것:

  • 사용자가 고치는 값은 *_config.rpy에 두고, 엔진(engine/, editor/)은 그 값을 읽기만 합니다.
  • init 숫자와 파일의 init offset을 더한 값이 -999~999 안에 들어야 합니다(init 999는 1000이 되어 Lint 경고).
  • 화면에 보이는 글자에 ·(가운뎃점), ≡를 쓰지 않습니다. 렌파이 기본 한글 글꼴에 없어서 네모로 나옵니다. 화면 글자의 [는 [[로 적습니다.
  • 셰이더의 색은 투명도를 곱한 값입니다. 색을 바꿀 때는 rgb / a로 풀고 vec4(col * a, a)로 내보냅니다.
  • 인터넷에서 받은 셰이더나 코드는 라이선스를 보고, 그대로 가져오지 말고 모양만 참고해서 새로 씁니다(GPL 코드는 가져오지 않습니다).
  • 판을 올릴 때는 엔진의 VERSION, 그 폴더 README.md, showpy/docs/ 문서, showpy/CHANGELOG.md를 같이 고칩니다.

효과 하나 더하기 (효과 폴더)

글자 등장 효과나 그림 전환은 코드를 고치지 않고 **ui_kit/effects/에 .glsl 파일 하나를 더하는 것**으로 넣습니다. 파일을 넣고 게임을 껐다 켜면 렌파이의 effect="이름", img_fx.use("이름")과 PyKaki의 목록에 저절로 생깁니다. 파일을 지우면 없어지고, 그 이름을 쓴 원고는 멈추지 않고 기본 모양으로 돕니다. 앱 [효과] 화면에서는 목록에서 숨기기만 합니다.

파일은 @로 시작하는 표시 줄과 들여 쓴 GLSL 코드로 되어 있습니다.

표시뜻
@effect 이름 한글이름글자 등장 효과의 시작
@transition 이름 한글이름그림 전환의 시작
@time 초그림 전환에 걸리는 시간의 기본값
@set u__이름 값값의 기본값. 원고에서 바꿈(img_fx.use("bands", count=10), effect="이름:u__이름=값")
@param u__이름 최소 최대 한글이름PyKaki 막대의 범위와 이름
@variablesuniform 줄
@fragment점마다 색을 정하는 코드

그림 전환의 @fragment에서는 l__t(진행 0→1), l__uv(점의 자리 0~1), l__size(가로 세로 픽셀), l__old(앞 그림 색), l__new(새 그림 색)를 쓰고, 다른 자리는 texture2D(tex0, 자리)(앞 그림), texture2D(tex1, 자리)(새 그림)로 읽습니다. 끝에 gl_FragColor에 색을 넣습니다. 셰이더 전환에 쓰는 그림 전환은 @set u__cut 값(0~1)으로 화면 셰이더가 바뀌는 때를 정합니다.

폴더에 들어 있는 효과(글자 maskup, tracking, sweep, backbox, karaoke, meltglitch, droplets, 그림 irisin, bands, pixelsort, datamosh, slide, mosaic, blinds, static, calibrate, tapestretch, blink, pushup)가 본보기입니다. 자세한 형식과 AI에게 새 효과를 부탁할 때 쓸 요청문은 ui_kit/effects/README.md에 있습니다. 글자 효과의 기본 효과는 ui_kit/engine/text_effects.glsl 한 파일에 있고, PyKaki도 빌드할 때 이 파일을 그대로 가져가서 렌파이와 같은 모양으로 그립니다.

화면 셰이더 하나 더하기

화면 셰이더도 효과처럼 셰이더 하나에 파일 둘로 따로 모여 있어서, 새 셰이더를 넣을 때 화면 효과 엔진 전체(screen_fx/engine/screen_fx.rpy)는 고치지 않습니다. 셰이더 코드와 값 목록이 든 screen_fx/engine/<이름>.rpy, 사용자가 고치는 값이 든 screen_fx/<이름>_config.rpy 두 파일만 더합니다. screen_fx/README.md 12장의 견본(흑백 mono) 두 파일을 새 이름으로 저장하고, 안의 mono를 새 이름으로 바꾼 뒤 값 목록(PARAMS), 막대(GROUPS), 셰이더 코드를 고칩니다. 빼려면 그 두 파일을 지우고(.rpyc까지), 지우지 않고 고르는 목록에서만 감추려면 screen_fx/shaders_off.txt에 이름을 적습니다. 효과 폴더의 .glsl 하나보다는 적을 것이 많습니다(값 목록과 막대를 파이썬으로 적음). screen_fx.register_shader로 등록하면 $ screen_fx.use("이름"), 대사 괄호 (fx="이름"), GUI 편집기 화면 효과 탭, PyKaki 셰이더 목록에 저절로 나옵니다. 세부 값의 막대(PARAMS, GROUPS)를 고쳤으면 시험 프로젝트에서 Lint를 한 번 돌려 screen_fx/shader_list.json을 다시 만들고, 저장소의 같은 자리에 복사한 뒤 PyKaki를 다시 빌드합니다.

PyKaki 고치기

cd pykaki && npm ci            # 처음 한 번
cd pykaki && npm run dev       # 개발 서버 http://localhost:5173 (예제 대본, 렌파이 프로젝트는 못 엶)
cd pykaki && npx tsc --noEmit  # 타입 검사
cd pykaki && npm run build     # pykaki/dist/index.html 한 파일
cd pykaki/app && npm ci && npm start -- --project "렌파이 프로젝트 폴더"   # 데스크톱 앱으로 켜기
cd pykaki/app && npm run dist  # 윈도우 앱 폴더 (pykaki/app/out/win-unpacked)
  • 화면을 고친 뒤에는 npx tsc --noEmit과 npm run build를 돌립니다. 앱은 빌드한 화면을 복사해서 씁니다.
  • 새 글자 효과를 넣으면 견본 영상(pykaki/public/effects/*.webm)을 pykaki/tools/record_effect_clips.py로 다시 찍고, 안내서도 다시 만듭니다.
  • 앱 쪽(pykaki/app/)을 고쳤으면 npm run web && node smoke.cjs로 진짜 Electron을 켜 보는 시험을 돌립니다. GitHub Actions "pygaki 앱"도 같은 시험을 돌리고 윈도우 앱 폴더를 만듭니다.
  • 도움말 글은 pykaki/docs/GUIDE.md를 고치면 다음 빌드에 들어갑니다.
  • 대본 파일(.flow.json)에 예전 판이 모르는 값을 더하면 pykaki/src/version.ts의 FEATURE를 1 올립니다(예전 앱이 "더 새 판" 경고를 띄움). 저장 형식 이름 "format": "renpy-flow", 파일 이름 .flow.json은 바꾸지 않습니다.
  • 앱은 사용자 허락 없이 밖으로 통신하지 않습니다. 게임과의 실시간 연결은 127.0.0.1만 씁니다.

두 프로그램의 형식 맞추기

PyKaki가 내보내는 원고(game/script_flow.rpy)의 줄 모양, 줄 끝의 찾는 표시(# @l:…), 게임이 PyKaki에 돌려주는 파일(showpy_inbox.json), 실시간 연결의 명령은 docs/LINK.md에 모두 적혀 있습니다. 이 형식을 바꾸면 docs/LINK.md와 양쪽 코드(pykaki/, showpy/)를 같은 커밋에서 고칩니다. 원고에 새 종류의 줄을 넣으면 게임 쪽(ui_kit/engine/script_edit.rpy)과 PyKaki 쪽(pykaki/src/inbox.ts)을 같이 맞춥니다.

묶음 만들기

렌파이 SDK + 플러그인 템플릿 + 런처 버튼 + 앱을 윈도우용 zip으로 묶습니다. 저장소에 태그를 올리면(git tag v1.0 && git push origin v1.0) GitHub Actions "배포 파일"이 묶어서 Releases에 초안으로 올립니다. 내 컴퓨터에서는 이렇게 만듭니다.

python bundle/make_bundle.py --sdk 렌파이SDK폴더 --app pykaki\app\out\win-unpacked --zip --tag v1.0

bundle/out/에 렌파이까지 든 묶음과, SDK가 이미 있는 사람용 덧붙임이 생깁니다. 템플릿에 넣는 플러그인과 템플릿에서만 다르게 두는 설정(처음에는 VHS 덮개 끔)은 make_bundle.py의 PLUGINS, TEMPLATE_SETTINGS에서 고칩니다. 묶음을 만들 때 만든 사람 컴퓨터의 경로가 들어 있으면 멈춥니다. 자세한 것은 bundle/README.md.

배포판과 묶음에는 개발용 파일(showpy_live.json, showpy_inbox.json, pykaki_preview.json, pykaki_goto.json, ui_kit_backup/, *.flow.json)이 들어가지 않게 합니다.

AI와 같이 고칠 때

저장소 맨 위 CLAUDE.md와 showpy/docs/DEV_RULES.md에 AI가 지킬 규칙이 있습니다. 새 기능은 먼저 할 수 있는지, 짧은 계획, 예상 시간을 듣고 시작하게 하고, 끝나면 무엇을 바꿨고 무엇을 확인했는지 정리하게 합니다. 시험은 시험 프로젝트에서 하게 합니다.

7주의와 라이선스

다른 코드와 함께 쓸 때

  • ui_kit은 렌파이 기본 스크린 main_menu, navigation, choice를, hotkeys는 keyboard_help를 대신 정의합니다. 다른 플러그인이나 직접 고친 코드가 같은 스크린을 또 정의하면 나중에 실행되는 쪽이 이깁니다.
  • splash는 렌파이의 splashscreen 레이블로 이어집니다. 스크립트에 이미 label splashscreen:이 있으면 그 안에 call splash_play를 넣으세요. 스플래시는 게임을 처음 켤 때만 나오고 Shift+R로는 다시 나오지 않습니다(splash.preview()로 확인).
  • screen_fx의 VHS 효과는 다른 CRT 셰이더와 같이 쓰면 효과가 두 번 겹칩니다.
  • screen_fx는 대사창을 sfx_say, 선택지를 sfx_choice 층에 띄웁니다(config.say_layer, config.choice_layer). 다른 코드가 대사창 층을 "screens"로 정해 두고 찾는다면 screen_fx/screen_fx_config.rpy의 screen_fx.split_text_layers를 False로.
  • screen_fx는 대사 괄호의 fx=(fx_transition, fx_overlay, fx_exclude)를 받기 위해 config.say_arguments_callback을 씁니다. 다른 코드가 이미 걸어 둔 함수는 이어서 불러 줍니다. screen_fx 폴더를 지우면 fx=를 적은 대사에서 오류가 나니 그 괄호도 지우세요.
  • ui_kit 편집기는 화면 효과가 닿지 않는 맨 위 층에 그려집니다. 효과 탭이 아닌 다른 탭을 쓰는 동안에는 screen_fx 효과가 잠시 꺼집니다.
  • 투명한 webm 영상은 렌파이의 side_mask 방식(왼쪽 절반 색, 오른쪽 절반 투명도)을 씁니다. 만드는 방법은 ui_kit/README.md에 있습니다.
